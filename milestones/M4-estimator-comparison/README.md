## 交付清单

同一个问题，用以下方法各算一遍并解释差异：

- [ ] IPTW-MSM
- [ ] 参数化 g-formula
- [ ] TMLE（或 lmtp 的 SDR）
- [ ] （可选）DML
- [ ] 结果差异的来源分析：模型设定差异 / 正性违背 / 样本量不足？
- [ ] 计算成本对比（对实际项目排期有意义）

## 不合格信号

> 只跑了一种方法就下结论。四种方法结果接近才有底气说稳健；差异大时，差异本身就告诉你哪个假设出了问题。

## 自评三问

| 问题 | 打分 |
|---|---|
| 我能不看代码，向同事口头讲清楚这个分析在做什么吗？ | ⬜ 能 ⬜ 勉强 ⬜ 不能 |
| 如果审稿人问「为什么不用另一种方法」，我能答上来吗？ | ⬜ 能 ⬜ 勉强 ⬜ 不能 |
| 换一个数据集，我能独立重做一遍吗？ | ⬜ 能 ⬜ 勉强 ⬜ 不能 |

**出现两个「不能」，回去重做这个阶段，不要往下走。**
