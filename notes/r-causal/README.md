# Causal Inference in R：原书中译

本目录按章节整理 [Causal Inference in R](https://www.r-causal.org/) 的中文翻译。
原书作者为 Malcolm Barrett、Lucy D’Agostino McGowan 和 Travis Gerke。

翻译保留原书的 R 代码、公式、引用键、交叉引用和图表结构。可执行代码在 Quarto 渲染时生成统计图和结果表；原书提供的静态插图作为资源文件引用。
