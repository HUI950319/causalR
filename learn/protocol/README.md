## 两条铁律

1. **time zero 的定义必须能经得起追问**：它有没有用到之后才知道的信息？
   入组标准的评估时点和它是不是同一刻？分组依据在那一刻能不能确定？
2. **每一处「协议 ↔ 数据」的妥协都要明写**。藏起来的妥协审稿人照样找得到，
   而且找到时你会失去解释权。
