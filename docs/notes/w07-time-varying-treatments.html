第 19 章 · 先说清策略，才有效应

Time-varying treatments · 时变处理

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 19 章，书页 249–260。本章是读书笔记，非原书译文。

第三部分的第一章，书自己先打了预防针：

尽管我们已尽力简化这些概念（如果你不信，去翻翻因果推断文献）， 这仍然是全书最技术化的章节之一。很遗憾，再简化下去会损失太多严谨性。 但既然你读到了这里，你就有资格读懂这一章。

— What If, §19 章首, p.249

而这一章真正要做的事，只有一件：把「平均因果效应」这个前十八章一直在用的词拆掉。

时固定处理下，\(E[Y^{a=1}] - E[Y^{a=0}]\) 是唯一的那个效应， 不必说明「什么时候处理」——因为处理只发生在时间零点。 时变处理下这句话不再成立：处理在 \(k = 0,1,\dots,K\) 每个时点都可能取不同的值， 「平均因果效应」于是不再唯一，它取决于你拿哪两条规则来比。

全章地图（笔记作者绘制，原书无此图）。本章从头到尾没有一个数据分析， 它做的是把第 1–3 章那三条识别条件逐条升级成「每个 \(k\) 都要成立」的版本， 并给出一件前十八章不曾有过的事：可识别性不再是「行 / 不行」，而是「对哪些策略行」—— 地图底部那三个并排的格子就是本章的核心裁决。

19.1 时变处理的因果效应：一个 k 的对比救不了场

先把记号立起来。\(A_k\) 是随访第 \(k\) 个月的二值处理，\(k = 0, 1, 2 \dots K\)，本章取 \(K = 59\) （5 年随访，逐月测量），结局 \(Y\) 在 \(K + 1 = 60\) 个月时测量、数值越大健康越好。 HIV 研究里 \(A_k = 1\) 表示第 \(k\) 月接受抗逆转录病毒治疗。 研究开始前无人接受治疗，即所有人 \(A_{-1} = 0\)。

上划线表示历史：\(\bar A_k = (A_0, A_1, \dots A_k)\) 是从 0 到 \(k\) 的处理史； 指整条历史 \(\bar A_K\) 时常简写成 \(\bar A\)。

  • 全程治疗：\(\bar A = (1,1,\dots 1) = \bar 1\)；
  • 全程不治：\(\bar A = (0,0,\dots 0) = \bar 0\)；
  • 大多数人是中间那种：有些月治有些月不治，没有 \(\bar 1\)、\(\bar 0\) 那样紧凑的写法。

为什么不能把「时变处理的效应」定义在单个 \(k\) 上

但我们不能再把一个时变处理的平均因果效应定义成单个时刻 \(k\) 上的对比， 因为对比 \(E\left[Y^{a_k=1}\right] - E\left[Y^{a_k=0}\right]\) 量化的是单个时刻 \(k\) 上处理 \(A_k\) 的效应， 而不是时变处理 \(A_k\) 在 0 到 59 之间所有 \(k\) 上的效应。

— What If, §19.1, p.250

于是：

我们只能把平均因果效应定义成两条处理策略之下反事实均值结局的对比， 这两条策略都要涉及从随访开始（\(k=0\)）到结束（\(k=K\)）所有时刻的处理。 其结果是，时变处理的平均因果效应不是唯一定义的。

— What If, §19.1, p.250

「不是唯一定义的」这几个字是整个第三部分的入口。 前十八章里「这个处理的因果效应」是一个确定的东西， 到这里它变成了一个需要你先写下两条规则才能指称的量。

书在边注里补了两句，都会在后面兑现：

为简单起见，我们暂时假设这段时间里没有人失访或死亡， 并且所有变量都被完美测量。

— What If, §19.1 边注, p.249

为了保持简单，我们的例子考虑的是在固定时刻测量的结局。 不过本章讨论的概念同样适用于时变结局与失效时间结局（见 Technical Point 21.8）。

— What If, §19.1 边注, p.250

还有一条纯记号的约定，值得抄下来，因为它和后面所有公式的下标都有关：

为了与许多已发表论文兼容，我们对时间使用从零开始的索引。 也就是说，第一个可能施加处理的时刻是 \(k = 0\) 而不是 \(k = 1\)。

— What If, §19.1 边注, p.249

19.2 处理策略：效应有多少个，取决于你比哪两条规则

处理策略（treatment strategy）——也被称为计划（plan）、政策（policy）、 方案（protocol）或方案制度（regime）——是在随访的每个时刻 \(k\) 分配处理的一条规则。

— What If, §19.2, p.250

这五个同义词值得一次记全：后面读文献时，strategy / plan / policy / protocol / regime 指的是同一件事，而 protocol 这个词到第 22 章会变成目标试验的七要素之一。

最简单的两条策略是「一直治」\(\bar a = \bar 1\) 与「一直不治」\(\bar a = \bar 0\)，对应的效应是 \(E\left[Y^{\bar a = \bar 1}\right] - E\left[Y^{\bar a = \bar 0}\right]\)。 但这只是无穷多条里的一条对比：

可能的对比数量非常大：我们至少可以定义 \(2^K\) 条处理策略， 因为二值的 \(a_k\) 有 \(2^K\) 种取值组合 \((a_0, a_1, \dots a_K)\)。 事实上，正如我们接下来要解释的，这 \(2^K\) 条策略还没有穷尽所有可能的处理策略。

— What If, §19.2, p.250

没穷尽，是因为还有动态的那一类。引入时变协变量 \(L_k\) = 第 \(k\) 月的 CD4 细胞计数：

\(L_k\) 的编码方向要记牢，本章后面有一处会绊你

变量 \(L_k\) 在 CD4 细胞计数低时取值 1——这表示预后不好——否则取 0。 在时间零点，所有个体的 CD4 计数都高，即 \(L_0 = 0\)。

— What If, §19.2, p.250

\(L_k = 1\) 是坏消息。 记住这一条：§19.3 里书给出的那组随机化概率 把「高 / 低」贴反了，见本页后面的核对。

于是就有了这样一条规则：「\(L_k = 0\) 时不治；\(L_k = 1\) 时开始治，并从此一直治下去」。

这条处理策略与上一段考虑的那些不同，因为我们没法用一条 \(\bar a = (a_0, a_1, \dots a_K)\) 的规则来表示它——那种规则下， 所有个体在 \(k=0\) 拿到同一个 \(a_0\)、在 \(k=1\) 拿到同一个 \(a_1\)，如此等等。 而现在，每个时刻都有一部分人被治、另一部分人不被治，取决于他们各自 \(L_k\) 的演变。

— What If, §19.2, p.250（复述）

静态策略 \(\bar a\)

处理不依赖协变量。可以写成一串固定的数： \(\bar 1\)、\(\bar 0\)、\((1,0,1,0\dots)\)「隔月治」、 \((0,1,1,1\dots)\)「除了第一个月都治」。

二值处理下至少 \(2^K\) 条。

书也称之为非动态（non-dynamic）策略。

动态策略 \(g\)

第 \(k\) 时刻的处理 \(a_k\) 依赖个体 \(\bar L_k\) 的演变。

「CD4 一低就开始治，之后一直治」是最典型的一条。

书约定用 \(g\) 表示任意策略（静态或动态）； 当 \(g\) 表示静态策略时，有时写 \(Y^{g = \bar a}\) 而不是 \(Y^g\) 或 \(Y^{\bar a}\)。

于是这一节的结论只有一句，但它会贯穿整个第三部分：

也就是说，对时变处理而言，因果效应没有单一的定义。 即使每个时刻 \(k\) 只有「治 / 不治」两个选项， 我们仍然能定义出与「策略对」一样多的因果效应。

— What If, §19.2, p.251

Fine Point 19.1：确定性 / 随机 × 静态 / 动态，以及「最优策略」

这条边栏把策略空间完整地切了一遍。

确定性动态策略是一条规则 \(g = \left[g_0(\bar a_{-1}, l_0),\ \dots\ g_K(\bar a_{K-1}, \bar l_K)\right]\)， 其中 \(g_k(\bar a_{k-1}, \bar l_k)\) 指定「过去史为 \((\bar a_{k-1}, \bar l_k)\) 的人在 \(k\) 时刻接受什么处理」。 HIV 例子里：若个体的 CD4 在 \(k\) 或之前曾经低过，则 \(g_k = 1\)，否则 \(g_k = 0\)。 确定性静态策略则是 \(g_k(\bar a_{k-1})\) 不依赖 \(\bar l_k\) 的那种。

随机策略不指定一个处理值，而指定一个接受某处理的概率。它同样有静态与动态两种：

  • 随机静态：「每个月独立地，以 0.3 的概率治、0.7 的概率不治」；
  • 随机动态：「每个月独立地，对 CD4 低的人以 0.3 的概率治，对 CD4 高的人不治」。

最优策略（optimal treatment strategy）定义为使 \(E[Y^g]\) 最大的那条 \(g\)（结局越大越好时）。 书给了两句非常实用的断言：

对药物治疗而言，最优策略几乎总是动态的，因为出现毒性时需要停药。 另外，任何随机策略都不可能优于最优的确定性策略。 然而随机策略（即随机试验）在科学上仍然是必需的， 因为在试验之前，我们并不知道哪条确定性策略是最优的。

— What If, Fine Point 19.1, p.251

这三句话连起来读，正好解释了「为什么还要做随机试验」这个临床上最常被问的问题： 随机化本身从来不是目的，它是在不知道最优规则是什么时的唯一发现手段。 策略分类的完整版见 Young et al. (2014)。

书末尾还有一条约定：正文中除非特别说明，字母 \(g\) 只指确定性处理策略。

Technical Point 19.1：动态策略可以只看协变量史，不看处理史

这一条初读像技术细节，其实是后面所有 g-方法能写下来的前提。

设 \(g\) 是一条依赖过去处理史与协变量史的动态策略， 则存在一条只依赖过去协变量史的策略 \(g' = \left[g'_0(\bar l_0),\ \dots\ g'_K(\bar l_K)\right]\) 与之对应， 由 \(g\) 递归地定义：\(g'_0(l_0) = g_0(\bar a_{-1} = 0, l_0)\) （按约定 \(\bar a_{-1}\) 只能取 0），以及 \(g'_k(\bar l_k) = g_k\!\left(\bar g'_k(\bar l_{k-1}),\ \bar l_k\right)\)。

由一致性（见 Technical Point 19.2），一个个体从零时刻起遵循策略 \(g\)， 与从零时刻起遵循策略 \(g'\)，将有相同的处理史、协变量史与结局史。 特别地，\(Y^g = Y^{g'}\) 且 \(\bar L^g(K) = \bar L^{g'}(K)\)。

— What If, Technical Point 19.1, p.252

为什么这件事重要：它说明「策略依赖过去处理史」并没有真正扩大策略空间—— 因为处理史本身已经被协变量史决定了（在你遵循该策略的前提下）。 于是后面写 g-公式、写 IP 权重时，只需要对 \(\bar l\) 求和 / 积分， 不必再额外枚举处理史。

书还补了一句等价性：个体在观测数据里到 \(t\) 为止遵循了 \(g\) （即 \(A_k = g_k(\bar A_{k-1}, \bar L_k)\) 对 \(k \le t\) 成立） 当且仅当他到 \(t\) 为止遵循了 \(g'\)。

19.3 序贯随机试验：三张图，一条分界线

这一节用三张因果图把「时变处理下会遇到的三种世界」一次摆齐。 三张图里 \(A_k\) 是时变处理、\(L_k\) 是已测变量集合、\(Y\) 是结局、 \(U_k\) 是 \(k\) 时刻未测变量的集合，它们是图上至少两个其它变量的共同原因。

在我们的 HIV 研究里，时变的 CD4 计数 \(L_k\) 是真实但未测的、对免疫系统的慢性损伤 \(U_k\) 的结果。个体的免疫损伤 \(U_k\) 越大，她的 CD4 计数 \(L_k\) 越低、健康状况 \(Y\) 越差。

— What If, §19.3, p.252（复述）

为简单起见，三张图只画 \(k = 0\) 与 \(k = 1\) 两个时点，并假定所有人都完全依从分配的处理。

Figure 19.1–19.3（照原图重绘，节点位置与弧线走向与原书一致，只换了字体与配色）。 三张图的骨架完全相同，差别只在两组箭头： \(L_0 \to A_0\)、\(L_1 \to A_1\)（图 19.2 起有）， 以及 \(U_0 \to A_0\)、\(U_1 \to A_1\)（只有图 19.3 有）。 这两组箭头的有无，就是本章全部裁决的分界线。

三张图分别对应什么：

图 从 \(\bar L_k\) 到 \(A_k\) 从 \(\bar U_k\) 到 \(A_k\) 能表示什么
19.1 无 无 分配概率只依赖过去处理史的序贯随机试验
19.2 有 无 分配概率依赖处理史 + 已测协变量史的序贯随机试验；或无未测混杂的观察性研究
19.3 有 有 不可能是随机试验——研究者用不到未测变量去分配处理

书给的两组具体数字值得抄下来，因为它们把「序贯随机」这个抽象词变成了可执行的分配规则：

  • 图 19.1 的版本：上个月没治的人（\(A_{k-1} = 0\)）以概率 0.5 分配到治疗， 上个月治了的人（\(A_{k-1} = 1\)）以概率 1 分配到治疗。
  • 图 19.2 的版本：未治且 CD4 为一类的人概率 0.4、未治且 CD4 为另一类的人概率 0.8、 此前已治的人一律 0.5，不论 CD4。

原书此处把「高 / 低 CD4」与 \(L_k\) 的取值贴反了

书页 253 原文是：

…randomly assigned with probability 0.4 for untreated individuals with high CD4 cell count (\(A_{k-1} = 0\), \(L_k = 1\)), 0.8 for untreated individuals with low CD4 cell count (\(A_{k-1} = 0\), \(L_k = 0\))…

— What If, §19.3, p.253（逐字）

但 §19.2（书页 250）刚刚定义过 \(L_k = 1\) 表示 CD4 低、预后差，\(L_0 = 0\) 是「CD4 高」。 而同一页稍后又写道：

…an observational study in which the lower the CD4 cell count \(L_k\), the more likely a patient is to be treated.

— What If, §19.3, p.253（逐字）

三句话连起来只能有一种自洽的读法：CD4 低（\(L_k = 1\)）→ 分配概率 0.8；CD4 高（\(L_k = 0\)）→ 0.4。 书上那一句里的「high」与「low」相对 §19.2 的编码是反的。 两处都已 150 dpi 整页渲染确认，不是 pdftotext 的提取错误。

这不影响任何结论——0.4 与 0.8 谁配谁，改变的只是例子的临床方向； 但初读时它足以让人怀疑自己记错了 \(L_k\) 的编码，所以记在这里。

「序贯随机试验」的定义就此立住：

在每个时刻 \(k\) 都把处理随机分配给每个个体的试验，被称为序贯随机试验。

— What If, §19.3, p.253

因此：

  • 图 19.1 与 19.2 都可以表示序贯随机试验；
  • 图 19.3 不能——\(A_k\) 部分地由未测变量 \(U\) 决定，而研究者显然无法用未测变量来分配处理；
  • 一般地说，序贯随机试验可以表示成一张有很多时点、 且没有任何从未测预后因子 \(U\) 指向任何时刻 \(A_k\) 的直接箭头的因果图。

而观察性研究落在哪里：

在观察性研究中，处理决策常常依赖于预后因子这类结局预测变量。 因此观察性研究通常由图 19.2 或图 19.3 表示，而不是图 19.1。

19.4 序贯可交换性：把「一次调整」变成「每个 k 都调整」

时固定处理要的是条件可交换性 \(Y^a \perp\!\!\!\perp A \mid L\)。 时变处理要的是它的逐时刻版本：序贯（条件）可交换性。

两个时点的情形写出来就是两条独立性的合取：

\[Y^g \perp\!\!\!\perp A_0 \mid L_0 \quad\text{且}\quad Y^g \perp\!\!\!\perp A_1 \mid A_0 = g(L_0),\ L_0,\ L_1\]

一般形式是本章最该背下来的一行：

\[Y^g \perp\!\!\!\perp A_k \mid \bar A_{k-1} = g(\bar A_{k-2}, \bar L_{k-1}),\ \bar L_k \qquad \text{对所有策略 } g \text{ 与 } k = 0, 1 \dots K\]

（书顺带交代了一条用词习惯：为简洁起见，全书省掉「条件」二字，直接说「序贯可交换性」。）

条件事件里那个 \(\bar A_{k-1} = g(\cdot)\) 不是装饰

注意条件里不是「\(\bar A_{k-1}\) 取任意值」，而是 \(\bar A_{k-1}\) 取的值与策略 \(g\) 相容（即这个人到 \(k-1\) 为止一直在按 \(g\) 行事）。 书在边注里解释了为什么可以这么写：

对于处理史 \([A_0 = g(L_0),\ A_1 = g(A_0, L_0, L_1)]\) 等于（即相容于） 他在策略 \(g\) 下本该接受的处理的人来说， 反事实结局 \(Y^g\)（由一致性）等于观测结局 \(Y\)， 因而也等于静态策略 \((a_0, a_1)\) 下的反事实结局，其中 \(a_0 = A_0\)、\(a_1 = A_1\)。

— What If, §19.4 边注, p.254

换句话说：可交换性只需要在「一路上都还在遵循 \(g\) 的人」里成立， 因为一旦某人偏离了 \(g\)，他之后的观测就不再是 \(g\) 下的世界。 第 21 章的 IP 加权和第 22 章的 per-protocol 分析都建立在这一句上。

Technical Point 19.2：正性与一致性的序贯版

正性从固定版「若 \(f_L(l) \ne 0\)，则对所有 \(a\)、\(l\) 有 \(f_{A\mid L}(a\mid l) > 0\)」升级为

\[\text{若 } f_{\bar A_{k-1}, \bar L_k}(\bar a_{k-1}, \bar l_k) \ne 0,\ \text{则 } f_{A_k \mid \bar A_{k-1}, \bar L_k}(a_k \mid \bar a_{k-1}, l_k) > 0\]

在序贯随机试验中，只要每个时刻 \(k\) 的随机化概率既不是 0 也不是 1（无论过去的处理与协变量史如何）， 正性就成立。若我们只关心某一条特定策略 \(g\)， 上面的正性条件只需对与 \(g\) 相容的处理史成立。

— What If, Technical Point 19.2, p.255（复述）

一致性从「若 \(A = a\)，则该个体 \(Y^a = Y\)」升级为一组四条：

\[Y^{\bar a} = Y^{\bar a^*} \text{ 若 } \bar a^* = \bar a; \quad Y^{\bar a} = Y \text{ 若 } \bar A = \bar a; \quad \bar L^{\bar a}_k = \bar L^{\bar a^*}_k \text{ 若 } \bar a^*_{k-1} = \bar a_{k-1}; \quad \bar L^{\bar a}_k = \bar L_k \text{ 若 } \bar A_{k-1} = \bar a_{k-1}\]

注意第三、第四条：一致性现在也管协变量了—— \(\bar L^{\bar a}_k\) 是策略 \(\bar a\) 下协变量史的反事实版本。 这是时固定世界里不需要说的话，因为那里协变量全在处理之前。

书承认技术上只需要更弱的条件（静态策略只要 \(\bar A = \bar a \Rightarrow Y^{\bar a} = Y\)； 动态策略只要「逐时刻遵循 \(g\) 的人有 \(Y^g = Y\)」）， 但更强的序贯一致性是一个自然的条件，我们将始终接受它。

最后一句把第 3 章那条「良好定义的干预」也带了过来：

如果我们认为「在第 \(k\) 月治疗」与「在第 \(k\) 月不治疗」在所有 \(k\) 上都足够良好定义， 那么涉及 \(A_k\) 的所有静态与动态策略也都同样良好定义。

— What If, Technical Point 19.2, p.255

Technical Point 19.3：序贯可交换性有好几种，它们不一样强

从序贯随机试验对应的 SWIG 上可以直接读出

\[\left(Y^{\bar a},\ \bar L^{\bar a}_{k+1}\right) \perp\!\!\!\perp A_k^{\bar a_{k-1}} \mid \bar A^{\bar a_{k-2}}_{k-1},\ \bar L^{\bar a_{k-1}}_k\]

取 \(\bar A^{\bar a_{k-2}}_{k-1} = \bar a_{k-1}\) 这一特例并用一致性，它等于

\[\left(Y^{\bar a},\ \bar L^{\bar a}_{k+1}\right) \perp\!\!\!\perp A_k \mid \bar A_{k-1} = \bar a_{k-1},\ \bar L_k\]

当这一条对所有 \(\bar a\) 成立时，我们说序贯可交换性成立。 而书随后指出了一件很不直观的事：

有趣的是，尽管这个序贯可交换性条件只涉及静态策略 \(g = \bar a\)， 它却等价于看起来更强的 \(\left(Y^{g}, \bar L^{g}_{k+1}\right) \perp\!\!\!\perp A_k \mid \bar A_{k-1} = g(\bar A_{k-1}), \bar L_k\)（对所有 \(g\)）， 因而在正性成立时足以识别任何静态与动态策略下的结局与协变量分布（Robins 1986）。

— What If, Technical Point 19.3, p.256

关键在于那个「联合」：

这个识别结果来自 \(\left(Y^{\bar a}, \bar L^{\bar a}_{k+1}\right)\) 与 \(A_k\) 之间的联合条件独立。 注意，对动态策略而言，序贯可交换性并不能从两条分开的独立性 \(Y^{\bar a} \perp\!\!\!\perp A_k \mid \cdot\) 与 \(\bar L^{\bar a}_{k+1} \perp\!\!\!\perp A_k \mid \cdot\) 推出。

— What If, Technical Point 19.3, p.256

这一条是「为什么动态策略比静态策略更娇贵」的代数版本： 动态策略要用 \(L\) 来决定治不治，于是 \(L\) 的反事实分布本身必须可识别， 而这要求 \(Y\) 与 \(L\) 一起与 \(A_k\) 独立，不能各自独立。 §19.5 里图 19.6 的失败，正是这条在图上的样子。

书还给出了两个更强、但识别时并不需要的版本： 序贯随机试验蕴含 \(\left(Y^{\bar a}, \bar L^{\bar a}_{k+1};\ \text{所有 } \bar a\right) \perp\!\!\!\perp A_k \mid \bar A_{k-1}, \bar L_k\)， 以及最强的 \(\left(Y^{\bar{\mathcal A}}, \bar L^{\bar{\mathcal A}}\right) \perp\!\!\!\perp A_k \mid \bar A_{k-1}, \bar L_k\)—— 后者被称为完全序贯可交换性（full sequential exchangeability）， 其中 \(\bar{\mathcal A}\) 表示全部 \(2^K\) 条静态策略 \(\bar a\) 的集合。 这两条都读不出 SWIG，这也是 SWIG 的边界所在。

Fine Point 19.2：为什么 SWIG 要画「从干预节点 \(a\) 出发」的箭头

\(a\) 在单一干预世界里是个常数，常数不可能影响别的变量——那为什么还要画箭头？

书给了两条理由。第一条是记账：它是一个方便的装置， 用来标记原 DAG 里哪些变量直接受 \(A\) 影响。第二条是它真的会改变结论：

考虑两张因果图：(1) 图 7.14 的因果 DAG，(2) 与图 7.14 相同、但额外多一条 \(A \to Y\) 直接箭头的 DAG。 如果我们不画从 \(a\) 出发的箭头，这两张 DAG 对应的 SWIG 会完全相同。 其结果是，我们将无法用 SWIG 推出：\(A\) 对 \(Y\) 的因果效应在 DAG (1) 中可识别（用前门公式） 而在 DAG (2) 中不可识别。

— What If, Fine Point 19.2, p.258

于是那条操作规则必须记牢：在 SWIG 上做 d-分离时， 所有包含任意干预节点 \(a\) 的路径都是被阻断的，哪怕记号上没有显式地条件化于 \(a\)。

同样的逻辑适用于确定性策略下的任何干预节点： 若图 19.9 里加入基线混杂因子 \(L_0\)、并把 \(g_0\) 换成 \(g_0(L_0)\)， 那么检查 \(Y^g \perp\!\!\!\perp A_1^g \mid A_0, L_0, L_1^g\) 时不需要再显式条件化于 \(g_0(L_0)\)—— 因为给定 \(L_0\) 之后 \(g_0(L_0)\) 就是常数；但要记得，条件化于 \(L_0\) 时， 经过 \(g_0(L_0)\) 的路径已经被阻断了。

而随机策略不一样。 若 \(g\) 给每个个体分配一个随机处理值 \(A_0^{+,g}\) （其分布可能依赖 \(L_0\)），就必须把 \(A_0^{+,g}\) 显式画进 SWIG 并写进条件事件， 因为它不再被 \(L_0\) 完全决定。Richardson & Robins (2013) 证明了 这类随机策略能被 g-公式识别的一个必要条件是 \(Y^g \perp\!\!\!\perp A_1^g \mid A_0, A_0^{+,g}, L_0, L_1^g\)。

最后一句是通往当代文献的暗门：他们还考虑了依赖处理自然取值的策略 （Robins et al. 2004），这类策略在 \(t\) 时刻基于 \(A_t^g\) 来分配 \(A_t^{+,g}\)， 可由扩展 g-公式识别；这类策略近年来被称为「修正处理政策」 （modified treatment policies，Diaz et al. 2021）。

lmtp 这个 R 包的全名就是 longitudinal modified treatment policies—— 路线图 W19 那一周要用的工具，它的理论出处就在这条边栏的最后一行。

19.6 时变混杂与时变混杂因子：「混杂因子」这个词在这里要重新定义

先说一句最硬的：

在观察性研究中，没有任何形式的序贯可交换性是保证成立的。

— What If, §19.6, p.259

能做的只是尽量测全：

达到近似的可交换性需要专业知识，它指导研究者在设计阶段 尽可能多地测量相关变量 \(\bar L_k\)。例如在 HIV 研究里，专家会同意 CD4 细胞计数、病毒载量与症状这类时变变量需要被恰当地测量并调整。

— What If, §19.6, p.259（复述）

而「测全了吗」这个问题永远无法确定地回答—— 我们能做的只是把自己的信念组织成一张因果图（图 19.1–19.4 就是四种不同的信念）。 书还提醒了一句：这几张图都是在没有选择（如失访删失）的前提下画的， 以便本章专注于混杂。

我们于是说 \(L_1\) 是 \(A_1\) 效应的一个混杂因子， 尽管 \(A_1\) 与 \(Y\) 的真正共同原因是那个未测的 \(U\)。

注意图 19.5 里根本没有 \(L_1 \to Y\) 这条箭头——\(L_1\) 不是结局的直接原因。 这正是第 7 章 §7.4「混杂因子不必是结局的原因」在时变世界里的重演。

书还在边注里提醒了第二条后门路径：

条件化于碰撞节点 \(L_1\) 之后会打开第二条后门路径： \(A_1 \leftarrow A_0 \to L_1 \leftarrow U \to Y\)。 这条路径可以安全地通过条件化于既往处理 \(A_0\) 来阻断，前提是研究者拿得到它。

— What If, §19.6 边注, p.259

这一句是整个第三部分「为什么必须把处理史一起放进条件」的最短理由： 调整 \(L_1\) 会打开一条经由 \(L_1\) 的碰撞路径，而堵住它的东西正是 \(A_0\)。

时变混杂因子的定义

把上面的论证推广到所有时点：

现在设想那张包含所有时点 \(k = 0, 1, 2 \dots\) 的很长的因果图， 其中 \(L_k\) 影响之后的处理 \(A_k, A_{k+1} \dots\)，并与结局 \(Y\) 共享未测原因 \(U_k\)。 ……那么在每个时刻 \(k\)，都需要用协变量史 \(\bar L_k\) 连同处理史 \(\bar A_{k-1}\) 来阻断 \(A_k\) 与 \(Y\) 之间的后门路径。 我们于是说 \(\bar L_k\) 里的时变协变量是 \(\bar A\) 对 \(Y\) 效应的时变混杂因子。

— What If, §19.6, p.259（复述）

边注补了一个同义词：时变混杂因子有时被称为时依混杂因子（time-dependent confounders）。

自检① 「这个时变处理的因果效应」这句话错在哪？

错在它没有指定两条策略。时变处理下， \(E[Y^{\bar a}] - E[Y^{\bar a'}]\) 里的 \(\bar a\) 与 \(\bar a'\) 是你自己选的， \(2^K\) 条静态策略加上无穷多条动态策略，每一对都定义一个不同的「平均因果效应」。

落到读论文上，这条自检有一个非常具体的用法： 看到「他汀使用对死亡的效应」这样的标题，先去正文里找那两条策略。 找不到，就说明作者没有意识到自己在估一个未定义的量—— 而这正是第 22 章要用「目标试验方案」来治的病。

顺带记住五个同义词：strategy / plan / policy / protocol / regime 是同一件事。

自检② 静态策略和动态策略，差别只是「看不看协变量」吗？

不止。本章给了三处实质差别：

  1. 最优性：对药物而言最优策略几乎总是动态的，因为出现毒性时需要停药 （Fine Point 19.1）。静态策略只是分析上方便，临床上很少是你真想推荐的那条。
  2. 可识别性：动态策略要求更强的条件。图 19.6 里多一个未测的 \(W_0\)， 静态策略仍然可识别、动态策略全部失守——因为动态策略要拿 \(L_1\) 当输入， 而 \(L_1\) 的反事实分布本身不可识别（§19.5）。
  3. 代数上：识别动态策略需要 \(\left(Y^{\bar a}, \bar L^{\bar a}_{k+1}\right)\) 与 \(A_k\) 的联合独立， 两条分开的独立性推不出它（Technical Point 19.3）。

所以「动态策略更贴近临床」与「动态策略更难识别」是同一件事的两面： 它更有用，正是因为它用到了更多的信息，而那些信息本身也要求可识别。

自检③ 拿到一个纵向数据集，本章要我先问哪三句？

  1. 「我要比的是哪两条策略？」 写不出 \(\bar a\) 与 \(\bar a'\)（或 \(g\)），就还没有因果问题。
  2. 「每个 \(k\) 上，处理决策依赖的是什么？」 只依赖 \(\bar A_{k-1}\) → 图 19.1；还依赖 \(\bar L_k\) → 图 19.2； 还依赖没记录下来的东西 → 图 19.3，到此为止，任何方法都救不了。
  3. 「有没有像 \(W_0\) 那样、同时影响处理与之后协变量的未记录变量？」 有的话，静态策略还能估，动态策略不能（§19.5）—— 而临床上你真正想要的那条规则，多半正是动态的。

第三问是本章最容易被跳过、也最值钱的一问。 它的现实形态非常具体： 一次没被记录进数据库的门诊预约——病人来没来门诊，既影响他当天是否开药， 又影响他下一次化验值有没有被测到。 电子病历数据里这件事几乎必然存在。

下一章 第 20 章「处理–混杂因子反馈」 要回答的是本章最后一句留下的问题： 既然 \(\bar L_k\) 必须被调整，为什么「把 \(\bar L_k\) 放进回归模型」这种做法反而会制造偏倚。

本章没有数据分析，但「策略」这个概念落到 R 上是很具体的一件事—— 判断一个人在观测数据里是否「一路遵循了策略 \(g\)」， 这是第 21 章 IP 加权与第 22 章克隆-删失-加权全都要用到的第一步：

# 长表：id, k（0..K）, A（当月是否治疗）, L（当月 CD4 低 = 1）, Y（随访结束时测）
library(dplyr)

# 1. 静态策略 ā：逐时刻比对一串固定的 0/1
follows_static <- function(df, a_vec) {
  df |>
    arrange(id, k) |>
    group_by(id) |>
    summarise(ok = all(A == a_vec[k + 1L]), .groups = "drop")   # k 从 0 起，故 +1
}

# 2. 动态策略 g：「L 一旦为 1 就开始治，之后一直治」
#    g 只依赖协变量史——Technical Point 19.1 保证了这不损失一般性
g_dyn <- function(L_hist) as.integer(cummax(L_hist) == 1L)

follows_dynamic <- function(df) {
  df |>
    arrange(id, k) |>
    group_by(id) |>
    summarise(ok = all(A == g_dyn(L)), .groups = "drop")
}

# 3. 「到 t 为止仍遵循 g」——第 21/22 章的人工删失时点就由它决定
deviates_at <- function(A, L) {
  d <- which(A != g_dyn(L))
  if (length(d) == 0L) NA_integer_ else min(d) - 1L   # 0-based：最后一个仍相容的 k
}
