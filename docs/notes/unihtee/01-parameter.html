1. TEM-VIP：这个包到底在估计什么

参数定义、六种「结局 × 尺度」组合，以及它和 CATE、交互系数、树分裂的区别

在碰 unihtee() 的参数之前，必须先弄清它输出的那个数是什么。 这个包只有一个导出函数，但它能估计六个不同的参数， 而且返回表的列名对六种情形完全一样——看着一样，含义完全不同。

数据结构与识别假设

观测 \(O = (W, A, Y) \sim P_0\)，\(n\) 个独立样本：

符号 含义 在 unihtee() 里的参数
\(W\) \(p\) 个基线协变量（治疗前测量） confounders
\(W_j\) 候选效应修饰变量，\(\{W_j\} \subseteq W\) modifiers
\(A \in \{0,1\}\) 二值治疗 exposure
\(Y\) 结局：连续 / 二分类 / 事件时间 outcome
\(\Delta\) 右删失指示（仅生存） censoring

因果解释需要三条标准假设（官方 vignette 的表述）：

  1. 无未测量混杂：\(Y^{(a)} \perp A \mid W\)；
  2. 正性：\(0 < P(A = 1 \mid W) < 1\) 几乎必然；
  3. 删失的正性（仅生存）：在关心的时间窗内删失机制不把某类人全部删掉。
注记假设不成立时，这个参数仍然是良定义的

TEM-VIP 首先是一个统计参数——\(P_0\) 的一个泛函，不需要任何因果假设就能估计。 上面三条假设只负责把它翻译成因果语言。 所以在混杂没调干净的观察性数据上，unihtee() 照样会给你一张显著性表， 只是表里的”效应修饰”读作”在调整了你给的 confounders 之后， \(W_j\) 与条件结局差的边际关联”。这一区分在 筛选软件与方法核查里反复出现。

绝对尺度的 TEM-VIP

条件平均治疗效应（CATE）：

\[ \tau(W) \;=\; \mathbb{E}_{P_0}[Y \mid A = 1, W] - \mathbb{E}_{P_0}[Y \mid A = 0, W]. \]

对第 \(j\) 个候选变量：

\[ \boxed{\; \Psi_j(P_0) \;=\; \frac{\operatorname{Cov}_{P_0}\bigl[\tau(W),\, W_j\bigr]} {\operatorname{Var}_{P_0}\bigl[W_j\bigr]} \;} \]

三种等价读法，任选一种记住：

  1. 一元回归斜率：把（不可观测的）\(\tau(W)\) 对 \(W_j\) 做最小二乘，斜率就是 \(\Psi_j\)。
  2. 单位解释：\(W_j\) 每上升一个单位，治疗效应平均改变 \(\Psi_j\) 个结局单位。
  3. 投影：\(\Psi_j\) 是 \(\tau(W)\) 在 \(\{a + b W_j\}\) 这个一维仿射空间上的 \(L^2(P_0)\) 投影的斜率系数。
警告\(\Psi_j\) 是边际的，不是偏效应

\(\Psi_j\) 里没有”控制其它修饰变量”这回事。如果 \(W_1\) 是真修饰变量、 \(W_2\) 与 \(W_1\) 相关但本身不修饰，那么 \(\Psi_2 \neq 0\)—— 这是参数本身的性质，不是估计误差，交叉拟合、换学习器、加样本量都消不掉。

这一点与 grf 的变量重要性、model4you::varimp() 都不同： 那两者是在联合模型里比较变量。把 unihtee 的结果当作”独立贡献”来读是错的。 效应修饰的效应尺度一页把 unihtee/uniCATE 的”单变量投影”与 TE-VIM 一类”联合重要性”的区别讲得更细。

与几种常见量的关系

你熟悉的量 和 \(\Psi_j\) 的关系
lm(Y ~ A * W_j) 的交互系数 当 \(\tau\) 真的是 \(W_j\) 的线性函数、且无混杂时两者一致；有混杂时 OLS 有偏而 \(\Psi_j\) 无偏（落地页最小例子里 0.76 vs 0.97，真值 1）
个体化 CATE \(\hat\tau_i\)（grf 等） \(\Psi_j\) 是把 \(\hat\tau\) 压缩成”每变量一个数”；反过来做不到
树的分裂变量（model4you、MOB） 树检验的是”模型参数在哪里不稳”，包含截距，即预后差异；\(\Psi_j\) 从定义上只看 \(\tau\)，不看 \(\mathbb{E}[Y\mid A=0,W]\)
\(\operatorname{Cor}(\tau, W_j)\) 差一个 \(\operatorname{sd}(\tau)/\operatorname{sd}(W_j)\) 的因子；unihtee 用的是回归斜率，因此有量纲

最后一行有实际后果：\(\Psi_j\) 的量纲是「结局单位 / \(W_j\) 单位」， 所以不同变量之间的 \(\hat\Psi_j\) 不可直接比大小， 除非先把 \(W\) 标准化。排序应当看 \(z\) 或 \(p\)，不要看 estimate。

相对尺度的 TEM-VIP

\[ \boxed{\; \Gamma_j(P_0) \;=\; \frac{\operatorname{Cov}_{P_0}\bigl[ \log \mathbb{E}[Y \mid A=1, W] - \log \mathbb{E}[Y \mid A=0, W],\; W_j\bigr]} {\operatorname{Var}_{P_0}\bigl[W_j\bigr]} \;} \]

即把 \(\tau\) 换成对数比。对二分类结局，\(\mathbb{E}[Y\mid A,W] = P(Y=1\mid A,W)\)， 于是括号里就是对数风险比。官方 vignette 说二分类结局上相对尺度 “often provides greater sensitivity”——本机在一个 \(n=500\) 的仿真里确实看到了 排序变化，但两把尺子挑出的头部变量并不相同，见 第 2 页。

重要effect = "relative" 不要用在连续结局上

源码把连续结局先 min–max 缩放到 \([0,1]\)，相对效应分支里要除以缩放后的 \(\hat Q(A_i, W_i)\)。缩放后最小的那个观测的 \(\hat Q\) 贴着 0，分母一小， 整条 EIF 就炸了。实测：

# y ~ N(10 + w1 + w2 + a*w3 - a*w4, 1)，n = 500
unihtee(dt, cn, cn, "a", "y", outcome_type = "continuous", effect = "relative")
  Y -> (Y+  0)*1 :  w_3 estimate =     3.6930   se = 5077385.1536   ace =   0.0770
  Y -> (Y+  0)*2 :  w_3 estimate =     7.3860   se = 10154770.3072  ace =   0.0770
  Y -> (Y+100)*1 :  w_3 estimate =     3.6930   se = 5077385.1536   ace =   0.0770
  Y -> (Y+100)*2 :  w_3 estimate =     7.3860   se = 10154770.3072  ace =   0.0770

两件事同时暴露：SE 有 7 位数；估计值随结局的乘法变换线性变化—— 一个真正的对数尺度参数不会这样。原因是 test_hypotheses() 无条件地把估计乘上 rescale_factor = max(Y) - min(Y)，而这个换算只对绝对尺度成立。 对照绝对尺度的同一组变换：

  Y -> (Y+  0)*1 :  w_3 estimate =     0.9012   se =   0.1579
  Y -> (Y+  0)*2 :  w_3 estimate =     1.8025   se =   0.3157
  Y -> (Y+100)*1 :  w_3 estimate =     0.9012   se =   0.1579
  Y -> (Y+100)*2 :  w_3 estimate =     1.8025   se =   0.3157

位移不变、随尺度线性——这才是 \(\Psi_j\) 该有的行为。

结论：相对尺度只用在 "binary" 和 "time-to-event" 上。 连续结局如果确实想要相对解释，先自己把 \(Y\) 取对数再按绝对尺度跑。

生存结局的两个参数

事件时间结局需要先指定一个 time_cutoff \(= t\)。

绝对（effect = "absolute"） —— 限制平均生存时间（RMST）之差：

\[ \Psi_j^{\text{RMST}}(P_0) = \frac{\operatorname{Cov}_{P_0}\Bigl[ \int_0^{t} S(u \mid 1, W)\,du - \int_0^{t} S(u \mid 0, W)\,du,\; W_j\Bigr]} {\operatorname{Var}_{P_0}[W_j]} . \]

相对（effect = "relative"） —— \(t\) 时刻生存概率的对数比：

\[ \Gamma_j^{S}(P_0) = \frac{\operatorname{Cov}_{P_0}\bigl[ \log S(t \mid 1, W) - \log S(t \mid 0, W),\; W_j\bigr]} {\operatorname{Var}_{P_0}[W_j]} . \]

警告相对生存参数的口径：是 \(t\) 时刻的比，不是 RMST 的比

本书效应修饰的效应尺度 把 unihtee(..., effect = "relative") 记作”log RMST 比”。 按 0.0.3 的源码，一步估计与 TMLE 用的都是 \(t\) 时刻生存概率的对数比：

# unihtee:::compute_eif()，effect == "relative" 的生存分支
data[, `:=`(aipws, integral + log(surv_exp_est / surv_noexp_est))]
time_cutoff <- max(data[[outcome]])
data <- data[get(outcome) == time_cutoff, ]     # 只取 t 这一行
# unihtee:::tml_estimator()，生存 + relative 的收尾
data_mod <- data_mod[data_mod[, .I[.N], by = "id"]$V1]   # 每人最后一行 = t
log_diff <- log(data_mod$surv_exp_est_star / data_mod$surv_noexp_est_star)
cov(log_diff, data_mod[[mod]]) / mod_vars[[mod]]

对数 RMST 比会写成 \(\log \int_0^t S_1 - \log \int_0^t S_0\)， 而上面是 \(\log S_1(t) - \log S_0(t)\)——先取对数再积分和先积分再取对数不是一回事。 额外的一处不一致：plugin_estimator() 的同一分支写的是 cumsum(int_weight * log(surv_exp_est / surv_noexp_est))， 也就是把对数比沿时间积了一次，与另两个估计量的口径不同。 插值估计只进入方差项（见第 4 页）， 所以它影响的是相对生存参数的 SE，不影响点估计。

六种组合与源码分派

unihtee() 按 outcome_type × effect 分派到不同的估计量， 边际效应（ace_estimate）也跟着换：

outcome_type effect TEM-VIP 的 \(\tau\) ace_estimate 的含义 分派到的边际估计量
continuous absolute CATE ATE one_step_ate_estimator / tml_ate_estimator
continuous relative 不要用 — one_step_estimator_ate_log_outcome / tml_estimator_ate_log_outcome
binary absolute 风险差 边际风险差 同上（ate）
binary relative 对数风险比 边际对数风险比 同上（ate_log）
time-to-event absolute RMST 差 边际 RMST 差 one_step_rmst_diff_estimator / tml_rmst_diff_estimator
time-to-event relative \(\log S(t\mid1,\cdot) - \log S(t\mid0,\cdot)\) 其边际均值 one_step_estimator_rmst_log_outcome / tml_estimator_rmst_log_outcome

这 8 个边际估计量各自有独立帮助页，逐个说明见 第 4 页。

ace_estimate 不只是”顺手给的一个数”：它被用来把 EIF 中心化， 也是 plot.unihtee() 那条回归线的截距。见 第 6 页。

一张图上的三个层次

                  ┌─────────────────────────────────────┐
  个体            │  τ(W)  —— CATE，n 个数              │  grf、X-learner
                  └──────────────┬──────────────────────┘
                                 │  对单个 W_j 做一元投影
                  ┌──────────────▼──────────────────────┐
  变量            │  Ψ_j = Cov(τ, W_j)/Var(W_j)，p 个数 │  unihtee、uniCATE
                  └──────────────┬──────────────────────┘
                                 │  对 W 取期望
                  ┌──────────────▼──────────────────────┐
  总体            │  ATE = E[τ(W)]，1 个数              │  ace_estimate
                  └─────────────────────────────────────┘

往下走会丢信息、但会换来可检验性：\(p\) 个 \(\Psi_j\) 各自有渐近正态的 \(\sqrt n\)-一致估计量，可以做正式检验并做 BH 校正； 而 \(\tau(W)\) 本身是一个非参数函数，没有 \(\sqrt n\) 的置信带。 这就是为什么筛选阶段用 unihtee，而不是先估 CATE 再看哪个变量重要。
