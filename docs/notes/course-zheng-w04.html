W04 · 机器学习与因果推断

郑老师训练营第四周 · 讲义 83 页 + 4 段视频约 2 小时 25 分

本页两部分：讲义原件内嵌展示，版权归课程作者所有；内容整理是笔记作者 根据讲义与视频语音转写写的，不是课程原话。出处、压缩处理与已知限制见 课程讲义总览。

一、预测问题与因果问题：两类问题的评价标准根本不同

讲义 p1–26。这一讲「并不是教大家任何具体的算法」，而是先划清边界。

预测问题 Prediction 因果问题 Causation
关注 给定信息条件下结果是否会发生 主动改变某个变量时结果是否改变
强调 相关性结构与预测准确性 干预效应与反事实比较
形式 学习 \(P(Y\mid X)\) 或 \(E(Y\mid X)\) 估计 \(A\) 对 \(Y\) 的影响
评价 预测误差：MSE、AUC、对数损失 效应大小、方向、对哪些人有效
对模型的要求 结构本身不要求反映真实的数据生成机制 必须处理混杂结构

冰淇淋销量与溺水人数的例子（p9）在这里承担的作用很具体：两者显著正相关， 但真相是温度/季节这个共同原因。启示写在同一页——预测模型可以利用相关性， 因果推断必须处理混杂结构。

讲义还给了传统统计与机器学习的一张正面对照（p12）：

维度 传统统计 机器学习
假设前提 有严格假设（正态、独立性） 基于数据学习，无需前提假设
目标 参数估计、因果推断 预测准确率、泛化能力
应用关注 模型解释为主 模型效果为主
输出 \(P\) 值、置信区间 准确率、AUC、F1 值

高预测 ≠ 好决策

讲义 p18 单独用一页讲这件事，四句话都值得记：

  • 强预测因子不一定是可干预因素
  • 准确识别高风险人群 ≠ 有效降低风险
  • 决策关心的是：改变可控变量是否改变结果（可干预性）
  • 因果推断是决策语言，机器学习是建模工具

对应的局限在 p17：机器学习学的是统计相关性，无法区分混杂因素与真实因果效应； 干预后数据分布可能发生变化，预测模型可能失效。

这一讲的落点在 p24——机器学习不是直接用来「算因果效应」，而是先估计一些「中间量」：

  • 倾向性评分 \(P(A\mid X)\)：谁更可能接受处理
  • 结果模型 \(E(Y\mid A,X)\)：结果如何由 \(A,X\) 决定

而因果推断负责定义目标因果效应（ATE / ATT）、用因果假设保证可识别性、 把估计量整合成因果效应。页脚那行小字说得最干净： 机器学习不引入新的因果信息，不修复未观测混杂、测量误差或选择偏倚。

二、分类、常用模型与 Super Learner：为什么不该只挑一个最优模型

讲义 p27–52。机器学习的三种分类维度（p30）：是否有标签（有监督 / 无监督）、 学习目标（回归 / 分类）、方法结构（线性 / 树 / 集成）。

在因果推断里，机器学习只承担两个任务（p33）：估计倾向性评分 \(P(A=1\mid X)\) 与估计结果回归 \(E(Y\mid A,X)\)。讲义给这两件事下了同一个判词： 二者都是建模问题而非因果问题，目标是减少模型错设带来的偏差。

常见算法及其在因果分析中的定位（p34–45），讲义在 p45 给了一张比较表：

模型 优势
Logistic 解释性强，可输出 OR 值；训练快，适合线性问题
决策树 逻辑清晰，可视化；可自动选择特征；能处理非线性关系
随机森林 鲁棒性强，抗过拟合；评估特征重要性；适合高维复杂数据
XGBoost 精度高、训练快；抗噪声能力强；支持缺失值处理
LightGBM 速度快、内存占用少；支持大规模数据；适合稀疏特征
KNN 简单直观、无训练过程；不依赖数据分布假设
SVM 边界明确，适合小样本 / 非线性问题
NN 学习能力强，支持复杂非线性；可扩展为深度学习

Super Learner（p47–51）是这一讲的终点。它的出发点是一个诚实的承认： 真实数据中很难事先判断哪种模型是「正确的」，而在因果推断里 一旦模型错设，因果效应估计将产生偏倚（p79）。

它的四步工作流程（p49）：

  1. 指定一组候选学习器
  2. 用交叉验证评估每个学习器
  3. 基于验证误差估计最优加权组合
  4. 构建加权后的最终预测模型

输出的是组合模型而非单一算法。理论优势（p50）里最关键的一条是： 样本量足够大时，性能不劣于候选模型中最优者——也就是说，用它至少不亏。

三、G 计算与倾向性评分：机器学习装在哪里：两条路径，一个双稳健

讲义 p53–83，是本周篇幅最大、也最接近后面几周的一讲。

先把目标量和假设摆正

因果推断的目标量（Estimand） 有两个（p57–58）：

\[\mathrm{ATE}=E[Y(1)-Y(0)] \quad\text{（总体干预策略评估）}\] \[\mathrm{ATT}=E[Y(1)-Y(0)\mid A=1] \quad\text{（真实接受治疗人群中的疗效评估）}\]

识别的三条基本假设（p59）：一致性（观察结果等于对应潜在结果）、 可交换性 / 无混杂 \(Y(a)\perp\!\!\!\perp A\mid X\)、正则性 / 重叠性 （每个 \(X\) 下接受与不接受处理都有正概率）。这一页有两行红字，是整周的分界线：

这些是假设，而不是模型输出。机器学习无法替代这些假设。

两条路径

p61 把 G 方法的实现分成两条，正好对应前两周：

路径 建模对象 做法
一 · G 计算 结局模型 \(E(Y\mid A,X)\) 构造反事实结果
二 · 倾向性评分 治疗模型 \(P(A\mid X)\) 构造平衡后的样本

G 计算成立的关键等式（p63）：无混杂条件下 \(E[Y(a)]=E\{E(Y\mid A=a,X)\}\)—— 左侧是潜在结果的期望，右侧是从观测数据中分两步估计的统计量 （先在协变量每一层内估 \(E(Y\mid A=a,X)\)，再按 \(P(X)\) 加权平均，即「标准化」）。 G 计算通过估计右侧来获得左侧。

IPTW 的权重（p73）：

\[w_i=\frac{A_i}{e(X_i)}+\frac{1-A_i}{1-e(X_i)}\]

为每个个体分配权重，构造一个新的「伪总体」；在这个伪总体中， 处理分配在协变量分布上近似随机。

机器学习装进来的位置

  • 在 G 计算里（p67）：估计结局模型 \(E(Y\mid A,X)\approx f_{\mathrm{ML}}(A,X)\)， 常用 Random Forest、Gradient Boosting、Neural Networks、Super Learner。 注意事项照旧——机器学习不改变因果假设，仅作为建模工具使用
  • 在倾向性评分里（p75）：常用 LASSO / Elastic Net、Random Forest、 Gradient Boosting、Super Learner，提高协变量平衡效果，但需防止极端概率

预测准 ≠ 倾向性评分好

讲义 p77 单独一页讲这个反直觉的点：倾向性评分的目标不是分类准确率， 关键诊断是协变量是否平衡（SMD < 0.1，以及重叠性）。过度追求预测性能 可能导致极端概率、引发权重不稳定。

视频里讲得更形象：如果一个模型把处理分配预测得极其准确， 那往往意味着它把人群分成了「几乎必治」和「几乎必不治」两类， 倾向性评分就贴近 0 或 1——重症患者几乎都用药、轻症患者几乎都不用药， 那就几乎找不到可比的对照，估计再好也缺乏支撑。

落到双稳健

p80 的对比表把两条路径的分工讲完：

方面 G 方法 倾向性评分方法
建模对象 结局模型 \(E(Y\mid A,X)\) 处理模型 \(P(A\mid X)\)
核心思想 标准化 平衡 / 加权
控制混杂方式 条件建模 + 标准化 样本加权
主要风险 结局模型错设 权重不稳定
机器学习用途 估计结局模型 估计倾向性评分

p81 的「双稳健」思想由此自然导出：G 计算依赖结局模型、PS 加权依赖 PS 模型， 但二者都可能错设；同时使用两类模型就有机会提高稳健性—— 讲义直接标红：这是 AIPW、TMLE 的理论起点，也就是第五、六周的内容。

四、R 操作：把两条路径都跑一遍：24 分钟，RHC 数据

第四讲没有讲义，只有 24 分钟视频。用的数据集是 rhc.csv—— 又是右心导管检查（RHC） 这个经典观察性研究：RHC 在上个世纪被广泛用于危重病人的监测， 但它是否真能改善生存一直有争议。研究问题是接受 RHC 与未接受 RHC 的患者死亡风险是否不同。

演示的流程是把 G 计算与 IPTW 两条路各走一遍，中间量都用 Super Learner 估：

  1. 定义干预变量 A（RHC）、结局变量 Y、基线协变量 W，提取成 data2
  2. G 计算：把 A 全部设为 1 预测一遍、全部设为 0 再预测一遍， 得到每个人在两种世界下的死亡概率，各取均值再相减即 ATE
  3. IPTW：用 Super Learner 估倾向性评分，算权重，看权重分布
  4. 平衡性检查：加权后算 SMD，标准是绝对值小于 0.1
  5. Bootstrap 求置信区间

权重上限的经验值

视频里给了一个讲义上没有的经验：理想权重一般小于 10。 演示数据里最大权重是 12.53，「稍微超过 10」，讲师的判断是「通常是可以接受的」。 权重过大意味着少数个体主导了整个估计，这也是 p77「防止极端概率」那条的实际体现。

# ============================================================================
# 课程演示：G-computation 与 倾向性评分(IPTW) 的实现
# —— 在中间量估计中引入 Super Learner
#
# 数据：rhc.csv（RHC 研究数据）
#
# 研究问题（示例）：
#   实施 RHC (A=1) 相比不实施 RHC (A=0)，是否影响死亡风险 (Y)？
#
# 变量说明：
#   - 处理/干预 A：RHC
#       1 = 行 RHC
#       0 = 未行 RHC
#
#   - 结局 Y：death
#       Yes / No （分析中转换为 1 / 0）
#
#   - 混杂变量 W（基线协变量）：
#       Cardiovascular, Congestive.HF, Age, Edu, DASIndex,
#       APACHE.score, blood.pressure, WBC, Heart.rate, DNR.status
#       （这些变量同时影响 RHC 的实施与死亡风险）
#
# 本脚本实现两条经典因果估计路径：
#
#   (1) G-computation（G 计算）：
#       - 目标：估计 E[Y(1)] 与 E[Y(0)]
#       - 做法：使用 Super Learner 拟合结果模型 E(Y | A, W)，
#               并基于该模型模拟反事实结局
#
#   (2) IPTW（逆概率加权）：
#       - 目标：构造一个“处理近似随机分配”的加权总体
#       - 做法：使用 Super Learner 估计倾向性评分
#               e(W) = P(A = 1 | W)，并据此生成权重
#
# 重要说明：
#   - G-computation 与 IPTW 是因果推断的估计框架
#   - Super Learner 仅作为灵活的机器学习工具，
#     用于估计上述方法所需的中间量
#   - 因果解释依赖于无未测混杂、重叠性和一致性等假设
# ============================================================================


# ===============================
# 0. 安装并加载需要的包
# ===============================

# install.packages() 只需要第一次安装时运行一次
install.packages(c(
  "readr",        # 读 csv
  "dplyr",        # 数据整理
  "SuperLearner", # Super Learner 框架
  "cobalt",       # 平衡性检查 (love plot / SMD)
  "WeightIt",     # 倾向性评分加权工具（可调用 super learner）
  "survey",       # 加权后推断（标准误、置信区间）
  "boot"          # bootstrap（用于 G-computation 的 CI）
))

# 每次打开 R 都需要 library() 加载包 
library(readr)
library(dplyr)
library(SuperLearner)
library(cobalt)
library(WeightIt)
library(survey)
library(boot)

# ===============================
#### 1. 读取数据 ####
# ===============================
data <- read_csv("C:/Users/zhangyan/Desktop/ML CR/rhc.csv")

# glimpse() 可以快速显示变量类型、缺失情况、前几行
glimpse(data)

# ===============================
#### 2. 定义变量+数据预处理 ####
# ===============================

## 2.1 定义变量

# 干预变量名: RHC (RHC干预:1=行RHC，0=未行RHC)
A <- "RHC"

# 结局变量名: death (是否死亡:No，Yes)
Y <- "death"

# 基线协变量 W（混杂变量）：影响 A 和 Y
W <- c("Cardiovascular","Congestive.HF","Age","Edu","DASIndex", 
       "APACHE.score","blood.pressure","WBC","Heart.rate","DNR.status")

# 只保留分析需要的列（避免其他列干扰建模/出错）
data2 <- data %>% select(all_of(c(A, Y, W)))


## 2.2 检查 A 和 Y 的原始类型 
# 很多数据集里A/Y是factor或字符型,需转换成0/1数值才能用于binomial模型

str(data2[[A]])
str(data2[[Y]])

# 将 Y 转为 0/1 (# death是 "Yes"/"No",把 Yes->1, No->0)
data2[[Y]] <- ifelse(data2[[Y]] == "Yes", 1, 0)

# 查看 A 和 Y 的分布
table(data2[[A]])
table(data2[[Y]])

# ===============================
#### 3. G-computation + Super Learner #### 
#    目标：估计 E[Y(1)]与E[Y(0)], ATE = E[Y(1)]-E[Y(0)] (风险差)
# ===============================

## 3.1 用 Super Learner 拟合结局模型

Y_vec <- data2[[Y]]  # 结局向量
X_outcome <- data2 %>% 
          select(all_of(c(A, W)))  # 自变量 = 干预(A) + 混杂(w)

# 使用 Super Learner结局模型
set.seed(2026)   # 结果可复现
fit_outcome <- SuperLearner(
  Y = Y_vec,   
  X = X_outcome,    # A + w
  family = binomial(),  # 结局是0/1->二项分布(logit 链接)
  SL.library = c(
    "SL.mean",   # 基线：只用均值
    "SL.glm",    # Logistic 回归
    "SL.glmnet"  # LASSO
    )
  )    # SL.library 中可添加："SL.xgboost", "SL.randomforest"

# 输出 Super Learner 结果(Risk:预测误差, Coef:权重)
fit_outcome

# 查看各学习器在集成中的权重（系数）
fit_outcome$coef


## 3.2 构造反事实数据：把所有人的 A 人为设为 1 / 0

# 反事实世界1：所有人都做 RHC (A=1)
# 反事实世界0：所有人都不做 RHC (A=0)

X1 <- X_outcome; X1[[A]] <- 1   # 所有人都 RHC
X0 <- X_outcome; X0[[A]] <- 0   # 所有人都不 RHC

# 用拟合好的Q 模型预测每个人在两种世界下的死亡概率（反事实风险）
p1 <- predict(fit_outcome, newdata = X1)$pred
p0 <- predict(fit_outcome, newdata = X0)$pred


## 3.3 计算边际风险与 ATE（风险差 RD）
# E[Y(1)]：把所有人的反事实概率取平均
# E[Y(0)]：同理

risk1_g <- mean(p1)         # 如果所有人都做RHC的死亡风险
risk0_g <- mean(p0)         # 如果所有人都不做RHC的死亡风险
RD_g <- risk1_g - risk0_g   # 风险差 ATE

res_g <- c(risk_if_A1 = risk1_g, risk_if_A0 = risk0_g, RD = RD_g)
print(res_g)


## 3.4 使用bootstrap 计算G-computation 的 percentile CI 
# bootstrap：重复“抽样 -> 拟合结局回归函数 -> 做反事实预测 -> 求 ATE”
# 得到 ATE 的经验分布，从而构造置信区间

gcomp_ate <- function(data, indices) {
  # data：原始数据；indices：bootstrap 重抽样行号
  d <- data[indices, ]
  
  # (1) 拟合结局模型 Q(A,W)
  sl_fit_boot <- SuperLearner(
    Y = d[[Y]],
    X = d[, c(A, W)],
    SL.library = c("SL.mean","SL.glm","SL.glmnet"),
    family = binomial()
  )
  
  # (2) 构造反事实数据（只需要 A+W 列即可）
  d_A1 <- d_A0 <- d
  d_A1[[A]] <- 1
  d_A0[[A]] <- 0
  
  # (3) 预测反事实风险（onlySL=TRUE 表示使用集成器的预测）
  pred_A1 <- predict(sl_fit_boot, newdata = d_A1[, c(A, W)], onlySL = TRUE)$pred
  pred_A0 <- predict(sl_fit_boot, newdata = d_A0[, c(A, W)], onlySL = TRUE)$pred
  
  # (4) 返回该次 bootstrap 的 ATE（风险差）
  mean(pred_A1) - mean(pred_A0)
}

# 执行bootstrap（考虑到计算时间，这里用5次，实际应用中建议1000+次）
set.seed(2026)
boot_results <- boot(data2, gcomp_ate, R = 5)

# 计算 percentile CI
CI_g <- boot.ci(boot_results, type = "perc")

# CI_g$percent 是一个向量：其中第4和第5个元素分别是 2.5% 和 97.5% 分位点
CI_low_g  <- CI_g $ percent[4]
CI_high_g <- CI_g $ percent[5]

# G 计算的结果:点估计（用原样本 RD_g）+ 置信区间（bootstrap percentile）
c(ATE = RD_g, CI_low = CI_low_g, CI_high = CI_high_g)


# ===============================
#### 4. IPTW（倾向性评分加权） + Super Learner ####
#   目标：用 e(W)=P(A=1|W) 构造权重，使加权后A与W近似独立（像随机试验）
# ===============================

## 4.1 用 WeightIt(method="super") 估计 PS 并生成权重

set.seed(2026)
w.out <- weightit(
  formula   = as.formula(paste(A, "~", paste(W, collapse = " + "))),
              # 等价于：A ~ W1 + W2 + ... + Wp
  data      = data2,
  estimand  = "ATE",      # 目标是平均处理效应ATE
  method    = "super",    # Super Learner 来拟合 e(W)
  SL.library = c(
      "SL.mean",      # 用总体均值预测 A（基线模型）
      "SL.glm",       # Logistic回归
      "SL.glmnet"     # LASSO
    )
  )

# 查看权重概况
summary(w.out)

# 查看权重分布
w <- w.out$weights 
summary(w)


## 4.2 平衡性检查:加权后两组是否更像随机？
# 看加权前后标准化均值差（SMD）
# 常用经验标准：|SMD| < 0.1 认为平衡不错

bal.tab(
  w.out,                 # weightit() 生成的倾向性评分权重对象
  un = TRUE,             # un = TRUE：显示“未加权”和“加权后”的结果
  thresholds = c(m = 0.1) # 设置平衡性阈值：|SMD| < 0.1 
)

# love.plot：可视化加权前后 SMD
love.plot(
  w.out,                 # 同样使用 weightit() 输出对象
  binary = "std",        # 对二分类变量使用“标准化均值差(SMD)”作为平衡性度量
  thresholds = c(m = 0.1),# 在图中画出|SMD| = 0.1 的阈值线
  abs = TRUE,            # 使用“绝对值 SMD”
  var.order = "unadjusted", # 按“未加权时的不平衡程度”排序变量
  line = TRUE            # 用线连接未加权和加权后
)

## 4.3 用 survey 在加权伪总体中估计风险差 + 95%CI
# survey 包把权重当作“抽样权重”，从而可计算标准误和置信区间

# 建立加权设计对象
design.w <- svydesign(ids = ~1,   # 每一行数据是一个独立个体
                      weights = ~w,  # 抽样权重
                      data = data2)

# 用线性概率模型(gaussian)来直接估计风险差（RD）与 CI
fit_rd <- svyglm(
  as.formula(paste(Y, "~", A)),  # 模型公式：Y ~ A
  design = design.w,             # 指定 survey 设计对象
  family = gaussian()
  )
# 提取 RD（RHC 的回归系数）以及置信区间
ATE_w <- coef(fit_rd)[A]    # ATE（风险差 RD）
CI_w  <- confint(fit_rd)[A, ]   # 95% CI
# CI_w 是长度为2的向量：下限、上限
CI_low_w <- CI_w [1]
CI_high_w <- CI_w [2]

# 输出倾向性评分加权的结果
c(ATE = ATE_w, CI_low = CI_low_w, CI_high = CI_high_w)
