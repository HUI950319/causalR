缺失数据

Missing Data · marginaleffects 官方文档中译

来源：Vincent Arel-Bundock，marginaleffects 官方文档 · Missing Data （GitHub 仓库，源文件 website/bonus/multiple_imputation.qmd，revision 870f15a0）。 网站内容 © 2025 Vincent Arel-Bundock, All Rights Reserved；marginaleffects 软件代码依 GPL-3 许可。 本页为中文翻译，非原文，经原作者授权翻译并发布。 页面中的代码块由本站在渲染时真实执行。

marginaleffects 包提供了一些便捷函数，用于计算和展示来自 mice 和 Amelia 包的多重插补模型的预测值、对比和边际效应。整个流程遵循 Rubin 规则（Rubin, 1987, p. 76），步骤如下：

  1. 插补出 \(M\) 份数据集。
  2. 在这 \(M\) 份插补数据集上分别拟合模型。
  3. 在这 \(M\) 份数据集上分别计算边际效应。
  4. 汇总（pool）结果。

为了突出整个流程，我们以一个简单的线性回归模型为例，不过同样的流程应该适用于任何通过公式接口和 data 参数拟合的模型类型。

marginaleffects 直接支持 mice 和 Amelia 这两个插补包，也支持任何能返回插补数据框列表的其他包。下面用 iris 数据集来演示：我们先随机制造一些缺失观测，然后用几个不同的包来插补缺失值。

library(marginaleffects)
set.seed(1024)

dat <- iris
dat$Sepal.Length[sample(seq_len(nrow(iris)), 40)] <- NA
dat$Sepal.Width[sample(seq_len(nrow(iris)), 40)] <- NA
dat$Species[sample(seq_len(nrow(iris)), 40)] <- NA

mice

首先，我们用 mice 包对数据集做插补：

library(mice)

dat_mice <- mice(dat, m = 20, printFlag = FALSE, .Random.seed = 1024)

然后，我们用标准的 mice 语法生成一个包含所有模型的 mira 类对象：

mod_mice <- with(dat_mice, lm(Petal.Width ~ Sepal.Length * Sepal.Width + Species))

最后，把这个 mira 对象喂给某个 marginaleffects 函数：

mfx_mice <- avg_slopes(mod_mice, by = "Species")

Amelia

library(Amelia)

dat_amelia <- amelia(dat, m = 20, noms = "Species", p2s = 0)

mod_amelia <- with(dat_amelia, lm(Petal.Width ~ Sepal.Length * Sepal.Width + Species))

其他插补包：missRanger，或插补数据框的列表。

有好几个 R 包可以插补缺失数据。事实上，Missing Data CRAN View 至少列出了十几个可选方案。由于各个包的用户接口差异很大，marginaleffects 支持一套统一的流程，稍作调整就可以配合所有插补包使用：

  1. 用外部包生成一个插补数据框的列表。
  2. 用 miceadds 包的 datalist2mids() 函数，把这个插补数据框列表转换成 mids 对象。
  3. 用 with() 函数拟合模型、生成 mira 对象，就像上面 mice 和 Amelia 两节演示的那样。
  4. 把 mira 对象传给某个 marginaleffects 函数。

下面以插补包 missRanger 为例，它会生成一个插补数据集的列表：

library(miceadds)
library(missRanger)

## convert lists of imputed datasets to `mids` objects
dat_missRanger <- replicate(20, missRanger(dat, verbose = 0), simplify = FALSE)
mids_missRanger <- datlist2mids(dat_missRanger)

## fit models
mod_missRanger <- with(mids_missRanger, lm(Petal.Width ~ Sepal.Length * Sepal.Width + Species))

## `missRanger` slopes
mfx_missRanger <- avg_slopes(mod_missRanger, by = "Species")

mice::pool()

在某些情况下，「手工」完成插补、拟合和后处理，最后用 mice::pool 函数把结果合并起来，可能会更有用。在下面这类情形中，这种做法效果不错：

library(marginaleffects)
library(mice)
set.seed(1024)
dat <- iris
dat$Sepal.Length[sample(seq_len(nrow(iris)), 40)] <- NA
dat$Sepal.Width[sample(seq_len(nrow(iris)), 40)] <- NA

关于 mice::pool() 有一个比较微妙的地方：它要求被合并的数据框中必须存在 term 列，而且这一列必须能唯一标识每一行。但在某些情况下，marginaleffects 函数的输出并不包含 term 列，这会导致使用 mice::pool() 时报错。

例如，

mfx <- avg_slopes(fit[[1]], hypothesis = ~pairwise)
mfx
#> 
#>                      Hypothesis Estimate Std. Error     z Pr(>|z|)    S 2.5 % 97.5 %
#>  (Petal.Width) - (Petal.Length)   -0.833      0.224 -3.72   <0.001 12.3 -1.27 -0.395
#> 
#> Type: response

colnames(mfx)
#> [1] "hypothesis" "estimate"   "std.error"  "statistic"  "p.value"    "s.value"    "conf.low"   "conf.high"

我们可以用标准的 R 访问符，手工给 marginaleffects 的输出加上一列 term，以绕开这个问题。

mfx <- lapply(fit, \(f) {
    out <- avg_slopes(f, hypothesis = ~pairwise)
    # add the missing `term` column
    out$term <- out$hypothesis
    return(out)
})

mice::pool(mfx)
#> Class: mipo    m = 20 
#>                             term  m  estimate       ubar          b          t dfcom       df       riv    lambda       fmi
#> 1 (Petal.Width) - (Petal.Length) 20 -1.087786 0.04836235 0.02034648 0.06972616   147 67.19845 0.4417446 0.3063959 0.3261571
