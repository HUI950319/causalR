假设检验

Hypothesis Tests · marginaleffects 官方文档中译

来源：Vincent Arel-Bundock，marginaleffects 官方文档 · Hypothesis Tests （GitHub 仓库，源文件 website/bonus/hypothesis.qmd，revision 870f15a0）。 网站内容 © 2025 Vincent Arel-Bundock, All Rights Reserved；marginaleffects 软件代码依 GPL-3 许可。 本页为中文翻译，非原文，经原作者授权翻译并发布。 页面中的代码块由本站在渲染时真实执行。 原文中指向原书章节的交叉引用已改写为指向 marginaleffects.com 的链接（那些章节不在本次翻译范围内）。

本教程是假设检验核心章节的补充：原书《假设检验》一章。它给出了更多进阶示例。

marginaleffects 包可以对任何受支持模型类别的系数进行线性或非线性假设检验，也可以对该包其他函数生成的量进行假设检验，例如 predictions()、comparisons() 或 slopes()。

假设检验有两个主要入口：

  1. marginaleffects 函数：使用 hypothesis 参数。
  2. 其他 R 对象和模型：使用 hypotheses() 函数。

hypothesis 参数和 hypotheses() 函数都接受多种输入类型，这让假设检验的设定非常灵活：

  1. 数值：原假设的取值。
  2. 公式：（非）线性假设检验的方程。
  3. 函数：对任意变换或聚合结果进行检验。
  4. 矩阵：对比矩阵和向量。

本教程将展示如何用这几种策略，对模型系数或 marginaleffects 包估计的量进行假设检验。读完之后，你将能够自定义假设检验和对比，来评估如下陈述：

  • 系数 \(\beta_1\) 和 \(\beta_2\) 相等。
  • \(Y\) 关于 \(X_1\) 的斜率，等于关于 \(X_2\) 的斜率。
  • 当 \(W=0\) 时 \(X\) 的平均处理效应，等于当 \(W=1\) 时 \(X\) 的平均处理效应。
  • 预测值的一个非线性函数等于 100。
  • 对照组的边际均值，等于其他 3 个处理组边际均值的平均值。
  • 跨层级对比：在多项模型中，\(X\) 对第 1 个结局水平的效应，等于 \(X\) 对第 2 个结局水平的效应。

数值（原假设）

修改假设检验最简单的方式是改变原假设。默认情况下，marginaleffects 包中的所有函数都假设原假设为 0。可以通过 hypothesis 参数来修改这一点。

系数

考虑一个简单的逻辑回归模型：

library(marginaleffects)
mod <- glm(am ~ hp + drat, data = mtcars, family = binomial)

默认情况下，summary() 函数会报告原假设设为 0 时的假设检验结果：

summary(mod)
#> 
#> Call:
#> glm(formula = am ~ hp + drat, family = binomial, data = mtcars)
#> 
#> Coefficients:
#>               Estimate Std. Error z value Pr(>|z|)  
#> (Intercept) -29.076080  12.416916  -2.342   0.0192 *
#> hp            0.010793   0.009328   1.157   0.2473  
#> drat          7.309781   3.046597   2.399   0.0164 *
#> ---
#> Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1
#> 
#> (Dispersion parameter for binomial family taken to be 1)
#> 
#>     Null deviance: 43.230  on 31  degrees of freedom
#> Residual deviance: 20.144  on 29  degrees of freedom
#> AIC: 26.144

使用 hypotheses()，我们可以轻松改变原假设：

hypotheses(mod, hypothesis = 6)
Term Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
(Intercept) -29.0761 12.41692 -2.82 0.00473 7.7 -53.41279 -4.7394
hp 0.0108 0.00933 -642.04 < 0.001 Inf -0.00749 0.0291
drat 7.3098 3.04660 0.43 0.66726 0.6 1.33856 13.2810

预测值

在预测值的语境下，改变原假设的取值尤其重要，因为 0 这个基准值未必有意义。例如，这里我们为一个假想单位计算结局的预测值，该单位的所有自变量都固定为其样本均值：

predictions(mod, newdata = "mean", type = "response")
Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
Type: response
0.232 0.143 1.62 0.105 3.2 -0.0487 0.512

上面报告的 Z 统计量和 p 值都假设原假设等于零。我们可以用 hypothesis 参数改变原假设：

predictions(mod, newdata = "mean", hypothesis = .5, type = "response")
Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
Type: response
0.232 0.143 -1.88 0.0605 4.0 -0.0487 0.512

在上面的例子中，mod 是一个逻辑回归模型，我们显式指定了 type="response"。如果不这样做，默认的 type 会是 invlink(link)，也就是说预测会先在链接尺度上进行，再转换回响应尺度。在这种情况下，hypothesis 应该在链接尺度上定义。

请注意，下面这些命令报告的 p 值和上面的不同，但彼此相等。

predictions(mod, newdata = "mean", hypothesis = 0, type = "invlink(link)")
Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
Type: response
0.232 0.143 1.62 0.105 3.2 -0.0487 0.512 
predictions(mod, newdata = "mean", hypothesis = 0, type = "link")
Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
Type: link
-1.2 0.804 -1.49 0.136 2.9 -2.77 0.375

比较和斜率

在计算风险比等不同的关注量时，把原假设设为 1 而不是 0 可能更合理：

avg_comparisons(
    mod,
    variables = "hp",
    comparison = "ratio",
    hypothesis = 1) |>
    print(digits = 5)
Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
Type: response
1.0027 0.0021743 1.2515 0.21074 2.2 0.99846 1.007

方程

hypotheses() 函数模拟了成熟的 car::deltaMethod 和 car::linearHypothesis 函数所采用的基于方程的语法。不过，marginaleffects 支持更多模型、依赖更少，还提供了一些便利功能，例如用于计算稳健标准误的 vcov 参数。

本节展示的语法形式是一个字符串方程，例如："am = 2 * vs"

系数

我们先估计一个简单的模型：

library(marginaleffects)
mod <- lm(mpg ~ hp + wt + factor(cyl), data = mtcars)

当 hypotheses() 的 FUN 和 hypothesis 参数都等于 NULL（默认值）时，该函数会返回一个包含原始估计值的 data.frame：

hypotheses(mod)
Term Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
(Intercept) 35.8460 2.041 17.56 <0.001 227.0 31.8457 39.846319
hp -0.0231 0.012 -1.93 0.0531 4.2 -0.0465 0.000306
wt -3.1814 0.720 -4.42 <0.001 16.6 -4.5918 -1.771012
factor(cyl)6 -3.3590 1.402 -2.40 0.0166 5.9 -6.1062 -0.611803
factor(cyl)8 -3.1859 2.170 -1.47 0.1422 2.8 -7.4399 1.068169

检验系数之间是否相等：

hypotheses(mod, "hp = wt")
Hypothesis Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
hp=wt 3.16 0.72 4.39 <0.001 16.4 1.75 4.57

系数的非线性函数

hypotheses(mod, "exp(hp + wt) = 0.1")
Hypothesis Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
exp(hp+wt)=0.1 -0.0594 0.0292 -2.04 0.0418 4.6 -0.117 -0.0022

vcov 参数的行为方式与其他所有 marginaleffects 函数中的一致，让我们可以轻松计算稳健标准误：

hypotheses(mod, "hp = wt", vcov = "HC3")
Hypothesis Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
hp=wt 3.16 0.805 3.92 <0.001 13.5 1.58 4.74

我们可以用 b1、b2、... 这样的简写来标识每个参数在 FUN 输出中的位置。例如，b2=b3 等价于 hp=wt，因为调用 hypotheses(mod) 时，这两个项名分别出现在第 2 行和第 3 行。

hypotheses(mod, "b2 = b3")
Hypothesis Estimate Std. Error z Pr(>|z|) S 2.5 % 97.5 %
b2=b3 3.16 0.72 4.39 <0.001 16.4 1.75 4.57 
hypotheses(mod, hypothesis = "b* / b3 = 1")

b2/b3=1 -0.99273 0.00413 -240.5539 <0.001 Inf -1.00 -0.985
b3/b3=1 0.00000 NA NA NA NA NA NA
b4/b3=1 0.05583 0.58287 0.0958 0.924 0.1 -1.09 1.198
b5/b3=1 0.00141 0.82981 0.0017 0.999 0.0 -1.62 1.628

hypotheses(mod, "`factor(cyl)6` = `factor(cyl)8`")

`factor(cyl)6`=`factor(cyl)8` -0.173 1.65 -0.105 0.917 0.1 -3.41 3.07

predictions(

比较和斜率

avg_comparisons() 函数可以帮我们回答这样的问题：平均而言，当某个自变量改变一定量时，期望结局会如何变化？来看这个例子：

mod <- lm(mpg ~ am + vs, data = mtcars)

请注意，p 值和置信区间是用 Delta 方法计算的，因此基于这样一个假设：hypotheses 表达式近似服从正态分布。对于（非常）非线性的参数函数，这个假设并不现实，我们会得到错误率不对的 p 值，以及覆盖概率不对的置信区间。对于这类假设检验，最好用自助法来计算置信区间（详见 inferences）：

Delta 方法给出的置信区间是对称的，等于估计值 ± 1.96 倍标准误；而自助法给出的置信区间（或许）更可靠，但高度偏斜。

函数

假设检验也可以使用任意的 R 函数来进行。这让用户可以对复杂的聚合或变换结果做假设检验。为此，我们定义一个自定义函数，它接受一个拟合模型或 marginaleffects 对象，并返回一个至少包含两列的数据框：term（或 hypothesis）和 estimate。

预测值

当给 hypothesis 参数传入一个函数时，该函数必须接受一个参数 x，它是一个包含 rowid 和 estimate 列的数据框（还可以有 newdata 中其他元素对应的可选列）。该函数必须返回一个包含 term（或 hypothesis）和 estimate 列的数据框。

在这个例子中，我们检验平均预测值是否与 2 不同：

dat <- transform(mtcars, gear = factor(gear), cyl = factor(cyl))

mod <- lm(wt ~ mpg * hp * cyl, data = dat)

hyp <- function(x) {
    data.frame(
        hypothesis = "Avg(Ŷ) = 2",
        estimate = mean(x$estimate) - 2
    )
}
predictions(mod, hypothesis = hyp)

Type: response

fun <- function(x) {
    predictions(x, vcov = FALSE) |>
        # label the new categories of outcome levels
        mutate(group = ifelse(group %in% c("3", "4"), "3 & 4", "5")) |>
        # sum of probabilities at the individual level
        summarize(estimate = sum(estimate), .by = c("rowid", "cyl", "group")) |>
        # average probabilities for each value of `cyl`
        summarize(estimate = mean(estimate), .by = c("cyl", "group")) |>
        # the `FUN` argument requires a `term` column
        rename(term = cyl)
}

任意量

只要用户能提供一个方差-协方差矩阵，marginaleffects 也可以为数据框中的任意量计算不确定性估计。（感谢 Kyle F Butts 提供了这个很棒的功能和示例！）

假设你运行了一次蒙特卡洛模拟，想对每次模拟返回的多个量做假设检验。这些量在每次抽样内部是相关的：

## simulated means and medians
draw <- function(i) { 
  x <- rnorm(n = 10000, mean = 0, sd = 1)
  out <- data.frame(median = median(x), mean =  mean(x))
  return(out)
}
sims <- do.call("rbind", lapply(1:25, draw))

## average mean and average median 
coeftable <- data.frame(
  term = c("median", "mean"),
  estimate = c(mean(sims$median), mean(sims$mean))
)

## variance-covariance
vcov <- cov(sims)

## is the median equal to the mean?
hypotheses(
  coeftable,
  vcov = vcov,
  hypothesis = "median = mean"
)

双重差分（Difference-in-Differences）

现在我们说明如何使用上文描述的机制，在对比之间做两两比较，这是一类通常与“双重差分”（Difference-in-Differences）研究设计相关联的分析。

首先，我们模拟具有两个处理组、前后两期的数据：
