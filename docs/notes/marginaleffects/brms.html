贝叶斯模型

Bayes · marginaleffects 官方文档中译

来源：Vincent Arel-Bundock，marginaleffects 官方文档 · Bayes （GitHub 仓库，源文件 website/bonus/brms.qmd，revision 870f15a0）。 网站内容 © 2025 Vincent Arel-Bundock, All Rights Reserved；marginaleffects 软件代码依 GPL-3 许可。 本页为中文翻译，非原文，经原作者授权翻译并发布。 页面中的代码块由本站在渲染时真实执行。 原文中指向原书章节的交叉引用已改写为指向 marginaleffects.com 的链接（那些章节不在本次翻译范围内）。

marginaleffects 包提供了一些便捷函数，用于计算和展示由 brms 包估计的贝叶斯模型的预测值、对比和边际效应。为了计算这些量，marginaleffects 依赖 brms 包中的核心函数从后验分布中抽样。所使用的抽样类型由 predictions 或 slopes 函数的 type 参数控制：

  • type = "response"：使用 brms::posterior_epred 函数计算期望值的后验抽样。
  • type = "link"：使用 brms::posterior_linpred 函数计算线性预测值的后验抽样。
  • type = "prediction"：使用 brms::posterior_predict 函数计算后验预测分布的后验抽样。

predictions 和 slopes 函数还可以通过 ... 省略号将额外的参数传递给 brms 的预测函数。例如，如果 mod 是一个混合效应模型，下面这条命令将计算后验预测分布的 10 次抽样，同时忽略所有组水平效应：

predictions(mod, type = "prediction", ndraws = 10, re_formula = NA)

如需查看可用参数的完整列表，请参阅 brms 的文档：

?brms::posterior_epred
?brms::posterior_linpred
?brms::posterior_predict

后验汇总（概率）

考虑下面这个关于泰坦尼克号生还情况的逻辑回归模型：

library(brms)
library(posterior)
library(marginaleffects)
mod <- brm(survived ~ woman * age + passengerClass,
           family = bernoulli(link = "logit"),
           data = dat)

我们可以将 marginaleffects 的大多数函数应用到这个模型上，然后调用 get_draws() 从后验分布中提取抽样。例如，我们可以计算每个舱位等级的平均预测结局的后验抽样：

pred <- avg_predictions(mod, by = "passengerClass")

为了汇总后验分布，我们调用 get_draws() 函数，以 posterior 包定义的 rvar 格式提取抽样。然后，我们调用 posterior 包中的函数来汇总该分布。

draws <- get_draws(pred, "rvar")

# expected value of the posterior distribution
E(draws$rvar)
#> main_marginaleffect.1st main_marginaleffect.2nd main_marginaleffect.3rd 
#>               0.6375378               0.4407461               0.2613210

# quantiles of the posterior distribution
quantile2(draws$rvar, c(0.05, 0.5, 0.95))
#>     main_marginaleffect.1st main_marginaleffect.2nd main_marginaleffect.3rd
#> q5                0.6031112               0.4017000               0.2339028
#> q50               0.6376490               0.4404498               0.2612416
#> q95               0.6742563               0.4814036               0.2896911

# mass of the posterior above 0.5
Pr(draws$rvar > 0.5)
#> main_marginaleffect.1st main_marginaleffect.2nd main_marginaleffect.3rd 
#>                 1.00000                 0.00725                 0.00000

带乘法交互项的逻辑回归

加载所需的库，并从 Rdatasets 档案库 下载泰坦尼克号乘客数据：

library(marginaleffects)
library(brms)
library(ggplot2)
library(ggdist)

dat <- get_dataset("Titanic", "Stat2Data")
dat$survived <- ifelse(dat$survived == "yes", 1, 0)
dat$woman <- ifelse(dat$sex == "female", 1, 0)

拟合一个带乘法交互项的 logit 模型：

mod <- brm(survived ~ woman * age + passengerClass,
           family = bernoulli(link = "logit"),
           data = dat)

调整预测值

我们可以使用 predictions 函数计算结局变量（即在泰坦尼克号上生还的概率）的调整预测值。默认情况下，该函数会为数据集的每一行计算预测值：

predictions(mod)

为了可视化结局变量与某个自变量之间的关系，我们可以使用 plot_predictions 函数绘制条件调整预测值：

plot_predictions(mod, condition = "age")

使用 newdata 参数和 datagrid 函数，为一些用户指定的自变量取值计算调整预测值：

pred <- predictions(mod,
                    newdata = datagrid(woman = 0:1,
                                       passengerClass = c("1st", "2nd", "3rd")))
pred

get_draws 函数从模型的后验分布中抽样，并生成一个包含 drawid 和 draw 列的数据框。

pred <- get_draws(pred)
head(pred)

这种“长”格式的数据便于绘制结果图：

ggplot(pred, aes(x = draw, fill = factor(woman))) +
    geom_density() +
    facet_grid(~ passengerClass, labeller = label_both) +
    labs(x = "Predicted probability of survival", y = "", fill = "Woman")

斜率

使用 slopes() 可以为数据集的每一行计算边际效应（也就是回归方程的斜率），使用 avg_slopes() 可以计算“平均边际效应”，也就是所有观测层面斜率的平均值：

mfx <- slopes(mod)
mfx

计算边际效应时，将部分自变量固定为用户指定的取值，其余自变量固定在其均值：

slopes(
    mod,
    newdata = datagrid(
        woman = 1,
        passengerClass = "1st"))

计算并绘制条件边际效应：

plot_slopes(mod, variables = "woman", condition = "age")

get_draws 会生成一个包含 drawid 和 draw 列的数据集：

draws <- get_draws(mfx)

dim(draws)

head(draws)

我们可以使用这个数据集绘制结果图。例如，绘制当 woman 变量等于 0 或 1 时，age 的边际效应的后验密度：

mfx <- slopes(mod,
    variables = "age",
    newdata = datagrid(woman = 0:1)) |>
    get_draws()

ggplot(mfx, aes(x = draw, fill = factor(woman))) +
    stat_halfeye(slab_alpha = .5) +
    labs(x = "Marginal Effect of Age on Survival",
         y = "Posterior density",
         fill = "Woman")

随机效应模型

本节复现了 Andrew Heiss 的博客文章中一个随机效应模型的部分分析：“在多层贝叶斯模型中正确计算后验预测值和平均边际效应的指南。” 主要目的是演示 marginaleffects 的用法。关于下文计算的各个量的详细讨论，请参阅原文。

加载库并下载数据：

library(brms)
library(ggdist)
library(patchwork)
library(marginaleffects)

vdem_2015 <- read.csv("https://github.com/vincentarelbundock/marginaleffects/raw/main/website/data/raw/vdem_2015.csv")

head(vdem_2015)

拟合一个基础模型：

mod <- brm(
  bf(media_index ~ party_autonomy + civil_liberties + (1 | region),
     phi ~ (1 | region)),
  data = vdem_2015,
  family = Beta(),
  control = list(adapt_delta = 0.9))

后验预测值

为了计算自变量特定取值下的后验预测值，我们使用 newdata 参数和 datagrid 函数。我们还使用 type 参数来计算两种类型的预测值：一种考虑残差（观测层面）方差（prediction），另一种忽略残差方差（response）。

nd = datagrid(model = mod,
              party_autonomy = c(TRUE, FALSE),
              civil_liberties = .5,
              region = "Middle East and North Africa")
p1 <- predictions(mod, type = "response", newdata = nd) |>
    get_draws() |>
    transform(type = "Response")
p2 <- predictions(mod, type = "prediction", newdata = nd) |>
    get_draws() |>
    transform(type = "Prediction")
pred <- rbind(p1, p2)

提取后验抽样并绘图：

ggplot(pred, aes(x = draw, fill = party_autonomy)) +
    stat_halfeye(alpha = .5) +
    facet_wrap(~ type) +
    labs(x = "Media index (predicted)", 
         y = "Posterior density",
         fill = "Party autonomy")

边际效应与对比

正如边际效应 vignette中所说，对于自变量取值的每一种组合，都应该有一个独特的边际效应。这里，我们只考虑一种自变量取值组合：region 为“中东与北非”，civil_liberties 为 0.5。然后，我们计算边际效应后验分布的均值：

mfx <- slopes(mod,
                       newdata = datagrid(civil_liberties = .5,
                                          region = "Middle East and North Africa"))
mfx

使用 get_draws() 从边际效应的后验分布中提取抽样，并绘图：

mfx <- get_draws(mfx)

ggplot(mfx, aes(x = draw, y = term)) +
  stat_halfeye() +
  labs(x = "Marginal effect", y = "")

绘制以某个自变量为条件的边际效应图：

plot_slopes(mod,
         variables = "civil_liberties",
         condition = "party_autonomy")

连续自变量

pred <- predictions(mod,
                    newdata = datagrid(party_autonomy = FALSE,
                                       region = "Middle East and North Africa",
                                       civil_liberties = seq(0, 1, by = 0.05))) |>
        get_draws()

ggplot(pred, aes(x = civil_liberties, y = draw)) +
    stat_lineribbon() +
    scale_fill_brewer(palette = "Reds") +
    labs(x = "Civil liberties",
         y = "Media index (predicted)",
         fill = "")

这条线在公民自由不同取值下的斜率，可以通过下面的方式得到：

mfx <- slopes(mod,
    newdata = datagrid(
        civil_liberties = c(.2, .5, .8),
        party_autonomy = FALSE,
        region = "Middle East and North Africa"),
    variables = "civil_liberties")
mfx

绘图如下：

mfx <- get_draws(mfx)

ggplot(mfx, aes(x = draw, fill = factor(civil_liberties))) +
    stat_halfeye(slab_alpha = .5) +
    labs(x = "Marginal effect of Civil Liberties on Media Index",
         y = "Posterior density",
         fill = "Civil liberties")

slopes 函数可以通过省略号（...）把任意参数继续传递给 posterior_predict 函数。这样可以改变返回的预测值类型。例如，posterior_predict.brmsfit 方法的 re_formula=NA 参数将计算不包含任何组水平效应的边际效应：

mfx <- slopes(
    mod,
    newdata = datagrid(
        civil_liberties = c(.2, .5, .8),
        party_autonomy = FALSE,
        region = "Middle East and North Africa"),
    variables = "civil_liberties",
    re_formula = NA) |>
    get_draws()

ggplot(mfx, aes(x = draw, fill = factor(civil_liberties))) +
    stat_halfeye(slab_alpha = .5) +
    labs(x = "Marginal effect of Civil Liberties on Media Index",
         y = "Posterior density",
         fill = "Civil liberties")

Hurdle 模型

本节复现了 Andrew Heiss 又一篇精彩博客文章中的部分分析。

首先，我们使用 gapminder 包中的数据，在 brms 中估计一个带随机效应的 hurdle 模型： 704G

library(gapminder)
library(brms)
library(dplyr)
library(ggplot2)
library(ggdist)
library(cmdstanr)
library(patchwork)
library(marginaleffects)

set.seed(1024)

CHAINS <- 4
ITER <- 2000
WARMUP <- 1000
BAYES_SEED <- 1234

gapminder <- gapminder::gapminder |> 
  filter(continent != "Oceania") |> 
  # Make a bunch of GDP values 0
  mutate(prob_zero = ifelse(lifeExp < 50, 0.3, 0.02),
         will_be_zero = rbinom(n(), 1, prob = prob_zero),
         gdpPercap = ifelse(will_be_zero, 0, gdpPercap)) |> 
  select(-prob_zero, -will_be_zero) |> 
  # Make a logged version of GDP per capita
  mutate(log_gdpPercap = log1p(gdpPercap)) |> 
  mutate(is_zero = gdpPercap == 0)

mod <- brm(
  bf(gdpPercap ~ lifeExp + year + (1 + lifeExp + year | continent),
     hu ~ lifeExp),
  data = gapminder,
  backend = "cmdstanr",
  family = hurdle_lognormal(),
  cores = 2,
  chains = CHAINS, iter = ITER, warmup = WARMUP, seed = BAYES_SEED,
  silent = 2)

贝叶斯估计与可信区间

对于由 brms 或 rstanarm 等包生成的贝叶斯模型，marginaleffects 包的函数会把后验分布的中位数报告为其主要估计值。

默认的可信区间是等尾区间（分位数），默认用于确定分布中心的函数是中位数。用户可以通过设置全局选项来自定义所报告的区间类型。请注意，报告的估计值和区间都会随之略有变化：

library(insight)
library(marginaleffects)

mod <- insight::download_model("brms_1")

options(marginaleffects_posterior_interval = "hdi")
options(marginaleffects_posterior_center = mean)
avg_comparisons(mod)

options(marginaleffects_posterior_interval = "eti")
options(marginaleffects_posterior_center = stats::median)
avg_comparisons(mod)

非线性假设检验

我们首先估计一个模型：

mod <- brm(am ~ mpg + hp, data = mtcars, family = bernoulli(),
           seed = 1024, silent = 2, chains = 4, iter = 1000)

请注意，我们可以用两种不同的方式计算平均对比：使用 avg_comparisons() 函数，或者使用 comparison 参数：

avg_comparisons(mod)

comparisons(mod, comparison = "differenceavg")

现在，我们使用 hypothesis 参数来比较 comparisons() 输出结果中的第一行和第二行：

comparisons(
    mod,
    comparison = "differenceavg",
    hypothesis = "b2 - b1 = 0.2")

brms 包的 hypothesis() 函数也可以执行非线性假设检验，并生成一些方便的统计量和汇总结果。这个函数接受一个 D×P 的后验分布抽样矩阵，其中 D 是抽样次数，N 是参数个数。我们可以用 get_draws(x, shape = "DxP") 得到这样一个矩阵，只需在我们的操作链中再加上几个调用即可：

avg_comparisons(mod, comparison = "differenceavg") |>
    get_draws(shape = "DxP") |>
    brms::hypothesis("b2 - b1 > .2")

手动计算：反事实比较

下面是一个手动复现 comparisons() 输出结果的示例，希望它能帮助一些读者理解其背后的原理：

library(marginaleffects)
data("ChickWeight")

mod = brm(data = ChickWeight,
          weight ~ Time * Diet + (Time|Chick),
          seed = 123,
          backend = "cmdstanr")

# NA
comparisons(mod,
    variables = "Time",
    by = "Diet",
    re_formula = NA)

d0 <- ChickWeight
d1 <- transform(d0, Time = Time + 1)
p0 <- posterior_epred(mod, newdata = d0, re_formula = NA)
p1 <- posterior_epred(mod, newdata = d1, re_formula = NA)
p <- p1 - p0
cmp <- apply(p, 1, function(x) tapply(x, ChickWeight$Diet, mean))
apply(cmp, 1, quantile, prob = .025)

# NULL
comparisons(mod,
    variables = "Time",
    by = "Diet",
    re_formula = NULL)

d0 <- ChickWeight
d1 <- transform(d0, Time = Time + 1)
p0 <- posterior_epred(mod, newdata = d0, re_formula = NULL)
p1 <- posterior_epred(mod, newdata = d1, re_formula = NULL)
p <- p1 - p0
cmp <- apply(p, 1, function(x) tapply(x, ChickWeight$Diet, mean))
apply(cmp, 1, quantile, prob = .025)
