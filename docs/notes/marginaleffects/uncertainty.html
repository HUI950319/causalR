混合效应模型：Satterthwaite 与 Kenward-Roger 校正

对线性混合效应模型，我们可以像前几章那样应用 Satterthwaite 和 Kenward-Roger 校正：

library(marginaleffects)
library(patchwork)
library(lme4)

dat <- mtcars
dat$cyl <- factor(dat$cyl)
dat$am <- as.logical(dat$am)
mod <- lmer(mpg ~ hp + am + (1 | cyl), data = dat)

使用经典标准误和 z 统计量、在均值处计算的边际效应：

slopes(mod, newdata = "mean")
#> 
#>  Term     Contrast Estimate Std. Error     z Pr(>|z|)    S   2.5 %  97.5 %
#>    am TRUE - FALSE   4.6661     1.1343  4.11   <0.001 14.6  2.4430  6.8892
#>    hp dY/dX         -0.0518     0.0115 -4.52   <0.001 17.3 -0.0743 -0.0294
#> 
#> Type: response

使用 Kenward-Roger 调整后的方差-协方差矩阵和自由度、在均值处计算的边际效应：

slopes(mod,
    newdata = "mean",
    vcov = "kenward-roger")
#> 
#>  Term     Contrast Estimate Std. Error     t Pr(>|t|)   S  2.5 %  97.5 %   Df
#>    am TRUE - FALSE   4.6661     1.2824  3.64   0.0874 3.5 -1.979 11.3113 1.68
#>    hp dY/dX         -0.0518     0.0152 -3.41   0.0964 3.4 -0.131  0.0269 1.68
#> 
#> Type: response

同样的选项可以用在本包的任意核心函数中，例如：

plot_predictions(mod, condition = "hp", vcov = "satterthwaite")

数值导数：对步长的敏感性

dat <- get_dataset("penguins", "palmerpenguins")
dat$large_penguin <- ifelse(dat$body_mass_g > median(dat$body_mass_g, na.rm = TRUE), 1, 0)
mod <- glm(large_penguin ~ bill_length_mm * flipper_length_mm + species, data = dat, family = binomial)

marginaleffects 在两种场合使用数值导数：

  1. 估计 slopes() 函数报告的偏导数。
    • 中心有限差分
    • \(\frac{f(x + \varepsilon_1 / 2) - f(x - \varepsilon_1 / 2)}{\varepsilon_1}\)，其中我们对所关心的预测变量求导，而 \(f\) 是 predict() 函数。
  2. 用 Delta 方法估计标准误。
    • 前向有限差分
    • \(\frac{g(\hat{\beta}) - g(\hat{\beta} + \varepsilon_2)}{\varepsilon_2}\)，其中我们对模型的系数求导，而 \(g\) 是某个返回所关心的量（斜率、对比、预测值等）的 marginaleffects 函数。

注意这两种场合所用的步长可以不同。如果变量和系数的量纲差别很大，那么为 \(\varepsilon_1\) 和 \(\varepsilon_2\) 取不同的值可能是合理的。

默认情况下，\(\varepsilon_1\) 被设为求导所针对变量取值范围的 1e-4 倍。默认情况下，\(\varepsilon_2\) 被设为 1e-8 与「最小绝对系数估计值的 1e-4 倍」二者中的较大值。（这些取法都是任意的，但我发现在实践中，更小的值可能产生不稳定的结果。）

\(\varepsilon_1\) 可以通过 slopes() 函数的 eps 参数来控制。\(\varepsilon_2\) 则可以通过设置一个全局选项来控制，该选项告诉 marginaleffects 用 numDeriv 包而不是它自己的内部函数来计算雅可比矩阵。这样可以更好地控制步长，同时还能用上其他求导方法，比如 Richardson 方法。要使用 numDeriv，我们先定义一个参数列表，它会被转发给 numDeriv::jacobian：

avg_slopes(mod, variables = "bill_length_mm")
#> 
#>  Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
#>    0.0279    0.00595 4.69   <0.001 18.4 0.0162 0.0395
#> 
#> Term: bill_length_mm
#> Type: response
#> Comparison: dY/dX

options(marginaleffects_numDeriv = list(method = "Richardson"))
avg_slopes(mod, variables = "bill_length_mm")
#> 
#>  Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
#>    0.0279    0.00595 4.69   <0.001 18.4 0.0162 0.0395
#> 
#> Term: bill_length_mm
#> Type: response
#> Comparison: dY/dX

options(marginaleffects_numDeriv = list(method = "simple", method.args = list(eps = 1e-3)))
avg_slopes(mod, variables = "bill_length_mm")
#> 
#>  Estimate Std. Error     z Pr(>|z|)   S 2.5 % 97.5 %
#>    0.0279      0.568 0.049    0.961 0.1 -1.09   1.14
#> 
#> Term: bill_length_mm
#> Type: response
#> Comparison: dY/dX

options(marginaleffects_numDeriv = list(method = "simple", method.args = list(eps = 1e-5)))
avg_slopes(mod, variables = "bill_length_mm")
#> 
#>  Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
#>    0.0279    0.00601 4.64   <0.001 18.1 0.0161 0.0396
#> 
#> Term: bill_length_mm
#> Type: response
#> Comparison: dY/dX

options(marginaleffects_numDeriv = list(method = "simple", method.args = list(eps = 1e-7)))
avg_slopes(mod, variables = "bill_length_mm")
#> 
#>  Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
#>    0.0279    0.00595 4.68   <0.001 18.4 0.0162 0.0395
#> 
#> Term: bill_length_mm
#> Type: response
#> Comparison: dY/dX

注意，使用不同的步长时，标准误可能有相当大的变化。分析者应当养成好习惯，考察自己的结果对这一设置的敏感性。

现在，我们用原生 R 代码来完整演示标准误的计算过程。首先，我们选定两个步长：

eps1 <- 1e-5 # slope
eps2 <- 1e-7 # delta method

s <- slopes(mod, newdata = head(dat, 3), variables = "bill_length_mm", eps = eps1)
print(s[, 1:5], digits = 6)
#> 
#>   Estimate Std. Error
#>  0.0179765 0.00875779
#>  0.0359630 0.01271744
#>  0.0849071 0.02128459
#> 
#> Term: bill_length_mm
#> Comparison: dY/dX

按下面这些步骤，我们可以手工得到同样的估计值：

linkinv <- mod$family$linkinv

## increment the variable of interest by h
dat_hi <- transform(dat, bill_length_mm = bill_length_mm + eps1)

## model matrices: first 3 rows
mm_lo <- insight::get_modelmatrix(mod, data = dat)[1:3,]
mm_hi <- insight::get_modelmatrix(mod, data = dat_hi)[1:3,]

## predictions
p_lo <- linkinv(mm_lo %*% coef(mod))
p_hi <- linkinv(mm_hi %*% coef(mod))

## slopes
(p_hi - p_lo) / eps1
#>         [,1]
#> 1 0.01797653
#> 2 0.03596304
#> 3 0.08490712

要得到标准误，我们需要构造一个雅可比矩阵，其中每一列存放向量值斜率函数对各个系数的导数。仍以同一个例子为例：

b_lo <- b_hi <- coef(mod)
b_hi[1] <- b_hi[1] + eps2

dydx_lo <- (linkinv(mm_hi %*% b_lo) - linkinv(mm_lo %*% b_lo)) / eps1
dydx_hi <- (linkinv(mm_hi %*% b_hi) - linkinv(mm_lo %*% b_hi)) / eps1
(dydx_hi - dydx_lo) / eps2
#>         [,1]
#> 1 0.01600803
#> 2 0.02772782
#> 3 0.02275957

这给出了 \(J\) 的第一列，而完整的矩阵可以从 marginaleffects 对象的属性中取回：

J <- components(s, "jacobian")
J
#>      (Intercept) bill_length_mm flipper_length_mm speciesChinstrap speciesGentoo bill_length_mm:flipper_length_mm
#> [1,]  0.01600803      0.6775552          2.897224                0             0                         122.6914
#> [2,]  0.02764455      1.1961404          5.153072                0             0                         222.4988
#> [3,]  0.02275957      1.1491919          4.440004                0             0                         224.0833

要构造完整的矩阵，我们只需依次遍历各个系数，逐个对其做增量即可。最后，标准误由下式得到：

sqrt(diag(J %*% vcov(mod) %*% t(J)))
#> [1] 0.008757785 0.012717441 0.021284589

这与我们最初得到的标准误一致：

print(s[, 1:5], digits = 7)
#> 
#>    Estimate  Std. Error
#>  0.01797650 0.008757785
#>  0.03596299 0.012717441
#>  0.08490708 0.021284589
#> 
#> Term: bill_length_mm
#> Comparison: dY/dX

恢复默认设置：

options(marginaleffects_numDeriv = NULL)

注意，对这个模型，我们的默认结果与 margins 生成的结果非常接近——但并不完全相同。正如预期的那样，对这个模型，margins 的结果同样对 eps 的取值非常敏感：

library(margins)
margins(mod, variables = "bill_length_mm", data = head(dat, 3), unit_ses = TRUE)$SE_dydx_bill_length_mm

margins(mod, variables = "bill_length_mm", data = head(dat, 3), eps = 1e-4, unit_ses = TRUE)$SE_dydx_bill_length_mm

margins(mod, variables = "bill_length_mm", data = head(dat, 3), eps = 1e-5, unit_ses = TRUE)$SE_dydx_bill_length_mm
