总边际效应

Total Marginal Effects · marginaleffects 官方文档中译

来源：Vincent Arel-Bundock，marginaleffects 官方文档 · Total Marginal Effects （GitHub 仓库，源文件 website/bonus/total_marginal_effect.qmd，revision 870f15a0）。 网站内容 © 2025 Vincent Arel-Bundock, All Rights Reserved；marginaleffects 软件代码依 GPL-3 许可。 本页为中文翻译，非原文，经原作者授权翻译并发布。 页面中的代码块由本站在渲染时真实执行。 原文中指向原书章节的交叉引用已改写为指向 marginaleffects.com 的链接（那些章节不在本次翻译范围内）。

Mize 和 Han (2025) 提出了若干策略，用来汇总一个分类自变量不同水平的效应，或者一个自变量在分类因变量不同水平上的效应。本笔记用 marginaleffects 实现了其中的一部分策略。这些量的定义和计算都很简单。关于动机和解读，请参阅发表在 Sociological Science 上的原文。

数据与模型

首先，我们加载所需的包，以及来自「综合社会调查」（General Social Survey）的数据。我们关心的是变量 race4 和 woman 对变量 conserv 的效应。由于 conserv 是二值变量，我们拟合一个 logit 模型。

library(marginaleffects) # marginal effects
library(modelsummary) # regression summaries
library(nanoparquet) # read data
library(nnet) # multinomial logit
library(future.apply) # parallel bootstrap
plan(multisession)
options(marginaleffects_parallel_inferences = TRUE)
options(width = 300)


# download data
gss <- read_parquet(url("https://marginaleffects.com/data/Mize_Han_GSS.parquet"))

# fit binary logit model
mod <- glm(conserv ~ woman + race4 + class, data = gss, family = binomial(link = "logit"))

平均边际效应不平等

Mize 和 Han (2025) 把「平均边际效应不平等」定义为各个边际效应绝对值的平均。这里对分类预测变量而言，「边际效应」这个说法指的就是 原书《反事实比较》一章 中所说的「反事实比较」。首先，我们计算 race4 这个预测变量每一个水平上的边际效应。

cmp <- avg_comparisons(mod,
  variables = list(race4 = "pairwise"))
cmp

这些结果表明，从 White 变为 Black，与 conserv 等于 1 的概率下降 16 个百分点相关联。

这些边际效应绝对值的平均，就是「平均边际效应不平等」：

加权平均边际效应不平等

Mize 和 Han (2025) 认为，当样本中不同类别的出现频率存在严重不平衡时，上一节计算的那个量可能并不合适。他们提出的补救办法，是按照各个对比在样本中所占的相对比例对其加权。首先，我们根据样本比例构造一个权重向量。

weights <- prop.table(table(gss$race4))
weights <- c(
  (weights["Black"] + weights["White"]) / 3,
  (weights["Hispanic"] + weights["Black"]) / 3,
  (weights["Hispanic"] + weights["Other"]) / 3,
  (weights["Hispanic"] + weights["White"]) / 3,
  (weights["Other"] + weights["Black"]) / 3,
  (weights["Other"] + weights["White"]) / 3
)

接下来，我们定义一个计算加权均值的 wmean() 函数，并把它传给 hypothesis 参数。

wmean <- function(x) weighted.mean(x, weights)
avg_comparisons(mod,
  variables = list(race4 = "pairwise"),
  hypothesis = ~ I(wmean(abs(x)))
)

 Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
    0.109     0.0135 8.03   <0.001 49.9 0.0821  0.135

Type: response

模型内部的比较

Mize 和 Han (2025) 还提出了一种比较不同分类预测变量的边际效应的策略。思路很简单。首先，我们为每一个预测变量计算平均边际效应不平等。做法是用 variables 参数为两个所关心的预测变量（race4 和 woman）计算对比。然后用 hypothesis 参数计算所关心的量，注意要在公式右端加上 |term，以便对这两个项分别计算所关心的量。

cmp <- avg_comparisons(mod,
  variables = list(race4 = "pairwise", woman = "pairwise"),
  hypothesis = ~ I(mean(abs(x))) | term
)
cmp

  Term Estimate Std. Error    z Pr(>|z|)    S  2.5 % 97.5 %
 race4   0.0838     0.0130 6.45   <0.001 33.1 0.0583  0.109
 woman   0.0699     0.0156 4.48   <0.001 17.0 0.0393  0.100

Type: response

我们发现 race4 的估计值比 woman 的更大。这个差异在统计上显著吗？这两个估计值彼此可区分吗？为了检验这一点，我们把上面的命令用管道传给 hypotheses() 函数。

avg_comparisons(mod,
  variables = list(race4 = "pairwise", woman = "pairwise"),
  hypothesis = ~ I(mean(abs(x))) | term) |>
  hypotheses(~pairwise)

        Hypothesis Estimate Std. Error      z Pr(>|z|)   S   2.5 % 97.5 %
 (woman) - (race4)  -0.0139      0.021 -0.661    0.509 1.0 -0.0551 0.0273

答案是否定的。虽然这两个估计值乍看之下似乎不同，但我们无法拒绝二者相等这一原假设。

跨模型的比较

设想我们希望把 woman 这个预测变量在一个控制了 race 的模型中的边际效应，与 woman 在一个不控制 race 的模型中的边际效应作比较。做法是拟合两个模型，然后比较各自的边际效应。首先，我们定义一个 estimator 函数，它负责拟合模型，并返回一个带有所关心差值的 marginaleffects 对象。1

estimator <- function(data) {
  # fit the two models we wish to compare
  mod1 <- glm(conserv ~ woman + class + race4, data = data, family = binomial(link = "logit"))
  mod2 <- glm(conserv ~ woman + class, data = data, family = binomial(link = "logit"))
  # compute the marginal effects in both models
  mfx1 <- avg_comparisons(mod1, variables = "woman", vcov = FALSE)
  mfx2 <- avg_comparisons(mod2, variables = "woman", vcov = FALSE)
  # compare the two models and store the difference in the estimate column
  # estimator() must return a marginaleffects object
  mfx1$estimate <- mfx1$estimate - mfx2$estimate
  return(mfx1)
}

estimator(gss)

 Estimate
  0.00636

Term: woman
Type: response
Comparison: Women - Men

最后，我们用 inferences() 函数对整个流程做自助法，得到置信区间。

inferences(gss, method = "rsample", estimator = estimator)

 Estimate   2.5 % 97.5 %
  0.00636 0.00195 0.0113

Term: woman
Type: response
Comparison: Women - Men

Estimate 列中报告的数值，表示 woman 在第一个模型中的边际效应与 woman 在第二个模型中的边际效应之差。置信区间则表示这个差值的不确定性。
