model4you 包函数手册

基于 0.9-9 的逐函数用法说明与本机实测

model4you 把一个已经拟合好的参数模型当作输入，用 model-based recursive partitioning（MOB）的思路去找”这个模型的参数在哪些人群里不一样”， 从而得到分层模型（树）和个体化模型（森林）。 它的典型用途是临床试验的亚组分析与个体化治疗效应估计。

本部分是该包的函数用法手册，逐个覆盖 CRAN 参考手册 （refman） 里的全部 22 个帮助主题，包括三个以 . 开头的内部函数。 每页给出参数逐项说明、可直接运行的代码、返回对象的结构， 以及本机实际运行后发现的默认值陷阱与失效路径。

核对环境与证据边界

本手册核对截止 2026 年 9 月 20 日，环境为：

项目 值
包版本 model4you 0.9-9（2026-02-12 发布，2026-02-05 打包）
R Windows R 4.4.3
关键依赖 partykit 1.3.0、survival 3.8-12、sandwich 3.1-3、ggplot2 4.0.2
示例数据 TH.data::GBSG2（n = 686，299 个事件）、模拟数据

证据分三级，正文中逐处标明：

  1. 文档——包自带帮助页与 DESCRIPTION/NEWS 的原文；
  2. 源码——本机已安装包的函数体（model4you::: 可复核）；
  3. 实测——在上述环境下实际运行的输出。

本手册不在本站渲染时执行代码：所有代码块都是静态的， 展示的输出是在上述环境中单独运行后粘贴回来的。 因此页面里的数字可以按种子复现，但森林类结果存在随机性， 本手册对每处随机结果都标注了种子与 ntree。

重要三处与官方文档不一致的实测结论

在展开之前先给出结论，它们影响所有使用者：

  1. pmtree() 的 ... 不会传给模型拟合。 帮助页写的是 “additional parameters passed on to model fit such as weights”， 但函数体里 ... 从未被使用，pmtree(mod, weights = w) 既不报错也不生效。 见第 1 页。
  2. pmodel(x = <权重矩阵>) 这条文档明确支持的路径是坏的， 必定抛出 $ operator is invalid for atomic vectors。 见第 4 页。
  3. pmforest() 的默认 control 不适合直接拿去做 varimp()： 默认 mincriterion = 0 接受任何分裂，终末节点可能只剩单一治疗组， varimp() 会间歇性报错（同一份数据 5 个种子里 1 个失败）， 且噪声变量的重要性被系统性抬高。包作者自己的论文复现脚本用的是 mincriterion = 0.95, minsplit = 40, minbucket = 30，不是这个默认值。 见第 5 页。

这个包在做什么

用一句话概括：把”模型参数是否随协变量变化”这个问题，交给递归分割来回答。

给定基模型 \(M\)（例如 survreg(Surv(time, cens) ~ horTh)）， 它只有一个二值协变量——治疗 \(A\)。这个模型假设所有人的治疗效应相同：

\[ \log T = \beta_0 + \beta_1 \cdot \mathbb{1}(A = 1) + \sigma \varepsilon \]

model4you 用其余变量 \(Z\)（zformula）去检验 \((\beta_0, \beta_1)\) 是否稳定：

  • pmtree()：按 \(Z\) 递归分割，每个终末节点重新拟合 \(M\)， 得到少数几个亚组和各自的 \(\hat\beta_1\) —— 这是分层模型（stratified model）；
  • pmforest() + pmodel()：建很多棵这样的树， 用森林的共现频率定义”谁和谁相似”，对每个个体用其邻居加权重新拟合 \(M\)， 得到 每人一个 \(\hat\beta_1\) —— 这是个体化模型（personalised model）。

三个层次的关系：

基模型 M                 全体共用一组参数
   │  pmtree()
   ▼
分层模型（树）            少数亚组，每组一组参数，规则可读
   │  pmforest() + pmodel()
   ▼
个体化模型（森林）        每人一组参数，无规则，可做依赖图与变量重要性
警告参数异质性 ≠ 因果的治疗效应异质性

model4you 检验的是基模型参数的不稳定性。默认情况下， 不稳定性检验同时针对截距和治疗系数（源码 .modelfit() 的 parm 参数 控制这一点，但 pmtree() / pmforest() 都没有把它暴露出来）。 因此树可能仅仅因为基线风险不同（纯预后变量）就切一刀， 这不是效应修饰。同一问题在本书 效应修饰的效应尺度 一页里有实证：GBSG2 上的纯预后变量 pnodes 在相乘尺度上照样”显著”。

此外，model4you 不做任何混杂校正。在观察性数据上， 基模型必须自己带上校正（或用加权数据），否则得到的是关联的异质性。

支持哪些基模型

DESCRIPTION 只承诺 lm()、glm()、survreg()。实测与源码补充如下：

基模型 建树 coef/logLik objfun varimp pmtest 说明
lm() ✅ logLik ✅ ✅（负平方误差，不是对数似然） ✅ ✅ logLik.pmodel_identity 对 lm 明确 stop()
glm() ✅ ✅ ✅（对数似然贡献） ✅ ✅ 最顺畅的一条路径
survreg() ✅ ✅ ✅ ✅（但不稳定，见第 5 页） ❌ 无 simulate.survreg 官方生存示例都走这条
coxph() ✅ ✅ ❌ 无 objfun.coxph 方法 ❌ 默认 risk 依赖 objfun，会报错 ❌ 无 simulate.coxph .modelfit() 里有 coxph 的 score 特判，NEWS 0.9-6 也为它改过代码，属于半支持

最右两列合起来是一个值得先知道的限制：生存结局上，model4you 能建树、 能给个体化系数，但两个推断工具（变量重要性、异质性检验）都用不了 ——varimp() 只在 survreg 上可用且不稳定，pmtest() 两种生存模型都不可用。

coxph() 这一栏是本手册的实测补充：它能建树、能取系数、能算 logLik， 但 objfun(tr, sum = TRUE) 会报 no applicable method for 'objfun' applied to an object of class "coxph"， 连带 varimp() 的默认 risk 也不可用。详见 2. pmtree 的方法 与 7. objfun。

最小可运行例子

library("model4you")
library("survival")
data("GBSG2", package = "TH.data")

## 1. 基模型：只有治疗一个协变量，必须 model = TRUE
bmod <- survreg(Surv(time, cens) ~ horTh, data = GBSG2, model = TRUE)

## 2. 分层模型
tr <- pmtree(bmod, data = GBSG2)
print(tr)

## 3. 个体化模型（ntree 实际使用时应更大）
set.seed(123)
frst <- pmforest(bmod, data = GBSG2, ntree = 50)
pm   <- pmodel(frst)          # 686 × 2 的系数矩阵
summary(pm[, "horThyes"])     # 每人一个 AFT 治疗效应

print(tr) 的实际输出（本机实测）：

注记复现脚本比帮助页更能说明”该怎么设参数”

2017 年那份脚本里，作者建森林用的是

pmforest(bm, ntree = 100,
         control = ctree_control(teststat = "max", testtype = "Univ",
                                 mincriterion = 0.95, minsplit = 40,
                                 minbucket = 30, lookahead = TRUE))

而 pmforest() 的默认值是 teststat = "quad"、mincriterion = 0、 没有 minsplit/minbucket 约束。作者自己不用默认值这件事， 本身就是对默认值的一个提示。
