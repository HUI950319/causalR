快速筛选效应修饰变量的 R 包

四条技术路线、筛选指标分类与两阶段流程

全面检索后可以把”快速筛选某个治疗/暴露 \(A\) 的效应修饰变量”的 R 方法归成 4 条路线。其中一些在上一篇没有提到，尤其值得加入的是 BioPred、SubgrpID、CRE、tehtuner、subscreen、SIDES/rsides、samTEMsel。

先给结论：如果你的目标是先从几十个变量快速筛出候选 effect modifiers，再进入正式验证，我最关注的不是单一方法，而是下面三类指标：

\[ \boxed{\text{effect-modifier-specific VIM}} \]

\[ \boxed{\text{CATE/HTE model variable importance}} \]

\[ \boxed{\text{treatment}\times X\text{ regularized selection}} \]

二、第一类：真正的”效应修饰变量重要性”

这是我认为最符合你问题本身的一类。

1. unihtee::unihtee()

目前很值得重点关注。

它不是问：

这个变量是否预测 Y？

而是直接定义：

这个变量对于 treatment-effect modification 有多重要？

其核心 estimand 是：

TEM-VIP

Treatment Effect Modifier Variable Importance Parameter。

unihtee() 会针对每个候选变量做 TEM-VIP inference，可以用于：

  • continuous outcome
  • binary outcome
  • time-to-event
  • observational data
  • binary exposure/treatment

并且有 absolute 和 relative effect scale。官方示例就是在观察性数据里，从多个 pretreatment covariates 中识别真正的 treatment effect modifiers。(GitHub)

所以：

20–100个候选变量
        ↓
unihtee()
        ↓
TEM-VIP
SE
Z
P
        ↓
排序

非常符合”快速筛选”。

与普通 RF importance 最大区别

普通 RF importance：

\[ X_j \rightarrow Y \]

而 TEM-VIP：

\[ X_j \rightarrow \text{heterogeneity of }A\rightarrow Y \]

因此概念更加干净。

三、uniCATE：单变量快速筛 modifier 很强

uniCATE::unicate()

核心 VIM 是：

\[ \beta_j \]

即用变量 \(X_j\) 对 CATE 做一维线性近似，其 slope 的绝对值反映 treatment-effect modification strength。

官方定义就是：

variable importance parameter = univariate CATE linear approximation slope。

并给出 formal hypothesis tests。(Insights Engineering)

因此非常适合：

age
BMI
HE4
CA125
stage
...
 ↓
逐个计算 modifier strength
 ↓
Estimate / SE / P

生存结局

直接有：

sunicate()

专门针对：

right-censored time-to-event outcome

可以筛选 survival treatment-effect modifiers。(GitHub)

这对 OS/PFS 非常有吸引力。

但需要注意：

uniCATE 的主要设计背景是 RCT。

如果是观察性数据，我会更倾向 unihtee。

四、tidyhte：R²-loss VIMP

这个也是非常标准的”变量重要性”思路。

核心：

add_vimp()

底层：

calculate_vimp()

定义大体是：

\[ VIMP_j = R^2_{\text{full}} - R^2_{\text{without }X_j} \]

即：

删除 \(X_j\) 后，解释 treatment-effect heterogeneity 的能力下降多少？

官方就是这样定义的。(Rdrr.io)

因此：

\[ VIMP_j\gg0 \]

提示：

\[ X_j \]

很可能是重要 modifier。

更重要的是它基于 Kennedy 的 doubly robust learner：

\[ Outcome\ model + Propensity\ model \rightarrow DR\ pseudo-outcome \]

然后再计算 HTE VIMP。tidyhte 明确支持 experimental 和 observational data。(Cran)

优点

相对于 GRF：

VIMP 有明确 population quantity 的解释。

因此做论文方法会比单纯 grf::variable_importance() 更漂亮。

五、GRF：最快、最成熟的 CATE screening 方法之一

基本：

cf <- causal_forest(X, Y, W)

variable_importance(cf)

variable_importance()

需要特别注意定义。

它实际上是：

每个变量在 forest 不同深度被用于 split 的加权频率。

不是 permutation importance，也不是 TE-VIM。(GRF Labs)

所以：

\[ VI_j \]

高表示这个变量在：

\[ \tau(X) \]

的 tree splitting 中经常很重要。

优点

特别快、方便：

50 variables
    ↓
causal_forest
    ↓
variable_importance
    ↓
排名

缺点

不能直接解释：

VI = 0.25 就意味着 effect modification = 0.25。

也没有一个正式的：

\[ H_0:VIM_j=0 \]

P 值。

六、GRF 中更适合”正式检验 modifier”的是 best_linear_projection()

GRF 官方把：

best_linear_projection()

作为 CATE analysis tool。(GRF Labs)

基本思想：

先通过 causal forest 得到：

\[ \tau(X) \]

然后研究：

\[ \tau(X) \approx \beta_0+ \beta_1X_1+ \cdots+ \beta_pX_p \]

可以得到：

  • coefficient
  • standard error
  • CI
  • P value

所以很适合：

variable_importance()
       ↓
快速排名
       ↓
选 Top 5–10
       ↓
best_linear_projection()
       ↓
正式检查 modifier

我认为这是 GRF 很合理的使用方式。

七、OS/PFS：GRF 有独立 survival 版本

causal_survival_forest()

支持：

RMST CATE

\[ E[\min(T(1),h)-\min(T(0),h)\mid X] \]

或者：

survival probability CATE

\[ P(T(1)>h\mid X)-P(T(0)>h\mid X) \]

并且可以输入/自动估计 treatment propensity W.hat。(GRF Labs)

训练以后同样可以：

variable_importance(csf)

快速看 modifier ranking。

所以对你的 OS/PFS：

\[ \boxed{ causal\_survival\_forest + variable\_importance } \]

是目前非常实用的一条初筛路线。

八、一个我这次检索中特别建议加入的包：BioPred

这个包很符合你说的：

快速寻找 predictive biomarker / effect modifier

主要函数：

XGBoostSub_con()
XGBoostSub_bin()
XGBoostSub_sur()

分别适合：

  • continuous
  • binary
  • survival

其方法是：

\[ \boxed{ A\text{-learning / Weight-learning} + XGBoost } \]

BioPred 将 modified-loss framework 与 XGBoost 结合，用于 individualized treatment rule 和 predictive biomarker discovery。(PubMed Central (PMC))

直接有一个你想要的函数

predictive_biomarker_imp()

它会输出：

predictive biomarker importance ranking

底层使用：

xgboost::xgb.importance()

计算 importance。(PubMed Central (PMC))

例如：

HE4       0.38
Stage     0.27
BMI       0.16
CA125     0.11
Age       0.08

这就特别适合初筛。

而且有：

XGBoostSub_sur()

所以对 PFS/OS 相当友好。(布里斯托大学统计网站)

九、model4you 其实也有你要的 VIM

我们前面更多讨论：

pmtree()

但实际上还有：

pmforest()

以及：

varimp()

即：

varimp.pmforest()

其 variable importance 是 permutation VIM。

算法会扰乱某一个变量，然后检查模型 performance/objective function 下降多少。

默认使用类似 mean decrease in accuracy 的 importance；还支持 conditional permutation importance。(Rdrr.io)

所以：

pmforest
   ↓
varimp()
   ↓
潜在 effect modifier ranking

这比只看一棵 MOB tree 更适合快速筛选。

十、StratifiedMedicine 其实专门有”过滤变量”函数

这个之前容易忽略。

filter_train()

直接就是：

Identify variables of interest.

支持：

Elastic Net

filter = "glmnet"

以及：

Random Forest importance

filter = "ranger"

(Rdrr.io)

更重要的是，它可以强制加入：

\[ Treatment\times X \]

例如：

\[ Y\sim X+A\times X \]

然后用 Elastic Net 筛掉：

\[ \beta_{A\times X}=0 \]

的变量。

官方 vignette 就展示了通过 treatment interaction 识别 prognostic + predictive variables。(CRAN镜像)

所以可以很简单地：

filter_train(
    Y,
    A,
    X,
    family = "survival",
    filter = "glmnet",
    hyper = list(
        interaction = TRUE
    )
)

它支持：

gaussian
binomial
survival

生存结局内部可以用 Cox elastic net。(Rdrr.io)

这一点对你非常实用。

十一、SubgrpID：被低估的 clinical subgroup screening 包

最新版已经到：

0.14，2026-03-10。(CRAN镜像)

它直接实现：

Sequential BATTing

即：

bootstrapping + aggregating thresholds from trees。

而且：

variable selection automatically built-in

并最终得到 multivariate predictive biomarker signature。(CRAN镜像)

主函数：

SubgrpID()

其中可以直接指定：

pre.filter
filter.method

过滤方法包括：

univariate
glmnet
unicart

而且支持：

continuous
binary
survival

。(R 搜索)

因此对于：

从 30–100 个 clinical variables 中先缩小到几个 predictive biomarkers

很好用。

十二、FindIt：非常纯粹的 treatment×variable selection

主函数：

FindIt()

可以指定：

model.main

作为 main/prognostic variables，

和：

model.int

作为 treatment interaction candidates。(R 搜索)

其方法特点是：

Adapted SVM + separate LASSO penalties

分别惩罚：

  • baseline/prognostic parameters
  • causal heterogeneity parameters

因此：

\[ \beta_X \]

和：

\[ \beta_{A\times X} \]

不会混为一谈。(今井浩介的主页)

这点其实非常适合你：

我只想找谁修饰 A 的效应，而不是谁预测 Y。

十三、samTEMsel：高维 + 非线性 modifier selection

这个更方法学化。

全称：

Sparse Additive Models for Treatment Effect-Modifier Selection

它直接建立：

\[ \tau(X) = \sum_j f_j(X_j) \]

通过 sparse additive structure 让不重要的：

\[ f_j(X_j) \]

变成 0。

因此既能：

变量选择

又能：

非线性 modifier modelling

比如真实关系可能不是：

\[ A\times Age \]

线性，而是：

\[ A\times f(Age) \]

该方法采用 back-fitting + sparsity constraints 选择 treatment effect modifiers。作者提供 samTEMsel R 代码。(OUP Academic)

十四、CRE：不是变量排名，而是”规则重要性”

主函数：

CRE::cre()

特别有意思。

第一步先估计 ITE/pseudo-outcome，可选择：

  • AIPW
  • causal forest
  • BART
  • S-learner
  • T-learner
  • X-learner

。(R 搜索)

然后：

很多 trees
   ↓
产生大量 candidate rules
   ↓
Stability Selection
   +
LASSO
   ↓
选稳定 HTE rules

例如：

Age < 63
HE4 > 500
Stage III/IV & BMI < 24

CRE 专门把 discovery 和 inference 分开，并使用 honest splitting。(PubMed Central (PMC))

因此它不是：

“Age importance = 0.3”

而是：

哪些临床规则稳定解释 HTE？

对于临床解释非常好。

十五、tehtuner：Virtual Twins + Type-I error control

这是另一个值得加入的方法。

主函数：

tunevt()

Step 1

先估计每个人：

\[ \widehat{CATE}_i \]

可以使用：

  • LASSO
  • MARS
  • random forest
  • SuperLearner

Step 2

再用：

  • LASSO
  • regression tree
  • classification tree
  • conditional inference tree

解释：

\[ \widehat{CATE}_i \]

。(R 搜索)

特别的是：

它通过 permutation 选择 tuning parameter，控制”错误发现 HTE”的 Type-I error。

(镜像克拉克森大学)

因此比普通：

CATE → CART

更稳妥一些。

十六、subscreen：真正意义上的”快速扫一遍所有 subgroup”

这个包名字就非常符合你的要求：

Systematic Screening of Study Data for Subgroup Effects

主要：

subscreencalc()

可以一次生成大量 candidate subgroups。

然后：

subscreenvi()

计算 variable importance。

它的 VIM 很特别：

对每个 treatment arm 分别做 random forest importance，然后看 不同 treatment arms 之间变量重要性的差异/变异。

如果某变量：

  • treatment A 中重要；
  • treatment B 中不重要；

那么它可能是一个潜在 treatment-effect modifier。(GitHub)

最新版本：

4.0.1，2025-03-18。(镜像站)

优点

特别适合：

exploratory screening。

缺点

这不是严格的 causal VIM。

因此适合作为：

\[ \text{hypothesis generation} \]

不能单独作为正式因果结论。

十七、树/亚组型快速搜索方法

这些不是典型”变量重要性”，而是看变量是否反复进入 subgroup rules。

SIDES::SIDES()

Differential Effect Search。

递归搜索：

哪些分割能够最大化 treatment difference。

支持 continuous、binary、survival、count 等 outcome。(Rdrr.io)

现在还有较新的：

rsides

2024 年发布的 SIDES-based subgroup search 实现。(沈阳航空航天大学开源镜像站)

TSDT::TSDT()

Treatment-Specific Subgroup Detection Tool。

做很多 bootstrap trees：

Bootstrap
   ↓
tree
   ↓
每个 split → subgroup
   ↓
比较 treatment-effect scoring function
   ↓
保留 superior subgroups

还可以自定义 scoring function，包括：

  • mean treatment difference
  • median difference
  • survival / RMST 等。

(R 搜索)

quint::quint()

QUalitative INteraction Trees。

它特别寻找：

\[ Treatment\ A > B \]

在一组患者，

但：

\[ Treatment\ B > A \]

在另一组患者。

也就是：

qualitative / crossover interaction

。(PubMed Central (PMC))

这个比较严格，但适用场景窄，主要 RCT + continuous outcome。

十八、哪些”普通 VIM 包”不能直接当 effect-modifier screening？

这一点非常关键。

比如：

randomForest::importance()
randomForestSRC::vimp()
caret::varImp()
ranger::importance()
vimp::vim()

本身通常估计：

\[ X_j\rightarrow Y \]

的重要性。

例如 Random Forest permutation importance 本质上是：

permute \(X_j\) 后预测 Y 的误差增加多少。

(R 搜索)

这通常表示：

\[ \boxed{\text{prognostic importance}} \]

而不是：

\[ \boxed{\text{effect modifier importance}} \]

除非你先把 outcome 换成：

CATE

或者：

DR pseudo-outcome

或者：

treatment-effect score

然后再计算 VIM。

二十、如果目标是”快速初筛 30–100 个变量”，我会这样选

场景 A：观察性研究 + 普通连续/二分类结局

第一梯队：

\[ \boxed{\texttt{unihtee}} \]

\[ \boxed{\texttt{tidyhte}} \]

\[ \boxed{\texttt{grf}} \]

理由：

  • 都围绕 causal HTE；
  • 可以考虑 treatment assignment；
  • 不只是普通 outcome prediction。

场景 B：观察性研究 + OS/PFS

我会重点比较：

① unihtee()

直接 TEM-VIP + survival。

② grf::causal_survival_forest()

然后：

variable_importance()

进行快速 ranking。

③ BioPred

XGBoostSub_sur()
predictive_biomarker_imp()

做非线性 ML screening。

④ StratifiedMedicine::filter_train()

family = "survival"

做 interaction Elastic Net 初筛。

⑤ SubgrpID

做 threshold/signature discovery。

二十一、我更建议你建立”两阶段筛选”

如果你有例如：

Age
BMI
Stage
HE4
CA125
CEA
AFP
P53
Ascites
Tumor reduction
NACT
...

不要直接跑几十个 Cox：

\[ Treatment\times X_j \]

然后看谁 \(P<0.05\)。

更合理的是：

                  所有候选变量
                       │
        ┌──────────────┼──────────────┐
        ↓              ↓              ↓
     TEM-VIP        Causal Forest   Interaction
     unihtee           GRF           LASSO
        │              │              │
        ↓              ↓              ↓
       rank           rank          selected
        └──────────────┼──────────────┘
                       ↓
                 候选modifier
                    3–8个
                       ↓
          adjusted interaction model
                       ↓
               A × modifier
                       ↓
              P-interaction + CI
                       ↓
             subgroup effect estimates

对你的研究方向，我最推荐的组合

如果是肿瘤观察性队列 + OS/PFS：

\[ \boxed{ \texttt{unihtee} + \texttt{causal\_survival\_forest} + \texttt{BioPred} } \]

作为三种不同机制的探索性 screening：

  • unihtee：因果 estimand / TEM-VIP
  • grf：CATE tree-based importance
  • BioPred：modified-loss XGBoost importance

如果三个方法都把例如 stage、age、HE4 排在前面，那么候选 modifier 的可信度明显强于单一算法。

然后再用：

\[ \boxed{ \text{adjusted Cox } Treatment\times Modifier } \]

做正式的 P for interaction。

这比只用 MOB 或只用 grf::variable_importance() 更完整，因为它把”筛选”和”确认性推断”分开了。
