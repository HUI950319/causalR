第 20 章 · 调了混杂，反而更错

Treatment-confounder feedback · 处理–混杂因子反馈

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 20 章，书页 261–270。本章是读书笔记，非原书译文。

第 19 章把识别条件升级完了。本章问的是下一个问题——那用什么方法去调整？ 而答案暴露出时变处理里最要命的一件事：

当存在处理–混杂因子反馈时，使用传统的调整方法可能在效应估计中引入偏倚。 也就是说，即使我们拥有有效估计任何处理策略的平均因果效应所需的全部信息， 我们一般也做不到。

— What If, §20 章首, p.261

请注意这句话的分量。 前十九章里，「拿到了所有需要的信息」等价于「能估出来」。 本章说：在时变世界里，这两件事第一次分开了。

全章地图（笔记作者绘制，原书无此图）。本章的论证结构非常干净： 先造一个「一切条件都满足」的世界，再证明在这个世界里传统方法照样失败。 地图中段那两个并排的灰格子是本章的核心—— 它们不是「有偏 vs 无偏」的对比，而是「两种都错」。

20.1 处理–混杂因子反馈的要素：箭头是双向的，只是分了时点

回到第 19 章那个 HIV 的序贯随机试验：每月的处理 \(A_k\)、协变量 \(L_k\)、 末次随访 \(K+1\) 月的健康状况 \(Y\)。图 20.1 与图 19.2 完全相同，画的是前两个月。 \(L_k\) 是时变混杂因子。

图 20.1 里还发生着另一件事。 不仅有一条从 CD4 计数 \(L_k\) 指向处理 \(A_k\) 的箭头， 还有一条从处理 \(A_{k-1}\) 指向未来 CD4 计数 \(L_k\) 的箭头——因为接受处理 \(A_{k-1}\) 会抬高未来的 \(L_k\)。 也就是说，混杂因子影响处理，处理又影响混杂因子。这就是处理–混杂因子反馈。

— What If, §20.1, p.261

时变混杂 ≠ 处理–混杂因子反馈，这两个词不是同义词

书紧接着就把它们分开了：

注意，时变混杂可以在没有处理–混杂因子反馈的情况下发生。 图 20.2 与图 20.1 相同，只是删掉了从处理 \(A_{k-1}\) 指向未来 \(L_k\) 与 \(U_k\) 的箭头。 在这张图表示的情形下，时变协变量 \(L_k\) 是时变混杂因子， 但它们不受既往处理影响。因此存在时变混杂，但不存在处理–混杂因子反馈。

— What If, §20.1, p.261

这个区分决定了你能不能用传统方法：图 20.2 那种世界里， \(L_k\) 只是一堆「更早就定下来的」协变量，普通的分层 / 回归是可以用的； 一旦有了 \(A_{k-1} \to L_k\) 这条箭头，本章后面的全部灾难就开始了。

Figure 20.1 与 20.2（照原图重绘）。 两张图的差别只有 \(A_0 \to L_1\) 与 \(A_0 \to U_1\) 这两条箭头。 左边是本章要处理的世界，右边是传统方法还能用的世界。

Fine Point 20.1：无环图怎么表示一个「环」

处理与混杂因子互相影响，听上去是个循环——而 DAG 是无环的。怎么办？

有趣的是，一张无环图——比如图 20.1——可以用来表示一个处理–混杂因子反馈环。 做到这种可视化的窍门，是把反馈环在时间上展开。 也就是 \(A_{k-1} \to L_k \to A_k \to L_{k+1}\) 如此等等。

— What If, Fine Point 20.1, p.262

代价是时间必须被离散化：

用无环图表示反馈环还要求时间被当作离散变量。 也就是说，我们说处理与协变量可以在每个区间 \([k, k+1)\) 内改变， 但我们不指定改变究竟发生在区间内的哪一刻。

— What If, Fine Point 20.1, p.262

而书认为这在实践中并不是限制——区间长度可以按数据的粒度来选： 病人每月看一次医生就按月离散，其它情形可以按年或按日； 而且正如第 17 章说过的，时间本来通常就是按离散区间测量的， 所以离散化往往根本不是一个可选项，而是既成事实。

图 20.3：把问题剥到最小

图 20.3 是图 20.1 里能展示处理–混杂因子反馈的最小子集（两个时点的序贯随机试验）。 书列出了四条简化，并说明它们都不影响后面的论证：

简化 内容 用意
① 不画 \(L_0\) 关心的是 \(L_1\) 造成的后果；就当 \(A_0\) 是边际随机化、\(A_1\) 是给定 \(L_1\) 的条件随机化
② 不画 \(U_0\) 同上，减少节点
③ 没有 \(A_0 \to A_1\) 意味着处理只根据 \(L_1\) 的信息分配
④ 没有 \(A_0\)、\(L_1\)、\(A_1\) 指向 \(Y\) 的箭头 意味着处理对任何个体的 \(Y\) 都没有因果效应，即尖锐零假设成立

更复杂的因果图不会给本章的讨论增加任何概念上的洞见，只会更难读。

— What If, §20.1, p.262

第 ④ 条是整章论证的支点：既然真实效应为 0， 那么任何给出非零答案的方法，它错在哪儿就一目了然了。

根据图 20.3，这个真实的（但研究者并不知道的）平均因果效应是 0， 因为从任一处理变量到结局都没有前向有向路径—— 你无法从 \(A_0\) 或 \(A_1\) 出发，顺着箭头方向走到 \(Y\)。

— What If, §20.1, p.262

而图 20.3 可以表示一个序贯随机试验（没有从 \(U\) 直接指向处理的箭头）， 所以按第 19 章的结论，我们本应能用 \(A_0, L_1, A_1, Y\) 的观测数据得出「效应为 0」。

反馈的第二种形态：共享未测原因 \(W_0\)

传统方法的这个局限，不仅适用于时变混杂因子受既往处理影响的情形（如图 20.3）， 也适用于时变混杂因子与既往处理共享原因 \(W\) 的情形（如图 20.4，它是图 19.4 的子集）。 我们把图 20.3 与图 20.4（以及图 19.2 与 19.4）都称为处理–混杂因子反馈的例子。

— What If, §20.1, p.263

边注还给了两者的身份：图 20.3 表示序贯随机试验或无未测混杂的观察性研究； 图 20.4 表示观察性研究。

把两件结构不同的事叫同一个名字，在这本书里是少见的。 理由在 §20.3 末尾：用观测数据根本区分不了它们—— 两者在条件化 \(L_1\) 之后打开的都是一条「经由对撞节点」的路径。

20.2 传统方法的偏倚：32 000 人，一张表，两个错答案

书造了一个假想的序贯随机试验：32 000 名 HIV 感染者，两个时点 \(k = 0, 1\)。

  • \(A_0 = 1\) 在基线以概率 0.5 随机分配；
  • \(A_1\) 在第 1 月随机分配，概率只依赖第 1 月初的 CD4 计数 \(L_1\)： \(L_1 = 0\)（高）时 0.4，\(L_1 = 1\)（低）时 0.8；
  • \(Y\) 在随访结束时测量，是 CD4 计数、血清病毒浓度与其它临床指标的函数，越大越健康。

边注强调这是理想试验：完全依从分配的策略，没有失访。

顺带把第 19 章那处贴反的标校准了

本章这一句 0.4 if $L_1 = 0$ (high), 0.8 if $L_1 = 1$ (low) 与 §19.2 的编码 （\(L_k = 1\) 是 CD4 低、预后差）完全一致， 也与「CD4 越低越可能被治」一致。

这反过来确认了第 19 章笔记里记下的那处问题： 书页 253 把 0.4 配给「high CD4 (\(L_k = 1\))」、把 0.8 配给「low CD4 (\(L_k = 0\))」， 在同一本书内部是自相矛盾的，本章这一页才是对的那一版。

  • 反馈在哪里看得见：\(\Pr[L_1 = 1 \mid A_0 = 0] = 12000/16000 = \mathbf{0.75}\)， 而 \(\Pr[L_1 = 1 \mid A_0 = 1] = 8000/16000 = \mathbf{0.50}\)—— 治疗过的人 CD4 变低的比例明显更小，这正是 \(A_0 \to L_1\) 那条箭头。
  • \(E[Y]\) 只依赖 \((A_0, L_1)\)，与 \(A_1\) 无关：84 / 52 / 76 / 44 各出现两次， 两次的 \(A_1\) 不同而均值相同 ✓ ——这就是「\(A_1\) 无效应」写在表里的样子。
  • 正性：八行没有一行是 0 人 ✓（书就是这么检查的）

最后一条是全章的钥匙：在 \(L_1\) 固定的层里，\(A_0=1\) 与 \(A_0=0\) 的均值差是 \(76 - 84 = -8\) 与 \(44 - 52 = -8\)。而 \(A_0\) 对 \(Y\) 没有任何因果效应。 这 \(-8\) 是纯粹的选择偏倚，§20.3 会说明它从哪来。

先确认：把 \(A_0\) 与 \(A_1\) 分开看，效应都是 0

（以下计算忽略随机变异，书自己也这么说明。）

\(A_1\) 的效应，在四个 \((A_0, L_1)\) 层里都是 0：比较第 1/2 行、3/4 行、5/6 行、7/8 行， 均值分别是 \(84\) vs \(84\)、\(52\) vs \(52\)、\(76\) vs \(76\)、\(44\) vs \(44\)，差都是 0。 因为识别条件成立，这些关联差有效地估计了相应的条件平均因果效应 \(E[Y^{a_1=1}\mid A_0, L_1] - E[Y^{a_1=0}\mid A_0, L_1]\)。

\(A_0\) 的效应也是 0：由于基线随机化，\(E[Y\mid A_0=1] - E[Y\mid A_0=0]\) 就是 \(E[Y^{a_0=1}] - E[Y^{a_0=0}]\) 的有效估计。书在边注里把加权平均写了出来：

\[E[Y\mid A_0 = 0] = \tfrac{2400}{16000}(84) + \tfrac{1600}{16000}(84) + \tfrac{2400}{16000}(52) + \tfrac{9600}{16000}(52) = \mathbf{60}\]

同样算得 \(E[Y\mid A_0 = 1] = \tfrac{8000}{16000}(76) + \tfrac{8000}{16000}(44) = \mathbf{60}\)。 差为 0。

那么把 \((A_0, A_1)\) 当成一个时变处理来比呢？

目标是「一直治」\((a_0=1, a_1=1)\) 对「一直不治」\((a_0=0, a_1=0)\)。 因为每个分量的效应都是 0，由 g-零定理（Technical Point 20.1）可知 \(E[Y^{a_0=1,a_1=1}] - E[Y^{a_0=0,a_1=0}]\) 也应该是 0。

书做了两次分析，两次都错：

分析一：不调整 \(L_1\)

比较两次都治的 9 600 人（第 6、8 行）与两次都不治的 4 800 人（第 1、3 行）：

\[E[Y\mid A_0{=}1, A_1{=}1] = \tfrac{3200}{9600}(76) + \tfrac{6400}{9600}(44) = \mathbf{54.7}\] \[E[Y\mid A_0{=}0, A_1{=}0] = \tfrac{2400}{4800}(84) + \tfrac{2400}{4800}(52) = \mathbf{68.0}\]

关联差 \(= 54.7 - 68 = \mathbf{-13.3}\)。

若做因果解读，就成了「两次都不治比两次都治更好」。 错的原因很明白：没有调整混杂因子 \(L_1\)。

分析二：按 \(L_1\) 分层调整

\(L_1 = 0\) 层：\(E[Y\mid A_0{=}1, L_1{=}0, A_1{=}1] = 76\)（第 6 行） 减 \(E[Y\mid A_0{=}0, L_1{=}0, A_1{=}0] = 84\)（第 1 行）\(= \mathbf{-8}\)。

\(L_1 = 1\) 层：\(44 - 52 = \mathbf{-8}\)。

什么？ 我们说过效应估计应该是 0，不是 \(-8\)。 调整了混杂因子的分析怎么也会给出错误答案？

— What If, §20.2, p.264

为什么「两层都是 \(-8\)」这件事特别致命

注意，因为两个 \(L_1\) 层里的效应都是 \(-8\)， 层特异效应的任何加权平均都不可能得到正确值 0。

— What If, §20.2 边注, p.264

这句话堵死了所有「换个标准化权重就好了」的补救幻想。 如果两层一个 \(+5\) 一个 \(-5\)，还可以指望某种加权能凑回 0； 两层同号同值时，加权平均恒等于那个值。

这是本书里少见的「一句话把整条退路封死」的写法。 它也解释了为什么第 21 章必须换一套完全不同的机器，而不是修补分层。

Technical Point 20.1：g-零检验与 g-零定理

设尖锐零假设为真，那么任何反事实结局 \(Y^g\) 就是观测结局 \(Y\)。 于是两个时点的研究里，对所有 \(Y^g\) 的序贯可交换性可以写成

\[Y \perp\!\!\!\perp A_0 \mid L_0 \qquad\text{与}\qquad Y \perp\!\!\!\perp A_1 \mid A_0, L_0, L_1\]

（这里用到了一个事实：对任意 \(a_0\) 与 \(l_0\)，总存在策略 \(g\) 使得 \(a_0 = g(l_0)\)。）

因此，在序贯可交换性之下，对这两条条件独立性的检验就是对尖锐零假设的检验。 这就是 g-零检验（Robins 1986）。

— What If, Technical Point 20.1, p.264

第一条独立性意味着 \(A_0\) 在 \(L_0\) 定义的任何层里都无因果效应， 第二条意味着 \(A_1\) 在 \(L_1\) 与 \(A_0\) 定义的任何层里都无因果效应。

而 g-零定理更强：

在对所有 \(g\) 的序贯随机化之下，上述两条独立性成立，当且仅当 \(Y^g\) 的分布（因而 \(E[Y^g]\)）对所有 \(g\) 都相同， 并且等于观测 \(Y\) 的分布与均值。

— What If, Technical Point 20.1, p.264

所以 §20.2 的论证不是「凑巧」：书先验证了两条分量独立性成立， 再用 g-零定理推出联合效应必为 0，然后才去看传统方法给出什么。 真值不是假设出来的，是定理给的。

Fine Point 20.2：位于因果通路上的混杂因子——一句流传很广的话在这里是错的

先厘清一件事：图 20.5 与 20.6 里，\(L_1\) 根本不在处理到结局的因果通路上 （那两张图里压根没有这样的通路），条件化它照样制造选择偏倚。

而图 20.7 是另一回事：那里 \(L_1\) 确实位于从 \(A_0\) 到 \(Y\) 的因果通路 \(A_0 \to L_1 \to Y\) 上。书对这张图给了一句很细的断言：

如果图 20.7 里 \(U_1\) 不是 \(L_1\) 与 \(Y\) 的共同原因（即没有选择偏倚）， 那么 \(L_1\) 各层内的 \(A\)–\(Y\) 关联将是 \(A_0\) 对 \(Y\) 的、不经由 \(L_1\) 的直接效应的无偏估计， 但仍然不是 \(\bar A\) 对 \(Y\) 总效应的无偏估计——因为 \(A_0\) 经由 \(L_1\) 中介的那部分效应没被算进去。

— What If, Fine Point 20.2, p.266

然后是那句要划掉的流行说法：

人们有时说，位于处理与结局之间因果通路上的变量不能被当作混杂因子， 因为调整这类变量会导致有偏的效应估计。 然而，对时变处理而言，这种对混杂因子的刻画是不准确的。 图 20.7 表明，后续处理 \(A_1\) 的一个混杂因子，可以位于既往处理 \(A_0\) 与结局之间的因果通路上。

— What If, Fine Point 20.2, p.266

最后一句给出了正确的提法：

至于「调整位于因果通路上的混杂因子」会不会带来偏倚， 那取决于你选择的调整方法。分层确实会带来偏倚；g-方法不会。

— What If, Fine Point 20.2, p.266

这条边栏值得在组会上念一遍。「中介变量不能当混杂调整」这句话在流行病学里被当作常识， 而本章说：在时变处理里，同一个变量既是下一时点的混杂因子，又是上一时点的中介—— 这不是矛盾，是常态；出问题的是方法，不是变量。

20.4 传统方法为什么补不好：回归本身就是一种分层

分层不行，那换参数化的结局回归呢？这个问题在高维数据下尤其要紧—— 因为高维下根本做不出上一节那种简单的分层表。

在图 20.5 生成的数据里，处理 \(A_k\) 只发生在两个月 \(k = 0, 1\)， 所以只有 \(2^2 = 4\) 条静态策略 \(\bar a\)。但当处理发生在多个时点 \(k = 0, 1 \dots K\) 时， 我们就无法列出一张包含所有处理值组合的表。 如果像实践中常见的那样 \(K\) 是 100 的量级，那就有 \(2^{100}\) 条静态策略 \(\bar a\)—— 一个远远超过任何研究样本量的天文数字。

— What If, §20.4, p.267

（边注补一句：数据组合数还要更大，因为每个时点 \(k\) 上还有多个混杂因子 \(L_k\)。 而且把动态策略也算上，策略总数还要多得多。）

于是又回到第 11 章那句话：只能建模。而建模在这里要做的事很具体—— 为「处理史 \(\bar a\) 对均值结局 \(Y\) 的效应」假设一个剂量–反应函数。 书举了最常见的那一种：

一种可能是假设策略 \(\bar a\) 的效应随该策略下的累积处理线性增长。 在这个假设下，所有恰好给药三个月的策略效应相同， 不管这三个月是随访的头三个月、最后三个月，还是别的什么时候。

— What If, §20.4, p.267

代价照例是模型设定错误的风险。但书接下来那句才是重点：

而且，付了这个代价也买不到任何对「传统方法会失败」这件事的保护。 在存在处理–混杂因子反馈时，回归建模不可能消除基于分层的传统方法的偏倚—— 因为回归本身就是一种基于分层的传统方法。

— What If, §20.4, p.267

具体地：定义累积处理 \(\text{cum}(\bar A) = A_0 + A_1\)（取值 0、1、2）， 两条策略就是 \(\text{cum}(\bar a) = 2\) 与 \(\text{cum}(\bar a) = 0\)， 真值仍应为 0。拟合

\[E\left[Y \mid \bar A, L_1\right] = \theta_0 + \theta_1 \text{cum}(\bar A) + \theta_2 L_1\]

则关联差 \(E[Y\mid \text{cum}(\bar A)=2, L_1] - E[Y\mid \text{cum}(\bar A)=0, L_1] = \theta_1 \times 2\) （这个模型正确地假设了该差在 \(L_1 = 0\) 与 \(L_1 = 1\) 两层里相同—— §20.2 里两层都是 \(-8\)，确实相同）。

于是有人可能想把 \(\theta_1 \times 2\) 解释成「在 \(L_1\) 各层内、『一直治』对『一直不治』的平均因果效应」。 但这种因果解读是没有根据的，因为如图 20.5 所示， 条件化于 \(L_1\) 会在处理 \(\text{cum}(\bar A)\) 的一个分量 \(A_0\) 与结局 \(Y\) 之间造出关联。 这意味着 \(\theta_1\)——以及那个均值关联差——即使真实因果效应为零、 且 \(E[Y\mid \bar A, L_1]\) 的回归模型是正确的，也仍然非零。

— What If, §20.4, p.268

匹配也一样（书只用了一句：A similar argument can be applied to matching）。

三个词，三种方法，同一个病

分层

在 \(L_1 = l\) 的子集里比较。

\(L_1\) 被条件化 → 对撞门打开。

回归 / 匹配

把 \(L_1\) 放进模型、或按 \(L_1\) 配对。

仍然是在「给定 \(L_1\)」下做比较 → 同一扇门。

判据不是「我用的是不是高级模型」，而是「我有没有把 \(L_1\) 放进条件」。 只要放了，且 \(L_1\) 受既往处理影响（或与之共享未测原因），偏倚就在那里。

而 g-方法的共同点恰恰是：它们都不把 \(L_k\) 放进最终那个因果对比的条件里—— IP 加权把 \(L_k\) 用在权重里，g-公式把 \(L_k\) 用在求和里，g-估计把它用在估计方程里。 第 21 章的三条路线，本质上是三种「用了 \(L_k\) 但不条件化于 \(L_k\)」的办法。

前面的图为了简单，都没有画 \(A_0 \to A_1\)。现实里医生当然会看既往用药史。 把这条箭头加回图 20.3 与 20.4，就得到图 20.8 与 20.9。

理由二：既往处理本身就是混杂因子

当然，无论是否存在处理–混杂因子反馈， 只要既往处理对结局有非零效应（如图 20.10）， 条件化于既往处理史总是必需的。

这就是为什么第 19 章与本章里所有序贯可交换性的陈述，条件里都带着处理史：

因此，时刻 \(k\) 的序贯可交换性一般要求条件化于 \(k\) 之前的处理史 \(\bar A_{k-1}\)； 只条件化协变量 \(L\) 是不够的。

假设我们只想估时固定处理 \(A_1\) 对 \(Y\) 的效应 （书称之为时变处理 \(\bar A\) 的短期效应）。那么：

不调整既往处理 \(A_0\)，在存在处理–混杂因子反馈时一般会造成选择偏倚， 在既往处理 \(A_0\) 直接影响结局时会造成混杂。 换句话说，即使处理 \(A_1\) 对任何个体的结局都没有效应， \(E[Y\mid A_1 = 1, L_1] - E[Y\mid A_1 = 0, L_1]\) 也不会是零（如图 20.8–20.10）。

— What If, §20.5, p.268

落到实践上就是那句非常眼熟的话：

在实践中，对时固定处理做因果推断时，比较当前使用者（\(A_1 = 1\)）与非使用者（\(A_1 = 0\)） 的分析可能产生偏倚。 要避免这种偏倚，可以调整既往处理史， 或者把分析限制在具有特定处理史的个体上。 这就是时固定处理「新使用者设计」背后的想法：把分析限制在过去未使用过该处理的个体上。

— What If, §20.5, p.269

边注补了一句很关键的定位：如果能正确调整既往处理，分析就不必限制在新使用者上。

新使用者设计（new-user design）在药物流行病学里通常被当成一条经验法则来教。 本节给了它一个结构性的出处：它不是「更干净的设计习惯」， 而是「在无法可靠调整既往处理时，用限制代替调整」的一种做法。

最后一击：处理测量错误会在零假设下造成偏倚

既然必须调整既往处理，那既往处理测错了会怎样？

书设定的情形很现实：研究者拿不到病历，只能靠问卷回忆既往用药， 于是手里只有误测的 \(A_0^*\) 而不是 \(A_0\)。 在图 20.8–20.10 上加一条 \(A_0 \to A_0^*\) 就能看出： 条件化于 \(A_0^*\) 无法阻断那些经由 \(A_0\) 的致偏路径。

因此，当处理是时变的时，我们发现——与一种广为流传的信念相反—— 处理的误测（即使测量误差是独立且非差异性的）也可能造成零假设下的偏倚。

— What If, §20.5, p.269

原因书也说了：因为既往处理是后续处理效应的混杂因子， 哪怕既往处理对结局本身没有任何因果效应。 边注还给了更狠的一条：Robins (1987) 证明了随机误测的处理可能导致偏离零假设方向的偏倚。 而在备择假设下，这种不完全的偏倚调整可能给出被夸大的效应估计。

第 9 章 §9.3 讲过「误测的混杂因子会造成向上或向下的偏倚」， 这里是它在时变世界里的一个具体后果—— 而「非差异性误分类只会把效应拉向零」这条流行病学口诀，在时变处理上不成立。

而「处理–混杂因子反馈」这个名字覆盖了两种结构： \(A_{k-1} \to L_k\)（实验或观察性研究）与 \(A_{k-1} \leftarrow W \to L_k\)（观察性研究）—— 书把它们叫同一个名字，因为用观测数据区分不了，而且后果完全一样。

自检① 我的研究里有没有处理–混杂因子反馈？

问三句，任何一句是「是」就有：

  1. 我要调整的那个时变协变量，会不会被上个月的治疗改变？ （CD4、血压、血糖、体重、肝肾功能——绝大多数临床指标都会）
  2. 它会不会和既往治疗共享某个没记录下来的原因？ （是否来门诊、是否被转诊、是否在住院期间——图 20.6 那一类）
  3. 医生是不是看着这个指标决定治不治？ 是的话它就是混杂因子，必须调整。

三句同时成立，就是本章描述的那个陷阱：这个变量必须调整（否则 \(A_1\) 有混杂）， 又不能用传统方式调整（否则 \(A_0\) 有选择偏倚）。

一个反过来的用法：如果第 1 句是「否」——协变量只在基线测、不受治疗影响—— 那就是图 20.2 的世界，传统方法还能用，不必上 g-方法。 先判断这一条，能省掉很多力气。

自检② 为什么「加权平均救不回来」这句话这么重要？

因为它区分了两类完全不同的问题：

  • 可以靠标准化解决的：层特异效应不同（效应修饰），只是各层权重选错了。 换一套权重（标准化到目标人群）就能得到你要的边际效应。
  • 本章这一类：层特异效应全都等于 \(-8\)，而真值是 0。 层内的那个数本身就是错的，加权只是在对一堆错数取平均。

所以本章的病不在「怎么把层合起来」，而在「层内的那个比较本身没有因果解释」。 这也是为什么补救办法必须是换一台机器（g-方法），而不是换一套权重。

自检③ g-方法凭什么不犯这个错？

本章没有正面回答（那是第 21 章的事），但它给出了判据：

一般而言，只有当处理各分量 \(A_k\) 的联合效应能够被同时且无偏地估计时， 处理策略效应的有效估计才是可能的。

— What If, §20.3, p.267

传统方法违反的正是「同时」二字：它们一个时点一个时点地条件化， 而在 \(L_1\) 上条件化的那一步，就把 \(A_0\) 的比较弄脏了。

g-方法的共同点是：用了 \(L_k\) 的信息，但最终的因果对比不条件化于 \(L_k\)。 IP 加权把它放进权重、g-公式把它放进对 \(L\) 的求和、g-估计把它放进估计方程—— 三条路线，一个共同点。

可以先拿本章的 Table 20.1 做一次手算验证（见下方代码）： g-公式给出的答案正是 0，与 g-零定理一致。

下一章 第 21 章「时变处理的 g-方法」 就把这三条路线全部展开， 并且用的就是本章这张表。

本章的数据全在一张 8 行的表里，可以直接敲进 R，把三种算法的答案一次算出来：

tab <- data.frame(
  N  = c(2400, 1600, 2400, 9600, 4800, 3200, 1600, 6400),
  A0 = c(0, 0, 0, 0, 1, 1, 1, 1),
  L1 = c(0, 0, 1, 1, 0, 0, 1, 1),
  A1 = c(0, 1, 0, 1, 0, 1, 0, 1),
  Y  = c(84, 84, 52, 52, 76, 76, 44, 44)
)
wm <- function(d) sum(d$N * d$Y) / sum(d$N)          # 加权均值

# ① 不调整：两次都治 vs 两次都不治
wm(subset(tab, A0 == 1 & A1 == 1)) - wm(subset(tab, A0 == 0 & A1 == 0))
#> -13.33333                                          ← 书上的 -13.3

# ② 按 L1 分层
sapply(0:1, function(l)
  wm(subset(tab, A0 == 1 & L1 == l & A1 == 1)) -
  wm(subset(tab, A0 == 0 & L1 == l & A1 == 0)))
#> -8 -8                                              ← 两层同号同值，加权平均救不回来

# ③ g-公式（第 21 章的做法，这里先验一下真值）
#    E[Y^{a0,a1}] = Σ_l1 E[Y | a0, l1, a1] · Pr[L1 = l1 | A0 = a0]
gform <- function(a0, a1) {
  p <- sapply(0:1, function(l) sum(tab$N[tab$A0 == a0 & tab$L1 == l]) /
                                 sum(tab$N[tab$A0 == a0]))
  y <- sapply(0:1, function(l) tab$Y[tab$A0 == a0 & tab$L1 == l & tab$A1 == a1])
  sum(p * y)
}
gform(1, 1) - gform(0, 0)
#> 0                                                  ← g-零定理说的那个 0
