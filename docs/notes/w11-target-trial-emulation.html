第 22 章 · 先写协议，再看数据

Target trial emulation · 目标试验模拟

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 22 章，书页 299–316。本章是读书笔记，非原书译文。

第一部分就说过：从观察数据做因果推断，可以看成在模拟一项假想的随机试验—— 那项试验就叫目标试验。但那时的目标试验都很简陋，比较的是时固定处理。 到这一章，工具齐了：

既然我们现在拥有处理时变处理因果推断所需的全部工具， 我们已经准备好讨论比较持续处理策略的现实目标试验了。 本章把目标试验的概念推广到持续处理策略，并勾勒出一个统一的因果推断框架—— 无论数据来自随机试验还是观察性研究。

— What If, §22 章首, p.299

而这一章为什么必须放在第 21 章之后，书也说得很清楚：

正是 g-方法的发展，让这里讨论的概念不只是一次形式上的演练： 如果所有重要的固定与时变混杂因子都有数据， 那么我们关心的这些效应，现在可以被有效地估计出来。

— What If, §22 章首, p.299

全章地图（笔记作者绘制，原书无此图）。 本章是全书唯一一章几乎不出现新公式的方法学章节—— 它讲的全是把因果问题写清楚这件事。 但它依赖前三章的全部机器：地图中段那句「必须用 g-方法」， 就是第 19–21 章的全部内容被折进这一章的位置。

22.1 意向性治疗效应与符合方案效应：两条通路，两个问题

设想一项随机试验：有感染危险病毒风险的个体被随机分配到 立即接种疫苗 + 一旦感染就用试验性抗病毒药（\(Z = 1\)） 或标准治疗（\(Z = 0\)，不接种、不用抗病毒药）。 \(Z\) 是分配的处理，\(A\) 是实际接受的处理，\(Y\) 是结局（死亡）。

Figure 22.1 与 22.3（照原图重绘）。图 22.2（未重绘）是图 22.1 去掉 \(Z \to Y\)， 即排除限制成立的双盲安慰剂对照试验，也就是第 16 章的图 16.1。 图 22.4（未重绘）是在图 22.3 上加一个被方框圈住的选择指示 \(S\)， \(Z\) 与 \(A\) 都指向它——这就是「所谓 per-protocol 分析」的结构。

分配 \(Z\) 通过两条通路影响结局：

  1. \(Z \to A \to Y\)：被分配到疫苗的人更可能真的接种；
  2. \(Z \to Y\)：知道自己被分配到「疫苗 + 有前景的抗病毒药」的人， 可能变得不那么小心防护——行为改变。

因此，分配处理 \(Z\) 的因果效应不仅取决于 \(A \to Y\) 这条箭头的强度（实际接受处理的效应）， 还取决于 \(Z \to A\)（研究中对分配处理的依从程度）与 \(Z \to Y\)（同时发生的行为改变）的强度。 \(Z\) 的效应不是「用 \(A\) 治疗的效应」，而是「把参与者分配去接受 \(A\) 治疗的效应」， 或者说「有意图用 \(A\) 治疗的效应」——这就是随机分配 \(Z\) 的效应 常被称为意向性治疗效应的原因。

— What If, §22.1, p.300

意向性治疗效应（ITT）

没有混杂：\(Z\) 是随机分配的，图 22.1 里从 \(Z\) 到 \(Y\) 没有后门路径， 所以 \(Y^z \perp\!\!\!\perp Z\)。

\[\frac{\Pr[Y=1\mid Z=1]}{\Pr[Y=1\mid Z=0]} = \frac{\Pr[Y^{z=1}=1]}{\Pr[Y^{z=0}=1]}\]

无论有没有人依从，这个等式都成立。

符合方案效应（per-protocol）

定义：如果所有人都按协议依从了分配的处理，本会观察到的效应。 形式上是 \(\Pr[Y^{z=1,a=1}=1]\) 对 \(\Pr[Y^{z=0,a=0}=1]\)； 在排除限制下简化为 \(\Pr[Y^{a=1}=1]\) 对 \(\Pr[Y^{a=0}=1]\)。

有混杂：后门路径 \(A \leftarrow U \to Y\)。

估计符合方案效应，要求把这项随机试验当成一项观察性研究来看待。

— What If, §22.1, p.301

Fine Point 22.1：排除限制，以及双盲为什么不总是好事

\(Z \to Y\) 这条箭头存在，就说排除限制不成立。 研究者常用双盲 + 安慰剂去掉它（图 22.2）。但书补了两条限制：

双盲的处理分配常常不可行。许多研究无法有效设盲， 因为没有实际可行的办法给出令人信服的安慰剂（例如开胸手术）， 或者因为某种处理的副作用会让人明显看出自己在用它，等等。 另外，当研究者关心的是量化处理在真实世界中的效应时，设盲（与安慰剂对照）并不可取—— 因为真实世界里不存在设盲（也不存在安慰剂）。

— What If, Fine Point 22.1, p.300

最后这一句在 §22.2 会变成一条设计原则： 目标试验必须是务实（pragmatic）试验，否则它模拟的不是真实世界。

ITT 的三条常见辩护，以及它们各自的漏洞

缺乏混杂在很大程度上解释了为什么意向性治疗效应在许多随机试验里被优待： 「有意图用 \(A\) 治疗的效应」可能不是我们想要的那个效应—— 我们想要的是「用 \(A\) 治疗的效应」即符合方案效应——但它更容易计算。 正如「一个不那么有趣的量比一个更有趣的量更容易计算」时常常发生的那样， 我们倾向于编出一些论证来正当化对那个不那么有趣的量的使用。

— What If, §22.1, p.301

辩护 书的裁决
① ITT 保零：\(A\) 无效应则 \(Z\) 也无效应 只在排除限制成立时为真。非双盲试验里（图 22.1），把 \(A \to Y\) 擦掉，\(Z \to Y\) 还在——\(A\) 无效应而 \(Z\) 有效应
② ITT 保守：它是符合方案效应的下界 不保证。见 Fine Point 22.4 的布洛芬例子
③ ITT 测的是真实世界的「效果」 见 Fine Point 22.4：三条理由都站不住

边注给了 ① 的精确版本：在统计学意义上，意向性治疗分析为 「无平均处理效应」这个原假设提供了一个有效的（可能功效不足的）\(\alpha\) 水平检验—— 在双盲安慰剂对照随机试验中。

即使 ITT 真的保守，那也未必是好事

假设目标是评估某个处理的安全性：人们可能天真地得出「处理 \(A\) 是安全的」这个结论， 因为 \(Z\) 对不良结局的意向性治疗效应接近零， 即使 \(A\) 在相当大比例的患者中确实导致了这个不良结局。 解释可能是：许多被分配到 \(Z=1\) 的人在发生不良结局之前就没吃、或停掉了处理。 那么意向性治疗效应就是一种危险的效应定义方式。

— What If, §22.1, p.302

边注还点了另一个场景：这条反对意见同样适用于非劣效试验—— 那里的目标是证明一种处理不劣于另一种，而 ITT 的「偏向零」正好帮了倒忙。

书的总结很直接：

总之，对于不依从严重的随机试验、以及那些评估危害而非获益的试验， 完全依赖意向性治疗效应估计是很难正当化的。

— What If, §22.1, p.302

Fine Point 22.4：一个很容易记住的反例——布洛芬

针对「ITT 保证保守」这条：

如果处理的符合方案效应不是单调的（即并非对所有个体都同向；见 Technical Point 5.2）， 且不依从程度很高，那么符合方案效应可能比意向性治疗效应更接近零。

— What If, Fine Point 22.4, p.303

而即使效应是单调的，在两种活性药头对头的试验里 ITT 也不保证保守：

假设患某种疼痛疾病的个体被随机分配到一种昂贵的药（\(Z=1\)）或布洛芬（\(Z=0\)）。 ……研究者不知道的是，两种药在减轻疼痛上同样有效，即符合方案风险比为 1。 然而，由于布洛芬有一种轻微、容易缓解的副作用，对布洛芬的依从恰好低于对昂贵药的依从。 结果，意向性治疗风险比大于 1，研究者错误地断定布洛芬在减轻严重疼痛上不如那种昂贵药。

— What If, Fine Point 22.4, p.303

针对「ITT 测的是真实世界效果」那条，书给了三条反驳：

  1. ITT 测的是在这项特定试验所观察到的依从条件下分配处理的效应—— 真实生活中的实际依从可能不同（例如被密切监测的参与者依从更好）， 而且可能被这项试验的结果本身改变（人们知道有效后更可能依从）；
  2. 如果目标真是「效果」，我们就不该做双盲安慰剂对照试验—— 真实生活里医患都知道用了什么药、也不存在安慰剂； 真正的效果度量应当包含「知晓分配」所带来的那些效应（比如行为改变）， 而双盲恰恰把它们消掉了；
  3. 打算遵医嘱的患者，更关心符合方案效应而不是意向性治疗效应。

Fine Point 22.2 与 22.3：那些「看起来像」但其实有偏的分析

伪 ITT 与修正 ITT（Fine Point 22.2）

伪意向性治疗分析：因为有人没完成随访，只能算 \(\Pr[Y=1\mid Z=1, C=0] / \Pr[Y=1\mid Z=0, C=0]\)。 删失可能引入任一方向的选择偏倚， 所以「有失访时的 ITT 分析需要对选择偏倚做适当调整」（见 §21.5）。

修正意向性治疗分析：对持续策略，常见做法是把分析限制在 至少启动了所分配策略的人（比如至少吃了一片药）。 它只包含随机化个体的一个子集，因此对 ITT 效应可能有偏， 一般需要调整影响依从的风险因子。

朴素的符合方案分析（Fine Point 22.3）

按实际接受治疗（as-treated）分析：比较 \(A=1\) 与 \(A=0\)，不管分配。 若驱动服药的原因与未测预后因子 \(U\) 相关（图 22.1、22.2），就有混杂； 若所有后门路径都能被已测的 \(L\) 阻断（图 22.3），则必须调整 \(L\)。

所谓 per-protocol（on-treatment）分析：只留下 \(A = Z\) 的人， 再在这群人里比 \(Z=1\) 与 \(Z=0\)。 它其实就是「限制在符合方案人群上的 ITT 分析」，一般有偏： 图 22.4 里条件化于 \(S=1\) 打开了非因果路径 \(Z \to A \leftarrow L \leftarrow U \to Y\)。

书的结论一句话：这两种分析都是「对一项随机试验做的观察性分析」， 因此和任何观察性分析一样，需要对混杂与选择偏倚做适当调整。

而持续策略把这件事推到了极端：

当随机试验研究的是处理可随时间变化的持续策略时（这很常见）， 不依从的概率大幅上升。于是意向性治疗效应相对于符合方案效应变得越来越没有信息量。 ……估计持续策略的符合方案效应，无论是在真正的随机试验中还是在模拟它的观察性分析中， 一般都需要 g-方法。

— What If, §22.1, p.302

22.2 比较持续策略的目标试验：协议必须把动态成分写出来

因为最终目标是用真实世界的观察数据去模拟它，所以目标试验必须是务实的：

  • 参与者与主治医生知道自己用的是什么（不设盲）；
  • 没有人用安慰剂（两条策略要么是活性处理、要么是不处理）；
  • 参与者被监测的频率与强度，与研究之外的普通患者相同。

例子是一项 HIV 试验：18 岁以上、无 AIDS、未用过抗逆转录病毒治疗的人， 在基线被随机分配到

  • \(g_1\)：「随访期间持续接受 \(A_k = 1\)，除非出现禁忌症或毒性」；
  • \(g_0\)：「随访期间持续 \(A_k = 0\)」。

随访从分配时开始，到死亡、失访或基线后 60 个月中最早的那个为止。

效应 由哪两个干预的对比定义 形式
意向性治疗效应 \((z=1, \bar c_K = \bar 0)\) 对 \((z=0, \bar c_K = \bar 0)\) \(\Pr\left[D_k^{z=1,\bar c_k = \bar 0}=1\right] - \Pr\left[D_k^{z=0,\bar c_k=\bar 0}=1\right]\)
符合方案效应 从基线到随访结束持续遵循 \(g_1\) 对 \(g_0\) \(\Pr\left[D_k^{g_1,\bar c_k=\bar 0}=1\right] - \Pr\left[D_k^{g_0,\bar c_k=\bar 0}=1\right]\)

两处细节值得单独记：

  • 两个定义里都带着 \(\bar c_k = \bar 0\)——「如果没有人失访」。 这正是 §21.5 那条「上标 \(\bar c = \bar 0\) 让大家心里真正想的那个对比变得明确」的落实。
  • 当分配与启动同时发生时（分配到 \(g_1\) 的人都在时刻 0 开始用药、分配到 \(g_0\) 的都不用）， ITT 效应就不只是「分配」的效应，也是「启动」的效应， 即 \(\Pr[D_k^{a_0=1,\bar c_k=\bar 0}=1] - \Pr[D_k^{a_0=0,\bar c_k=\bar 0}=1]\)。 这一点是 §22.3 里「观察性类比」的全部依据。

本章最实用的一条：因毒性停药不是不依从

合理的试验协议不会要求「无论个体发生什么都必须继续用药」。 例如我们的策略 \(g_1\)「持续治疗」要求在出现禁忌症或毒性时停药。 也就是说，符合方案效应一般涉及的是动态策略（「这么做；如果 X 发生了就改做那样」） 的比较，而不是静态策略（「这么做，不管发生什么」）。

— What If, §22.2, p.305

而协议如果写得含糊，后果很具体：

具体地说，一个被分配到 \(g_1\)、因毒性而停药的个体 不应当被标记为「没有遵循 \(g_1\)」。事实上，这个人完全遵循了（本应被写成那样的）\(g_1\)。 当在真实世界里「不这么做」根本不是一个选项时， 停用最初分配的处理、或启动其它有医学指征的处理，都不可能被算作对协议的偏离。

— What If, §22.2, p.305

边注给了对策：理想情况下，协议应当把关心的处理策略完整写出来， 这样符合方案效应才是良好定义的（Hernán & Robins, 2017）。

这一条直接对应第 19 章的动态策略：临床上真正想比的策略几乎总是动态的， 而把动态成分漏写进协议，就会在分析阶段把「合规的停药」误判成「不依从」并错误地删失他们。

一个很反直觉的结论：完全依从反而是坏事

书设想：试验进行中，共识开始形成——\(g_0\) 不如 \(g_1\)， 于是一些医生开始建议「CD4（\(L_k\)）首次跌破 200 时开始治疗」。 结果许多被分配到 \(g_0\) 的人实际遵循的是 \(g_0'\)：「持续 \(A_k=0\)，但在 \(L_k < 200\) 之后转为 \(A_k = 1\)」。

\(g_1\) 对 \(g_0'\) 的对比既不是 ITT 效应，也不是原来的符合方案效应—— 它是另一项目标试验（把人随机分配到 \(g_1\) 或 \(g_0'\)）里的符合方案效应。

有趣的是，如果我们关心的策略与实际试验里的那些不同， 那么「所有参与者都完全遵守协议里规定的策略」反而是不利的。 完全依从意味着这份试验数据不能用来模拟一项协议不同的目标试验 （因为实际数据里没有任何个体遵循了新目标试验的协议）。 ……正是不依从，让我们能够用一项给定随机试验的数据， 去模拟其它回答不同的、也许更相关的因果问题的随机试验。

— What If, §22.2, p.307

这段话值得对着二次分析的审稿意见念一遍： 「依从率低」在 ITT 的语境里是缺陷，在目标试验模拟的语境里是数据的信息量。

Technical Point 22.1 与 22.2：三种「直接效应」，只有一种有目标试验

直接效应 定义 能不能有目标试验
受控直接效应（controlled） \(E[Y^{a=1,m}] - E[Y^{a=0,m}]\)，把中介 \(M\) 固定在 \(m\) 能：对 \(A\) 与 \(M\) 都做序贯随机化的试验；它其实就是第 19 章那种「持续策略对比」的特例（把 \(A, M\) 换成 \(A_0, A_1\)）
纯直接效应 / 自然直接效应（pure / natural） \(E\left[Y^{a=1, M^{a=0}}\right] - E\left[Y^{a=0,M^{a=0}}\right]\) 不能。它是跨世界量（同一个反事实同时被 \(a=1\) 与 \(a=0\) 索引），无法从对 \(A\)、\(M\) 或两者的随机试验中识别，在 FFRCISTG 模型下也无法从观察数据识别
主分层直接效应（principal stratum） 在 \(M^{a=0} = M^{a=1} = m\) 的那部分人里 \(A\) 对 \(Y\) 的效应 它不涉及联合反事实 \(Y^{a,m}\)，因而不要求对 \(M\) 的干预良好定义；但当 \(A\) 几乎对所有人都影响 \(M\) 时，它只适用于极小的一个子人群，政策相关性很低

书对纯直接效应的处理特别值得注意：Pearl (2001) 把它改名为自然直接效应， 并证明在某些因果图下它可以在他的 NPSEM-IE 模型下被识别—— 因为该模型假设了一些不可检验的跨世界独立性，而这些假设无法被任何随机试验反驳。

这正是第 23 章的入口：中介分析之所以长期有争议， 争的不是统计，而是「你愿不愿意接受一个原则上无法被试验反驳的假设」。

22.3 模拟一个目标试验：先写协议，再看数据

如果做不了务实随机试验，我们可以试着通过分析现有的观察数据来模拟它。 这时我们就把那项试验称为我们这次观察性分析的目标试验。

— What If, §22.3, p.307

协议要素：书这里列了六项，不是常被引用的「七要素」

至少，我们需要明确指定协议的下列关键成分： 入选标准、随访的起点与终点、处理策略、关心的结局、因果对比、数据分析计划。

— What If, §22.3, p.307（逐项照录）

这里只有六项，而且把「随访起点与终点」合成了一项。 文献（以及 causalR 路线图 W11）里常说的「七要素」来自 Hernán & Robins 2016 那篇方法学论文，它把分配程序（assignment procedures） 单列，并把随访期与结局分开。两处不矛盾，但条目数与切分方式不同—— 引用时要说清是哪一版，本页按书上的六项照录。

书还提醒了一件容易被忽略的事：

注意，精确指定目标试验的协议，可能需要对可用数据做一些探索。 例如，只有在确定数据里含有 HIV 诊断信息之后， 我们才能合理地提议去模拟一项以 HIV 感染者为对象的目标试验。

— What If, §22.3, p.307

「先写协议」不等于「闭着眼睛写协议」——可行性探索是允许的， 不允许的是看了结果再改协议。

ITT 在观察数据里一般模拟不了

在对现有观察数据的分析中，模拟意向性治疗效应很少是可能的， 因为「实际被分配到某条策略」这件事是未知的。

— What If, §22.3, p.307

最接近的替代品是比较「启动者」：

  • 在基线启动 \(A_0 = 1\) 并留在研究中直到随访结束；
  • 在基线启动 \(A_0 = 0\) 并留在研究中直到随访结束。

它与真 ITT 的差别很明确：真 ITT 按「被分配到的策略」分组，这个对比按「启动了哪条策略」分组。 边注还给了一个更接近的替代：如果有处方（而不是配药）数据， 按基线是否拿到处方分组会更像目标试验里的 ITT 分析。 另一条边注点明：比较启动者的观察性分析，等价于 Fine Point 22.2 里的修正 ITT 分析。

而符合方案效应的观察性类比，定义与目标试验里完全相同—— 因为观察性研究里没有事先写好的协议，每一个符合方案效应都对应一项特定的目标试验。

一般而言，我们只能用观察数据去模拟那些「至少有一些个体实际遵循了其预期干预」的目标试验。 不过在某些情形下，研究者可能愿意使用建模（例如剂量–反应结构模型） 外推到数据中实际不存在的干预之外。

— What If, §22.3, p.308

「效力 / 效果」这个二分法，书建议直接放弃

书先摆出这个二分法被用得有多混乱： 有时把同一项试验里的 ITT 当作 effectiveness、把符合方案效应当作 efficacy； 有时又反过来——把随机试验里的 ITT 当作 efficacy（即使有不依从）， 而把模拟它的观察性研究里的符合方案效应当作 effectiveness（即使假设了完美依从）。

也就是说，尤其是在涉及长期持续策略的场景里， 「效果」与「效力」这两个标签是含糊的： 无论是「有不依从环境下的意向性治疗效应」还是「真实世界环境下的符合方案效应」， 都很难说它度量的是「完美条件下的处理因果效应」。

— What If, §22.3, p.309

与其坚持一个人为的效力–效果二分， 不如接受「所有因果效应都位于一条『效果连续谱』上的某处」。 这时，对「定义了所关心因果效应的那些处理策略」做出明确定义，才是更有信息量的， 因为决策者需要的是关于良好定义的干预的效应信息。

— What If, §22.3, p.309

22.4 时间零点：两个难题，两套解法

目标试验模拟的一个关键成分，是确定观察性分析中随访的起点， 也称为基线或时间零点。入选标准需要在那个时点被满足，而不是更晚； 研究结局从那个时点之后开始计数，而不是更早。

— What If, §22.4, p.309

书先解释了为什么随机试验里不会搞错：时间零点就是满足入选标准并被分配策略的那一刻。 往前挪不合理（策略还没分配、入选标准还没定义），往后挪则有偏：

随访从随机化之后才开始是可能有偏的，因为试验头两年的死亡会被排除在分析之外， 处理的任何短期效应都会被漏掉。更成问题的是，如果处理确实有短期效应， 那么到第 2 年时，活性处理组中更易感的个体已经死掉了，另一组则不然。 这种两年后易感者比例的差异，破坏了随机化所实现的基线可比性，为选择偏倚打开了大门。

— What If, §22.4, p.309

边注给了那个著名的现实案例：

绝经后激素治疗对心脏病效应的观察性研究与随机试验之间那场广受关注的分歧， 部分正是由于前者对时间零点的错误处理（Hernán et al. 2008）。

— What If, §22.4 边注, p.309

难题一：时间零点不唯一

入选标准只能在一个时刻满足

最简单的情形：随访就从那个唯一的时刻开始。

例：比较「CD4 首次跌破 500 时立即启动治疗」与 「CD4 首次跌破 350 时延迟启动」—— 随访从 CD4 首次跌破 500 那一刻开始。

入选标准可以在多个时刻满足

这才是常出问题的情形。

例：绝经后、无慢病史、过去两年未用激素治疗的女性。 若她从 51 岁到 65 岁持续满足这些条件， 随访该从哪一岁开始？51？52？53？

在目标试验里，一位女性在其一生中可以在多个时刻有资格被招募， 即她有多个有资格的时刻。

— What If, §22.4, p.310

三种选法：(a) 第一个有资格的时刻；(b) 随机选一个；(c) 每一个都用。 其中 (c) 就是序贯目标试验模拟——每一个起点开一项新试验。开多少项取决于数据的采集频率：

  • 固定日程采集（如很多流行病学队列每两年一次）→ 每个预定时点开一项新试验；
  • 个体特异日程（如电子病历）→ 选一个固定时间单位（日 / 周 / 月），每个时间单位开一项新试验。

时间单位选粗了会引入偏倚——一条常被忽略的边注

无偏的时间单位选择因研究而异。例如，考虑一项研究，其中时变处理与混杂因子 对许多个体而言一周内变化不止一次。那么选择周或月作为时间单位会引入偏倚。 这个偏倚可以通过选择日作为时间单位来消除。 如果没有逐日的处理与混杂因子数据，这个偏倚就无法被完全纠正。

— What If, §22.4 边注, p.310

这一条应当写进任何 EHR 研究的数据可行性评估： 「我的处理与混杂因子多久变一次」决定了「我的时间单位能取多粗」， 而后者又决定了「这份数据到底能不能无偏地模拟目标试验」。

书也点明了 (c) 的代价：

从统计角度看，序贯模拟策略 (c) 可能比前两种更有效率，因为它用上了更多可用数据。 然而，由于个体可能被纳入多项目标试验，必须对效应估计的方差做适当调整。 这可以通过对整个分析做 bootstrap 来实现。

— What If, §22.4, p.310

难题二：基线时无法唯一分配策略

目标试验把 CD4 刚跌破 500 的人分配到三条策略之一： (1) 立即开始；(2) CD4 跌破 350 时开始；(3) CD4 跌破 200 时开始。

用观察数据模拟时：在时间零点就开始治疗的人 → 分到策略 (1)。 但在时间零点没开始治疗的人，其数据同时与策略 (2) 和 (3) 相容。 该分给谁？

一种可能是随机选一条策略分给他，但那在统计上是低效的。 另一种可能是在数据中为这些个体各造两个完全相同的副本——克隆—— 并把两个克隆各分配到一条不同的策略。 克隆随后在其数据不再与所分配那条臂相容的时刻被删失。

— What If, §22.4, p.310

克隆 + 删失 + 加权：三个动作，缺一不可

  1. 克隆：一个人被复制成多份，每份指派一条与其基线数据相容的策略。
  2. 删失：当这个人的数据不再与该策略相容时，那个克隆被删失。 例：若他在 CD4 跌到 350 时没开始治疗，则「CD4 跌到 350 就开始」那个克隆在那一刻被删失。
  3. 加权：这种删失很可能是信息性的， > 由此引入的潜在偏倚需要通过用 IP 加权调整时变因子来纠正。 > > — What If, §22.4, p.310

而最关键的是那条「双重分配」规则：

重要的是，如果这个人在任何一个克隆被删失之前就已经死亡， 那么两个克隆都会死亡，因而这次死亡会被同时算给两条策略。 这种事件的双重分配，防止了「等待期内发生的事件被系统性地只算给其中一条策略」所可能造成的偏倚。

— What If, §22.4, p.311

方差同样要 bootstrap（因为同一个人通过克隆被多次纳入分析）。 克隆 + 删失 + 加权可以与序贯目标试验模拟组合使用。

出处：Robins et al. (2008)、Cain et al. (2010)；相关工作见 van der Laan & Petersen (2007)。

Fine Point 22.5：宽限期——以及它为什么会让 ITT 失效

在真实世界里，抗逆转录病毒治疗不可能在被分配的当天就开始。 取决于医疗系统，可能要几周或几个月才能完成必要的临床与行政流程、并让患者被充分告知。 因此，研究者需要定义一个宽限期（比如 3 个月），在此期间启动仍被视为「立即启动」。 否则这项研究估计的就是「现实中很少发生、或者实践中无法成功实施」的策略的效应。

— What If, Fine Point 22.5, p.311

宽限期的后果是同一个人的数据在宽限期内与不止一条策略相容—— 于是又回到克隆 + 删失 + 加权。而最值得记的是这条副作用：

使用带克隆与删失的宽限期时，意向性治疗效应无法被估计， 因为几乎每个人都会向每条策略贡献一个克隆。 由于每个人在基线都被分配到了所有策略， 基于基线分配的对比（即「意向性治疗分析」）比较的是结局本质上完全相同的两组。 因此，基线带宽限期的分析天然是朝着估计某种符合方案效应去的，一般需要纳入充分的调整。

— What If, Fine Point 22.5, p.311

最后一条实现细节：一个良好定义的、带宽限期的启动策略， 应当指定宽限期内启动的时点（详见 Cain et al. 2010 的附录）。

22.5 用数据回答 What If 问题的统一方法：两类研究只差三件事

本书描述并整合了两个因果推断框架：反事实与因果图。 明确的目标试验模拟把两者重新统摄起来，并把它们落到可操作的因果推断上。 通过把因果推断围绕一个科学家深深熟悉的概念——实验——来组织， 目标试验框架帮助研究者用自己的专业知识把因果问题表述清楚。 一旦因果问题被表述得没有歧义，研究设计与数据分析就自然而然地流出来了。

— What If, §22.5, p.311–312

Fine Point 22.6：随机试验与观察研究的数据，只差三件事

只有三件事把随机试验与观察研究的数据区分开来。在随机试验中： (i) 由于随机化，预期没有基线混杂； (ii) 随机化概率是已知的； (iii) 每个个体在基线被分配到哪条策略是已知的。

— What If, Fine Point 22.6, p.313

观察性分析怎么补：(i) 靠测量并适当调整一组充分的协变量； (ii) 靠正确设定「给定过去史的处理分配模型」。 而 (iii)——

有趣的是，(iii) 对于估计符合方案效应而言并不是必需的， 无论在随机试验还是观察研究中，因为有效估计量（作为充分统计量的函数）并不使用这一信息。 也就是说，分析者不需要知道被比较的是哪些策略，更不需要知道谁被分配到了哪一条： 在一项随机试验里，你可以把随机分配变量从数据集中删掉， 只要测到了一组充分的混杂因子，仍然能估出符合方案效应。

— What If, Fine Point 22.6, p.313

（在完全依从的动态策略试验中，一组充分的混杂因子就是策略在分配处理时用到的全部 时固定与时变协变量；Robins 1986。）

这一条读起来像技术细节，实际上是全章最强的论证： 如果「知道谁被随机到哪一组」对估计符合方案效应都不是必需的， 那么随机试验与观察研究在这个目标上的差别就只剩「有没有基线混杂」一件事。

于是本章最锋利的那个判断出现了：

考虑到这些相似性，人们可能会预期随机试验与观察研究会被用相似的方式分析， 只是观察性分析在估计 ITT 的类比量时要额外调整基线混杂因子。 然而在实践中，随机试验与观察研究的典型分析方式截然不同—— 这既令人费解，而且（如我们下面所论证的）是成问题的。

— What If, §22.5, p.312

常规做法 问题出在哪
典型的「ITT 分析」：不做任何混杂或选择偏倚调整 不调基线混杂是对的（随机化保证）；不调随机化后混杂也是对的（基线分配的效应不可能被随机化后的事情混杂）。但基线随机化保证不了「失访者与未失访者可交换」——所以有效估计 ITT 效应可能需要一个「对随机化后（时变）预后因子做过调整」的 ITT 分析
所谓的「per-protocol 分析」：把首次偏离协议的人删失，不做任何调整 书给了三条理由说它可疑

「所谓 per-protocol 分析」的三宗罪

第一：和 ITT 分析一样，可能有差异性失访造成的选择偏倚， 需要用 g-方法调整基线后（时变）风险因子。

第二：这种分析部分地无视了随机化分组， 于是「在一条策略下仍在协议内的那部分人」与「另一条策略下仍在协议内的那部分人」未必可交换。

也就是说，这种「per-protocol 分析」类似于一项观察性分析， 因此需要用 g-方法来调整那些影响「是否继续留在协议内」的时变风险因子造成的偏倚。

— What If, §22.5, p.314

（工具变量估计有时能在不显式调整任何变量的情况下有效估计符合方案效应， 但其有效性取决于有一个有效的工具以及很强的建模假设； 某些形式的工具变量估计是 g-估计的特例，见 Technical Point 16.6。）

第三：这种分析忽略了被比较的持续策略本来是动态策略。

一个常见的错误是：把停止治疗的个体删失，好像「停药」按定义就是对协议的偏离—— 这正是这种分析也被称为 on-treatment 分析的原因。 我们在前面已经讨论过：因毒性或禁忌症而停药的人并没有偏离协议，因此不应当被删失。

— What If, §22.5, p.314

边注还补了一条对生存结局的强化：

对失效时间结局而言，只要处理对结局有因果效应，g-方法就总是必需的。 原因是处理 \(A_k\) 通过对时变指示变量 \(D_{k+1}\) 的效应，影响 \(k\) 之后的所有变量 （见 Technical Point 21.10）。

— What If, §22.5 边注, p.314

书的结论是一条对称性要求，值得整段抄下来：

上述所有考虑，同时适用于随机试验的分析与「用观察数据模拟目标试验」的分析。 当目标是估计符合方案效应或其观察性类比时，随机试验与观察研究的分析应当是相同的。 如果我们觉得有必要在观察性研究的分析中调整时变混杂与选择偏倚， 那我们也应当同样觉得有必要在随机试验的分析中调整随机化后的混杂与选择偏倚。

— What If, §22.5, p.314

Fine Point 22.7：一个让人不适的算术题——被混杂的观察研究给出了正确的政策

某国许多肺癌患者在用一种未经检验的非处方药 \(A\)。监管方资助了一项双盲安慰剂对照随机试验， 随机抽取当年确诊肺癌者的 20%，全部参与者都依从了分配。60 个月死亡风险：

\(A = 0\) \(A = 1\)
\(Y=1\) 450 550
\(Y=0\) 550 450
合计 1 000 1 000

风险 45% vs 55%，监管方据此禁掉了该药。 后来，在未被抽入试验的那 80% 患者中做了一项观察性研究， 发现用药者与未用药者的死亡风险都是 0%。这两个结果怎么可能同时成立？

书的推演（笔者已逐步复核）：由随机抽样与随机化， 试验两臂各 1 000 人与观察研究的 8 000 人有相同的反事实类型分布。 观察研究里 0% 死亡意味着 (i) 没有「注定死」（doomed）的人； (ii) 所有 \(Y^{a=1}=1\) 的人必定是「被害」（hurt）型且实际接受了 \(A=0\)； (iii) 所有 \(Y^{a=0}=1\) 的人必定是「被救」（helped）型且实际接受了 \(A=1\)。

于是可以把试验数据按类型重建：

「被害」型 \(A=0\) \(A=1\) 「被救」型 \(A=0\) \(A=1\)
\(Y=1\) 0 550 \(Y=1\) 450 0
\(Y=0\) 550 0 \(Y=0\) 0 450
合计 550 550 合计 450 450

两表相加正好复原试验数据（\(550 + 450 = 1000\) ✓），因而也不存在「免疫」型。

我们的结论是：监管方应当重新批准处理 \(A\)，并建议维持现行做法， 因为观察研究表明，每一位肺癌患者不知怎么地都掌握着试验者无从获得的私人知识： 这个处理对他个人是有害还是有益。

— What If, Fine Point 22.7, p.315

书给的极端解释是：人群有 55/45 的族群划分，出于遗传原因该药对第一群一律有害、 对第二群一律有益；两群人各自通过观察同伴的结果学会了避开 / 选用它—— 即同时存在最大程度的定性效应修饰与最大程度的混杂。

上面描述的极端设定当然不现实，但它有助于说明一个重要的点： 随机试验比较的是「全治」与「全不治」，而最优策略是「只治第二族群」。 当效应修饰因子（族群）的数据没有被收集时， 在随机试验里就不可能把个体分配到最优策略。 相反，在观察研究里，所有个体都遵循了最优策略，因而得到了「无人死亡」这个最优结局。 于是，是那项被混杂的观察研究、而不是那项无混杂的随机试验，揭示了正确的政策。

— What If, Fine Point 22.7, p.315

Fine Point 22.8 把它推广到更现实的设定：若观察数据的 \(E[Y]\) 同时低于试验两臂的均值， 那么 \(E[Y] = E[Y^g]\) 对应的是一条随机动态策略 \(g\)—— 「以 \(\Pr[A=1\mid U]\) 的概率给药」，其中 \(U\) 是使 \(Y^a \perp\!\!\!\perp A \mid U\) 的未测变量集。 \(g\) 本身无法实施（\(U\) 没测），但这个发现可以促使研究者去测一些处理前协变量 \(V\)， 再用随机试验数据找出并实施一条确定性动态策略 \(g^*(x)\)，使 \(E[Y^{g^*}]\) 低于观察到的 \(E[Y]\)。

这两条边栏是全书对「随机试验至上」最克制也最有力的一次反驳： 它没有说随机试验不好，它说的是「全治 vs 全不治」这个对比本身可能问错了问题。

这章停在哪里

第 22 章没有引入任何新的估计量，它做的是把前三章的机器装进一套研究纪律：

老问题 本章的处理
「这个药有效吗」 先问：哪两条策略？ ITT 与符合方案效应回答的是不同的问题
随机试验 > 观察研究 只差三件事（无基线混杂 / 已知随机化概率 / 已知分配），而第三件对符合方案效应甚至不必要
「per-protocol 分析」 常规做法有三宗罪；正确做法是把它当观察性分析，用 g-方法
「因毒性停药 = 不依从」 错。合规的停药是策略的一部分，删失他们才是错
「依从率低是缺陷」 在目标试验模拟里，不依从正是能模拟其它试验的原因
「随访从哪天开始不重要」 时间零点是最常见的错误来源；两个难题各有解法
「效力 vs 效果」 人造二分；所有效应都在一条效果连续谱上

而本章真正的方法论内核只有一句： 把因果问题写成一份试验协议——如果写不出来，那它还不是一个因果问题。

自检① 拿到一份 EHR 数据，第一天该做什么？

写协议，不是跑模型。 按书上的六项逐条写：

  1. 入选标准——在哪个时刻判定？这个时刻会不会重复出现？
  2. 随访起点与终点——时间零点是什么事件？终点是死亡 / 失访 / 行政截尾中最早者？
  3. 处理策略——把动态成分写全（「持续治疗，除非出现毒性或禁忌症」）。 漏写这半句，分析阶段就会把合规停药者误删失。
  4. 结局——怎么测、什么时候测、会不会被处理影响测量时机。
  5. 因果对比——ITT 类比（比较启动者）还是符合方案效应？
  6. 数据分析计划——用哪种 g-方法、权重怎么估、方差怎么算（克隆或序贯模拟一定要 bootstrap）。

第 3 项是最容易漏也最贵的一项；第 1 项决定了你要不要做序贯模拟。

自检② 我的时间单位该取多细？

按 §22.4 那条边注反推：取决于处理与混杂因子多久变一次。

  • 队列每两年访视一次 → 每次访视开一项新试验；
  • 电子病历、处方按日记录 → 能取日就不要取月；
  • 如果处理与混杂因子一周内会变多次，取周或月就会引入偏倚， 而没有逐日数据时这个偏倚无法被完全纠正。

这一条应当在数据可行性评估阶段就回答，因为它决定的不是分析精度， 而是「这份数据到底能不能无偏地模拟这项目标试验」。

自检③ 克隆-删失-加权的三个动作，各自防的是什么？

  • 克隆防的是低效（随机指派一条策略也无偏，但浪费信息）；
  • 删失保证的是相容性：一个克隆只能代表「一路都与该策略相容」的那段随访；
  • 加权防的是删失造成的选择偏倚——这种删失几乎必然是信息性的 （谁在 CD4 跌到 350 时没开始治疗，与他的预后有关）。

外加一条不能省的规则：克隆被删失之前发生的死亡， 要同时算给两条策略——否则等待期内的事件会被系统性地只算给其中一条。

还有一条容易忘的后果（Fine Point 22.5）： 一旦在基线用了宽限期 + 克隆，ITT 效应就估不出来了—— 因为每个人都向所有策略各贡献了一个克隆。

library(dplyr)

## ① 序贯目标试验模拟：每个「有资格的时刻」开一项新试验
##    long: id, t（日历时间单位）, eligible, A, L, event, censor
make_trials <- function(long, horizon = 60) {
  starts <- long |> filter(eligible) |> select(id, trial = t)
  starts |>
    inner_join(long, by = "id", relationship = "many-to-many") |>
    filter(t >= trial, t < trial + horizon) |>
    mutate(k = t - trial) |>                    # 试验内的随访时间，从 0 起
    arrange(id, trial, k)
}
## 同一个人进入多项试验 ⇒ 方差必须 bootstrap（按 id 整体重抽，不是按行）

## ② 克隆 + 删失 + 加权：基线数据与多条策略相容时
##    strategies: 一个命名 list，每个元素是 function(A, L, k) -> 是否仍相容
clone_and_censor <- function(dat, strategies) {
  purrr::imap_dfr(strategies, function(compatible, nm) {
    dat |>
      group_by(id, trial) |>
      mutate(
        strategy = nm,
        ok       = compatible(A, L, k),
        # 首次不相容处人工删失；此前的事件照常保留（含死亡 ⇒ 两条策略都记）
        cens_k   = ifelse(any(!ok), min(k[!ok]), NA_integer_)
      ) |>
      filter(is.na(cens_k) | k < cens_k) |>
      ungroup()
  })
}
