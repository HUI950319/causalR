W09 · 处理效应异质性分析

郑老师训练营第九周 · 讲义 79 页 + 5 段视频约 2 小时 11 分

本页两部分：讲义原件内嵌展示，版权归课程作者所有；内容整理是笔记作者 根据讲义与视频语音转写写的，不是课程原话。出处、压缩处理与已知限制见 课程讲义总览。

全课最后一周，问题从「这个干预有没有效」转成「它对谁有效」。 讲义开篇一句话定了调（p3）：

「平均」之下，个体效果各异。精准医疗的核心挑战：同药不同效。

前八周求的都是一个 ATE——一个数字代表整个人群。这一周要估的是 \(\tau(x)\)， 每个人一个数。视频里讲师说得很直白：这块内容「我想很多人会比较陌生， 基本上我想你们第一次接触到这方面的知识点」。

异质性就是原书说的效应修饰，见第 4 章； 它与交互作用的区别见第 5 章。

处理效应异质性分析（79 页）。阅读器自带翻页、缩放与页码跳转； 手机上若页内不显示，直接打开或下载。 想直达某页，在链接末尾加 #page=36 之类的锚点。

一、从 ATE 到 CATE：ITE 永远算不出来，能算的是 CATE

讲义 p6–9。ATE 的局限只有一句（p6）：无法回答「谁受益更多」的问题。

新概念是条件平均处理效应 CATE：

\[\tau(x)=E\!\left[Y(1)-Y(0) \mid X=x\right]\]

造成异质性的原因是能够改变治疗效果大小的基线特征——年龄、基因型、 生物标志物、疾病严重程度等（p9）。讲义 p8 给了四个「同药不同效」的临床例子：

  • 华法林：患者 A 卒中风险降低 65%、无出血；患者 B 发生严重颅内出血
  • 抗血小板药：CYP2C19 基因型导致疗效 3–5 倍差异
  • 肿瘤免疫治疗：PD-L1 高表达者肿瘤完全缓解、长期生存；低表达者治疗无效且出现免疫性肺炎
  • 抗抑郁药：仅约 30% 患者对一线治疗充分应答

ITE 与 CATE 不是一回事，这是全周最容易混的地方

讲义 p18 用降压药举了个能记住的例子：

  • ITE（个体处理效应）：张三服用后血压下降 5 mmHg—— 但我们永远无法同时知道他不服用的结果。\(\tau_i=Y_i(1)-Y_i(0)\) 对单个个体是确定性的，但不可观测（反事实缺失）
  • CATE：所有 50 岁、男性、有高血压病史的人，平均血压下降 4.8 mmHg

关键那句在 p18 底部：当我们用模型预测时，对张三给出的 \(\hat\tau(x)=4.8\)， 是基于他特征的群体平均，而非他个人的真实 ITE。

所以「个体化治疗效应」这个说法容易误导——算出来的始终是「与他特征相同那群人的平均」。 特征给得越细，这个平均越接近个体；但视频里也提醒了代价： 条件给得越细，「对模型的要求、对样本量的要求就越高」。

三类方法，三个分析单元

讲义 p11、p23 把三类 HTE 方法的分野讲得很清楚：

方法 分析单元 回答的问题
亚组分析 群体 该亚组里，平均效应是多少？
疾病风险评分 DRS 风险层级 该风险层里，平均效应是多少？
效应评分法 个体患者 特定患者，预测效应是多少？

亚组分析（p12–14）的核心工具是交互项检验： \(Y=\beta_0+\beta_1T+\beta_2X+\beta_3(T\times X)+\varepsilon\)， 重点看 \(\beta_3\) 是否显著（\(\beta_3\neq 0\)、\(P<0.05\) 存在效应修饰作用）。 四大约束原则是先验性、生物学合理性、临床可操作性、一致性（p12）。

疾病风险评分（p15–16）用基线预后风险作为效应修饰的代理变量。 讲义在这里标了一个关键限制：模型构建仅能使用治疗前变量—— 治疗后变量已被治疗影响，用了会引入偏倚。它的局限也写得直白： 预后因子 \(\neq\) 效应修饰因子，高风险不等于高获益。

二、效应评分法：四种 Meta-Learner：分解与组合

讲义 p27–41。核心任务是从 \((X, T, Y)\) 数据中精准估计 \(\tau(x)\)，两大策略阵营： 参数化方法 vs 非参数 / 机器学习方法。

参数化那条路就是传统回归加交互项（p28）： \(\hat\tau(x)=\beta_1+\beta_3X\)。优势是简单透明、统计性质明确、软件支持完善； 局限是线性假设、交互项必须事先知道哪些 \(X\) 可能有交互作用、维度灾难。

Meta-Learner 的思路是「将 CATE 估计问题拆解为多个预测子问题」（p31）， 核心特质是灵活——可以把任何预测模型（随机森林、神经网络、甚至传统回归） 转化为 CATE 估计器。四种策略：

策略 公式 讲义的比喻 优点 缺点
S-Learner 单一学习器 \(\hat\tau(x)=\hat\mu(x,T{=}1)-\hat\mu(x,T{=}0)\) 一位全科医生同时学习治与不治的结局 充分利用所有数据，避免数据分割 当特征 \(X\) 维度很高时，治疗 \(T\) 的信号可能被淹没，导致低估异质性
T-Learner 双学习器 \(\hat\tau(x)=\hat\mu_1(x)-\hat\mu_0(x)\) 两位专科医生各看一类病人，再会诊给出差异 概念最简单，直接建模估计异质性 两个模型独立，误差会叠加；治疗组样本量不平衡时效果差
X-Learner 先得 \(\hat\mu_1\)、\(\hat\mu_0\)，再算「伪效应」分别训练，最后用倾向评分加权平均 —— 观察性研究中治疗组数量远小于对照组时优于 T-Learner 实现相对复杂，计算步骤多
R-Learner 基于 Robinson 正交化分解：\(Y-E[Y\mid X]=\tau(X)\cdot(T-E[T\mid X])+\text{误差}\) —— 具有双重稳健性，只要 \(e(x)\) 或 \(m(x)\) 之一估计正确，\(\tau(x)\) 就一致；理论性质优良 对估计稳健性要求高，需要高质量估计两个干扰参数

讲义 p41 给了一套可以照着走的三步决策法

第一步，从简单开始。 先尝试传统回归或 T-Learner 作为基准，建立性能底线。

第二步，根据数据特点选择。

  • 治疗组与对照组样本量严重不平衡 → 优先考虑 X-Learner
  • 对估计稳健性有极高要求，或倾向评分和条件均值能够较好估计 → R-Learner
  • 数据维度高、交互复杂，目标是探索未知的异质性模式 → 因果森林

第三步，进行敏感性分析。 尝试 2–3 种不同策略，比较结果的稳定性—— 「如果多种方法给出高度一致的结果，结论的可信度会大大增强； 如果结果差异显著，则需要深入探究差异来源。」

三、因果森林：换一个分裂准则：从预测到推断的专用设计

讲义 p37–57。因果森林 2019 年提出，与随机森林的根本区别只有一处—— 决策树的分裂准则（p37、p43）：

随机森林（用于预测） 因果森林（用于推断）
目标 准确预测结局 \(Y\) 准确估计处理效应 \(\tau(x)\)
分裂准则 选择使子节点内结局的方差减少最多的特征和分割点 选择使子节点间处理效应的差异最大化的特征和分割点

一句话：一个优化对 \(Y\) 的预测，一个优化对 \(\tau\) 的估计。

聚合方式（p39）：每个患者被每棵因果树分配到一个叶子节点， 在该叶子内利用其他样本估计一个局部处理效应；对所有树的局部效应估计取平均得到该患者的 \(\hat\tau(x)\)；计算所有树估计结果的方差，提供置信区间。

因果森林比 Meta-Learner 多出来的能力（p57）——视频里称之为「其他方法都没有的」：

  1. CATE 的预测器：直接输出每个个体的 \(\hat\tau(x)\)，揭示个体效应分布
  2. 识别异质性：整体检验（森林的「异质性重要性」检验）+ 变量重要性排序—— 评估哪些协变量 \(X\) 对驱动效应异质性贡献最大
  3. 发现与描述亚组：按 \(\hat\tau(x)\) 的分布划分高 / 低获益群体， 并用部分依赖图 PDP可视化高获益群体的特征

四、整合应用：因果森林算完 CATE，事情还没完

讲义 p58–67。视频里点题：「我们讲了因果森林算出的 CATE 之后，这事情还没结束， 因为它只是算开，怎么用呢？」因果森林是一个具体的算法/估计器， 而 Meta-Learner 与双重稳健估计是更高级的估计框架或策略，两者层级不同（p59）。

两条整合策略（p60）：

  • 策略一 · 因果森林作「基学习器」（前期整合）：直接嵌入 S/T/X-Learner 或双重稳健框架内，用于估计倾向评分、条件均值或直接估计 CATE
  • 策略二 · 因果森林作「侦察兵」（后期整合）：独立运行因果森林识别关键异质性变量， 再把这些变量作为分层因素，对另一估计器（如 TMLE）得到的 CATE 进行分组评估和比较

亚组内的 ATE 为什么不直接取 CATE 平均

讲义 p63 单独一页回答这个很自然会想到的问题：

因果森林 双重稳健估计
CATE 估计在特定亚组上可能存在偏差，且难以提供准确的标准误和置信区间 AIPW / TMLE 提供无偏或低偏的亚组 ATE 估计
更适合回答「可能是什么」 更适合回答「确切是多少」以及「这个差异是否真实存在」

视频里讲师用了一个更好懂的类比：这就像随机对照研究里， 总人群分组均衡、没有混杂因素，但取出一个亚组之后，亚组内部仍然要用回归控制混杂—— 分组均衡是对总体说的，不是对每个子集说的。

所以标准做法是：因果森林负责找到分层变量、算出 CATE 并分组， AIPW / TMLE 负责在每个组内给出可信的 ATE 与置信区间。

讲义 p66 还提到一个现成的整合函数：R 的 EpiForsk 扩展包里有 CausalForestDynamicSubgroups，可以结合因果森林与 AIPW， 一次做完「动态分组 → 样本外估计各亚组 GATE → 亚组间差异的正式统计检验 → 协变量分布热力图」四件事（p66–67）。

五、案例：牙齿脱落对死亡率的高维效应异质性：整套流程的范文

讲义 p68–76 用一篇 Journal of Dental Research 的论文 （Matsuyama 等，High-Dimensional Effect Heterogeneity of Tooth Loss on Mortality） 把全周的方法串成一条完整流水线。

基本情况（p69）：日本老年学评估研究（JAGES）2013 年基线调查数据， 最终纳入 69,265 名 65 岁及以上老年人，随访时间中位数 9.2 年。 暴露是牙齿状态（按 WHO 功能牙齿标准分为 \(\geq 20\) 颗牙与 \(<20\) 颗牙， 47.2% 的参与者牙齿缺失），结局是全因死亡，纳入 44 个协变量。

步骤 做法 结果
ATE 逆概率加权（IPW）平衡两组，44 个协变量建逻辑回归算稳定权重 牙齿脱落与死亡风险增加 3.2 个百分点相关（系数 0.032；95%CI 0.023–0.040）；Cox 模型 \(\mathrm{HR}=1.19\)（95%CI 1.14–1.25）
CATE 广义随机森林 GRF 的因果森林，20 折交叉拟合预计算 CATE；再用 AIPW 估计 CATE 五等分亚组的组平均处理效应 GATE 按 CATE 五等分后，效应最大组死亡率高达 32.5%，效应最小组仅 12.7%，相差近 2.5 倍，且五等分组的 GATE 呈递增趋势

for(var in names(W)) {
    if(is.factor(W[[var]])) {
        if(nlevels(W[[var]]) == 2) {
            # 二分类变量：转换为0/1
            W[[var]] <- as.numeric(W[[var]]) - 1
        } else {
            # 多分类变量：创建哑变量
            dummies <- model.matrix(~ W[[var]] - 1)
            colnames(dummies) <- paste0(var, "_", levels(W[[var]]))
            # 移除原始变量，添加哑变量
            W <- cbind(W, dummies)
            W[[var]] <- NULL
        }
    }
}

# 函数：计算带置信区间的PDP
compute_pdp_with_ci <- function(fit, X_data, feature_name, grid_points = 50) {
    # 获取特征的最小值和最大值
    feature_min <- min(X_data[, feature_name])
    feature_max <- max(X_data[, feature_name])
    
    # 创建网格点
    grid_vals <- seq(feature_min, feature_max, length.out = grid_points)
    
    # 存储结果
    results <- data.frame(
        x = grid_vals,
        yhat_mean = NA,
        yhat_lower = NA,
        yhat_upper = NA
    )
    
    # 对每个网格点计算CATE的分布
    for(i in 1:length(grid_vals)) {
        # 创建新数据，固定当前特征为特定值
        X_new <- X_data
        X_new[, feature_name] <- grid_vals[i]
        
        # 预测CATE
        cate_pred <- predict(fit, X_new)$predictions
        
        # 计算均值、2.5%和97.5%分位数
        results$yhat_mean[i] <- mean(cate_pred)
        results$yhat_lower[i] <- quantile(cate_pred, 0.025)
        results$yhat_upper[i] <- quantile(cate_pred, 0.975)
    }
    
    return(results)
}
