1 多个处理组示例：合成 MEPS 数据 本文旨在展示如何应用 PSweight 程序包，使用平衡权重方法研究多个处理组 。该示例将基于合成版本的 MEPS 数据集。 本分析将聚焦于无混杂的描述性比较。

1.1 合成 MEPS 数据集

我们使用 2009 年医疗支出面板调查（MEPS）数据的一个合成数据集。我们的合成数据 集包括 20 个分类协变量和 5 个连续协变量。我们关注的主要结局是每位个体在 2009 年的 医疗总支出（healthExp）。我们希望研究亚洲人、黑人、白人和西班牙裔之间的健康差异 （种族）。 我们将使用几种不同的方法分析该合成数据集，包括逆概率加权、重叠加权，以及以处理组平均处理效应 （ATT）为目标的加权方法——该效应基于一个特定的参考组定义。对于每种方法，我们感兴趣的是估计四个 组中任意两个组的六个边际对比，即在特定目标人群上的边际均值之间的对比，也就是两个组在医疗支出 方面的平均控制差异。我们同时报告点估计、稳健三明治标准误和相应的 95% 置信区间。 #Load the synthetic MEPS Data Set meps <- read.csv(“meps_syn.csv”) #Transfer race to categorical variables meps\(race <- factor(meps\)race)

1.2 设计：倾向评分估计与平衡检查
