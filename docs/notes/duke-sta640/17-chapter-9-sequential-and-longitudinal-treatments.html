第 2 页

纵向观察性研究 I 之前的所有讨论都聚焦于单个时间点的处理 （横断面或面板设置） I 在现实情境中很常见，例如医学研究中，会在一段时间内对受试者重复收集数据 （处理、协变量和/或结局）——纵向研究 I 尤其关注估计时变处理对在较晚时间测量的目标结局的效应 I 混杂因素可以随时间变化，受过去处理影响，并影响未来协变量和/或结局 I 如果这些混杂因素本身受到处理影响，那么存在时变混杂因素时，标准回归调整无法给出一致估计量

第 3 页

序贯可忽略分配

我们考虑哪类研究

I 具有多个时间点的处理，其中处理分配在给定观测历史条件下是可忽略的。

I 如果我们可以论证上述假设成立，这可以作为随机化实验或观察性研究的一个可能模板

I 示例 1：患者在不同时间就诊。

I 示例 2：工作人员在工作场所暴露于危害（与健康工作者幸存者效应有关）

常见目标是估计处理在整个研究期间对结局的累积效应。

第 4 页

时变处理：示例 (Daniel et al. 2013, SIM)

I 在许多纵向医学研究中，患者的处理会随时间变化，并在研究期间测量多次，同时还会测量其他时变协变量。

I 例如，纳入一项比较两种降糖药物研究的 2 型糖尿病患者可能会在多个时间点接受随访，每次测量其 HbA1c（血糖水平的长期测量指标）、血压、胆固醇水平、BMI、贫血状态及其他变量

I 假设我们希望比较两种处理对入组后 18 个月时 HbA1c 的效应，以及入组后 18 个月内发生心脏事件的风险（或危险）。

第 5 页

时变处理：挑战 (Daniel et al. 2013, SIM)

A1 L2 A2 … Y

I 研究允许根据 HbA1c 和其他协变量的当前值（及过去值）改变处理剂量和类型。 I HbA1c 较高可能会导致增加当前药物的剂量；但 HbA1c 较高也被认为会增加发生心脏事件的风险，因此某一时间点的 HbA1c 成为后续处理与结局关系的混杂因素 I 由于 HbA1c 会随时间变化（这种变化在基线时无法预见），因此称为时变混杂因素

第 6 页

时变处理：挑战 (Daniel et al. 2013, SIM)

I 要估计处理对心脏事件风险的因果效应，似乎有必要在分析中控制 HbA1c

I HbA1c 不仅会影响处理，反过来也是如此!!!

I 有效的降糖药物会降低 HbA1c，因此当前处理变量的取值会对 HbA1c 的未来取值产生因果效应

I 这意味着控制 HbA1c 会产生问题，因为 HbA1c 的未来测量值位于过去处理与结局之间的因果路径上 I 以 HbA1c 为条件会阻断部分处理效应；此外，以处理后果为条件还可能引入碰撞点分层偏倚

第 10 页

因果目标量

I 典型目标量——由处理序列产生的边际因果效应： τa1 a2,a10 a20 = E[Yi (a1, a2 ) − Yi (a10 , a20 )],

对于所有 (a1, a2 ) , (a10 , a20 ) ∈ {0, 1}2 。

I 例如，比较始终接受高剂量处理 Pr(Y (1, 1) = 1) 与始终接受低剂量处理 Pr(Y (0, 0) = 1) 时的癌症进展 Y。

I 注意，我们只控制 (a1, a2 )，这就是为什么潜在结果 Yi () 仅是 a1, a2 的函数，而不是 L 的函数。

第 11 页

标准调整的问题

估计 Pr(Y (1, 1) = 1) − Pr(Y (0, 0) = 1) 的两种“标准”方法：

I 方法 1。“不要以进展 L obs 为条件，因为它是中间结局”：

Pr(Y = 1| A1 = 1, A2 = 1) − Pr(Y = 1| A1 = 0, A2 = 0) = 60% − 60% = 0

I 方法 2。“以中间进展 L obs 为条件，因为它被用于决定处理 A2”：

Pr(Y = 1| A1 = 1, A2 = 1, L o b s = 1) − Pr(Y = 1| A1 = 0, A2 = 0, L o b s = 1) = 60% − 80% = −20%

第 12 页

标准调整的问题 估计 Pr(Y (1, 1) = 1) − Pr(Y (0, 0) = 1) 的两种“标准”方法： I 方法 1。“不要以进展 L obs 为条件，因为它是中间结局”： Pr(Y = 1| A1 = 1, A2 = 1) − Pr(Y = 1| A1 = 0, A2 = 0) = 60% − 60% = 0

I 方法 2。“以中间进展 L obs 为条件，因为它被用于决定处理 Z2”： Pr(Y = 1| A1 = 1, A2 = 1, L o b s = 1) − Pr(Y = 1| A1 = 0, A2 = 0, L o b s = 1) = 60% − 80% = −20%

A1 L A2 Y

令 Ltobs（通常简写为 Lt）表示时变混杂因素，包括时变协变量和 t 时刻的中间结局。 令 āt = (a1, a2, …, at ), Āt = (A1, . . . , At ) I 序贯可忽略性：t 时刻的处理以依赖于观测到的过去（包括协变量和中间结局）的概率进行随机化，即在任意时间 t： {Yi (āt ), ∀āt } ⊥ Ai,t | Hi,t , 其中 Hi,t = (A1, …, At−1 ; L1, …Lt−1 ) 是观测历史 I obs 15 / 73

第 16 页

可识别性

I E[Y (a1, a2 )] 是潜在结果的函数 I E[Y (a1, a2 )] 的可识别性意味着它可以用观测数据表示

E[Y(a1, a2 )] = E[Y(a1, a2 ) | A1 = a1 ] (1) = E[Y(A1, a2 ) | A1 = a1 ] (2) Õ = E[Y(A1, a2 )| A1 = a1, L o b s = l]P(L o b s = l | A1 = a1 ) (3) l=0,1 Õ = E[Y(A1, a2 )| A1 = a1, L o b s = l, A2 = a2 ]P(L o b s = l | A1 = a1 ) (4) l=0,1 Õ = E[Y(A1, A2 ) | A1 = a1, L o b s = l, A2 = a2 ]P(L o b s = l | A1 = a1 ) (5) l=0,1

I (1), (4) 来自序贯可忽略性 I (2), (5) 来自一致性 (SUTVA)；(3) 来自全概率法则

第 17 页

I 同样，我们可以估计 Pr(Yi (1, 1) = 1) = 60%

A1 L2 A2 … Y

Pr(Y (āT )) = Õ Pr(Y obs | L2obs, …, LTobs, AT = aT ) L2o b s ,…, LTo b s

第 20 页

g-计算

I 为使 g-计算可操作化，一个关键组成部分是指定模型 为所有组成部分 I 结局回归 Pr(Y obs | L obs, …, LTobs, AT = aT ) 2
