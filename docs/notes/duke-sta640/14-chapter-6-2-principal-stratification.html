第 6.2 章：处理后混杂： 主层化

第 2 页

处理后混杂 ▶ 到目前为止，所讨论的大多数问题都是对处理前混杂（即协变量）进行调整 ▶ 混杂发生在处理之后（但在最终结局之前）会给因果推断带来不同的挑战 ▶ 处理后混杂：处理后的中间变量 𝐷 位于 𝑍 和 𝑌 之间的因果路径上：

𝑍 −→ 𝐷 −→ 𝑌 。

▶ 在经济学中称为“内生性”选择问题 ▶ Rosenbaum (1984) 表明：以与处理前协变量 𝑋 相同的方式调整处理后变量 𝐷，会导致有偏的因果效应 ▶ 包括一系列广泛的（看似不同的）问题

第 3 页

示例：随机实验中的不依从

▶ 随机对照试验中的不依从是处理后/分配后混杂的一个特例

▶ （随机）分配的处理 𝑍；实际接受的处理 𝐷；结局 𝑌

▶ 不依从：𝑍 通常会强烈影响 𝐷，但对于某些单位，仍有 𝐷 ≠ 𝑍

▶ 分配后混杂：𝑍 = 1、𝐷 = 𝑑 的单位通常不同于 𝑍 = 0、𝐷 = 𝑑 的单位，因此直接比较会导致有偏的因果效应估计

第 4 页

示例：集群随机试验中的选择偏倚 Li et al. (2022, Clinical Trials)

▶ 集群随机试验：处理在集群（而非个体）层面分配 ▶ 集群随机试验通常先分配处理，然后再招募研究单位，且为开放标签 ▶ 如果某种处理相对于另一种处理具有明显或被感知的优势，就会受到分配后选择偏倚的影响 ▶ 分配：𝑍；招募指标：𝐷 ▶ 问题在于：招募样本由 𝐷 = 1 的单位组成，但已招募的处理组（𝑍 = 1，𝐷 = 1）不同于已招募的对照组 𝑍 = 0，𝐷 = 1 ▶ 这是由于招募状态在分配后的自我选择，破坏了最初的随机化。

第 5 页

示例：死亡导致的删失（或截断） （Zhang and Rubin, 2003, JEBS）

▶ 目标：随机研究一种药物在处理两年后对生活质量（QOL）的效应 ▶ 处理 𝑍：随机分配至处理组（0）和对照组（1） ▶ 结局 𝑌：随机分配后两年的 QOL ▶ 中间结局 𝐷 𝑖：两年存活的指示变量 ▶ 复杂之处：一些受试者会在研究完成前死亡；这些受试者的 QOL 没有明确定义

▶ 这类结局称为死亡导致的“删失”或“截断”

▶ 统计学挑战：QOL 仅在存活单位（𝐷 = 1）上有定义。如果处理对存活有非零效应，那么存活的处理组单位 𝑍 = 1，𝐷 = 1 不同于存活的对照组单位 𝑍 = 1，𝐷 = 0

第 6 页

主层化 （Frangakis and Rubin, 2002, Biometrics）

▶ Frangakis and Rubin (2002) 将针对不依从的工具变量方法（Angrist et al. 1996）推广为主层化，适用于所有处理后混杂情形 ▶ 假设 𝐷 为二元变量：根据 𝐷 的联合潜在取值，单位可分为四组，𝑆 𝑖 = (𝐷 𝑖 (0), 𝐷 𝑖 (1))：

00 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 0} 10 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 0} 01 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 1} 11 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 1}

▶ 这种关于（二元）处理后变量 𝐷 的单位交叉分类就是主层化。

第 7 页

主层化的性质

▶ 关键性质：主层成员身份 𝑆 𝑖 不受处理分配影响

▶ 主层成员身份只反映受试者的特征：可以将其视为处理前变量

▶ 因此，潜在结果 𝑌 𝑖 (0) 和 𝑌 𝑖 (1) 的比较是定义明确的因果效应，因为它定义在一组共同的单位上（即同一主层）

▶ 主层化因果效应（𝑃𝐶𝐸）：

𝜏 𝑃𝐶𝐸 = E[𝑌𝑖 (1) − 𝑌𝑖 (0)|𝑆𝑖 = (𝑑0 , 𝑑1 )] 𝑑0 , 𝑑1 ∈ {0, 1}

第 8 页

主层化示例 1：处理不依从 Angrist et al., 1996

▶ 𝐷 𝑖 (𝑧) = 在分配为 𝑧 时接受的处理，𝑧 = 0, 1 ( 0，如果受试者 𝑖 在分配为 𝑧 时接受对照处理； 𝐷 𝑖 (𝑧) = 1，如果受试者 𝑖 在分配为 𝑧 时接受积极处理。

00 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 0} = 永不接受者 10 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 0} = 反抗者 01 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 1} = 服从者 11 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 1} = 总是接受者

𝜏𝐶 𝐴 𝐶 𝐸 = 𝐸 [𝑌𝑖 (1) − 𝑌𝑖 (0) | 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 1]

第 9 页

主层化示例 2：死亡导致的删失（或截断）

𝐷 𝑖 (𝑧) = 在分配为 𝑧 时两年存活的指示变量， 𝑧 = 0, 1 ( 0，如果受试者 𝑖 在分配为 𝑧 时死亡； 𝐷 𝑖 (𝑧) = 1，如果受试者 𝑖 在分配为 𝑧 时存活。

▶ 永不存活者：无论接受何种处理都会死亡的受试者

00 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 0}

10 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 0}

01 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 1}

▶ 总是存活者：无论接受何种处理都会存活的受试者

11 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 1} 9 / 56

第 10 页

死亡导致的删失（或截断）

▶ 只有对于总是存活者，积极处理相对于对照处理的因果效应才有明确的定义 11 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 1}： h i 𝜏 𝑆 𝐴 𝐶 𝐸 = 𝐸 𝑌𝑖 (1) − 𝑌𝑖 (0) | 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 1

其中 𝑆 𝐴 𝐶 𝐸 表示存活者平均因果效应

▶ 对于 10 = {𝑖 : 𝐷 𝑖 (0) = 1, 𝐷 𝑖 (1) = 0} 和 01 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 1} 组，在 QOL 上的平均因果效应需要假设我们知道如何权衡特定的 QOL 与死亡（以及摆脱痛苦）

▶ 对于 00 = {𝑖 : 𝐷 𝑖 (0) = 0, 𝐷 𝑖 (1) = 0} 组，没有 QOL 可比较

▶ 𝐷 𝑖 (𝑧)：在分配为 𝑧 时的招募状态，𝐷 𝑖 (𝑧) = 0 表示未招募；𝐷 𝑖 (𝑧) = 1 表示已招募 ▶ 主层
