公式卡

23 章的式子是一条链的不同段落，不是四十个互不相关的公式

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）。 本页是覆盖全书 23 章的公式速查卡，不是原书译文，也不是任何一章的笔记。 原书没有公式表；按「反事实 → 识别假设 → 识别公式 → 估计方法」四段排列， 以及各节的取舍，都是笔记作者的组织。

三张查阅卡分工不同，查之前先认准要查的是哪一类：

想知道的是 去哪张卡
某个字母为什么这么写、在第几页被定义 记号与约定（第 1–10 章，逐条带边注页码）
一致性 / 可交换性 / 正性站不站得住 三条识别条件
式子长什么样、属于链条的哪一段 本页（第 1–23 章）

本页不重复前两张卡已经讲透的内容：因果与关联三种度量的对照表、 \(Y^a \perp\!\!\!\perp A\) 与 \(Y \perp\!\!\!\perp A\) 之别、三条条件各自的含义与失效后果， 本页只给形式，讨论一律指路。

一、一条主线：读到任何一条新公式，先问它在第几段

全书的式子都落在这四段里，同一行的四个式子说的是同一件事， 只是分别处在「想要什么 / 凭什么能算 / 等于哪个观测量 / 样本上怎么算」四个位置：

段 它回答什么 典型式子 主要章节
① 反事实 想知道的那个量是什么 \(E[Y^a]\)、\(Y^{a,e}\)、\(E\left[Y^{\bar a}\right]\)、\(E[Y^g]\)、\(E\left[Y^{a=1,M^{a=0}}\right]\) 1、5、19、23
② 识别假设 凭什么能从观测数据算它 \(Y^a \perp\!\!\!\perp A \mid L\)、\(\Pr[A=a\mid L=l]>0\)、\(Y = Y^A\) 2、3、19
③ 识别公式 它等于哪个只含观测量的式子 g 公式、IP 加权、前门公式、Wald 估计量 2、7、16、21
④ 估计方法 样本有限、\(L\) 有多维时怎么算 MSM、SNMM、倾向评分、双稳健 11–18、21

四段不是四种方法，是同一个问题的四个位置

IP 加权与标准化在第 ③ 段是同一个式子的两种写法（正性下相等，TP 2.3，书页 25）； 它们在第 ④ 段才分家——一个给处理建模，一个给结局建模。 「这两个方法哪个更好」之所以难回答，是因为问题问的是第 ④ 段， 而它们在第 ③ 段本来就是一回事。见第 13 章 §13.4。

三、点处理 · 识别那一段：第 2、3、7 章

三个条件（只给形式，讨论见另一张卡）

\[A_i = a \ \Longrightarrow\ Y_i^a = Y_i \qquad\text{等价写法 } Y = Y^A \qquad\text{（一致性）}\]

\[Y^a \perp\!\!\!\perp A \mid L \qquad\text{（条件可交换性）}\]

\[\Pr[A = a \mid L = l] > 0 \quad \text{对所有 } \Pr[L=l] \neq 0 \text{ 的 } l \qquad\text{（正性）}\]

正性只在支持集内成立时，能识别的是一个受限量（TP 3.1）：

\[\Pr[L \in Q(a)] \cdot E[Y^a \mid L \in Q(a)], \qquad Q(a) = \{l : \Pr[A=a\mid L=l] > 0\}\]

两种调整方式，同一个答案

\[\boxed{\ E[Y^a] \;=\; \sum_l E[Y \mid A = a,\ L = l]\,\Pr[L = l]\ } \qquad\text{标准化 / g 公式}\]

\[\boxed{\ E[Y^a] \;=\; E\!\left[\frac{I(A=a)\,Y}{f(A \mid L)}\right]\ } \qquad\text{IP 加权}\]

两式在正性下相等（TP 2.3，书页 25）。二值结局时 \(\Pr[Y^a=1] = E[Y^a]\)， 所以「风险」与「均值」是同一个数（TP 1.1）。

权重家族

\[W^A = \frac{1}{f(A\mid L)}, \qquad SW^A = \frac{f(A)}{f(A\mid L)}, \qquad SW^A(V) = \frac{f(A\mid V)}{f(A\mid L)}\]

删失也当成一次处理（§12.6）：

\[W^{A,C} = W^A \times W^C, \qquad W^C = \frac{1}{\Pr[C=0\mid L,\ A]}\ (\text{未删失者}),\quad W^C = 0\ (\text{被删失者})\]

\[SW^C = \frac{\Pr[C=0\mid A]}{\Pr[C=0\mid L,\ A]}, \qquad SW^{A,C} = SW^A \times SW^C\]

被删失者的权重是 \(0\)，不是某个大数

\(W^C\) 对被删失者取 0——他们被整个踢出伪人群，由未删失者按权重顶上。 把它错记成「删失者权重很大」会把整个伪人群的构造讲反。 来历见边注：\(W^{A,C} = 1/f(A,\,C=0\mid L)\)，一个联合密度的倒数，不是两件事相乘的巧合。

绕开可交换性的三条路

三条都不要求「\(L\) 已经足够」，代价各不相同（第 7 章末列举，§16.6 复盘）。

前门公式（Pearl 1995，TP 7.4）——需要一个完全中介 \(M\)，且 \(M\) 与 \(A\)、\(Y\) 不共享未测量原因：

\[\Pr[Y^{a}=1] \;=\; \sum_{m} \Pr[M=m \mid A=a] \sum_{a'} \Pr[Y=1 \mid M=m,\, A=a'] \Pr[A=a']\]

差分中的差分 / 阴性对照结局（TP 7.3，p.100）——需要加法等混杂 \(E[Y^0 \mid A=1] - E[Y^0 \mid A=0] = E[C \mid A=1] - E[C \mid A=0]\)， 其中 \(C\) 是处理可得之前测到的结局：

\[E[Y^1 - Y^0 \mid A=1] \;=\; \big(E[Y \mid A{=}1] - E[Y \mid A{=}0]\big) - \big(E[C \mid A{=}1] - E[C \mid A{=}0]\big)\]

工具变量（第 16 章）——\(Z\) 需满足相关性、排他性限制、与 \(Y\) 的混杂无关：

\[\frac{E[Y\mid Z=1] - E[Y\mid Z=0]}{E[A\mid Z=1] - E[A\mid Z=0]} \qquad\text{连续工具下写成}\qquad \frac{\operatorname{Cov}(Y,Z)}{\operatorname{Cov}(A,Z)}\]

这个比值要有因果解释，还需要第四个条件：同质性（§16.3）或单调性（§16.4）。 在单调性 \(A^{z=1} \ge A^{z=0}\)（排除 defiers）下，它识别的是依从者中的效应：

\[E\big[Y^{a=1}-Y^{a=0}\ \big|\ A^{z=1}=1,\ A^{z=0}=0\big] \qquad\text{（§16.4，p.212）}\]

\(C\) 在这一节不是删失

TP 7.3 的 \(C\) 是阴性对照结局（处理可得之前测到的结局）， 与 §8.5 起的删失指示 \(C\) 同字母、不同物。 它的要件只有两条：\(A\) 不导致 \(C\)，且 \(C\) 与 \(Y\) 共享那个未测量的 \(U\)； \(C\) 与 \(Y\) 之间有没有因果箭头无关紧要。

四、点处理 · 估计那一段：第 11–18 章

回归：模型是对条件均值形状的限制

\[E[Y \mid A] = \theta_0 + \theta_1 A \qquad E[Y\mid X] = \mathrm{expit}\!\Big(\sum_i \theta_i X_i\Big)\ \text{（二值结局）}\]

\(\theta\) 是统计参数，没有因果解释；只有 §12.4 起结构模型里的 \(\beta\) 才有。

边际结构模型（MSM，§12.4）

\[E[Y^a] = \beta_0 + \beta_1 a \qquad\Longrightarrow\qquad \beta_1 = E[Y^{a=1}] - E[Y^{a=0}]\]

连续处理必须非饱和，例如 \(E[Y^a] = \beta_0 + \beta_1 a + \beta_2 a^2\)； 加入效应修饰因子 \(V\)（§12.5）：

\[E[Y^a \mid V] = \beta_0 + \beta_1 a + \beta_2 V a + \beta_3 V \qquad\text{存在加法效应修饰} \iff \beta_2 \neq 0\]

用 \(SW^A\)（或 \(SW^A(V)\)）加权后的普通回归来拟合。

结构嵌套均值模型与 g-估计（第 14 章）

模型只写效应那一部分，不设截距、不设 \(L\) 的主效应：

\[E\left[Y^{a} - Y^{a=0}\mid A=a,\ L\right] = \beta_1 a + \beta_2 a L\]

g-估计的三步：由一致性把模型接到数据上 \(Y^{a=0} = Y - \psi_1 A\)， 定义候选反事实并搜索：

\[H(\psi^\dagger) = Y - \psi_1^\dagger A \qquad \operatorname{logit}\Pr[A=1\mid H(\psi^\dagger),\ L] = \alpha_0 + \alpha_1 H(\psi^\dagger) + \alpha_2 L\]

\[\boxed{\ \hat\alpha_1 = 0 \text{ 的那个 } \psi^\dagger \text{ 就是 } \psi_1\ }\]

一句话记法：把处理效应减掉之后，\(A\) 就不该还能预测它了。

倾向评分（§15.2）

\[\pi(L) = \Pr[A=1\mid L] \qquad\text{平衡性质}\quad A \perp\!\!\!\perp L \mid \pi(L)\]

于是 \(Y^a \perp\!\!\!\perp A \mid L\) 蕴含 \(Y^a \perp\!\!\!\perp A \mid \pi(L)\)—— 分层、匹配、加权三种用法的共同理论基础。

双稳健估计量（§18.4）

\[\frac{1}{n}\sum_{i=1}^{n}\left[\hat b(X_i) + \frac{A_i}{\hat\pi(X_i)}\big(Y_i - \hat b(X_i)\big)\right]\]

\(\hat b\) 与 \(\hat\pi\) 只要有一个对，估计量就相合。用机器学习估这两个函数时 必须样本分割 + 交叉拟合，否则过拟合会把 \(\sqrt{n}\) 收敛率毁掉：

\[\hat\Delta_{\text{cross-fit}} = \frac{\hat\Delta + \hat\Delta'}{2}\]

五、生存：第 17 章

三个量共用一个 \(D_k\)（到 \(k\) 为止是否已发生结局），差别全在分母：

\[\text{生存率} = \Pr[D_k=0],\quad \text{风险} = \Pr[D_k=1],\quad \text{风险率} = \Pr[D_k = 1\mid D_{k-1}=0]\]

\[\Pr[D_k = 0] = \prod_{m=1}^{k}\Pr[D_m = 0\mid D_{m-1}=0]\]

按人-时拟合的 logistic 模型，时变截距 \(\theta_{0,k}\) 用时间的灵活函数来估：

\[\operatorname{logit}\Pr[D_{k+1}=1\mid D_k=0,\ A] = \theta_{0,k} + \theta_1 A + \theta_2 A\cdot k + \theta_3 A\cdot k^2\]

风险率接近零时，\(\theta_1\) 近似对数风险比。结构嵌套模型在生存数据里只能换成 加速失效时间模型（§17.6）：

\[\frac{T_i^{a}}{T_i^{a=0}} = \exp(-\psi_1 a) \quad\Longleftrightarrow\quad T_i^{a=0} = T_i^{a}\exp(\psi_1 a)\]

风险比里藏着一个碰撞变量

这一章的标题就是结论：把风险比按时间切开，每个时点的分母都已经被 「活到该时点」这件事筛选过，而存活本身是处理的后代。 细节见第 17 章，本页只登记式子。

六、时变处理：第 19–21 章

历史记号

\[\bar A_k = (A_0, A_1, \dots, A_k), \qquad \bar L_k = (L_0, L_1, \dots, L_k), \qquad \bar a = (a_0, \dots, a_K)\]

策略：静态与动态（§19.2）

静态策略是一串定死的值 \(\bar a\)，共 \(2^K\) 条；动态策略 \(g\) 是一条规则， \(A_k = g_k(\bar A_{k-1}, \bar L_k)\)，反事实记作 \(Y^g\)。 「\(L_k=1\) 就开始治并从此一直治下去」这类规则写不成 \(\bar a\)， 所以动态策略不在那 \(2^K\) 条里——效应有多少个，取决于你比哪两条规则。

序贯版的三条条件

\[Y^g \perp\!\!\!\perp A_k \mid \bar A_{k-1} = g(\bar A_{k-2}, \bar L_{k-1}),\ \bar L_k \qquad \text{对所有策略 } g \text{ 与 } k = 0,1,\dots,K\]

\[\text{若 } f_{\bar A_{k-1}, \bar L_k}(\bar a_{k-1}, \bar l_k) \ne 0,\ \text{则 } f_{A_k \mid \bar A_{k-1}, \bar L_k}(a_k \mid \bar a_{k-1}, l_k) > 0\]

（TP 19.2，p.255。只关心某一条 \(g\) 时，正性只需对与 \(g\) 相容的处理史成立。）

时变 g 公式（§21.1）

\[\boxed{\ E\left[Y^{\bar a}\right] = \sum_{\bar l} E\left[Y \mid \bar A = \bar a,\ \bar L = \bar l\right] \prod_{k=0}^{K} f\!\left(l_k \mid \bar a_{k-1}, \bar l_{k-1}\right)\ }\]

两个时点的最小版本长这样，一眼能看出那串连乘是从哪来的：

\[\sum_{l_1} E[Y \mid A_0 = a_0,\ A_1 = a_1,\ L_1 = l_1]\, f(l_1 \mid a_0)\]

时变 IP 权重与时变 MSM（§21.2）

\[W^{\bar A} = \prod_{k=0}^{K} \frac{1}{f\!\left(A_k \mid \bar A_{k-1}, \bar L_k\right)}, \qquad SW^{\bar A} = \prod_{k=0}^{K} \frac{f\!\left(A_k \mid \bar A_{k-1}\right)}{f\!\left(A_k \mid \bar A_{k-1}, \bar L_k\right)}\]

左边有 \(2^K\) 个未知量，右边的 MSM 只有两个参数：

\[E\left[Y^{\bar a}\right] = \beta_0 + \beta_1 \operatorname{cum}(\bar a), \qquad \operatorname{cum}(\bar a) = \sum_{k=0}^{K} a_k\]

带效应修饰时，权重分子换成 \(SW^{\bar A}(V) = \prod_k f(A_k\mid \bar A_{k-1}, V) \big/ f(A_k\mid \bar A_{k-1}, \bar L_k)\)。

时变 g-估计：blip 函数（§21.4）

\[E\left[Y^{\bar a_{k-1}, a_k, \bar 0_{k+1}} - Y^{\bar a_{k-1}, \bar 0_k} \mid \bar L_k = \bar l_k,\ \bar A_{k-1} = \bar a_{k-1},\ A_k = a_k\right] = a_k\, \gamma_k\!\left(\bar a_{k-1}, \bar l_k, \beta\right)\]

其中 \(\gamma_k(\cdot,\ \beta = 0) = 0\)。它是「在 \(k\) 时刻最后加一笔大小为 \(a_k\) 的处理」 对 \(Y\) 均值的效应（§21.4，p.287）。候选反事实逐时点往回剥：

\[H_k(\psi^\dagger) = Y - \sum_{j \ge k}\big(\text{第 } j \text{ 笔处理的 blip}\big), \qquad \operatorname{logit}\Pr\left[A_k = 1 \mid H_k(\psi^\dagger),\ \bar L_k,\ \bar A_{k-1}\right] = \alpha_0 + \alpha_1 H_k(\psi^\dagger) + \alpha_2 W_k\]

为什么非用 g-方法不可：\(A_0 \to L_1 \to A_1\)

\(L_1\) 同时是 \(A_1\) 的混杂因子、又是 \(A_0\) 的后代。 不调整 \(L_1\) 则 \(A_1\) 有混杂，调整 \(L_1\) 则在 \(A_0\) 上打开选择偏倚—— 普通回归两头都堵不住，这就是第 20 章整章要说的那件事。 回归本身就是一种分层，所以「把 \(L_1\) 也放进模型」补不好（§20.4）。

七、目标试验与中介：第 22–23 章

意向性治疗效应与符合方案效应（§22.1）

效应 对比的是 式子
意向性治疗效应 被分配到 \(g_1\) 对被分配到 \(g_0\) \(\Pr\left[D_k^{z=1,\bar c_k = \bar 0}=1\right] - \Pr\left[D_k^{z=0,\bar c_k=\bar 0}=1\right]\)
符合方案效应 从基线起持续遵循 \(g_1\) 对 \(g_0\) \(\Pr\left[D_k^{g_1,\bar c_k=\bar 0}=1\right] - \Pr\left[D_k^{g_0,\bar c_k=\bar 0}=1\right]\)

两个定义都带 \(\bar c_k = \bar 0\)——「如果没有人失访」。这个上标不是装饰： 它让「处理 \(\bar A\) 的因果效应」这句话里大家心里真正想的那个对比变得明确（§21.5）。

中介公式（§23.1）

\[\boxed{\ E\left[Y^{a=1,M^{a=0}}\right] = \sum_m E[Y\mid A=1,\ M=m]\ \Pr[M=m\mid A=0]\ }\]

由此分解总效应：

成分 式子 别名
纯直接效应 \(E\left[Y^{a=1,M^{a=0}}\right] - E\left[Y^{a=0,M^{a=0}}\right]\) 自然直接效应
总间接效应 \(E\left[Y^{a=1,M^{a=1}}\right] - E\left[Y^{a=1,M^{a=0}}\right]\) 自然间接效应

两者相加即 \(E[Y^{a=1}] - E[Y^{a=0}]\)。

中介公式识别的是一个跨世界量

\(E\left[Y^{a=1,M^{a=0}}\right]\) 要求同一个人「处理取 1、而中介取她在处理取 0 时本会有的值」—— 这两件事在任何试验里都不可能同时发生。它的证明（TP 23.1）中间那一行用了一条 跨世界条件独立：在因果图代表 NPSEM-IE 时被假设成立， 代表 FFRCISTG 模型时则不成立。所以它的识别假设比总效应严格得多， 这也是第 23 章前两节要为中介分析辩护的原因。

可分离效应（§23.2）

把处理拆成两个原则上可分别干预的成分 \(A \to (N, O)\)，于是有 \(Y^{n,o}\)。 「只去掉尼古丁成分」这个有公共卫生意义的量是 \(E\left[Y^{n=0,o=1}\right]\)， 而它的 g 公式与中介公式同形：

\[\sum_m E[Y\mid O=1,\ M=m]\ \Pr[M=m\mid N=0] \;=\; \sum_m E[Y\mid A=1,\ M=m]\ \Pr[M=m\mid A=0]\]

（因为在数据里 \(O=1\) 当且仅当 \(A=1\)、\(N=0\) 当且仅当 \(A=0\)。） 同一个数，两种解释：一个跨世界的中介量， 或一个可以被三臂试验反驳的真实干预（§23.3）。

八、最容易抄错的六处：每一处都有一个同形但不同义的邻居

一 · \(\beta\) 与 \(\psi\) 不是同一层的参数

\(\beta\) 是结构模型本身的参数（MSM 的 \(\beta_1\)、SNMM 的 \(\beta_1, \beta_2\)、blip 里的 \(\beta\)）； \(\psi^\dagger\) 是 g-估计搜索时的候选值，搜到 \(\hat\alpha_1 = 0\) 才认。 两者在第 14、21 章交替出现，抄式子时看清有没有那个 \(\dagger\)。

二 · \(W^A\) 与 \(W^{\bar A}\) 差一条连乘

点处理的权重是一个分数；时变处理的权重是 \(K+1\) 个分数的连乘。 把时变权重写成单个分数，等于默认「后面每个月的处理都与历史无关」。

三 · \(\theta\) 没有因果解释，\(\beta\) 才有

第 11 章的 \(\theta\) 是统计模型参数，第 12 章起结构模型的 \(\beta\) 才是因果参数。 同一条 logistic 回归，加权之前拟合出的是 \(\theta\)，用 \(SW^A\) 加权之后拟合出的才是 \(\beta\)。

四 · 上标 \(\bar c = \bar 0\) 不能省

省掉它，「处理的因果效应」这句话就没定义清楚——它默认了一个「无人失访」的世界。 第 21、22 章一律写出来，本页照办。

五 · SNMM 的条件里有 \(A=a\)

\(E\left[Y^{a} - Y^{a=0}\mid A=a,\ L\right]\) 是在实际接受了 \(a\) 的人里的效应， 与 MSM 的 \(E[Y^a]\)（全人群）不是一个量。 只有 \(\gamma_k\) 不依赖 \(\bar l_k\) 时，两者才对得上（TP 21.7，p.288）。

六 · 前门公式里的两个求和不能对调

外层对 \(m\) 求和用的是 \(\Pr[M=m\mid A=a]\)（干预那一侧）， 内层对 \(a'\) 求和用的是 \(\Pr[A=a']\)（观测那一侧的边际分布）。 把 \(a'\) 写成 \(a\) 是最常见的抄错，那样整个式子就退化成一个条件期望。
