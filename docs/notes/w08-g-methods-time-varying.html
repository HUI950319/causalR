第 21 章 · 三条路线，同一个 0

G-methods for time-varying treatments · 时变处理的 g-方法

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 21 章，书页 271–298。本章是读书笔记，非原书译文。

第 20 章留下一个死局：时变混杂因子必须调整，而传统方法一调整就出错。 本章给出解药，而且是三份：

本章描述在存在处理–混杂因子反馈时，传统方法偏倚问题的解决方案： 使用 g-方法——g-公式、IP 加权、g-估计，以及它们的双稳健推广。 用与上一章相同的数据集，这里我们展示三种 g-方法都给出正确的（零）效应估计。

— What If, §21 章首, p.271

这三样东西都不是新的：第 13 章讲过 g-公式，第 12 章讲过边际结构模型的 IP 加权， 第 14 章讲过结构嵌套模型的 g-估计。本章做的是把它们各自加上下标 \(k\)。

全章地图（笔记作者绘制，原书无此图）。 上半张图是非参数的世界：三条路线在 Table 21.1 上给出同一个 0。 下半张图是参数的世界：一旦必须建模，三条路线就分化出三种不同的脆弱性—— 这一层分化才是本章真正的内容，也是 W7–W10 选方法时的实际依据。

21.1 时变处理的 g-公式：把「标准化」写成一串连乘

先复习时固定的情形。若只关心 \(A_1\) 的效应，识别条件之下

\[E[Y^{a_1}] = \sum_{l_1} E[Y \mid A_1 = a_1, L_1 = l_1]\, f(l_1), \qquad f(l_1) = \Pr[L_1 = l_1]\]

这就是 g-公式：标准化到研究人群中混杂因子分布的均值结局。

而时变处理下，权重换了一个：

\[\boxed{\ \sum_{l_1} E[Y \mid A_0 = a_0, A_1 = a_1, L_1 = l_1]\, f(l_1 \mid a_0)\ }\]

唯一的改动，就是那个 \(\mid a_0\)

权重是给定过去的混杂因子 \(L_1\) 的分布，而这里的「过去」是与干预相对应的那个处理取值。 ……也就是说，对时变处理而言，识别条件下 g-公式估计量是 标准化到研究人群中混杂因子分布的均值结局，其中表达式里的每一个因子 都以过去的处理史与协变量史为条件。 在处理与混杂因子都只测一次的时固定情形下，这种对既往史的条件化是不必要的。

— What If, §21.1, p.272

注意 \(f(l_1 \mid a_0)\) 里的 \(a_0\) 是「策略指定的那个值」，不是这个人实际接受的值。 这就是为什么 g-公式能算出「所有人都遵循 \(\bar a\)」的那个世界： 它把每一层的协变量分布，都换成在该策略下应有的分布。

书也顺手交代了正性在这里的样子：

g-公式只有在下述情形下才是可计算的（即良好定义的）： 对任何使 \(f(l_1\mid a_0) \ne 0\) 的取值 \(l_1\)，人群中都存在 \((A_0 = a_0, A_1 = a_1, L_1 = l_1)\) 的个体。

— What If, §21.1, p.272

在 Table 21.1 上算一遍

Table 21.1 就是第 20 章的 Table 20.1，原样搬过来。书只写了两行算式：

\[E\left[Y^{a_0=0,a_1=0}\right] = 84 \times 0.25 + 52 \times 0.75 = \mathbf{60}\] \[E\left[Y^{a_0=1,a_1=1}\right] = 76 \times 0.50 + 44 \times 0.50 = \mathbf{60}\]

差是 0，与预期一致。g-公式在传统方法失败的地方成功了。

两个权重 \(0.25 / 0.75\) 与 \(0.50 / 0.50\) 分别是 \(\Pr[L_1 = l_1 \mid A_0 = 0]\) 与 \(\Pr[L_1 = l_1 \mid A_0 = 1]\)——正是第 20 章里「\(A_0 \to L_1\) 那条箭头」的数值形态。 g-公式没有回避它，而是把它当成了权重。

另一种看法：g-公式是一次模拟

另一种理解 g-公式的方式，是把它看成一次模拟。 在 \(Y\) 与 \(\bar L\) 联合的序贯可交换性之下，g-公式模拟了 如果研究人群中每个人都遵循策略 \(\bar a\)，本会观察到的反事实结局 \(Y^{\bar a}\) 与协变量史 \(\bar L^{\bar a}\)。

— What If, §21.1, p.272–273

书用两张因果解释的结构化树图（causally interpreted structured tree graph）演示： 图 21.1 是 Table 21.1 的树形表示，图 21.2 是「一直治」之下的反事实人群。

Figure 21.1 与 21.2（照原图重绘并压缩：原图每个分支上都标着概率与人数， 本页把终端的「人数 · 结局均值」并成一列，虚线支表示概率为 0 的分支）。 右树是 g-公式做的那次模拟：(i) 给策略指定的处理赋概率 1， (ii) 保持 \(\Pr[L_1 = l_1 \mid A_0 = a_0]\) 与 \(E[Y \mid A_0, A_1, L_1]\) 不变。 于是 \(E[Y^{\bar a = \bar 1}] = 0.5(76) + 0.5(44) = 60\)。

两个必须记住的要点，书用「First / Second」明确编了号

第一：g-公式的值取决于 \(L\) 里放了什么。

假设我们没有收集 \(L_1\) 的数据，因为我们（错误地）相信研究由「图 20.8 去掉 \(L_1 \to A_1\)」那样的图表示。 于是没有 \(L_1\) 时 g-公式变成 \(E[Y\mid A_0 = a_0, A_1 = a_1]\)，因为没有协变量史可调整。 然而，由于研究实际上由图 20.8 表示（其中 \(A_1\) 受 \(L_1\) 影响）， 不含 \(L_1\) 的 g-公式不再有因果解释。

— What If, §21.1, p.273

第二：即使 g-公式有因果解释，它的每个分量都可能没有。

考虑图 20.9，其中只有静态序贯可交换性成立。含 \(L_1\) 的 g-公式正确识别了 \(E[Y^{\bar a}]\)。 值得注意的是，无论我们是否添加从 \(A_0\)、\(A_1\) 到 \(Y\) 的箭头， g-公式都继续具有 \(E[Y^{\bar a}]\) 的因果解释—— 尽管它的两个分量 \(E[Y\mid A_0, A_1, L_1]\) 与 \(\Pr[L_1 \mid A_0]\) 都完全没有因果解释。 也就是说，\(\Pr[L_1 = l_1 \mid A_0 = a_0] \ne \Pr[L_1^{a_0} = l_1]\) 且 \(E[Y\mid A_0, A_1, L_1] \ne E[Y^{a_0,a_1}\mid L_1^{a_0}]\)。

— What If, §21.1, p.273

这两句合起来是一条很重要的方法论态度： g-公式是一个整体上有因果含义的量，它的零件可以只是统计关联。 （在图 20.1、20.2 那样的序贯随机试验里，上面那两个不等号才会变成等号。）

高维的一般形式

\[\sum_{\bar l} E\left[Y \mid \bar A = \bar a,\ \bar L = \bar l\right] \prod_{k=0}^{K} f\!\left(l_k \mid \bar a_{k-1}, \bar l_{k-1}\right)\]

求和是对所有可能的 \(\bar l\) 历史，\(\sum_{\bar l}\) 也可以写成 \(\sum_{l_K}\dots\sum_{l_1}\sum_{l_0}\)。

实际数据里这些分量算不出来，只能估： 用线性回归估 \(E[Y\mid \bar A, \bar L]\)，用 logistic 回归估各时点离散混杂因子的分布 （\(L_0\) 的分布可以像 §13.3 那样不建模直接估），再把估计值插回公式—— 这就是插入式 g-公式（plug-in g-formula）；当估计来自参数模型时，叫参数化 g-公式。

Fine Point 21.1：「史」这个词不一定是时间意义上的

然而，「史」这个词不必按时间来定义，因为正如 Fine Point 7.4 所解释的， 混杂因子理论上可以在处理的时间未来。反过来，正如图 7.4 旁所解释的， 调整某些处于处理时间过去的变量可能引入选择偏倚（即 M-偏倚）。 因此在本书中，时刻 \(k\) 上具有因果相关性的「史」， 应当理解为为达到处理 \(A_k\) 的条件可交换性所需要的那组处理与混杂因子。 多数情况下，这种用法与时间顺序上的历史是一致的。

— What If, Fine Point 21.1, p.274

这条边栏是整套 g-方法在实操中最容易被忽略的一句： 「按时间排序」只是一个通常够用的默认值，真正的定义是「达到可交换性所需要的集合」。 Technical Point 21.1 里那条「选择一个与 DAG 拓扑相容的全序」把这件事写成了算法输入。

Technical Point 21.1：g-公式密度，以及 g-公式的四个输入

确定性静态策略 \(\bar a\) 下，\((Y, \bar L)\) 的 g-公式密度是

\[f\!\left(y \mid \bar a_K, \bar l_K\right) \prod_{k=0}^{K} f\!\left(l_k \mid \bar a_{k-1}, \bar l_{k-1}\right)\]

\(Y\) 的 g-公式密度就是它对 \(\bar l\) 的边际（连续分量用积分）。 动态策略只需把 \(a_k\) 换成递归定义的 \(a_k^g\)；静态策略是「每个 \(g_k\) 都是常值函数」的特例。

更一般地，给定观测数据 \(O = (\bar A, X, Y)\) 与未观测数据 \(U\)，g-公式的输入有四个：

输入 内容
(i) 一条确定性处理策略 \(g\)
(ii) 表示观测数据（及其未测共同原因）的因果 DAG
(iii) \(X\) 的一个子集 \(L\)——我们打算调整的那些变量
(iv) \(L\)、\(\bar A\)、\(Y\) 的一个与 DAG 拓扑相容的全序（每个变量排在它的祖先之后）

\(\bar L_k\) 就是这个序里排在 \(A_{k-1}\) 之后、\(A_k\) 之前的全部变量。

当所选序下 \(Y^g\) 的序贯可交换性与正性成立时，\(Y\) 的 g-公式密度等于 如果所有个体都遵循策略 \(g\) 本会观察到的密度 \(f_{Y^g}(y)\)。 否则，g-公式仍然可以被计算出来，但它没有因果解释。

— What If, Technical Point 21.1, p.275

「仍然可以被计算出来，但没有因果解释」——这句话适用于本书里几乎每一个估计量， 但在这里格外值得记住：g-公式是一个函数，不是一个保证。

21.2 时变处理的 IP 加权：权重变成一串连乘

时固定的权重是 \(W^{A_1} = 1/f(A_1\mid L_1)\) 或 \(SW^{A_1} = f(A_1)/f(A_1\mid L_1)\)。 时变的版本把它们逐时点连乘：

\[W^{\bar A} = \prod_{k=0}^{K} \frac{1}{f\!\left(A_k \mid \bar A_{k-1}, \bar L_k\right)}, \qquad SW^{\bar A} = \prod_{k=0}^{K} \frac{f\!\left(A_k \mid \bar A_{k-1}\right)}{f\!\left(A_k \mid \bar A_{k-1}, \bar L_k\right)}\]

时变处理的 IP 权重的分母，非正式地说，是一个个体在给定其处理史与协变量史之下、 接受他实际接受到的那条处理史的概率。

— What If, §21.2, p.276

注意这句话与第 12 章那句的差别只有两个字：「处理值」变成了「处理史」。 这正是第 12 章笔记里那句预言的兑现——时变处理下权重会随时间累乘， 分子上的稳定化因子是压住极端权重的唯一手段。

— What If, §21.2, p.278

但书立刻堵住了反向推论：

— What If, §21.2 边注, p.278

这是一条便宜、可写进 SAP、而且结论方向明确的诊断： 不一致 ⇒ 一定有模型错了；一致 ⇒ 什么也证明不了。

边际结构模型：把 \(2^K\) 个未知量压成两个参数

\[E\left[Y^{\bar a}\right] = \beta_0 + \beta_1 \operatorname{cum}(\bar a), \qquad \operatorname{cum}(\bar a) = \sum_{k=0}^{K} a_k\]

左边有 \(2^K\) 个不同的未知量，每条策略 \(\bar a\) 一个；右边只有 2 个未知参数。 参数 \(\beta_1\) 度量时变处理 \(\bar A\) 的平均因果效应， 而 \(E[Y^{\bar a}] - E[Y^{\bar a = \bar 0}] = \beta_1 \times \operatorname{cum}(\bar a)\)。

— What If, §21.2, p.278（复述）

边注提醒：这个边际结构模型是非饱和的（饱和模型等号两边的未知量个数相等）。

拟合方式与第 12 章相同：在伪人群里对 \(E[Y\mid \bar A] = \theta_0 + \theta_1 \operatorname{cum}(\bar A)\) 做普通最小二乘， 数学上等价于在原人群里用 \(SW^{\bar A}\) 或 \(W^{\bar A}\) 做加权最小二乘。

一条很细、但足以解释「为什么加权回归的标准误不能直接用」的边注

统计课上常证明：在 \(E[Y\mid \bar A]\) 模型设定正确时， 普通最小二乘与加权最小二乘的估计对关联参数 \(\theta_1\) 都是相合的。 这个证明假设权重只依赖 \(\bar A\)。 而当权重像我们这里一样依赖于「给定 \(\bar A\) 后仍与 \(Y\) 相关」的协变量 \(\bar L\) 时， 加权回归对 \(\theta_1\) 不再相合。

— What If, §21.2 边注, p.279

换句话说：加权最小二乘在这里估的不是 \(\theta_1\)，而正是我们要的 \(\beta_1\)。 这不是 bug，是整套机器的工作方式；但它也解释了为什么软件默认输出的标准误是错的。

方差照旧三条路：bootstrap、解析方差（要自己编程）、 稳健方差估计量（多数软件直接输出，给出保守的 95% 区间）。 非饱和的边际结构模型下，用 \(SW^{\bar A}\) 的区间通常比 \(W^{\bar A}\) 窄，所以偏好 \(SW\)。

边际结构模型可以被检验——这是它相对参数化 g-公式的一个实质优势

模型设错的样子很具体：真实的均值可能依赖于别的处理史函数 （比如只有最后 5 个月的累积处理 \(\sum_{k=K-5}^{K} a_k\)），或非线性地依赖累积处理。

书给了一个可以直接照做的检验：拟合

\[E\left[Y\mid \bar A\right] = \theta_0 + \theta_1 \operatorname{cum}(\bar A) + \theta_2 \operatorname{cum}_{-5}(\bar A) + \theta_3 \operatorname{cum}(\bar A)^2\]

对联合假设 \(\theta_2 = \theta_3 = 0\) 做两个自由度的 Wald 检验， 就是对「我们的边际结构模型设定正确」这一原假设的检验。 也就是说，边际结构模型的 IP 加权不受 Technical Point 21.3 所描述的 g-零悖论的影响。

— What If, §21.2, p.279

边注补：这个检验对上述两个特定方向通常有良好的统计功效， 尤其是在使用 \(SW^{\bar A}\) 权重并用 bootstrap 估方差时。 实践中也可以用把处理史的不同摘要当协变量、并用三次样条这类柔性函数的模型。

这条与 §21.1 的参数化 g-公式形成了本章最重要的一组对照： 边际结构模型的设定可以被数据检验，参数化 g-公式的设定在零假设下则注定不可能全对。

效应修饰照第 12 章 §12.5 的办法办，但有一条硬限制：

\[E\left[Y^{\bar a}\mid V\right] = \beta_0 + \beta_1 \operatorname{cum}(\bar a) + \beta_2 V + \beta_3 \operatorname{cum}(\bar a) V\]

权重换成 \(SW^{\bar A}(V) = \prod_k \dfrac{f(A_k\mid \bar A_{k-1}, V)}{f(A_k\mid \bar A_{k-1}, \bar L_k)}\)。

在存在处理–混杂因子反馈时，\(V\) 只能包含基线变量。 如果 \(V\) 含有 \(k > 0\) 的 \(L_k\) 分量，那么即使处理在任何时刻对均值结局都没有效应， 参数 \(\theta_1\) 与 \(\theta_3\) 也可能不为 0。

— What If, §21.2, p.279

这一句是第 20 章那条对撞门在边际结构模型里的复现： 把时变协变量放进 \(V\)，等于把它放回条件里。

Technical Point 21.2：动态策略不能用稳定化权重

对确定性动态策略 \(g\)，g-公式等于 \(E\left[Y\, I(\bar A_K = \bar A^g_K)\, W^{\bar A}\right]\)， 也就是伪人群中遵循了策略 \(g\) 的那些人的 \(Y\) 均值 \(E_{ps}[Y\mid \bar A_K = \bar A^g_K]\)。

与静态策略不同， \(E\left[Y I(\bar A_K = \bar A_K^g) SW^{\bar A}\right] \big/ E\left[I(\bar A_K = \bar A_K^g) SW^{\bar A}\right]\) 不等于 g-公式，因为 \(SW^{\bar A}\) 的分子依赖于 \(\bar A\)。 因此稳定化权重不能与动态策略一起使用。

— What If, Technical Point 21.2, p.278

这是一条很容易踩的坑：§21.2 正文刚说完「非饱和模型下偏好 \(SW\)」， 而临床上真正想比的又往往是动态策略——两条建议在这里打架，Technical Point 给的裁决是： 动态策略优先，稳定化权重让位。 （随机动态策略 \(f^{int}\) 下 g-公式等于 \(E\left[Y \prod_k \frac{f^{int}(A_k\mid \cdot)}{f(A_k \mid \cdot)}\right]\)， 即把分子换成干预分布而不是观测分布。）

Technical Point 21.3：g-零悖论——参数化 g-公式的原罪

设尖锐零假设为真，且存在处理–混杂因子反馈。那么 g-公式的真值对任何 \(\bar a\) 都相同； 但它的两个分量 \(E[Y\mid \bar A, \bar L]\) 与 \(f(l_k\mid \cdot)\) 都会依赖 \(\bar a\)（第 20 章已说明）。

现在假设我们用基于互异（即变差独立）参数 \(\theta\) 与 \(\varphi\) 的标准非饱和参数模型 去估计 g-公式的这两个分量。那么 Robins & Wasserman (1997) 证明了： 当 \(L_k\) 含有任何离散分量时，这些模型不可能全部被正确设定—— 因为 g-公式的估计值一般会依赖 \(\bar a\)。 其后果是，基于估计 g-公式的推断理论上可能错误地拒绝尖锐零假设， 即使是在一个序贯随机试验里。

— What If, Technical Point 21.3, p.280

书给了一个务实的补充：

幸运的是，g-零悖论在实践中并没有妨碍参数化 g-公式给出零效应估计， 大概是因为该悖论引入的偏倚相对于典型的随机变异而言很小。

— What If, Technical Point 21.3, p.280

而另外两条路线没有这个病：

  • 边际结构均值模型 \(E[Y^{\bar a}] = \beta_0 + \beta_1 \operatorname{cum}(\bar a)\) 在零假设下必定被正确设定——那时 \(\beta_1 = 0\)，\(E[Y^{\bar a}]\) 不依赖 \(\bar a\) 的任何函数；
  • 结构嵌套均值模型的 blip 函数 \(\gamma_k(\bar a_{k-1}, \bar l_k, \beta)\) 在零假设下取 \(\beta = 0\) 也必定正确，与你为过去史选了什么函数形式无关。

用一句话记住这条：参数化 g-公式的模型族里，「零效应」这个点可能根本不在模型能表达的范围内。 （更多讨论见 Cox & Wermuth 1999、McGrath et al. 2022。）

21.3 时变处理的双稳健估计量：两个模型，对一个就行

IP 加权要求处理模型正确，g-公式要求结局模型正确。 双稳健方法只要求两者之一正确（而且你不需要知道是哪一个正确）。

— What If, §21.3, p.280（复述）

边注把它的用处说得很直白：

双稳健估计量给了我们两次机会把事情做对—— 在大多数观察性研究那种「混杂因子很多、必须用非饱和模型」的处境里。

— What If, §21.3 边注, p.280

时固定的三步（先把套路立住）

以二值 \(A\)、二值 \(Y\)、许多混杂因子 \(L\) 为例：

  1. 第一步：从处理模型算出预测值 \(\hat f(a\mid L) \equiv \widehat{\Pr}[A = a\mid L]\)。
  2. 第二步：把 \(\hat W^a = 1/\hat f(a\mid L)\) 当作一个协变量放进结局模型， 在 \(A = a\) 的人里做极大似然拟合，例如 \(b(a, L; \theta) = \operatorname{expit}\left(\theta_{a,0} + \theta_{a,1} L + \theta_{a,2} \hat W^a\right)\)。
  3. 第三步：把 \(\hat b(1, L; \hat\theta)\) 与 \(\hat b(0, L; \hat\theta)\) 在全体（包括未处理者）上取样本均值， 两者之差就是双稳健估计。

这个「把权重当协变量塞进结局模型」的技巧，是整段的关键

它看起来像个奇技淫巧，实际上是让估计方程的某些样本均值恒等于 0， 从而在结局模型错设时由权重接管、在权重错设时由结局模型接管。 Technical Point 21.5 把这件事讲成了一条可操作的规则：

例如，在拟合 \(b_1\) 的线性 logistic 模型时加入单变量项 \(\theta_1 \frac{A_0 A_1}{\hat\pi_0 \hat\pi_1}\)， 就能保证 \(P_n\left[\frac{A_0A_1}{\hat\pi_0\hat\pi_1}(Y - \hat b_1)\right] = 0\)； 再在 \(b_0\) 的 logistic 模型里加入 \(\theta_0 \frac{A_0}{\hat\pi_0}\)，就能保证第二项也为 0。

— What If, Technical Point 21.5, p.283（复述）

书还点出了插入式（plug-in）版本的好处：对二值 \(Y\)， 增广 IP 加权估计量 \(\hat\psi_{TR}\) 可能落在 \([0,1]\) 之外， 而插入式的 \(\hat\psi_{gfor} = P_n[\hat b_0(L_0)]\) 永远落在 \([0,1]\) 内。

时变版：序贯回归（ICE）+ 权重

以「一直治」\(\bar a = \bar 1\) 为例，三步的结构不变，但第二步变成一串倒着做的回归：

步 做什么 关键细节
1 拟合合并（over \(k\)）的处理模型 \(\pi_k(\bar L_k;\alpha)\) 个体在时刻 \(k\) 只有在此前一直被治（\(\bar A_{k-1} = \bar 1_{k-1}\)）时才贡献该时刻的拟合；由此得到逐时刻的权重 \(\hat W^{\bar 1_m} = \prod_{k=0}^{m} 1/\hat\pi_k\)
2 从最后一个时刻 \(K\) 倒着做到 \(m = 0\)，每个时刻拟合一个结局模型 \(b_m(\bar L_m;\beta_m)\) 时刻 \(K\) 的因变量是 \(Y\)；时刻 \(m < K\) 的因变量是上一步模型的预测值 \(\hat B_{m+1}\)；每个模型都只在「治到 \(m\)」的人里拟合，并把 \(\hat W^{\bar 1_m}\) 作为协变量
3 把 \(\hat B_0\) 在全体上取样本均值 这就是 \(\widehat E\left[Y^{\bar a = \bar 1}\right]\)

注意第 1 步那个「逐时刻权重」：

也就是说，对一个 \(\bar A_K = \bar 1_K\) 的「一直被治」个体， 我们为每个时点 \(m\) 各赋一个不同的权重 \(W^{\bar 1_m}\)， 而不是像上一节那样只在随访结束时赋一个 \(W^{\bar 1_K}\)。

— What If, §21.3, p.281

稳健性不止「双」——它是 \(K+2\) 重的

如果 (i) 所有 \(m\) 的结局模型都正确，或 (ii) 所有 \(m\) 的处理模型都正确， 那么估计就是（渐近）无偏的——这时称为双稳健。 然而它实际上是多重稳健的，因为对任意 \(m \in \{0, 1, \dots, K-1\}\)， 只要时刻 0 到 \(m\) 的处理模型正确、且时刻 \(m+1\) 到 \(K\) 的结局模型正确， 它也是（渐近）无偏的。我们称这个性质为 \(K+2\) 重稳健。

— What If, §21.3, p.282

书还说存在稳健性更好的估计量——Technical Point 21.4 给出三重稳健的增广 IP 加权估计量 （Robins et al. 1994；Molina et al. 2017 指出它实际是 \(K+2\) 重稳健）， 以及 Tchetgen Tchetgen (2009) 的四重稳健改造； 正文更是直接说：我们还能给出一个 \(2^{K+1}\) 重稳健的估计量。

「\(K+2\) 重稳健」这个说法第一次读会觉得像营销词，其实它的含义非常具体： 你可以在随访的前半段相信处理模型、后半段相信结局模型， 而这在真实数据里是常见处境——早期的处理决策规则清楚、晚期的结局机制清楚。

这个估计量有个更熟悉的名字：

这个双稳健估计量来自 Bang & Robins (2005)，并与更早的一个估计量（Robins, 2000）密切相关。 该估计量就是靶向最小损失估计量（TMLE）， 在 van der Laan & Rubin (2006) 与 van der Laan & Gruber (2012) 后来引入的术语里 也叫靶向极大似然估计量。

— What If, §21.3 边注, p.281

书对落地的判断也很坦率：

多重稳健估计量的实现，长期以来受制于计算约束与缺乏用户友好的软件， 尤其是基于风险的生存分析。我们预期在不远的将来软件会出现， 这些（用机器学习与样本分割拟合的）多重稳健估计量 在研究复杂处理策略对失效时间结局的效应时会变得更常见。

— What If, §21.3, p.282

路线图 W17–W20 那一段（SuperLearner / TMLE / lmtp）就是这句话的落地版； 这里值得记住的是它们不是「另一套方法」，而是本节这三步的机器学习实现。

21.4 时变处理的 g-估计：一次只剥掉最后一笔处理

第 14 章的结构嵌套均值模型只有一条方程，因为只有一个时点。 时变版本有多少个时点就有多少条方程。两个时点的饱和模型是：

\[\text{时刻 } k=0:\quad E\left[Y^{a_0, a_1 = 0} - Y^{a_0=0, a_1=0} \mid A_0 = a_0\right] = \beta_0 a_0\]

\[\text{时刻 } k=1:\quad E\left[Y^{a_0,a_1} - Y^{a_0, a_1=0} \mid L_1^{a_0} = l_1,\ A_0 = a_0,\ A_1^{a_0} = a_1\right] = a_1\left(\beta_{11} + \beta_{12} l_1 + \beta_{13} a_0 + \beta_{14} a_0 l_1\right)\]

「嵌套」这个词的字面含义

结构嵌套模型的这两条方程，正是它被称为「嵌套」的原因。 第一条方程建模的是「在时刻 0 接受处理、此后再不接受」的效应， 第二条方程建模的是「在时刻 1 接受处理、此后再不接受」的效应， 如果有更多时点就依此类推。

— What If, §21.4, p.285

两条方程都是饱和的：第二条的 4 个参数刚好参数化了 \((A_0, L_1)\) 定义的 4 种过去史下 \(a_1\) 对 \(Y\) 的效应； 第一条只有 1 个参数，因为在 \(k=0\) 时所有人的过去史都相同（没有更早的处理与协变量）。

边注把第二条方程的四个效应列了出来（\(a_1\) 的效应）：

过去史 \(a_1\) 的效应
\(A_0 = 0\)，\(L_1^{a_0=0} = 0\) \(\beta_{11}\)
\(A_0 = 0\)，\(L_1^{a_0=0} = 1\) \(\beta_{11} + \beta_{12}\)
\(A_0 = 1\)，\(L_1^{a_0=1} = 0\) \(\beta_{11} + \beta_{13}\)
\(A_0 = 1\)，\(L_1^{a_0=1} = 1\) \(\beta_{11} + \beta_{12} + \beta_{13} + \beta_{14}\)

（由一致性，\(A_0 = a_0\) 时 \(L_1^{a_0} = L_1\)。）

秩保持，以及它为什么可以不当真

配套的可加秩保持模型是逐个体的：

\[Y_i^{a_0, 0} = Y_i^{0,0} + \psi_0 a_0, \qquad Y_i^{a_0,a_1} = Y_i^{a_0,0} + \psi_{11}a_1 + \psi_{12}a_1 L_{1,i}^{a_0} + \psi_{13}a_1a_0 + \psi_{14}a_1a_0L_{1,i}^{a_0}\]

第一条是秩保持的（\(\psi_0\) 对每个人都一样）；第二条只在给定 \((a_0, l_1)\) 之内保持秩， 所以叫条件（局部）秩保持。而书的态度与第 14 章一致：

正如第 14 章所讨论的，由于个体在未测的遗传与环境风险上的异质性，秩保持在生物学上是不可信的。 这正是我们主要关心结构嵌套均值模型的原因——它对「是否存在因未测因素造成的额外效应异质性」 完全不置可否。然而，在 \(Y\) 的序贯可交换性之下， 对秩保持模型的一类 g-估计量，即使秩保持模型被错误设定， 对均值模型的参数 \(\beta\) 仍然是相合的。

— What If, §21.4, p.286

边注另有一句很实用的：用 g-估计拟合非饱和的结构嵌套均值模型时，正性不是必需的。

把模型接到观测数据上

由一致性，可以把模型改写成只含观测变量的形式：

\[Y^{A_0,0} = Y - \left(\psi_{11}A_1 + \psi_{12}A_1L_1 + \psi_{13}A_1A_0 + \psi_{14}A_1A_0L_1\right), \qquad Y^{0,0} = Y^{A_0,0} - \psi_0 A_0\]

于是定义候选反事实（把真值换成候选值 \(\psi^\dagger\)）：

\[H_1(\psi^\dagger) = Y - \left(\psi_{11}^\dagger A_1 + \psi_{12}^\dagger A_1L_1 + \psi_{13}^\dagger A_1A_0 + \psi_{14}^\dagger A_1A_0L_1\right), \qquad H_0(\psi^\dagger) = H_1(\psi^\dagger) - \psi_0^\dagger A_0\]

当 \(\psi^\dagger = \psi\) 且 \(\bar A_{k-1} = \bar a_{k-1}\) 时， 候选反事实 \(H_k(\psi^\dagger)\) 等于真实的反事实 \(Y^{\bar a_{k-1}, \bar 0_k}\)—— 即「到 \(k-1\) 为止按 \(\bar a_{k-1}\) 处理、此后一律不处理」下的结局。

— What If, §21.4, p.286

Fine Point 21.3：把饱和模型的五个参数逐个解出来

序贯可交换性在 \(k=1\) 上意味着：在 \((A_0, L_1)\) 的四个联合层内， \(H_1(\psi)\) 在 \(A_1 = 1\) 与 \(A_1 = 0\) 的人里均值相等。 于是（用原书 Table 21.2）：

层 \((A_0, L_1)\) \(A_1 = 0\) 的 \(H_1\) \(A_1 = 1\) 的 \(H_1\) 解出
\((0,0)\) \(84\) \(84 - \psi_{11}\) \(\psi_{11} = 0\)
\((0,1)\) \(52\) \(52 - \psi_{11} - \psi_{12}\) \(\psi_{12} = 0\)
\((1,0)\) \(76\) \(76 - \psi_{11} - \psi_{13}\) \(\psi_{13} = 0\)
\((1,1)\) \(44\) \(44 - \psi_{11} - \psi_{12} - \psi_{13} - \psi_{14}\) \(\psi_{14} = 0\)

再把这四个值代回，得到 Table 21.3 的 \(H_0(\psi)\)：\(A_0 = 0\) 的四行是 \(84/84/52/52\)， \(A_0 = 1\) 的四行是 \(76-\psi_0\) 等等。\(k=0\) 的序贯可交换性 \(Y^{0,0}\perp\!\!\!\perp A_0\) 要求 两组 16 000 人的 \(H_0(\psi)\) 均值相等：

\[\underbrace{84 \times 0.25 + 52 \times 0.75}_{= 60} \;=\; \underbrace{(76-\psi_0)\times 0.5 + (44-\psi_0)\times 0.5}_{= 60 - \psi_0} \quad\Longrightarrow\quad \psi_0 = 0\]

五个参数全为 0，于是任何静态或动态策略 \(g\) 下的 \(E[Y^g]\) 都等于 60。 与 g-公式、IP 加权完全一致。

这一段是全书里少有的「把 g-估计算到底」的地方，值得手推一遍： 它把「序贯可交换性」这个抽象条件，变成了四个可以直接解方程的等式。

一般形式：blip 函数

\[E\left[Y^{\bar a_{k-1}, a_k, \bar 0_{k+1}} - Y^{\bar a_{k-1}, \bar 0_k} \mid \bar L_k = \bar l_k,\ \bar A_{k-1} = \bar a_{k-1},\ A_k = a_k\right] = a_k\, \gamma_k\!\left(\bar a_{k-1}, \bar l_k, \beta\right)\]

其中 \(\gamma_k(\cdot, \beta = 0) = 0\)。书给了一句非常好记的定义：

因此，结构嵌套均值模型是一个关于 「在 \(k\) 时刻最后加一笔（last blip）大小为 \(a_k\) 的处理」对 \(Y\) 均值的效应的模型， 而这个效应是过去处理与协变量史 \((\bar a_{k-1}, \bar l_k)\) 的函数 \(\gamma_k\)。

— What If, §21.4, p.287

非饱和的例子：\(\gamma_k = \beta_1\)（效应不随时间与历史变化）、 \(\beta_1 + \beta_2 k\)（随处理时刻线性变化）、 \(\beta_1 + \beta_2 k + \beta_3 a_{k-1} + \beta_4 l_k + \beta_5 l_k a_{k-1}\)（允许被最近的处理与协变量修饰）。

估计办法（网格搜索版）：对每个候选 \(\psi^\dagger\) 计算 \(H_k(\psi^\dagger)\)，拟合合并的 logistic 模型

\[\operatorname{logit}\Pr\left[A_k = 1 \mid H_k(\psi^\dagger), \bar L_k, \bar A_{k-1}\right] = \alpha_0 + \alpha_1 H_k(\psi^\dagger) + \alpha_2 W_k\]

\(\hat\beta\) 就是使 \(\hat\alpha_1\) 最接近 0 的那个格点（每人贡献 \(K+1\) 条观测）。 也可以直接解「score 检验 \(p\) 值 = 1」对应的估计方程，省掉网格。

相合性需要四条：(i) 结构嵌套均值模型正确；(ii) \(Y\) 的序贯可交换性成立； (iii) 处理模型 \(\operatorname{logit}\Pr[A_k=1\mid \bar L_k, \bar A_{k-1}]\) 正确； (iv) \(H_k(\psi^\dagger)\) 以线性方式进入该 logistic 模型（不能是 \(H_k^2\) 或其它非线性形式）。

维数一上去，网格搜索就不能用了

5 个参数、每维 20 个格点就是 \(20^5\) 个组合。

当 \(\beta\) 的维数大于 2 时，用网格搜索找 \(\hat\beta\) 可能在计算上很困难。

— What If, §21.4, p.289

替代办法是解 5 维估计方程（标准方程求解器即可）； 而 Technical Point 21.8 指出：当 blip 函数对 \(\beta\) 线性时，\(\hat\beta\) 有显式闭式解， 并给出了一个 \(2^{K+1}\) 重稳健的闭式版本。 边注还提醒：\(\beta\) 的 95% 区间可以用 score 检验的接受域， 计算量更小的做法是 \(\hat\beta_j \pm 1.96 \times\) 标准误。

Technical Point 21.7：结构嵌套模型与边际结构模型的关系——一个经典的方差–偏倚权衡

一个结构嵌套均值模型是半参数边际结构均值模型，当且仅当 \(\gamma_k(\bar a_{k-1}, \bar l_k, \beta) = \gamma_k(\bar a_{k-1}, \beta)\) 不依赖 \(\bar l_k\)。

— What If, Technical Point 21.7, p.288

这时它对应的边际结构模型形式是 \(E[Y^{\bar a}] = \alpha_0 + \sum_{k=0}^{K} a_k \gamma_k(\bar a_{k-1}, \beta)\)， 其中 \(\alpha_0 = E[Y^{\bar 0_K}]\)。但是：

这样的结构嵌套均值模型并不只是一个边际结构均值模型， 因为它还额外施加了一条很强的假设：不存在被过去协变量史修饰的效应。 相比之下，边际结构模型对「是否存在时变协变量的效应修饰」不置可否。

— What If, Technical Point 21.7, p.288

于是有了那条权衡：

模型对了

最有效的 g-估计量比最有效的 IP 加权估计量更有效， 因为 g-估计额外用上了「无过去协变量效应修饰」这条假设来提高效率。

模型错了

若边际结构模型对、而结构嵌套模型错 （因为 \(\gamma_k\) 其实依赖 \(\bar l_k\)）， 则 g-估计有偏，而 IP 加权仍然无偏。

「这是一个经典的方差–偏倚权衡」——书的原话。

落到选型上：要效率就用 g-估计（并承担「没有被 \(L\) 修饰」的赌注）， 要稳健就用 IP 加权的边际结构模型。

Technical Point 21.9：g-估计之后，怎么把 \(E[Y^g]\) 算出来

g-估计给出的是 blip 参数 \(\beta\)，不是反事实均值。若模型不依赖 \(L_k\)， 静态策略下可以直接加总： \(\widehat E[Y^{\bar a}] = \widehat E[Y^{\bar 0_K}] + \sum_k a_k \gamma_k(\bar a_{k-1}, \tilde\beta)\)。 但只要 blip 依赖 \(L_k\)、或者你要的是动态策略，就必须模拟 \(L_k\)——书给了一个四步的 Monte Carlo 算法：

  1. 用 \(H_0(\tilde\beta)\) 的样本均值估 \(E[Y^{\bar 0_K}]\)；
  2. 拟合 \(f(l_k\mid \bar a_{k-1}, \bar l_{k-1})\) 的参数模型（跨人、跨时点合并）；
  3. 重复 \(V\) 次：抽 \(l_{v,0}\)，再递归地按策略 \(g\) 决定的处理史抽 \(l_{v,k}\)， 累加 \(\hat\Delta_{g,v} = \sum_j a_{v,j}\gamma_j(\cdot, \tilde\beta)\)；
  4. \(\widehat E[Y^g] = \widehat E[Y^{\bar 0_K}] + \sum_v \hat\Delta_{g,v}/V\)。

而这一段最漂亮的是最后那句「保零」性质：

注意，若估计 \(\tilde\beta\) 对 \(\beta = 0\) 是相合的，则 \(\gamma_k(\cdot, \tilde\beta)\) 收敛到 0。 因此 \(\hat\Delta_{g,v}\) 收敛到 0、\(\widehat E[Y^g]\) 收敛到 \(\widehat E[Y^{\bar 0_K}]\)， 即使 \(f(l_k\mid \cdot)\) 的模型是错的。 也就是说，结构嵌套均值模型保零（preserves the null）。

— What If, Technical Point 21.9, p.291（复述）

这正是 Technical Point 21.3 那条「g-零悖论不影响 g-估计」的算法版本： 协变量模型错了只会让非零效应估计变差，不会凭空造出一个非零效应。

21.5 删失是一种时变处理：把 \(C_k\) 和 \(A_k\) 并列

前面一直假设没有删失。现实里要把删失看成时变变量 \(C_1, C_2, \dots C_{K+1}\)： \(C_m = 0\) 表示到 \(m\) 时刻仍未删失。删失是单调缺失（一旦 \(C_m = 0\) 则此前全为 0）， 且按定义所有人 \(C_0 = 0\)。

g-公式于是改写成处处以「仍未删失」为条件的版本：

\[\sum_{\bar l} E\left[Y \mid \bar C = \bar 0,\ \bar A = \bar a,\ \bar L = \bar l\right] \prod_{k=0}^{K} f\!\left(l_k \mid c_k = 0,\ \bar a_{k-1},\ \bar l_{k-1}\right)\]

假设识别条件在把处理 \(A_m\) 替换为 \((A_m, C_{m+1})\) 之后仍然成立。 那么容易证明，上式对应的是联合处理 \((\bar a, \bar c = \bar 0)\) 之下反事实均值结局 \(E\left[Y^{\bar a, \bar c = \bar 0}\right]\) 的 g-公式—— 即「所有人都接受策略 \(\bar a\) 且无人失访」时本会观察到的均值结局。

— What If, §21.5, p.292

边注给了一句很到位的评论：

上标 \(\bar c = \bar 0\) 让很多人在说「处理 \(\bar A\) 的因果效应」时心里真正想的那个因果对比 变得明确，即使他们选择不写这个上标。

— What If, §21.5 边注, p.292

IP 加权的版本是两组权重相乘：

\[W^{\bar C} = \prod_{k=1}^{K+1} \frac{1}{\Pr\left[C_k = 0 \mid C_{k-1} = 0, \bar A_{k-1}, \bar L_{k-1}\right]}, \qquad SW^{\bar C} = \prod_{k=1}^{K+1} \frac{\Pr\left[C_k = 0 \mid C_{k-1} = 0, \bar A_{k-1}\right]} {\Pr\left[C_k = 0 \mid C_{k-1} = 0, \bar A_{k-1}, \bar L_{k-1}\right]}\]

然后在 \(W^{\bar A}\times W^{\bar C}\)（或 \(SW^{\bar A}\times SW^{\bar C}\)）加权的伪人群里 拟合 \(E\left[Y\mid \bar A, \bar C = \bar 0\right] = \theta_0 + \theta_1\operatorname{cum}(\bar A)\)。

非稳定化权重：删失被「废除」

在非稳定化 IP 权重造出的伪人群里，被删失的个体被具有相同处理与协变量史的、 未被删失的个体的复本所替代。因此伪人群的规模与删失发生之前的原研究人群相同。 非稳定化 IP 权重在伪人群中废除了删失。

— What If, §21.5, p.292

稳定化权重：删失变成随机发生

稳定化权重造出的伪人群，规模与删失之后的原人群相同， 即每个时刻 \(k\) 被删失者的比例与研究人群中相同。 稳定化权重不消除伪人群中的删失， 它们让删失在每个时刻相对于已测协变量史 \(\bar L_k\) 随机地发生。 也就是说，有选择，但没有选择偏倚。

— What If, §21.5, p.293

两者的共同点才是关键：

无论用哪种 IP 权重，伪人群中都不存在从 \(L_k\) 和 \(A_k\) 指向未来 \(C_m\)（\(m>k\)）的箭头。 重要的是，在联合处理 \((\bar A, \bar C)\) 的可交换性条件下， IP 加权可以无偏地估计 \((\bar A, \bar C)\) 的联合效应， 即使 \(\bar L\) 的某些分量受既往处理影响。

— What If, §21.5, p.293

g-估计必须先处理删失，顺序不能反

最后，在使用结构嵌套模型的 g-估计时，我们首先需要用 IP 加权调整删失造成的选择偏倚。 实践中这意味着：先估计删失的非稳定化 IP 权重 \(W^{\bar C}\) 以造出一个无人被删失的伪人群， 然后再在这个伪人群上做 g-估计。

— What If, §21.5, p.293

注意这里指定的是非稳定化权重——因为 g-估计要的是「删失被废除」的那个伪人群， 而不是「删失随机发生」的那个。这是一处容易写错的实现细节。

Technical Point 21.10：接上第 17 章，做成生存分析

第 17 章讲的是点干预对失效时间结局的效应，本章讲的是持续策略对非失效时间结局的效应。 实践中要的往往是两者的组合：持续策略对失效时间结局的效应。

图 21.4 画了这种情形：两个时点，失效时间结局用时变指示变量 \(D_k\) 表示（同第 17 章）。 书特意说明：每个 \(D_k\) 本应有指向图上所有未来变量的箭头，为减少杂乱而省略了； 时变删失指示变量也为简化而省略。

两条路线：

  • g-公式：为离散时间风险 \(\Pr\left[D_{k+1} = 1\mid \bar A_k, \bar L_k, D_k = C_{k+1} = 0\right]\) 与混杂因子的条件密度各拟合模型，风险用合并 logistic 模型近似（第 17 章的做法）。 细节与应用见 Young et al. (2011)；ICE 版本见 Wen et al. (2021)。
  • IP 加权：对同一个合并 logistic 风险模型，给每个人在每个时刻 \(k\) 赋 \(W_k^{\bar A}\times W_k^{\bar C}\)（或其稳定化版本）。 该模型的参数估计的是「边际结构合并 logistic 模型」的参数（Robins 1998a）； 细节与应用见 Hernán et al. (2001)。多重稳健版本的综述见 Wen et al. (2022)。

这条边栏是 causalR 路线图 W10「生存与竞争风险」那一周真正的技术入口—— 注意权重是「每个时刻一个」，不是随访结束时一个。

21.6 大 g-公式：把 U 也放进去的那个理论版本

这一节回答一个很自然的疑问：为什么整整三章都只讲 g-公式这一条识别路线？

原因是，在实践中，很少有复杂纵向数据的因果分析依赖其它识别条件与公式。 例如，基于「前门公式是识别公式」那类识别条件的现实应用非常少。

— What If, §21.6, p.294

但书接着给了一个统一的说法：

对任何因果 DAG，已测与未测变量的组合 \(X = (L, U)\) 都能保证（联合）序贯可交换性， 因为处理变量的任何父节点都包含在 \(A\) 或 \(X\) 之中。 因此，如果因果图上每个变量都被测量、且正性成立， 基于 \(X\) 的 g-公式就能识别任何策略 \(g\) 下的 \(E[Y^g]\)。 我们把「把 \(L\) 换成 \(X\)」的 g-公式称为大 g-公式（big g-formula）， 因为它不只基于观测数据。

— What If, §21.6, p.294

「事实变量」这个词，以及大 g-公式的用法

我们把 \((A, L, Y, U)\) 称为事实变量（factuals），以区别于反事实变量。 事实变量是在真实世界里存在的变量。 与观测变量不同， 某些事实变量（如 \(U\)）不可用于数据分析，通常是因为它们没有被测量。

— What If, §21.6 边注, p.294

于是大 g-公式的地位很清楚：

大 g-公式是识别任何处理策略下反事实密度的正确公式， 但它在实践中无法使用，因为它包含未测变量。

— What If, §21.6, p.294

接下来才是这一节真正的问题：

一个有趣的数学问题于是出现：大 g-公式能否被化简成只依赖观测数据 \((A, L, Y)\) 联合分布的泛函？ 如果能，我们就得到了一个新公式，它 (i) 复现大 g-公式的结果（因而是正确的）， 且 (ii) 只用观测变量写出（因而可以用于数据分析）。

— What If, §21.6, p.294

前门公式就是一个成功的例子：在前门准则的识别条件下， \(E[Y^a]\) 的大 g-公式化简成了只含观测变量的前门公式（证明见 Technical Point 21.11）。

书随后提出了两个一般性问题，并告诉我们答案都是肯定的：

问题 答案 出处
能否总是判定大 g-公式可否改写成只依赖 \((A, L, Y)\) 分布的公式？ 能 Tian & Pearl (2002)、Shpitser & Pearl (2006)、Huang & Valtorta (2006)
当答案为「是」时，能否显式写出那个识别公式？ 能 同上

这一节最该带走的一句话：它是数学问题，不是因果问题

重要的是，这些是关于「已知服从 DAG 上 d-分离所刻画的某些独立关系」的 \((A, L, Y, U)\) 分布性质的纯数学问题。 也就是说，这些问题既不涉及反事实，也不涉及因果。 与因果唯一的联系，是「这张 DAG 是一张因果 DAG」这个断言。 若是，大 g-公式就有因果解释；若不是，那些肯定的答案虽然仍然为真，却没有因果含义。 当然，在观察性分析里，我们永远无法确定地知道：我们猜想是因果图的那张图，真的是因果图。

— What If, §21.6, p.295

这段话可以当作整个第三部分的收束： 识别是数学，因果是假设。 全书从第 1 章起反复说的那件事，在这里得到了最干净的陈述。

书在本节的三条 Technical Point 里还给出了两个额外的前门公式证明 （21.11 用大 g-公式、21.12 用 SWIG 上一条新的 d-分离性质）， 以及 21.13 里一般结构嵌套均值模型的定义—— blip 不必相对「此后一律不治」定义，可以相对任意策略 \(g\) 定义， 并由此定义最优方案结构嵌套模型（opt-SNMM），用来估计 \(g_{opt} = \arg\max_g E[Y^g]\)（Robins 2004）。 21.13 末尾还提到：序贯可交换性不是唯一可能的识别假设—— Shahn et al. (2022) 在时变平行趋势假设（双重差分的时变推广）下也识别了 blip 函数。

自检① 三种 g-方法，我该选哪一个？

本章给的判据是可操作的：

  1. 先都算一遍。 参数化 g-公式与 IP 加权的估计若差异超出抽样变异（bootstrap 量化）， 就一定有模型错了——这是本章给的唯一一条「结论方向明确」的诊断（§21.2）。
  2. 要比动态策略 → IP 加权时不能用稳定化权重（Technical Point 21.2）； g-估计需要 Monte Carlo 模拟 \(L_k\)（Technical Point 21.9）； 参数化 g-公式最直接。
  3. 样本小、想要效率 → g-估计（承担「效应不被过去协变量修饰」的赌注）。 想要稳健 → IP 加权的边际结构模型（Technical Point 21.7 的方差–偏倚权衡）。
  4. 两个模型都没把握 → 双稳健 / TMLE，而且它实际是 \(K+2\) 重稳健（§21.3）。

落到 R 上：gfoRmula（参数化 g-公式，CRAN）、ipw / WeightIt + survey（IP 加权）、 lmtp（动态与修正处理政策的多重稳健估计）。这正是路线图 W8–W10 与 W19 的工具链。

自检② 为什么「g-公式和 IP 加权给出同一个数」不能当作验证？

因为在非参数情形下它们恒等——这是代数事实，与识别条件是否成立无关（§21.2）。

有信息量的比较只发生在参数模型之下，而且它的逻辑是单向的：

  • 两个参数化估计差得多 ⇒ 至少一个模型设错了（永远成立）；
  • 两个参数化估计很接近 ⇏ 模型是对的——它们可能在同一方向上都有偏。

这条不对称性值得写进任何一份用 g-方法的分析计划： 差异是证据，一致不是。

自检③ g-零悖论到底该不该担心？

理论上：当存在处理–混杂因子反馈、尖锐零假设为真、且 \(L_k\) 有离散分量时， 参数化 g-公式的结局模型与协变量模型不可能同时正确， 因此可能错误地拒绝尖锐零假设，哪怕数据来自一个序贯随机试验（Technical Point 21.3）。

实践上：书自己说，g-零悖论并没有妨碍参数化 g-公式在实际中给出零效应估计， 推测是因为它引入的偏倚比典型的随机变异小。

而这条恰恰是选另外两条路线的一个正面理由： 边际结构均值模型与结构嵌套均值模型在零假设下必定被正确设定—— 前者此时 \(\beta_1 = 0\)，后者此时 \(\beta = 0\) 且 blip 恒为 0，与函数形式无关。

所以正确的态度不是「担心」或「不担心」，而是： 如果你的分析结论是「没有效应」，就不要只用参数化 g-公式一条路线。

tab <- data.frame(
  N  = c(2400, 1600, 2400, 9600, 4800, 3200, 1600, 6400),
  A0 = c(0, 0, 0, 0, 1, 1, 1, 1),
  L1 = c(0, 0, 1, 1, 0, 0, 1, 1),
  A1 = c(0, 1, 0, 1, 0, 1, 0, 1),
  Y  = c(84, 84, 52, 52, 76, 76, 44, 44)
)
n <- function(...) sum(subset(tab, ...)$N)

## ① g-公式：Σ_l1 E[Y | a0, l1, a1] · Pr[L1 = l1 | A0 = a0]
gform <- function(a0, a1) {
  p <- sapply(0:1, function(l) n(A0 == a0 & L1 == l) / n(A0 == a0))
  y <- sapply(0:1, function(l) tab$Y[tab$A0 == a0 & tab$L1 == l & tab$A1 == a1])
  sum(p * y)
}
c(gform(1, 1), gform(0, 0), diff = gform(1, 1) - gform(0, 0))
#> 60 60 0

## ② IP 加权：W = 1 / [f(A0) · f(A1 | A0, L1)]，造伪人群
tab$fA0 <- 0.5                                            # 设计已知
tab$fA1 <- with(tab, ifelse(L1 == 1,
                            ifelse(A1 == 1, .8, .2),      # L1 低 → 0.8
                            ifelse(A1 == 1, .4, .6)))     # L1 高 → 0.4
tab$W   <- 1 / (tab$fA0 * tab$fA1)
tab$NW  <- tab$N * tab$W
sum(tab$NW)                                               #> 128000 = 32000 × 4
ipw <- function(a0, a1) with(subset(tab, A0 == a0 & A1 == a1), sum(NW * Y) / sum(NW))
c(ipw(1, 1), ipw(0, 0), diff = ipw(1, 1) - ipw(0, 0))
#> 60 60 0                                                 ← 与 g-公式逐格相等

## ③ g-估计（饱和结构嵌套均值模型，Fine Point 21.3 的解法）
##    在每个 (A0, L1) 层内，令 H1(ψ) 在 A1 = 1 与 A1 = 0 的均值相等
h1 <- function(a0, l1) {
  y0 <- tab$Y[tab$A0 == a0 & tab$L1 == l1 & tab$A1 == 0]
  y1 <- tab$Y[tab$A0 == a0 & tab$L1 == l1 & tab$A1 == 1]
  y1 - y0                    # = -(ψ 的相应线性组合)；全为 0 ⇒ ψ11..ψ14 全为 0
}
