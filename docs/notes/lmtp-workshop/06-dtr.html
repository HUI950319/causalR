动态处理方案

Dynamic Treatment Regimes · Beyond the ATE 工作坊中译

来源：Nick Williams、Kara Rudolph、Iván Díaz，Beyond the ATE · Dynamic Treatment Regimes （GitHub 仓库），GPL-3.0 许可。 本页为中文翻译，非原文；按 GPL-3.0 保留原作者署名与许可证，并标明这是修改（翻译）后的版本。 原站的 webR 交互代码块在本站以静态代码块呈现，不重新执行； 原文用交互式表格展示的 DynTxRegime::bmiData 数据集，本站改为列说明。

回忆一下：若函数的输出只依赖于协变量，这类干预称为动态干预或动态处理方案。 下面来学习如何用 lmtp 估计动态处理方案的效应。

模拟 BMI 数据

后台已经把一个名为 bmi 的数据集载入 R。

  • 该数据来自 DynTxRegime 包，模拟的是一项两阶段 RCT（\(A\) = {A1, A2}）， 研究代餐奶昔（MR）与热量赤字饮食（CD）对青少年肥胖的效应。

  • 基线变量包括性别、种族和父母 BMI。

  • 时变协变量包括第 1 阶段采集的 BMI（baselineBMI）和第 2 阶段采集的 BMI （month4BMI）。主要结局是 12 个月时的 BMI（month12BMI）。

  • 数据中不存在删失。

原站在此处渲染出该数据集的交互式表格。各列依次为：gender、race、parentBMI、 baselineBMI、month4BMI、month12BMI、A1、A2；其中四个 BMI 列按一位小数显示。 数据本身随 DynTxRegime 包分发，可用 data(bmiData, package = "DynTxRegime") 载入。

练习 1

编写一个移位函数：在时点 1 给所有观测分配代餐，而在时点 2 只对 4 个月 BMI 大于 30 的 观测分配代餐。

\[ \dd_t(a_t, h_t, \epsilon_t) = \begin{cases} \text{Meal replacement} &\text{ if } t = 1 \\ \text{Meal replacement} &\text{ if } t = 2 \text{ and } \text{4-month BMI} > 30 \\ \text{Calorie deficit} &\text{ otherwise.} \end{cases} \]

d_dtr <- # 在这里写你的移位函数！

✅ 参考答案

 
d_dtr <- function(data, trt) {
  if (trt == "A1") return(rep("MR", nrow(data)))

  ifelse(data$month4BMI > 30, "MR", "CD")
}

下面用 lmtp 的 SDR 估计量，估计该动态处理方案对 12 个月 BMI 的效应。

fit_dtr <- lmtp_sdr(
  data = bmi,
  trt = c("A1", "A2"),
  outcome = "month12BMI",
  baseline = c("gender", "race", "parentBMI"),
  time_vary = list("baselineBMI", "month4BMI"),
  shift = d_dtr,
  outcome_type = "continuous",
  folds = 1,
  learners_trt = "SL.glm",
  learners_outcome = c("SL.mean", "SL.glm", "SL.gam")
)
