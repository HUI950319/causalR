一、流行病学的三件事，因果推断只是其中之一：先分清描述、预测、因果

讲义 p6–44。这一节的用处是先把「因果推断」从旁边两件事里摘出来， 否则后面所有方法都会被当成「又一种建模技巧」。

流行病学的任务分三类，对应的统计工具完全不同：

任务 回答什么 常用统计 讲义
描述 疾病怎么分布（时间、地点、人群） 统计描述、区间估计、\(t\) / 方差 / 卡方、聚类 p10–11
预测 这个人现在患病概率多少（诊断）、将来出事概率多少（预后） logistic / Cox / 机器学习，评价看 AUC、校准度、DCA p12–25
因果推断 干预了会不会不一样 本课程后面全部内容 p26–44

预测那一段讲得比一般课细：诊断模型用横断面数据（\(T=0\) 时同时测预测因子与 金标准结局），预后模型必须有纵向关系（\(T=0\) 是基线时点，结局在随访终点）。 配的案例是儿童百日咳列线图，建模组 AUC 0.83、外部验证 0.80， Hosmer-Lemeshow \(P\) 值都大于 0.05（p20–25）。

这一节埋的一句话，后面三节都在还它

预测模型只问「结果会不会发生」，因果推断问「干预与不干预的潜在结果差多少」（p26）。 同一个 logistic 回归，放在预测里看 AUC，放在因果里看 \(\beta\) —— 问的问题不同，对模型的要求也就不同。这条线索到第 3 节的 「回归系数 \(\beta_1 = \mathrm{ATE}\) 吗？」才被彻底挑明。

因果推断的两类流行病学设计：实验性研究（RCT，实验组 vs 安慰剂组直接比发生率） 与分析性观察研究（队列、病例对照）。讲义给了一份国内方法演变的时间表（p36）—— 差异性分析（2000 年前）→ 回归（2000 年后）→ 倾向得分（2015 年后）→ 机器学习（2025 年后），四个阶段各自的优缺点在 p37–44。

二、混杂偏倚及其控制：郑老师说这是整门课最大的障碍

讲义 p45–82。视频里这一讲开门见山：「我们从因果推断，最大的障碍就是混杂偏倚。」

误差先分两类：随机误差可以用统计方法估计，系统误差即偏倚才是麻烦， 其中又分选择偏倚、信息偏倚、混杂偏倚（p46–47）。

判断一个变量是不是混杂，靠三个条件

讲义把混杂三要素落成了可操作的检验步骤（p53–59）：

条件 内容 怎么查
1 与研究因素（暴露）相关 单因素关联：\(t\)、卡方、方差、秩和
2 与结局存在因果关系 单因素关联：线性、logistic、Cox
3 不在暴露与结局的因果链上（不是中介） 专业判断，统计查不出来

第 3 条只能靠领域知识，这也是讲义反复标红的地方。举的例子是疫苗接种与住院率， 年龄同时满足三条，所以年龄是混杂（p56–59）。

「分组不均衡」与「潜在混杂因素」

RCT 随机分组 → 基线均衡可比；观察性研究按暴露或结局自然分组 → 分组不均衡（p60–62）。 讲义在这里给了一个实用的推论：

分组不均衡 → 组间差异 → 差异即相关 → 相关意味着混杂条件 1 或 2 成立 → 造成分组不均衡的因素是潜在混杂因素（p63–64）

也就是说，实际做研究时通常不严格鉴定「是不是混杂」，而是用基线表把潜在混杂 挑出来先调整了再说（p67）。

控制策略分事先与事后

  • 事先（设计阶段）：随机分组、限制、配对
  • 事后（分析阶段）：分层分析、多因素分析、倾向得分、工具变量（p68）

再按混杂是否被测量分一次（p69）：已测混杂用回归 / 分层 / 倾向得分， 未测混杂只能靠工具变量、阴性对照、敏感性分析。

案例是 2020 年 JACC 上的「吸烟悖论」——STEMI 患者里吸烟者院内死亡率反而更低。 讲义用四个递进的 Cox 模型演示 Adjusted 到底调了什么（p70–82）： 模型①不控制混杂，②只加年龄，③加一批协变量，④再加 IS。 把单因素的 \(\beta\) 变成多因素的 \(\beta_1\)，年龄造成的偏倚才被剥离。

三、从吸烟与肺癌的争议，到五类方法：本周最值得看的一讲

讲义 p83–126，对应时长 65 分钟的第 3 讲，是第一周信息量最大的一段。

开头用的是科学史：20 世纪四五十年代 Hill 做了一系列病例对照与队列研究， 得出吸烟致肺癌，并归纳出 Hill 法则；而现代统计学奠基人 Fisher 反对， 提出基因混杂假说，认为「你们的数据只显示了关联，但无法证明因果关系」（p84–85）。 这场争议直到 1980 年代两大框架提出才有了形式化的答案：

  • Rubin 潜在结果框架：每个个体对每种处理状态都有一个潜在结果 \(Y_i(1)\)、\(Y_i(0)\)， 个体因果效应是 \(Y_i(1)-Y_i(0)\)，但对每个人永远只能观察到一个，另一个是缺失的； 可估的是 \(\mathrm{ATE}=E[Y(1)]-E[Y(0)]\)（p86–90）
  • Pearl 因果结构模型：用有向无环图 DAG 把领域知识画成假设， 据此识别混杂、中介、碰撞变量与工具变量（p91–93）

讲义特别点出两者常常合用：随机化塑造了反事实人群， 而观察性研究要做的是「用统计方法创造出类似随机化的条件」（p94）。

五类方法，一条递进线

# 方法 核心做法 讲义
1 回归 把混杂放进模型，看 \(\beta\) p95–99
2 G 计算 把全样本强制设 \(A=1\) 与 \(A=0\) 各预测一遍，两次均值作差 p100–102
3 倾向得分 把多个协变量降维成一个概率，再匹配 / 加权 p103–106
4 机器学习 用 Super Learner 把两个模型都建得更准 p107–113
5 双重稳健 结果模型与暴露模型一起上，错一个还能救 p114–124

回归这一段最该看的是 p99：\(\beta_1\) 等于 ATE 需要两个假设—— 条件可忽略性（所有重要混杂都已纳入模型）和正确的函数形式 （\(A\) 对 \(Y\) 的效应是线性可加、且对任何 \(X\) 都是恒定的 \(\beta_1\)）。 第二条平时几乎没人检验，却是回归与 G 计算分道扬镳的地方。

G 计算被讲义称为「将反事实思想操作化」，三步（p101）：

  1. 建结果预测模型 \(Y \sim \beta_0+\beta_1 A+\beta_2 X_2+\beta_3 X_3^2+\mathrm{spline}(X_3)+\cdots\)
  2. 把全样本的 \(A\) 强制设为 1、其余变量不动，预测 \(\hat Y_i(1)\)；再全部设为 0，预测 \(\hat Y_i(0)\)
  3. \(\mathrm{ATE}=\overline{\hat Y(1)}-\overline{\hat Y(0)}\)

它的优势正好补回归的短板：模型里可以放任意交互项、非线性项，甚至换成随机森林， 因为最后取的是预测值的均值，不是某个系数（p102）。

倾向得分的定位是降维——把多个协变量浓缩成一个 \(0\) 到 \(1\) 的概率， PS 相近即群体特征相近（p103）。构造反事实的方式有匹配、加权、逆概率加权 IPTW、 标准化死亡比加权 SMRW、重叠加权（p104–106）。

机器学习这一段的落点是 Super Learner：多个基学习器（逻辑回归、决策树、 随机森林、XGBoost、SVM、KNN）的预测结果作为输入，再由一个元学习器用交叉验证 分配权重（p110）。它同时治两个病——倾向得分不准确、结果模型设定错误（p111）。

双重稳健是本周的终点，也是后面五、六周的起点：结果模型 \(\mu_a(X)=E[Y|A=a,X]\) 与暴露模型 \(e(X)=P(A=1|X)\) 一起建，只要有一个设定正确，估计就仍然一致（p116）。 讲义给了三条实现路线和对应 R 包（p117）：

  • 增强逆概率加权 AIPW —— drtmle、AIPW
  • 靶向最大似然估计 TMLE —— tmle、ltmle
  • 双重机器学习 DML —— DoubleML

TMLE 及其衍生方法（CV-TMLE、C-TMLE、HAL-TMLE、Longitudinal TMLE 等）在 p118–124 铺开，正是第六周的内容。

全周的落点在最后一页

讲义 p125 的小结只有三句，但它是整门课的立场：

数据驱动不能带来因果关系，现代医学因果推断是预测模型 + 领域知识的结合。 That is, we cannot answer causal questions with the data alone, no matter how big the data are and how deep the neural network is.

也就是说，后面八周所有的机器学习方法，都是在 DAG 与反事实框架给定之后才上场的， 不是用来替代那个框架的。

视频里两个当场踩到的坑

Windows 路径：从资源管理器复制来的路径是反斜杠 \，直接粘进 setwd() 会报符号识别不了，要逐个改成 /，或写成 \\（1.3 讲）。

取子集要写全数据框名：data[data$sex == 1, ] 能跑， data[sex == 1, ] 报「未定义的列」——因为 sex 不在当前环境里。 视频里这一段试了好几次才说清（1.4 讲）。

「取值」一列：连续变量给最小值到最大值，分类变量列出实际出现的水平 （超过 6 个截断）。「含义」一列抄自课程发的数据赋值表，空白表示赋值表里没有这一条。

赋值表和数据对不上：多数协变量是 1/2 不是 0/1

对着上表的「取值」和「含义」两列看会发现，课程发的赋值表与数据本身并不一致：

变量 赋值表写的 数据里实际是
sex、hypertension、heart_disease、residence、marital、smoking、alcohol、cardio_metabolic 0 / 1 1 / 2
education_level 1 / 2 / 3 1 / 2 / 3 / 4（多一档）
diabetes、PA_CAT、CESD_CAT、lungfun 0 / 1 0 / 1 ✓

也就是说分析变量（暴露、中介、结局）是 0/1，多数协变量却是 1/2。 课程脚本没有重新编码这些列。

后果分两种：二分类协变量放进回归时系数大小不受影响，但「哪一组是参照」会与赋值表 的说法相反，解释方向容易写反；education_level 则是实打实的问题—— 按赋值表当成 3 档处理会漏掉第 4 档。用之前先 table() 一遍。
