超级学习

Rachael Phillips

基于 sl3 R 包，作者为 Jeremy Coyle、Nima Hejazi、Ivana Malenica、Rachael Phillips 与 Oleg Sofrygin。

学习目标

读完本章之后，你将能够：

  1. 选择一个由真实预测函数最优化的表现度量；或者反过来，把所关心的真实预测定义为该表现度量的最优化元。

  2. 组装一套多样化的学习器集合（“库”），供超级学习器考虑。具体来说，你应当能够：

    1. 通过修改调参参数来定制一个学习器；
    2. 用不同的调参参数设定，从同一个基学习器创建出多个变体；
    3. 把筛选器（screener）与学习器耦合起来，构造出只把筛选器选出的那一小部分协变量作为协变量来考虑的学习器。

  3. 指定一个能最优化所关心目标函数的元学习器（meta-learner）。

  4. 结合手头的预测问题、分析在现实世界中的预期用途、统计模型、样本量、协变量个数，以及离散结局的结局发生率，为所选的库与元学习器给出论证。

  5. 依据交叉验证风险估计表与超级学习器系数，解读超级学习器的拟合结果。

引言

数据分析中一项常见任务是预测，也就是利用观测数据学习一个函数，它以协变量／预测变量上的数据为输入，输出一个预测值。有时，所关心的科学问题本身适合作因果效应估计。但即便在这类预测并不居于台前的场景中，预测任务也嵌在流程之内。举例来说，在针对平均处理效应的靶向最小损失估计（TMLE）中，估计结局回归与倾向性评分都需要预测建模。

从数据中对关系建模有多种可用策略，我们把它们交替称为”估计量”、“算法”和”学习器”。对某些数据，必须用能够捕捉变量间复杂关系的算法才能充分建模；对另一些数据，参数型回归学习器可能就拟合得相当不错。对于给定的数据集与预测问题，一般不可能事先知道哪种方法最好。

超级学习器（Super Learner, SL）解决了”选哪个算法”的问题，因为它可以同时考虑许多算法——从最简单的参数回归，到最复杂的机器学习算法（例如神经网络、支持向量机等）。此外，已经证明在大样本下，给定所指定的学习器集合，它的表现能达到尽可能好（与那个未知的先知一样好）(van der Laan 和 Dudoit 2003; van der Laan, Dudoit, 和 Keles 2004; Dudoit 和 van der Laan 2005; van der Vaart, Dudoit, 和 van der Laan 2006)。SL 代表了一种完全预先设定、灵活且有理论依据的预测建模方法。它已被证明在各种应用中都具有自适应性与稳健性，即便样本量很小也是如此。关于 SL 流程的详细说明有大量文献可查 (Polley 和 van der Laan 2010; Naimi 和 Balzer 2018)。关于设定 SL 的实务考量——包括如何指定一个丰富而多样的学习器库、如何为 SL 选择表现度量，以及如何指定交叉验证（CV）方案——在一篇预印本文章中有介绍 (Phillips 等 2023)。这里，我们聚焦于介绍 sl3，也就是 tlverse 中面向 SL 的标准软件包。

用 sl3 做超级学习

如何拟合超级学习器

本节演示用 sl3 拟合任意 SL 的核心功能。在随后的各节中，我们会介绍 sl3 的更多功能。

  1. 用 make_sl3_Task 定义预测任务；

安装 sl3 软件（按需）

安装任何包之前，我们建议先清空 R 工作空间，再重启 R 会话。在 RStudio 中，可以依次点击 “Session” → “Clear Workspace”，再点击 “Session” → “Restart R”。

我们可以用 devtools R 包提供的 install_github 函数来安装 sl3。本材料中使用的是 sl3 的开发（“devel”）版本，因此下面演示如何安装该版本。

library(devtools)

sl3_Task 会记录各变量在预测问题中所扮演的角色。与预测任务相关的额外信息（例如观测层面的权重、offset、id、CV 折）同样可以在 make_sl3_Task 中指定。sl3 中默认的 CV 折结构是 V=10 折的 V 折交叉验证（VFCV）。如果在任务中指定了 id，则采用聚集型的 V=10 VFCV 方案；如果结局类型是二值或分类的，则采用分层的 V=10 VFCV 方案。通过传入一个 origami 折对象（由 origami R 包中的 make_folds 函数生成），可以指定不同的 CV 方案。更多信息请参阅上一章关于交叉验证的内容，或查阅 origami 的 make_folds 函数文档（例如在 RStudio 中加载 origami R 包后，在控制台输入 “?make_folds”）。关于 sl3_Task 的更多细节，请参阅其文档（例如在 R 中输入 “?sl3_Task”）。

现在我们对一些学习器有了概念，让我们实例化其中几个。下面我们实例化 Lrnr_glm 与 Lrnr_mean，分别是主效应项广义线性模型（GLM）和均值模型。

上面创建的这两个学习器都只用了默认的调参参数。我们也可以定制学习器的调参参数，以纳入多样化的不同设定，并把同一个学习器在不同调参设定下作为不同候选者来考虑。

下面，我们以同一个基学习器 Lrnr_glmnet（即带弹性网正则化的 GLM）为基础，创建出两个不同的候选者：一个 L2 惩罚／岭回归，一个 L1 惩罚／lasso 回归。

# penalized regressions:
lrn_ridge <- Lrnr_glmnet$new(alpha = 0)
lrn_lasso <- Lrnr_glmnet$new(alpha = 1)

上面通过在 Lrnr_glmnet 中设定 alpha，我们定制了该学习器的调参参数。下面实例化 Lrnr_hal9001 时，我们展示如何同时修改多个调参参数（具体是 max_degree 与 num_knots）。

我们再实例化一些不强加线性或单调关系的学习器，从而把候选集合进一步扩充到非参数学习器。

# spline regressions:
lrn_polspline <- Lrnr_polspline$new()
lrn_earth <- Lrnr_earth$new()

# fast highly adaptive lasso (HAL) implementation
lrn_hal <- Lrnr_hal9001$new(max_degree = 2, num_knots = c(3,2), nfolds = 5)

# tree-based methods
lrn_ranger <- Lrnr_ranger$new()
lrn_xgb <- Lrnr_xgboost$new()

我们再加入一个广义可加模型（GAM）和一个贝叶斯 GLM，让将要作为 SL 候选者的这个池子更加多样。

lrn_gam <- Lrnr_gam$new()
lrn_bayesglm <- Lrnr_bayesglm$new()

现在我们已经实例化了一组学习器，需要把它们组织到一起，好让 SL 把它们当作候选者。在 sl3 中，我们通过创建一个所谓的学习器 Stack 来做到这一点。Stack 的创建方式与创建学习器相同——这是因为 Stack 本身就是一个学习器；它与其他所有学习器有着相同的接口。Stack 的特别之处在于它一次考虑多个学习器：它可以同时训练它们，从而让它们的预测能够被组合和／或比较。

stack <- Stack$new(

  lrn_ranger, lrn_xgb, lrn_gam, lrn_bayesglm

小结

本节演示了用 sl3 拟合任意 SL 的核心功能，它包含以下三个步骤：

  1. 用 make_sl3_Task 定义预测任务；
  2. 用 Lrnr_sl 实例化 SL；
  3. 用 train 把 SL 拟合到该任务上。

这个例子仅用于演示。关于如何针对手头预测任务构造一个设定得当的 SL，其逐步指引参见 Phillips 等 (2023)。

手工计算交叉验证预测

我们可以”手工”得到 CV 预测：逐折取数，然后用拟合好的候选学习器（它们是在每一折的训练集上训练的）去预测验证集的结局（这些结局在训练中未曾出现）。

##### CV predictions "by hand" #####
# for each fold, i, we obtain validation set predictions:
cv_preds_list <- lapply(seq_along(task$folds), function(i){
  
  # get validation dataset for fold i:
  v_data <- task$data[task$folds[[i]]$validation_set, ]
  
  # get observed outcomes in fold i's validation dataset:
  v_outcomes <- v_data[["whz"]]

  # make task (for prediction) using fold i's validation dataset as data, 
  # and keeping all else the same:
  v_task <- make_sl3_Task(covariates = task$nodes$covariates, data = v_data)
  
  # get predicted outcomes for fold i's validation dataset, using candidates 
  # trained to fold i's training dataset
  v_preds <- sl_fit$fit_object$cv_fit$predict_fold(
    task = v_task, fold_number = i
  )
  # note: v_preds is a matrix of candidate learner predictions, where the 
  # number of rows is the number of observations in fold i's validation dataset 
  # and the number of columns is the number of candidate learners (excluding 
  # any that might have failed)
  
  # an identical way to get v_preds, which is used when we calculate the 
  # cv risk by hand in a later part of this chapter:
  # v_preds <- sl_fit$fit_object$cv_fit$fit_object$fold_fits[[i]]$predict(
  #   task = v_task
  # )
  
  # we will also return the row indices for fold i's validation set, so we 
  # can later reorder the CV predictions and make sure they are equal to what 
  # we obtained above
  return(list("v_preds" = v_preds, "v_index" = task$folds[[i]]$validation_set))

手工计算交叉验证的预测表现

与上面”手工”取得 CV 预测的做法类似，我们也可以用一种把流程摊开来的方式计算 CV 表现／风险。具体做法是：逐折取数，用拟合好的候选学习器（它们在每一折的训练集上训练）去预测验证集的结局（这些结局在训练中未曾出现），然后度量预测表现（即风险）。随后把每个候选学习器各折的风险在所有折上取平均，得到 CV 风险。cv_risk 函数在内部完成了这一切；下面我们展示如何手工做一遍，这有助于理解 CV 风险及其计算方式。

##### CV risk "by hand" #####
# for each fold, i, we obtain predictive performance/risk for each candidate:
cv_risks_list <- lapply(seq_along(task$folds), function(i){
  
  # get validation dataset for fold i:
  v_data <- task$data[task$folds[[i]]$validation_set, ]
  
  # get observed outcomes in fold i's validation dataset:
  v_outcomes <- v_data[["whz"]]

  # make task (for prediction) using fold i's validation dataset as data, 
  # and keeping all else the same:
  v_task <- make_sl3_Task(covariates = task$nodes$covariates, data = v_data)
  
  # get predicted outcomes for fold i's validation dataset, using candidates 
  # trained to fold i's training dataset
  v_preds <- sl_fit$fit_object$cv_fit$fit_object$fold_fits[[i]]$predict(v_task)
  # note: v_preds is a matrix of candidate learner predictions, where the 
  # number of rows is the number of observations in fold i's validation dataset 
  # and the number of columns is the number of candidate learners (excluding 
  # any that might have failed)
  
  # calculate predictive performance for fold i for each candidate
  eval_function <- loss_squared_error # valid for estimation of conditional mean
  v_losses <- apply(v_preds, 2, eval_function, v_outcomes)
  cv_risks <- colMeans(v_losses)
  return(cv_risks)
})
# average the predictive performance across all folds for each candidate
cv_risks_byhand <- colMeans(do.call(rbind, cv_risks_list))
cv_risk_table_byhand <- data.table(
  learner = names(cv_risks_byhand), MSE = cv_risks_byhand
)
# check that the CV risks are identical when calculated by hand and function

下面我们展示如何手工计算 SL 的 revere-CV 预测表现／风险，这或许有助于理解 revere，以及它如何被用来得到 SL 的部分 CV 表现／风险估计。

sl_revere_risk_list <- lapply(seq_along(task$folds), function(i){
  # get validation dataset for fold i:
  v_data <- task$data[task$folds[[i]]$validation_set, ]

  # get observed outcomes in fold i's validation dataset:
  v_outcomes <- v_data[["whz"]]

  # make task (for prediction) using fold i's validation dataset as data,
  # and keeping all else the same:
  v_task <- make_sl3_Task(
    covariates = task$nodes$covariates, data = v_data
  )

  # get predicted outcomes for fold i's validation dataset, using candidates
  # trained to fold i's training dataset
  v_preds <- sl_fit$fit_object$cv_fit$fit_object$fold_fits[[i]]$predict(v_task)

  # make a metalevel task (for prediction with sl):
  v_meta_task <- make_sl3_Task(
    covariates = sl_fit$fit_object$cv_meta_task$nodes$covariates,
    data = v_preds
  )

  # get predicted outcomes for fold i's metalevel dataset, using the fitted
  # metalearner, cv_meta_fit
  sl_revere_v_preds <- sl_fit$fit_object$cv_meta_fit$predict(task=v_meta_task)
  # note: cv_meta_fit was trained on the metalevel dataset, which contains the
  # candidates' cv predictions and validation dataset outcomes across ALL folds,
  # so cv_meta_fit has already seen fold i's validation dataset outcomes.

  # calculate predictive performance for fold i for the SL
  eval_function <- loss_squared_error # valid for estimation of conditional mean
  # note: by evaluating the predictive performance of the SL using outcomes
  # that were already seen by the metalearner, this is not a cross-validated
  # measure of predictive performance for the SL.
  sl_revere_v_loss <- eval_function(
    pred = sl_revere_v_preds, observed = v_outcomes
  )
  sl_revere_v_risk <- mean(sl_revere_v_loss)
  return(sl_revere_v_risk)
})

把集成超级学习器作为候选者放进离散超级学习器

我们建议用 CV 来评估 SL 的预测表现。上面我们展示了如何用 cv_sl 做到这一点。我们也看到，当把某个学习器作为候选者放进 SL 时（用 sl3 的说法，就是把学习器放进传给 Lrnr_sl 的 learners 那个 Stack 里），我们就能查看它的 CV 风险。此外，使用 dSL 时，取得最低 CV 风险的那个候选者就定义了最终的 SL。因此我们可以用 dSL 来自动化这样一个流程：得到一个最终 SL，它代表交叉验证预测表现最好的那个候选者。

集成 SL（ensemble SL, eSL）是一种以任意参数或非参数算法作为元学习器的 SL。因此，eSL 由多个候选者的组合所定义；它的预测由多个候选者预测的组合所定义。当把 eSL 及其候选学习器一起作为 dSL 的候选者时，eSL 的 CV 表现就可以与构造它所用的那些学习器作比较，而最终的 SL 将是取得最低 CV 风险的那个候选者。下面我们展示如何把一个 eSL、以及多个 eSL，作为候选者放进 dSL。

回忆第 2 节中定义的 SL 对象 sl：

# in the section 2 we defined Lrnr_sl as
# sl <- Lrnr_sl$new(learners = stack, metalearner = Lrnr_nnls$new())

sl 是一个 eSL，因为它用 NNLS 作元学习器。下面我们把 sl 改名为 eSL_metaNNLS，以明确它是一个以 NNLS 为元学习器的 eSL。注意，这个 eSL 中的候选学习器就是传给 learners 参数的那些，即 stack。

# let's rename it to clarify that this is an eSL that uses NNLS as meta-learner
eSL_metaNNLS <- sl

要把 eSL_metaNNLS 作为 stack 中的一个额外候选者，我们可以创建一个新的 stack，同时包含原来的候选学习器和这个 eSL。

stack_with_eSL <- Stack$new(stack, eSL_metaNNLS)

要实例化一个以 eSL_metaNNLS 及构造它所用的那些单个学习器为候选者的 dSL，我们定义一个新的 Lrnr_sl，把 stack_with_eSL 作为候选者、把 Lrnr_cv_selector 作为元学习器。

cv_selector <- Lrnr_cv_selector$new(eval_function = loss_squared_error)
dSL <- Lrnr_sl$new(learners = stack_with_eSL, metalearner = cv_selector)

把 eSL 作为候选者放进 dSL，使得 eSL 的 CV 表现可以与构造它所用的其他学习器作比较。这与上面调用 CV SL（cv_sl）类似。二者的区别在于：把 eSL 作为 dSL 的候选者，自动化了”让最终 SL 成为 CV 预测表现最好（即 CV 风险最低）的那个学习器”这一流程。如果 eSL 胜过其他任何候选者，dSL 最终就会选中它，所得的 SL 就是这个 eSL。这一做法的另一个优势是，可以同时评估多个采用更灵活元学习器方法（例如 HAL 这类非参数机器学习算法）的 eSL。

下面我们展示如何把多个 eSL 作为候选者放进一个 dSL：

# instantiate more eSLs
eSL_metaNNLSconvex <- Lrnr_sl$new(
  learners = stack, metalearner = Lrnr_nnls$new(convex = TRUE)
)
eSL_metaLasso <- Lrnr_sl$new(learners = stack, metalearner = lrn_lasso)
eSL_metaEarth <- Lrnr_sl$new(learners = stack, metalearner = lrn_earth)
eSL_metaRanger <- Lrnr_sl$new(learners = stack, metalearner = lrn_ranger)
eSL_metaHAL <- Lrnr_sl$new(learners = stack, metalearner = lrn_hal)
# adding the eSLs to the stack that defined them
stack_with_eSLs <- Stack$new(
  stack, eSL_metaNNLS, eSL_metaNNLSconvex, eSL_metaLasso, eSL_metaEarth, 
  eSL_metaRanger, eSL_metaHAL
)
# specify dSL
dSL <- Lrnr_sl$new(learners = stack_with_eSLs, metalearner = cv_selector)

我们放进这个 dSL 的候选者包括：

  1. 与前面相同的那个 eSL，eSL_metaNNLS；
  2. 在 (1) 中被当作候选者的那些学习器；
  3. 一个 eSL，其候选学习器与 (1) 相同，元学习器为带凸组合约束的 NNLS；
  4. 一个 eSL，其候选学习器与 (1) 相同，元学习器为 lasso，使用第 2 节中实例化的 lrn_lasso；
  5. 一个 eSL，其候选学习器与 (1) 相同，元学习器为多元自适应回归样条（earth），使用第 2 节中实例化的 lrn_earth；
  6. 一个 eSL，其候选学习器与 (1) 相同，元学习器为 ranger，使用第 2 节中实例化的 lrn_ranger；以及
  7. 一个 eSL，其候选学习器与 (1) 相同，元学习器为 HAL，使用第 2 节中实例化的 lrn_hal。

在 sl3 中，让 dSL 跑这么多 eSL 目前计算量非常大，因为这相当于为每个 eSL 各跑一次交叉验证 SL。对于像上面定义的 dSL 这类计算密集的学习器，推荐使用并行编程（下文会介绍）。也就是说，应当在调用 dSL$train(task) 之前先定义好并行处理方案，以缩短运行时间。

学习器及其部分调参参数的文档，可以在 R 会话中查到（例如要看 Lrnr_glmnet 的参数，可以在 RStudio 的 R 控制台输入 “?Lrnr_glmnet”），也可以在线查阅 sl3 学习器参考手册。sl3 中的所有学习器都只是对 R 中其他软件包已有函数的包装。例如，sl3 的 Lrnr_xgboost 是 sl3 中用于拟合 XGBoost（极端梯度提升）算法的学习器。正如 Lrnr_xgboost 文档所述，「该学习器借助 xgboost 包、通过 xgb.train 为 xgboost 模型提供拟合流程」。一般而言，sl3 中某个学习器的文档会把读者指向 sl3 所包装的那个原始函数与原始包。有鉴于此，sl3 的学习器文档是查阅任何学习器的好起点，因为它会准确告诉我们该学习器基于哪个包、哪个函数。不过，对某个学习器作任何深入考察（例如对全部调参参数的详细解释，或它如何对数据建模），通常都需要参考原始包。沿用上面的例子：虽然 Lrnr_xgboost 的文档会提供一些信息，比如让我们知道 Lrnr_xgboost 用的是 xgboost 包的 xgb.train 函数，但要对 sl3 中可用的 XGBoost 算法有最深入的理解，还是要去参考 xgboost R 包及其 xgb.train 函数。

协变量筛选

一个丰富的学习器库，其特征之一是能有效处理高维协变量。当数据中协变量数目相对于有效样本量而言很多时（见 Phillips 等 (2023) 的图 1 流程图），候选学习器应当与一系列所谓的”筛选器”（screener）耦合。筛选器不过是一个返回协变量子集的函数。它的用意是与某个候选学习器耦合，从而定义出一个新的候选学习器——这个新学习器把筛选器返回的那一小部分协变量当作自己的协变量。

当数据维度非常高时，协变量筛选是必不可少的；而在任何 SL 或机器学习应用中，它都可能很实用。凡是考虑了与结局之关联的协变量筛选，都必须经过交叉验证，否则会让算法预测表现的估计产生偏倚。把”筛选器—学习器”耦合体作为额外候选者纳入 SL 库，我们就是在对协变量筛选做交叉验证。各 CV 折中保留下来的协变量可能各不相同。

所谓”一系列筛选器”，是指一组降维程度各异、并且采用不同拟合流程的筛选器（例如：基于 lasso 的筛选器保留系数非零的协变量；基于重要性的筛选器按某种重要性指标保留最重要的前 \(j\) 个协变量）。sl3 中当前可用的筛选器在下面各部分分别介绍。

我们会看到，要在 sl3 中定义一个筛选器与学习器的耦合体，需要创建一个 Pipeline。Pipeline 是一组按顺序拟合的学习器，其中前一个学习器的拟合结果被用来定义下一个学习器的任务。

基于变量重要性的筛选器

基于变量重要性的筛选器按某种重要性指标保留最重要的前 \(j\) 个协变量。sl3 中由 Lrnr_screener_importance 提供这一筛选器，参数 \(j\)（默认为五）由用户通过 num_screen 参数给出。用户还可以通过 learner 参数选择所采用的重要性指标。任何带 importance 方法的学习器都可以用在 Lrnr_screener_importance 中；目前包括以下这些：

sl3_list_learners(properties = "importance")
[1] "Lrnr_lightgbm"     "Lrnr_randomForest" "Lrnr_ranger"      
[4] "Lrnr_xgboost"

我们来考虑基于 Lrnr_ranger 变量重要性排序的协变量筛选，按 ranger 的 “impurity_corrected” 重要性选出最重要的前十个协变量。我们把这个筛选器与 Lrnr_glm 耦合，定义出一个新学习器，它会：（1）按 ranger 的 “impurity_corrected” 重要性选出最重要的前十个协变量；（2）把筛选器选出的协变量传给 Lrnr_glm，于是 Lrnr_glm 依据这一缩减后的协变量集合拟合模型。如上所述，这种耦合确立了一个新的学习器，需要定义一个 Pipeline。Pipeline 正是 sl3 中从（1）走到（2）的方式。

ranger_with_importance <- Lrnr_ranger$new(importance = "impurity_corrected")
RFscreen_top10 <- Lrnr_screener_importance$new(
  learner = ranger_with_importance, num_screen = 10
)
RFscreen_top10_glm <- Pipeline$new(RFscreen_top10, lrn_glm)

我们甚至可以为整个 Stack 定义 Pipeline，这样其中每个学习器都会在筛选器选出的那十个协变量上拟合。

RFscreen_top10_stack <- Pipeline$new(RFscreen_top10, stack)

基于系数阈值的筛选器

Lrnr_screener_coefs 依据协变量在一个（可能带正则化的）GLM 中所估系数的大小来筛选协变量。threshold（默认 1e-3）规定了系数——因而也是协变量——被保留所需的最小绝对值。此外还可以选择性地提供 max_retain 参数，把选出的协变量数目限制在不超过 max_retain。

我们来考虑用 Lrnr_screener_coefs 筛选协变量，选出 lasso 回归系数非零的那些变量。我们把这个筛选器与 Lrnr_glm 耦合，定义出一个新学习器，它会：（1）选出 lasso 回归系数非零的协变量；（2）把筛选器选出的协变量传给 Lrnr_glm，于是 Lrnr_glm 依据这一缩减后的协变量集合拟合模型。其结构与上面非常相似。

lasso_screen <- Lrnr_screener_coefs$new(learner = lrn_lasso, threshold = 0)
lasso_screen_glm <- Pipeline$new(lasso_screen, lrn_glm)

我们同样可以为整个 Stack 定义 Pipeline，这样其中每个学习器都会在 lasso 筛选器选出的那部分协变量上拟合。

lasso_screen_stack <- Pipeline$new(lasso_screen, stack)

基于相关性的筛选器

Lrnr_screener_correlation 通过做相关性检验（默认 Pearson）来提供协变量筛选流程，然后选出（1）排名靠前的变量（默认），或者（2）p 值低于用户指定阈值的变量。

我们来考虑用 Lrnr_screener_coefs 筛选协变量。下面演示如何用一个 Stack 搭出 pipeline，其形式与前面的例子相同；单个学习器的 Pipeline 也与前面的例子一样。

# select top 10 most correlated covariates
corRank_screen <- Lrnr_screener_correlation$new(
  type = "rank", num_screen = 10
)
corRank_screen_stack <- Pipeline$new(corRank_screen, stack)

# select covariates with correlation p-value below 0.05, and a minimum of 3
corP_screen <- Lrnr_screener_correlation$new(
  type = "threshold", pvalue_threshold = 0.05, min_screen = 3
)
corP_screen_stack <- Pipeline$new(corP_screen, stack)

增补型筛选器

增补型筛选器的特别之处在于，它强制某些协变量总是被纳入。也就是说，如果某个筛选器剔除了一个”必留”协变量，Lrnr_screener_augment 会在 Pipeline 中的学习器拟合之前把它重新加回来。下面给出该筛选器的用法示例。我们假定 aged 与 momage 是必须保留在学习器拟合中的协变量。

keepme <- c("aged", "momage")
# using corRank_screen as an example, but any instantiated screener can be

corRank_screen_augmented <- Lrnr_screener_augment$new(
  screener = corRank_screen, default_covariates = keepme
)
corRank_screen_augmented_glm <- Pipeline$new(corRank_screen_augmented, lrn_glm)

当领域专家强烈认为某些协变量集合必须被纳入（即便在筛选流程之下也是如此）时，Lrnr_screener_augment 就很有用。

sl3 的进阶功能

变量重要性度量

变量重要性可能既有趣又有信息量，但它也可能自相矛盾、令人困惑。尽管如此，我们的合作者往往都喜欢它，因此我们在 sl3 中做了一个评估变量重要性的函数。sl3 的 importance 函数返回一张表，其中变量按重要性递减排列（即最重要的排在第一行）。

sl3 中的重要性度量，基于”移除或置换某个协变量（或协变量分组）后拟合的 SL”与”使用实际观测协变量（或协变量分组）拟合的 SL”之间预测表现的比值或差值，并对所有协变量逐一如此计算。照此，预测表现的比值／差值越大，该协变量（或协变量组）在 SL 预测中就越重要。

这一度量的直觉是：它计算在”丢掉某个协变量（或某一组协变量）、其余一切保持不变”时的预测风险（例如 MSE），并把这个预测风险与来自完整分析数据集的风险作比较。如果预测风险之比为 1，或差值为 0，那么丢掉那个协变量（组）没有产生影响，按这一度量它就不重要。这一流程对所有协变量／分组重复进行。如上所述，我们可以移除每个协变量（或协变量组）并在没有它的情况下重新拟合 SL，也可以只是把它置换掉（更快），指望这种打乱能破坏其中原有的有意义信息。用置换代替移除的想法能节省大量时间，randomForest 的变量重要性度量中也采用了这一做法。不过置换法风险更大。sl3 的 importance 默认是移除每个协变量再重新拟合。下面我们使用 permute 方式，因为它快得多。

条件密度估计

在某些场景中，估计因变量在其之前的预测变量／协变量条件下的条件密度可能很有用。在因果推断的语境下，这最常出现在处理变量取连续值的时候。具体来说，当估计连续取值处理的处理机制（常称为广义倾向性评分）时，就需要条件密度估计（CDE）。与二值处理的经典倾向性评分（PS，即给定协变量下接受处理的条件概率）\(\mathbb{P}(A = 1 \mid W)\) 相比，广义 PS 是处理 \(A\) 在给定协变量 \(W\) 条件下的条件密度 \(\mathbb{P}(A \mid W)\)。

CDE 往往需要与非常具体的算法实现绑定的专门方法。据我们所知，文献中提出的通用且灵活的 CDE 算法寥寥无几。我们在 sl3 中实现了其中两种：一种是半参数 CDE 方法，它对底层分布（高阶）矩的恒定性作了某些假设；另一种则利用条件风险函数与密度函数之间的关系，通过汇合风险回归（pooled hazard regression）来做 CDE。两种方法都很灵活，因为它们都允许用任意回归函数或机器学习算法来估计冗余量（分别是条件均值与条件风险）。下面我们分别阐述这两个框架。重要的是，依据 Dudoit 和 van der Laan (2005) 及相关工作，适用于密度估计的损失函数是负对数密度损失 \(L(\cdot) = -\log(p_n(\cdot))\)。

受矩约束的位置—尺度族

这一类半参数 CDE 方法利用了通用形式 \(\rho(Y - \mu(X) / \sigma(X))\)，其中 \(Y\) 是所关心的因变量（例如 PS 中的处理 \(A\)），\(X\) 是预测变量（例如 PS 中的协变量 \(W\)），\(\rho\) 是一个指定的边际密度函数，而 \(\mu(X) = \E(Y \mid X)\) 与 \(\sigma(X) = \E[(Y - \mu(X))^2 \mid X]\) 是因变量的冗余函数，可以灵活地估计。在这一框架内表述的 CDE 流程，可以刻画为属于条件位置—尺度族，即 \(p_n(Y \mid X) = \rho((Y - \mu_n(X)) / \sigma_n(X))\)。用条件位置—尺度族做 CDE 并非没有潜在缺点（例如对密度函数形式的限制可能导致误设偏倚），但这一策略的灵活之处在于，它允许用任意机器学习算法来估计 \(Y\) 在给定 \(X\) 下的条件均值 \(\mu(X) = \E(Y \mid X)\)，以及 \(Y\) 在给定 \(X\) 下的条件方差 \(\sigma(X) = \E[(Y - \mu(X))^2 \mid X]\)。

在数据有限的场景中，“目标密度属于某个位置—尺度族”这一假设所施加的额外结构，可能因为能在数据支撑稀薄的区域作平滑而带来好处。不过在实践中，我们无从知道这一假设是否成立、何时成立。这一流程并非我们自己的新贡献（我们也未能在文献中找到它的正式表述）；尽管如此，我们在下面给出一个非正式的算法梗概。该算法假定我们能获得观测数据随机变量 \(O = (Y, X)\) 的 \(n\) 份独立同分布（i.i.d.）副本、一个事先设定的核函数 \(\rho\)、一个用于估计 \(\mu(X)\) 的候选回归流程 \(f_{\mu}\)，以及一个用于估计 \(\sigma(X)\) 的候选回归流程 \(f_{\sigma}\)。

  1. 通过施用回归估计量 \(f_{\mu}\) 来估计 \(Y\) 在给定 \(X\) 下的条件均值 \(\mu(X) = \E[Y \mid X]\)，得到 \(\hat{\mu}(X)\)。
  2. 通过施用回归估计量 \(f_{\sigma}\) 来估计 \(Y\) 在给定 \(X\) 下的条件方差 \(\sigma(X) = \mathbb{V}[Y \mid X]\)，得到 \(\hat{\sigma}^2(X)\)。注意这一步只涉及条件均值 \(\E[(Y - \hat{\mu}(X))^2 \mid X]\) 的估计。
  3. 用核平滑估计 \((Y - \hat{\mu}(X))^2 / \hat{\sigma}^2(X)\) 的一维密度，得到 \(\hat{\rho}(Y)\)。
  4. 构造出估计的条件密度 \(p_n(Y \mid X) = \hat{\rho}((Y - \hat{\mu}(X)) / \hat{\sigma}(X))\)。

这个算法梗概涵盖了该 CDE 方法的两种形式，它们在上面第二步处分道扬镳。为简化方法，可以选择只估计条件均值 \(\mu(X)\)，而把条件方差假定为恒定（即简单地估计为残差的边际均值 \(\E[(Y - \hat{\mu}(X))^2]\)）。基于所作的方差假设，这一子类 CDE 方法具有同方差误差。另一种做法是把条件方差估计为残差 \((Y - \hat{\mu}(X))^2\) 在给定 \(X\) 下的条件均值 \(\E[(Y - \hat{\mu}(X))^2 \mid X]\)，其中用候选算法 \(f_{\sigma}\) 来求这个期望。两种做法都已在 sl3 中实现，对应学习器 Lrnr_density_semiparametric。mean_learner 参数指定 \(f_{\mu}\)，可选的 var_learner 参数指定 \(f_{\sigma}\)。下面我们演示用这一方法做 CDE。

汇合风险回归

sl3 中另一种可用的 CDE 方法最初由 Dı́az 和 van der Laan (2011) 提出，它利用了（条件）风险函数与密度函数之间的关系。为构建这一 CDE 框架，Dı́az 和 van der Laan (2011) 提出把支撑集为 \(\mathcal{Y}\) 的连续因变量 \(Y\) 依据分箱数目 \(T\) 和某种分箱流程（例如把 \(\mathcal{Y}\) 切成 \(T\) 个长度完全相同的箱）离散化。调参参数 \(T\) 在概念上对应于经典核密度估计中带宽的选择。离散化之后，每个单元由一组记录来表示，而表示某个给定单元的记录数取决于该单元所落入的那个箱（沿离散化后的支撑集）的序号。

举例来说，这一流程的一次具体实施可能把 \(Y\) 的支撑集划成 \(T = 4\) 个等长的箱（注意这需要 \(T+1\) 个切点）：\([\alpha_1, \alpha_2), [\alpha_2, \alpha_3), [\alpha_3, \alpha_4), [\alpha_4, \alpha_5]\)（注意最右侧区间是闭区间，其余只是半闭）。接着会构造一个人工的重复测量数据集，其中每个单元最多由 \(T\) 条记录表示。为更好地理解这一结构，考虑某个单元 \(O_i = (Y_i, X_i)\)，其 \(Y_i\) 值落在第三个箱 \([\alpha_3, \alpha_4)\) 内。这个单元将由三条不同的记录表示：\(\{Y_{ij}, X_{ij}\}_{j=1}^3\)，其中 \(\{\{Y_{ij} = 0\}_{j=1}^2\)，\(Y_{i3} = 1\}\)，以及 \(X_i\) 的三份完全相同的副本 \(\{X_{ij}\}_{j=1}^3\)。这种”同一单元用多条记录表示”的形式，使得”\(Y_i\) 落入离散化支撑集上某个给定箱”的条件风险概率，可以用标准的二值回归技术来评估。

事实上，这一提议把二值回归问题重新表述为一组相应的风险回归：\(\mathbb{P} (Y \in [\alpha_{t-1}, \alpha_t) \mid X) = \mathbb{P} (Y \in [\alpha_{t-1}, \alpha_t) \mid Y \geq \alpha_{t-1}, X) \times \prod_{j = 1}^{t -1} \{1 - \mathbb{P} (Y \in [\alpha_{j-1}, \alpha_j) \mid Y \geq \alpha_{j-1}, X) \}\)。这里，\(Y \in \mathcal{Y}\) 落入箱 \([\alpha_{t-1}, \alpha_t)\) 的概率可以直接用二值回归流程估计——办法是把相应的似然，重新表述为在这种重复测量结构数据集中一个二值变量的似然。最后，把风险估计按箱宽 \(\lvert \alpha_t - \alpha_{t-1} \rvert\) 重新标度，就可以映射为密度估计，即对 \(\alpha_{t-1} \leq a < \alpha_t\)，有 \(p_{n, \alpha}(Y \mid X) = \mathbb{P}(Y \in [\alpha_{t-1}, \alpha_t) \mid X) / \lvert \alpha_t - \alpha_{t-1} \rvert\)。下面我们给出该算法的非正式梗概。

  1. 施用某种流程把 \(Y\) 的观测支撑范围 \(\max(Y) - \min(Y)\) 划分为 \(T\) 个箱：\([\alpha_1, \alpha_2), \ldots, [\alpha_{t-1}, \alpha_t), [\alpha_t, \alpha_{t+1}]\)。
  2. 把观测数据展开为重复测量数据结构，把每个单独观测表示为最多 \(T\) 条记录的集合，并在每条记录旁记录该观测的 ID。对单个单元 \(i\)，其记录集合形如 \(\{Y_{ij}, X_{ij}\}_{j=1}^{T_i}\)，其中 \(X_{ij}\) 在指标集 \(\mathcal{J}\) 上保持不变，\(Y_{ij}\) 是一个在其最后一个指标处（即 \(Y_i\) 所落入的那个箱）由 \(0\) 跳到 \(1\) 的二值计数过程，而 \(T_i \leq T\) 标明 \(Y_i\) 落在其支撑集上的哪个箱。
  3. 用任意二值回归估计量或合适的机器学习算法，估计在给定 \(X\) 条件下归入某箱的风险概率 \(\mathbb{P}(Y_i \in [\alpha_{t-1}, \alpha_t) \mid X)\)。
  4. 对每个观测 \(i = 1, \ldots, n\)，把累积风险除以 \(X_i\) 所落入那个箱的宽度，从而把条件风险概率估计重新标度到条件密度的尺度上。如果支撑集被划分为大小相等的箱（每箱约 \(n/T\) 个样本），这就相当于按一个常数重新标度；如果支撑集被划分为范围相等的箱，则各箱的标度可能不同。

这一提议的一个关键要素，是可以灵活地使用任意二值回归流程或合适的机器学习算法来估计 \(\mathbb{P}(Y \in [\alpha_{t-1}, \alpha_t) \mid X)\)，这便于纳入集成学习之类的灵活技术 (Breiman 1996; van der Laan, Polley, 和 Hubbard 2007)。这种极高的灵活度与 sl3 的底层设计原则完美契合；不过我们尚未以其完全的一般性实现这一方法。这一 CDE 方法的一个版本——它把原提议中的任意二值回归限定为高度自适应 lasso（HAL）算法 (Benkeser 和 van der Laan 2016)——由 haldensify 包 (Hejazi, Benkeser, 和 van der Laan 2022) 支持（haldensify 中的 HAL 实现由 hal9001 包 (Coyle 等 2022; Hejazi, Coyle, 和 van der Laan 2020) 提供）。这一使用 haldensify 的 CDE 算法在 sl3 中被封装为学习器 Lrnr_haldensify，演示如下。

  n_bins = c(5, 10)

结语

  • 超级学习器（SL）是一种通用方法，可以应用于各种能由损失函数定义的估计与预测问题。

  • 把 SL 返回的估计量代入目标参数映射是很直接的。

    • 例如，假设我们要估计某个二值处理干预的平均处理效应（ATE）：\(\Psi_0 = E_{0,W}[E_0(Y|A=1,W) - E_0(Y|A=0,W)]\)。
    • 我们可以用在原始数据上训练好的 SL（记作 sl_fit），预测所有受试者在每种干预下的结局。我们要做的只是取两种所关心干预下反事实结局的平均之差。
    • 就上面的 \(\Psi_0\) 而言，我们首先需要两个长度为 \(n\) 的预测结局向量，分别对应两种干预。一个向量代表”把所有受试者都设为接受 \(A=1\)“这一干预下的预测结局，即对所有 \(i=1,\ldots,n\) 的 \(Y_i|A_i=1,W_i\)；另一个向量代表”把所有受试者都设为接受 \(A=0\)“这一干预下的预测结局，即对所有 \(i=1,\ldots,n\) 的 \(Y_i|A_i=0,W_i\)。
    • 拿到这两个反事实预测结局向量之后，我们只需求平均再作差，就把 SL 估计量”代入”了目标参数映射。
    • 在 sl3 中，就我们当前的 ATE 例子而言，可以用 mean(sl_fit$predict(A1_task)) - mean(sl_fit$predict(A0_task)) 实现；其中 A1_task$data 在数据的处理列上全为 1（或对应接受处理的那个水平），其余保持不变，而 A0_task$data 在处理列上全为 0（或对应不接受处理的那个水平）。

  • 取得反事实预测结局、并创建这些反事实 sl3 任务，是一个值得做的练习。然而，把 SL 的拟合结果代入目标参数映射，偏倚太大（例如把 mean(sl_fit$predict(A1_task)) - mean(sl_fit$predict(A0_task)) 的结果称作 ATE 的估计）。那样我们得到的 ATE 估计量，是为估计预测函数而优化的，而不是为估计 ATE 而优化的！

  • 归根结底，我们想要的是一个能最好地逼近我们所关心问题的估计量。也就是说，我们在意的是尽可能把 \(\psi_0\) 估计好。SL 是帮我们走到那一步的关键一环：反事实预测结局估计（如上文所述），以及其他由 SL 得到的估计（例如倾向性评分），在估计 \(\psi_0\) 时都扮演关键角色。但 SL 并不是估计流程的终点。具体来说，如果我们只是把 SL 的估计代入目标参数，就不会得到目标 estimand 的渐近线性估计量；SL 不是有效的代入型估计量，也不支持统计推断。这为什么要紧？

    • 渐近线性估计量是指以 \(\frac{1}{\sqrt{n}}\) 的速率收敛到 estimand 的估计量，因而允许作正式的统计推断，即置信区间与 \(p\) 值（见 van der Laan 和 Rose (2011) 第 4–6 章）。

    • 代入型（plug-in）估计量之所以可取，是因为它们同时尊重统计模型的局部与全局约束（例如结局的取值界限），并且有限样本性质更好（见 van der Laan 和 Rose (2011) 第 6 章）。

    • 有效（efficient）估计量在这一意义上是最优的：它具有尽可能小的方差，因而最为精确。一个估计量是有效的，当且仅当它是渐近线性的且影响曲线等于正则梯度（canonical gradient）（见 van der Laan 和 Rose (2011) 第 6 章）。

      • 正则梯度是一个针对特定目标 estimand 的数学对象，它给出了该估计问题难度的信息（van der Laan 和 Rose (2011) 第 5 章）。后续各章会展示多种正则梯度。
      • 从业者不必会计算正则梯度，也能说清一个估计量值得拥有哪些性质（例如代入型、支持有效推断、有效，以及优化有限样本表现的能力）。正是这些性质促使人们使用 TMLE，因为 TMLE 满足它们。

  • TMLE 是一套通用策略，它成功地构造出有效且渐近线性、并在有限样本下稳健的代入型估计量。

  • SL 对纯预测非常好用，也适合为似然中各成分取得初始估计（这是 TMLE 的第一步）；但我们还需要第二步——靶向／更新／波动（targeting/updating/fluctuation）——才能具备上面提到的那些理想统计性质。

  • 在接下来的各章中，我们会聚焦于各种靶向最大似然估计量与靶向最小损失估计量，二者都简称 TMLE。
