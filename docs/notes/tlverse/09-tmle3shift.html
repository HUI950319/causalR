随机化处理方案

Nima Hejazi

主角是 tmle3shift R 包。

注记学习目标
  1. 把随机化处理方案与静态、动态及最优动态处理方案区分开来。
  2. 说明真实世界的数据分析可以如何纳入对随机化处理方案因果效应的评估。
  3. 对比人群层面的（一般）随机化处理方案与（个体化的）修正处理策略。
  4. 用 tmle3shift R 包估计修正处理策略的人群层面因果效应。
  5. 依据由一组反事实移位构成的网格，设定并解读一组基于不同修正处理策略的因果效应。
  6. 用一组反事实移位网格构造边际结构模型，以随机化干预的方式度量变量重要性。
  7. 用 tmle3shift R 包实现这样的修正处理策略：只在观测数据所能支撑的范围内对个体单元作移位。

为什么要用随机化干预？

随机化处理方案，或称随机化干预（stochastic interventions），构成了一个相对简单、却极其灵活且富有表达力的框架，用来定义现实的因果效应。与前面讨论过的干预方案不同，随机化干预几乎可以施加于任何形式的处理变量——二值、有序、连续——从而让人能够通过这一形式体系定义出丰富的因果效应。本章侧重于考察可施加于连续处理变量的几类随机化干预，而静态与动态处理方案并不容易施加于这类变量。值得注意的是，由此得到的因果效应恰好具有一种呼应普通回归调整的解释。

下一章我们会介绍随机化干预的另外两种用法——一种是新近提出的、适用于二值处理变量的干预 (Kennedy 2019)，另一种是在存在处理后变量（即中介变量）时对因果效应的定义。这里我们聚焦于 tmle3shift R 包提供的工具，它给出了”对处理变量观测值作加性移位”这类随机化干预之因果效应的靶向最小损失估计量。本章部分内容更全面、更技术化的论述见 Dı́az 和 van der Laan (2012)、Dı́az 和 van der Laan (2018)、Hejazi 等 (2020) 与 Hejazi (2021)。

数据结构与记号

让我们回到熟悉的数据单元 \(O = (W, A, Y)\)，其中 \(W\) 表示基线协变量（例如年龄、生理性别、受教育程度），\(A\) 是处理变量（例如营养补充剂的剂量），\(Y\) 是所关心的结局（例如疾病状态）。这里我们考虑取连续值（即 \(A \in \R\)）或水平很多的有序型 \(A\)。对某项给定研究，我们考虑观测到 \(n\) 个独立同分布的单元 \(O_1, \ldots, O_n\)。

沿着路线图，设 \(O \sim P_0 \in \M\)，其中 \(\M\) 是非参数统计模型，对数据生成分布 \(P_0\) 的形式尽可能不加限制。为了把随机化干预及其对应因果效应的定义形式化，我们引入一个基于 Pearl (2009) 的结构因果模型（SCM），用来定义系统在所设想的干预之下如何变化：

\[\begin{align} W &= f_W(U_W) \\ \nonumber A &= f_A(W, U_A) \\ \nonumber Y &= f_Y(A, W, U_Y). \end{align} \tag{162.1}\]

这组结构方程提供了一个机制性模型，描述构成观测数据单元 \(O\) 的各变量之间的关系。该 SCM 描述了变量之间的时间顺序（即 \(Y\) 发生在 \(A\) 之后，\(A\) 又发生在 \(W\) 之后）；指定了确定性函数 \(\{f_W, f_A, f_Y\}\)，它们基于各变量的前驱变量以及外生（未观测）变量 \(\{U_W, U_A, U_Y\}\) 来生成 \(\{W, A, Y\}\)；并要求每个外生变量都被假定包含相应观测变量的全部未观测原因。

我们可以把数据单元 \(O\) 的似然作如下因子分解，从而在某个典型观测 \(o\) 上显露出密度 \(p_0\) 的各正交成分：

\[\begin{align} p_0(o) = &q_{0,Y}(y \mid A = a, W = w) \\ \nonumber &g_{0,A}(a \mid W = w) \\ \nonumber &q_{0,W}(w),\\ \nonumber \end{align} \tag{162.2}\]

其中 \(q_{0, Y}\) 是 \(Y\) 在给定 \(\{A, W\}\) 下相对于某支配测度的条件密度，\(g_{0, A}\) 是 \(A\) 在给定 \(W\) 下相对于支配测度 \(\mu\) 的条件密度，\(q_{0, W}\) 是 \(W\) 相对于支配测度 \(\nu\) 的密度。为继续沿用熟悉的记号，我们记 \(\overline{Q}(A, W) = \E[Y \mid A, W]\)、\(g(A \mid W) = g_{A}(A \mid W)\)，并以 \(q_W\) 表示 \(W\) 的边际分布。重要的是，该 SCM 以这组方程所刻画的随机变量 \((O, U)\) 的分布来参数化 \(p_0\)。这反过来又隐含了一个关于”由对数据生成过程的干预所产生的反事实随机变量”其分布的模型。

定义随机化干预的因果效应

因果效应是以对 SCM 式 162.1 的假想干预之间的对照来定义的。修改 SCM 各成分的随机化干预可以从两个等价的角度来理解。一个一般的随机化干预，是把产生 \(A\) 的方程 \(f_A\)、以及 \(A\) 的自然条件密度 \(g(A \mid W)\)，替换为某个候选密度 \(g_{A_{\delta}}(A \mid W)\)。在没有干预的情况下，我们会把 \(\mathcal{A}\)（\(A\) 的支撑集）中任一给定取值 \(a\)——也就是函数 \(f_A\) 在给定 \(W = w\) 处求值的结果——视为从条件密度 \(g(A \mid W)\) 所定义分布中随机抽取的结果，即 \(A_{\delta} \sim g_{A_{\delta}}(\cdot \mid W)\)。在施加干预时，我们只需移除结构方程 \(f_A\)，转而从候选密度 \(g_{A_{\delta}}(A \mid W)\) 所定义的分布中抽取干预后的取值 \(A_{\delta}\)。干预后的取值 \(A_{\delta}\) 之所以说被”随机地修改”，是因为它抽自一个任意的（实践中由用户定义的）分布。注意，只要选取退化的候选分布（把全部质量放在单个取值上），就能还原出我们熟悉的静态干预情形。Stock (1989) 最早考虑了估计这类随机化干预的总效应。

虽然对候选的处理后密度 \(g_{A_{\delta}}(A \mid W)\) 的选择几乎没有限制，但实践中它往往依据对自然（或干预前）密度 \(g(A \mid W)\) 的了解来选取。当 \(g_{A_{\delta}}(A \mid W)\) 是分段光滑可逆的（见下文）(Haneuse 和 Rotnitzky 2013) 时，干预后密度 \(g_{A_{\delta}}(A \mid W)\) 与一个把观测对 \(\{A, W\}\) 映射为干预后量 \(A_{\delta}\) 的函数 \(d(A, W; \delta)\) 之间，存在直接的对应关系。在这种情形下，由 \(d(A, W; \delta)\) 定义的随机化干预被称为依赖于处理的自然取值，并被称作修正处理策略（modified treatment policy, MTP）(Haneuse 和 Rotnitzky 2013; Dı́az 和 van der Laan 2018; Hejazi 2021)。Haneuse 和 Rotnitzky (2013) 与 Young, Hernán, 和 Robins (2014) 对修正处理策略与一般随机化干预之下因果效应解释的差异作了详尽讨论。

注记定义（分段光滑可逆性）

对每个 \(w \in \mathcal{W}\)，假定区间 \(\mathcal{I}(w) = (l(w,), u(w))\) 可以被划分为若干子区间 \(\mathcal{I}_{\delta,j}(w): j = 1, \ldots, J(w)\)，使得 \(d(a, w; \delta)\) 在 \(\mathcal{I}_{\delta,j}(w)\) 上等于某个 \(d_j(a, w; \delta)\)，且 \(d_j(\cdot,w; \delta)\) 有反函数 \(b_j(\cdot, w; \delta)\)，其导数为 \(b_j'(\cdot, w; \delta)\)。

随机化干预会产生一个反事实随机变量 \(Y_{A_{\delta}} := f_Y(A_{\delta}, W, U_Y)\)，其中反事实结局 \(Y_{A_{\delta}} \sim \mathcal{P}_0^{A_{\delta}}\) 来自把 \(A\) 的自然取值替换为 \(A_{\delta}\)（无论是从 \(g_{A_{\delta}}(A \mid W)\) 抽取，还是通过对 \(d(A, W; \delta)\) 求值）。本章余下部分，我们将聚焦于如下形式的加性 MTP：

\[ d(a, w; \delta) = \begin{cases} a + \delta & \text{if } a + \delta \leq u(w) \\ a & \text{if } a + \delta > u(w), \end{cases} \tag{162.3}\]

其中 \(\delta \in \mathbb{R}\) 规定了在层 \(W = w\) 的语境下，观测到的 \(A = a\) 应被移位的幅度，而 \(l(w)\) 与 \(u(w)\) 分别是层 \(W = w\) 内处理 \(A\) 的最小值与最大值。举例来说，设 \(A\) 表示营养补充剂的（连续取值）剂量（例如维生素药片的数量），并假定 \(A\) 在给定 \(W = w\) 下的分布支撑于区间 \((l(w), u(w))\)。也就是说，在由 \(W = w\) 定义的协变量层内，某个个体服用的药片数最少为 \(l(w)\)，最多为 \(u(w)\)。这样一个随机化干预可以解释为某项诊所政策的结果：鼓励个体比他们依据基线特征 \(W\) 通常会被建议的剂量（\(A\)）多服用 \(\delta\) 片维生素（\(A + \delta\)）。这一类随机化干预由 Dı́az 和 van der Laan (2012) 引入，并在 Haneuse 和 Rotnitzky (2013)、Dı́az 和 van der Laan (2018)、Hejazi 等 (2020) 与 Hejazi (2021) 中得到进一步讨论。按照 Dı́az 和 van der Laan (2012)，只要考虑随机抽取 \(\P_{A_{\delta}}(g_{0, A})(A = a \mid W) = g_{0,A}(a - \delta(W) \mid W)\)，这类干预就可以表示为一般随机化干预。

为了评估我们所施干预的因果效应，我们把所关心的参数取为：在随机修改后的干预分布之下结局的反事实均值。这个目标因果 estimand 是 \(\psi_{0, \delta} \coloneqq \E_{P_0^{A_{\delta}}}\{Y_{A_{\delta}}\}\)，即反事实结局变量 \(Y_{A_{\delta}}\) 的均值。Dı́az 和 van der Laan (2018) 证明了 \(\psi_{0, \delta}\) 可以由 \(O\) 的分布的一个泛函来识别：

\[\begin{align} \psi_{0,\delta} = \int_{\mathcal{W}} \int_{\mathcal{A}} & \E_{P_0} \{Y \mid A = d(a, w), W = w\} \nonumber \\ &q_{0, A}(a \mid W = w) q_{0, W}(w) d\mu(a)d\nu(w). \end{align} \tag{162.4}\]

在某些识别条件之下（我们马上会逐条列出），式 162.4 中的统计参数恰好等于反事实均值 \(\psi_{0, \delta}\)。本书并不关心因果参数的识别问题——即确立那些在一定假设下具有因果解释的观测数据统计泛函——但我们在下面回顾识别反事实均值 \(\psi_{0, \delta}\) 的关键假设。由于前面引入的 SCM 产生的是独立同分布的单元 \(O\)，常见的识别假设——一致性（在 \(A_i = d(a_i, w_i)\) 时有 \(Y^{A_{\delta,i}}_i = Y_i\)，\(i = 1, \ldots, n\)）与无干扰（对 \(i = 1, \ldots, n\) 与 \(j \neq i\)，\(Y^{A_{\delta,i}}_i\) 不依赖于 \(d(a_j, w_j)\)）——都成立。除此之外，我们还需要无未测混杂（观察性研究中随机化假设的类比）与正性。

注记定义（无未测混杂）

对 \(i = 1, \ldots, n\)，有 \(A_i \indep Y^{A_{\delta,i}}_i \mid W_i\)。这是众所周知的随机化假设在观察性研究中的类比。

注记定义（处理正性）

对所有 \(w \in \mathcal{W}\)，若 \(a_i \in \mathcal{A}\) 则 \(d(a_i, w_i) \in \mathcal{A}\)，其中 \(\mathcal{A}\) 表示 \(A \mid W = w_i\)（\(\forall i = 1, \ldots n\)）的支撑集。

估计随机化干预的因果效应

Dı́az 和 van der Laan (2012) 在非参数模型 \(\M\) 中推导出了有效影响函数（EIF）——构造有效估计量的关键量——并发展了该量的经典估计量与有效估计量，包括代入型、逆概率加权、一步法与靶向最大似然（TML）估计量。一步法与 TML 估计量都能对所关心的目标量 \(\psi_{0, \delta}\) 作半参数有效的估计与推断。如 Dı́az 和 van der Laan (2018) 所述，\(\psi_{0, \delta}\) 相对于非参数模型 \(\M\) 的 EIF 为

\[ D(P_0)(x) = H(a, w)({y - \overline{Q}(a, w)}) + \overline{Q}(d(a, w), w) - \Psi(P_0), \tag{162.5}\]

其中辅助协变量 \(H(a,w)\) 可表示为

\[ H(a,w) = \mathbb{I}(a + \delta < u(w)) \frac{g_0(a - \delta \mid w)} {g_0(a \mid w)} + \mathbb{I}(a + \delta \geq u(w)), \tag{162.6}\]

当处理 \(A\) 落在由协变量层 \(W\) 界定的范围之内时（即对 \(A_i \in (u(w) - \delta, u(w))\)），它可以化简为

\[ H(a,w) = \frac{g_0(a - \delta \mid w)}{g_0(a \mid w)} + 1 \tag{162.7}\]

有效影响函数是构造半参数有效估计量的关键要素。接下来我们聚焦于靶向最大似然（TML）估计量，Dı́az 和 van der Laan (2018) 给出了如下配方：

  1. 构造 \(g_0(A, W)\) 的初始估计 \(g_n\) 与 \(\overline{Q}_0(A, W)\) 的初始估计 \(\overline{Q}_n\)，理想情况下使用数据自适应的回归技术。
  2. 对每个观测 \(i\)，计算辅助协变量 \(H(a_i,w_i)\) 的估计 \(H_n(a_i, w_i)\)。
  3. 构造一维 logistic 回归模型 \[ \text{logit}\overline{Q}_{\epsilon, n}(a, w) = \text{logit}\overline{Q}_n(a, w) + \epsilon H_n(a, w),\] 或把 \(H_n\) 作为权重纳入的类似回归模型。估计该回归模型的参数 \(\epsilon\)，得到 \(\epsilon_n\)。该回归模型的结果给出 \(\overline{Q}_n^{\star}\)。
  4. 计算目标参数的 TML 估计量 \(\Psi_n\)，它由初始估计 \(\overline{Q}_{n, \epsilon_n}\) 的更新 \(\overline{Q}_n^{\star}\) 所定义： \[ \psi_n = \Psi(P_n^{\star}) = \frac{1}{n} \sum_{i = 1}^n \overline{Q}_n^{\star}(d(A_i, W_i), W_i). \tag{162.8}\]

正如前面讨论过的，TML 估计量的构造使其具有渐近线性，并且通常是双稳健的。渐近线性意味着估计量 \(\psi_n\) 与目标参数 \(\psi_0\) 之间的渐近差可以用 EIF 表示，即

\[ \sqrt{n}(\psi_n - \psi_0) = \frac{1}{\sqrt{n}}\sum_{i=1}^n D(P_0)(O_i) + o_p(1). \tag{162.9}\]

渐近线性与正则性一起，刻画了这样一类估计量：其渐近方差以 EIF 的渐近方差为下界。这意味着这类估计量是 EIF 估计方程的解（即把 TML 估计量 \(\psi_n\) 代入 EIF 方程会得到接近零的解），而且它们的抽样方差可以用 EIF 的方差以闭式近似。后一点在计算上很方便，因为估计方差并不严格需要重抽样方法（例如自助法）。中心极限定理确立了估计量 \(\psi_n\) 的渐近分布以 \(\psi_0\) 为中心且为高斯分布：

\[ \sqrt{n}(\psi_n - \psi_0) \to \text{Normal}(0, \sigma^2(D(P_0))). \tag{162.10}\]

因此，方差 \(\sigma^2(D(P_0))\) 的估计 \(\sigma_n^2\) 可以按下式计算

\[ \sigma_n^2 = \frac{1}{n} \sum_{i = 1}^{n} D^2(\overline{Q}_n^{\star}, g_n)(O_i), \tag{162.11}\]

从而可以算出覆盖水平为 \((1 - \alpha)\) 的 Wald 型置信区间 \(\psi_n \pm z_{(1 - \alpha/2)} \cdot \sigma_n / \sqrt{n}\)。在某些条件下，基于自助法的重抽样同样可用于计算 \(\sigma_n^2\) (van der Laan 和 Rose 2011)。

挑选稳定的随机化干预

有时，某个特定的移位参数 \(\delta\) 取值可能导致正性违反，并在估计过程中引发下游的不稳定。为遏制这类问题，我们可以依据候选取值对估计量的影响来选择 \(\delta\)。回忆 \(\psi\) 的 TMLE 中辅助协变量的简化表达式为 \(H = \frac{g(a - \delta \mid w)}{g(a \mid w)}\)，其中 \(g(a - \delta \mid w)\) 由所关心的随机化干预定义。我们可以通过考虑界 \(C(\delta) = \frac{g(a - \delta \mid w)}{g(a \mid w)} < M\) 来设计随机化干预，以避免违反正性假设，其中 \(M\) 是 \(C(\delta)\) 的一个（可由用户指定的）上界。注意 \(C(\delta)\) 对应于赋给”反事实处理值为 \(A = a + \delta\)、自然处理值为 \(A = a\)、协变量为 \(W = w\)“那个单元的逆权重。因此 \(C(\delta)\) 可以视为某个观测对估计量 \(\psi_n\) 影响力的一种度量。通过限制 \(C(\delta)\)（无论是通过选择 \(M\) 还是选择 \(\delta\)），我们就能限制估计量的潜在不稳定性。我们可以定义一个新的移位函数 \(\delta(A, W)\) 来把这一流程形式化：

\[ \delta(a, w) = \begin{cases} \delta, & \delta_{\text{min}}(a,w) \leq \delta \leq \delta_{\text{max}}(a,w) \\ \delta_{\text{max}}(a,w), & \delta \geq \delta_{\text{max}}(a,w) \\ \delta_{\text{min}}(a,w), & \delta \leq \delta_{\text{min}}(a,w) \\ \end{cases}, \tag{162.12}\]

其中 \[\delta_{\text{max}}(a, w) = \text{argmax}_{\left\{\delta \geq 0, \frac{g(a - \delta \mid w)}{g(a \mid w)} \leq M \right\}} \frac{g(a - \delta \mid w)}{g(a \mid w)}\] 且 \[\delta_{\text{min}}(a, w) = \text{argmin}_{\left\{\delta \leq 0, \frac{g(a - \delta \mid w)}{g(a \mid w)} \leq M \right\}} \frac{g(a - \delta \mid w)}{g(a \mid w)}.\]

上式给出了在单个观测 \((a_i, w_i)\) 层面实施移位的策略，从而让所有观测都能被移位到合适的取值，无论是 \(\delta_{\text{min}}\)、\(\delta\) 还是 \(\delta_{\text{max}}\)。tmle3shift 包实现了 shift_additive_bounded 与 shift_additive_bounded_inv 两个函数，它们定义了该策略的一个变体：

\[ \delta(a, w) = \begin{cases} \delta, & C(\delta) \leq M \\ 0, \text{otherwise} \\ \end{cases}, \tag{162.13}\]

它对应这样一种干预：当干预后密度 \(g(a - \delta \mid w)\) 与自然处理密度 \(g(a \mid w)\) 之比 \(C(\delta)\) 不超过界 \(M\) 时，把处理的自然取值 \(A = a\) 移位 \(\delta\)。当 \(C(\delta)\) 超过界 \(M\) 时，该随机化干预就豁免这个单元不作处理修改，让它保持自然处理取值 \(A = a\)。

用边际结构模型作估计与推断

事先选定移位参数 \(\delta\) 的取值可能有难度。一个办法是指定一网格移位 \(\delta\)，用它来定义一组相关的随机化干预 (Hejazi 等 2020)。当我们考虑在若干个 \(\delta\) 取值下估计反事实均值 \(\psi_n\) 时，可以通过工作边际结构模型（MSM）为这些估计量建立一个概括性的汇总度量。用工作 MSM 汇总这些估计 \(\psi_n\)，使我们能够对沿 \(\delta\) 网格所呈现的趋势作推断，而这可以通过对工作 MSM 斜率参数 \(\beta_0\) 作一个简单假设检验来评估。考虑一个 \(\delta\) 的网格 \(\{\delta_1, \ldots, \delta_k\}\)，对应反事实均值 \(\{\psi_{\delta_1}, \ldots, \psi_{\delta_k}\}\)。接着，记 \(\psi(\delta) = (\psi_{\delta}: \delta)\) 为由 \(\delta\) 定义的网格上的反事实均值网格，并记 \(\psi_n(\delta)\) 为 \(\psi(\delta)\) 的 TML 估计量。把 \(\psi_n\) 随 \(\delta\) 变化的情况汇总起来的 MSM 可以表示为 \(m_{\beta}(\psi_{\delta}) = \beta_0 + \beta_1 \delta\)。这个简单的工作模型用参数 \((\beta_0, \beta_1)\) 概括了 \(\psi_{\delta}\) 的变化，其中后者是把反事实均值投影到这个简单双参数工作模型上所得直线的斜率。

MSM \(m_{\beta}(\delta)\) 的更一般表达式是 \(\beta_0 = \text{argmin}_{\beta} \sum_{\delta}(\psi_{\delta}(P_0) - m_{\beta}(\delta))^2 h(\delta)\)，即如下估计方程的解： \[u(\beta, (\psi_{\delta}: \delta)) = \sum_{\delta}h(\delta) \left(\psi_{\delta}(P_0) - m_{\beta}(\delta) \right) \frac{d}{d\beta} m_{\beta}(\delta) = 0.\]

现在设 \(\psi = (\psi(\delta): \delta)\) 是 d 维的。我们可以用各个反事实均值的 EIF 来表示 MSM 参数 \(\beta_0\) 的 EIF：

\[\begin{align} D_{\beta}(O) = &\left(\sum_{\delta} h(\delta) \frac{d}{d\beta} m_{\beta}(\delta) \frac{d}{d\beta} m_{\beta}(\delta)^t \right)^{-1} \\ \nonumber &\sum_{\delta} h(\delta) \frac{d}{d\beta} m_{\beta}(\delta) D_{\psi_{\delta}}(O). \end{align} \tag{162.14}\]

在 式 162.14 中，第一个成分的维度是 \(d \times d\)，第二个是 \(d \times 1\)。上式中我们假定工作 MSM 是线性的；不过对基于 GLM 的工作 MSM，可以套用类似的流程。

上面我们直接应用 delta 方法得到了 \(\beta\) 的 EIF。对这个工作 MSM 参数的推断，可由其 EIF \(D_{\beta}\) 的求值得到，而后者又是用各个相应估计 \(\psi_n(\delta)\) 的 EIF 表示的。\(\beta_n\) 的极限分布可表示为 \[\sqrt{n}(\beta_n - \beta_0) \to N(0, \Sigma),\] 其中 \(\Sigma\) 是 \(D_{\beta}(O)\) 的经验协方差矩阵。有了它，我们不仅能估计反事实均值沿 \(\delta\) 网格的趋势，还能评估斜率估计是否具有统计显著性——通过形如 \((H_0: \beta_0 = 0; H_1: \beta_0 \neq 0)\) 的假设检验以及等价的 Wald 型置信区间。注意，MSM 参数 \(\beta_0\) 的估计量 \(\beta_n\) 由于是由各个 TML 估计量构造而来，因而是渐近线性的（事实上它本身就是一个 TML 估计量）。

刚才讨论的策略，是先求出网格 \(\{\delta_1, \ldots, \delta_k\}\) 中反事实均值 \(\psi_{n,\delta}\) 的 TML 估计，再据此构造工作 MSM 斜率 \(\beta_0\) 的估计 \(\beta_n\)；不过这未必是最佳策略，在考虑小样本下估计稳定性时尤其如此。在样本较小时，或许更稳妥的做法是直接针对参数 \(\beta_0\) 作 TML 估计，而不是对若干个各自独立靶向的 TML 估计施用 delta 方法来构造它。

为此，考虑一个针对 \(\beta_0\)（工作 MSM \(m_{\beta}\) 的参数）的 TML 估计量，它采用形如 \(\overline{Q}_{n, \epsilon}(A,W) = \overline{Q}_n(A,W) + \epsilon (H_{\beta_0}(g), H_{\beta_1}(g))\) 的靶向更新步骤（对所有 \(\delta\)），其中 \(H_{\beta_0}(g)\) 是 \(\beta_0\)（截距）的辅助协变量，\(H_{\beta}(g)\) 是 \(\beta_1\)（斜率）的辅助协变量。注意这些辅助协变量的形式取决于 EIF \(D_{\beta}\)。这样的 TML 估计量避免了直接估计网格中每一个 \(\psi_{\delta}\)，而是巧妙地把它们的辅助协变量拼接成适用于 \(\beta_0\) 与 \(\beta_1\) 的形式。要构造一个直接针对工作 MSM 参数的靶向最大似然估计量，我们可以使用 tmle_vimshift_msm Spec（而不是 tmle_vimshift_delta Spec）。

  max_shifted_ratio = 2
)

# fit the TML estimator and examine the results
tmle_msm_fit <- tmle3(tmle_msm_spec, data, node_list, learner_list)
