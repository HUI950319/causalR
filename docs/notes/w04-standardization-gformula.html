第 13 章 · 把模型挪到结局那一侧

Standardization and the parametric g-formula · 标准化与参数化 g-公式

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 13 章，书页 169–180。本章是读书笔记，非原书译文。

配套代码：R · Stata —— 来自 cibookex-r（Tom Palmer，GPL-3；R 代码原作者 Joy Shi 与 Sean McGrath）。

本章和上一章是同一个问题、同一份数据、同一组识别条件， 只有一件事变了：模型建在哪一侧。

在实践中，研究者常常要在 IP 加权与标准化之间做选择，作为从观察性数据得到效应估计的分析路径。 两种方法基于相同的识别条件，但基于不同的建模假设。

— What If, §13 章首, p.169

这句话是本章的全部：识别条件不变，所以能不能做因果推断的答案不变； 建模假设变了，所以做出来的数会不一样——而这个差别本身， 在 §13.4 里被翻译成了一条可以写进脚本的诊断。

全章地图（笔记作者绘制，原书无此图）。灰框是上一章走过的路，蓝框是本章。 两条路从同一个方框分出去，又在同一个方框汇合——这正是本章想让人看见的结构： 识别条件是共用的，分歧只发生在「模型建在哪一侧」， 而分歧的大小在 §13.4 被反过来当成了诊断工具。 最下面那个虚线框是 §13.5，它不属于任何一条技术路线， 却是全书第一部分的结论在真实数据上的落地。

13.1 用标准化替代 IP 加权：同样的识别条件，不同的建模假设

估计对象和上一章完全一样，只是这里把删失显式写进了记号：

我们把 \(E[Y^{a,c=0}]\) 定义为：如果所有人都接受了处理水平 \(a\)、并且没有任何人被删失， 本应观察到的平均体重增加。戒烟的平均因果效应可以表示为差 \(E[Y^{a=1,c=0}] - E[Y^{a=0,c=0}]\)。

— What If, §13.1, p.169（复述）

数据仍是 NHEFS 中 1629 名 25–74 岁的吸烟者，其中 1566 人在随访访视测到了体重， 因而未被删失（\(C=0\)）。\(L\) 仍是那 9 个基线变量： 性别、年龄、种族、教育（5 类）、吸烟强度、吸烟年数、 日常体力活动（3 类）、业余锻炼（3 类）、体重。

观察到的关联差 \(E[Y\mid A=1, C=0] - E[Y\mid A=0, C=0] = 2.5\) （Table 12.1 那张基线特征表说明了为什么它不能当因果差看）。

边注里那句限定：\(L\) 必须不受 \(A\) 影响

和上一章一样，我们将假定为调整 \(C\) 所需的 \(L\) 的分量不受 \(A\) 影响。 否则，我们就需要用第三部分描述的那种更一般的方法。

— What If, §13.1 边注, p.169

这条边注在第二部分里会反复出现。它是「基线协变量」这四个字的真正含义： 不是「在基线测的」，而是「不可能被处理改变的」。 一旦 \(L\) 里混进了被 \(A\) 影响的变量，本章这一整套（以及上一章那一整套）都失效， 要等到第三部分的 g-方法。

两条路的分工，书写得很干净：

  • IP 加权造一个伪人群，其中 \(L\) 的分布在处理组与未处理组相同； 它需要估计处理与删失的联合分布 \(\Pr[A=a, C=0\mid L]\)，把它放在权重的分母上。
  • 标准化在可交换性与正性之下，用未删失的处理组中的标准化均值 一致地估计 \(E[Y^{a=1,c=0}]\)；未删失的未处理组同理。

标准化均值的算法是两步：先算每一层里的条件均值，再按层的大小加权平均。

更紧凑地说，接受了处理水平 \(a\) 的未删失者中的标准化均值是

\[\sum_l E[Y\mid A=a,\ C=0,\ L=l]\ \Pr[L=l]\]

当（像我们的例子里那样）\(L\) 中有些变量是连续的， 就需要把 \(\Pr[L=l]\) 换成概率密度函数 \(f_L[l]\)，上面的求和变成积分。

— What If, §13.1, p.170（复述）

注意这个式子里有两类待估的量：条件均值 \(E[Y\mid A=a, C=0, L=l]\) 和分布 \(\Pr[L=l]\)。 §13.2 处理第一类，§13.3 处理第二类——而 §13.3 的答案是「不用估」。

两条边注顺带补了两个「原来如此」：

Technical Point 2.3 证明了：在条件可交换性、正性与一致性之下， 处理组中的标准化均值等于「如果所有人都被处理」的均值。 推广到删失是平凡的：把证明与定义里的 \(A=a\) 换成 \((A=a, C=0)\) 即可。

— What If, §13.1 边注, p.170

处理组中的平均因果效应也可以用标准化估计（Technical Point 4.1）： 只需要把右边式子里的 \(\Pr[L=l]\) 换成 \(\Pr[L=l\mid A=1]\)。

— What If, §13.1 边注, p.170

换一个加权分布就换一个目标人群——这正是第 4 章 §4.6 讲的 ATE / ATT 之分， 在这里落成了式子里的一个下标。路线图 W3 那一周要区分的 ATE / ATT / ATO， 区别全在这一个位置。

Fine Point 13.1：结构性正性下，两条路的表现完全不同

这一条是本章最实用的一段，也是 IP 加权与标准化第一次真正分岔的地方。

结构性正性缺失使得在使用 IP 加权时，整个人群的平均因果效应无法识别。 正性对标准化同样是必需的，因为当 \(\Pr[A=a\mid L=l] = 0\) 而 \(\Pr[L=l] \neq 0\) 时，条件均值结局 \(E[Y\mid A=a, L=l]\) 是没有定义的。

— What If, Fine Point 13.1, p.170

提取陷阱：这里的 \(\neq\) 被 pdftotext 吞成了 \(=\)，语义正好反掉

文本层读出来是「\(\Pr[A = a\mid L = l] = 0\) and \(\Pr[L = l] = 0\)」， 读起来完全通顺，但意思是错的：如果那一层根本不存在（\(\Pr[L=l]=0\)）， 条件均值没有定义是无关紧要的，因为它在求和里的权重也是 0。

真正的麻烦恰恰是那一层存在、却没有人接受该处理： \(\Pr[L=l] \neq 0\) 而 \(\Pr[A=a\mid L=l] = 0\)。已按 170 dpi 整页渲染 PDF 第 179 页确认原文印的是 \(\neq\)。

这是本仓库笔记里第二次踩中同一个坑（第 4 章有四处）。 规律很稳定：≠ 在这本书里是零宽叠加字形，文本层只会吐出 =。 凡是读到「某概率 = 0 且另一概率 = 0」这种并列，一律整页渲染复核。

而实际影响的差别，书讲得非常直白：

但偏离正性在依赖参数模型的 IP 加权估计与标准化估计之间，实际影响可能差别极大。 使用标准化时，只要你愿意依赖参数外推，就可以无视正性的缺失—— 也就是说，可以拟合一个 \(E[Y\mid A, L]\) 的模型，让它在有结构零的层上平滑地铺过去。 这种平滑会给估计引入偏倚，因此名义上的 95% 置信区间覆盖真值的频率会低于 95%。

— What If, Fine Point 13.1, p.170

接着是一句值得单独抄下来的话：

还要注意，在有结构性正性问题的场景里，建模的目的是不同的： 我们建模不是因为数据不够，而是因为我们想估计一个即使有无穷多数据也无法识别的量 （因为结构性非正性）。这是一个重要的区分。

— What If, Fine Point 13.1, p.170

第 11 章说「建模是为了借邻居的信息，因为每一层的人太少」——那是统计问题， 数据变多就会消失。这里说的是识别问题，数据再多也不会消失。 同一个 glm() 调用，两种完全不同的性质。

标准误更小，不等于更好

一般来说，在正性被违反或接近被违反时，处理效应的标准误在标准化下会比在 IP 加权下更小。 这并不必然意味着标准化优于 IP 加权；偏倚上的差别可能远远盖过标准误上的差别。

— What If, Fine Point 13.1, p.170

IP 加权在正性接近违反时会给你一个警报：极端权重、宽得离谱的区间。 标准化则会安静地给你一个好看的数——模型把空格子平滑地填上了， 而你从输出里看不出那里原本没有人。

所以「标准化的区间更窄」这件事，在正性有问题的时候，是症状而不是优点。 上一章自检①「看权重的范围」在这里没有对应物——这正是两个都做的理由之一。

13.2 用模型估计均值结局：只欠一个 E[Y|A, C=0, L]

理想情况是非参数地估每一层的 \(E[Y\mid A=1, C=0, L=l]\)， 就像第 2 章 §2.3 在 Table 2.2 上做的那样——那里全部信息都能从一张 20 行的表里数出来。

但在我们当前这个例子里，非参数估计 \(E[Y\mid A=1, C=0, L=l]\) 是不可能的： 高维数据、许多混杂因子、有些还有多个水平。 只有 403 个被处理的个体散布在数百万个层里时， 我们得不到有意义的层特异估计。只能求助于模型。

— What If, §13.2, p.171（复述）

和上一章 §12.2 的论证一字不差，只是主语从 \(\Pr[A=1\mid L]\) 换成了 \(E[Y\mid A, C=0, L]\)。 维数灾难对两条路是同样致命的——它不是选择哪条路的理由。

模型是什么样的

为了得到 \(E[Y\mid A=a, C=0, L=l]\) 的参数估计，我们对平均体重增加拟合了一个线性回归模型， 把处理 \(A\) 与 \(L\) 中全部 9 个混杂因子作为协变量。 对（准）连续协变量——年龄、体重、吸烟强度与吸烟年数——用了线性项与二次项。 我们纳入了戒烟 \(A\) 与吸烟强度之间的一个乘积项。

— What If, §13.2, p.171（复述）

书紧接着把这两条设定翻译成了限制：

13.3 把均值标准化到混杂因子的分布：复制三份数据集

标准化均值是条件均值的加权平均，权重是 \(\Pr[L=l]\)。 原则上这些比例可以非参数地从数据里算出来——这正是第 2 章 §2.3 做的事。 但对高维的 \(L\)，这样做非常繁琐。

书接下来的一句是本节的转折：

幸运的是，我们不需要估计 \(\Pr[L=l]\)。 我们只需要对研究中每个个体 \(i\) 的 \(l\) 值估计 \(E[Y\mid A=a, C=0, L=l]\)， 然后计算平均 \(\frac{1}{n}\sum_{i=1}^{n} \widehat{E}[Y\mid A=a, C=0, L_i]\)。 这是因为加权均值 \(\sum_l E[Y\mid A=a,C=0,L=l]\Pr[L=l]\) 也可以写成双重期望 \(E\big[E[Y\mid A=a, C=0, L]\big]\)。

— What If, §13.3, p.172（复述）

一句话：样本本身就是 \(L\) 的一个无偏样本，所以对每个人算一遍再平均， 等价于按 \(\Pr[L=l]\) 加权。这一步把「估计一个数百万维的分布」 换成了「做一次 mean()」，而且换得不付任何参数代价。

四步法，先在 20 个人身上跑一遍

方法有 4 步：扩展数据集、结局建模、预测、按平均做标准化。 书先把它用在第 2 章 Table 2.2 的 20 个人上——那里没有删失、\(L\) 只有两个水平、\(Y\) 是二值的。

步 做什么 在 Table 2.2 上的样子
① 扩展 把数据复制三份，得到 3 块 20 行 → 60 行，每块 20 人

最容易误解的一步：为什么复制出来的两块不会「污染」拟合

注意只有数据集第一块（真实数据）里的行会对模型参数的估计有贡献， 因为第二、三块所有行的结局都是缺失的。

— What If, §13.3, p.172

把 \(Y\) 设成缺失不是装饰，它是整个技巧成立的机关。 glm() 默认丢弃结局缺失的行，于是第二、三块只以「待预测的新数据」的身份存在； 把它们和真实数据放进同一个 data.frame，纯粹是为了省掉手工构造 newdata 的麻烦， 顺便保证因子水平、样条基、缺失处理三者在拟合与预测时完全一致。

换句话说：四步法在统计上就是 predict(fit, newdata = 把 A 全设成 a 的那份数据) 再取均值。 书之所以写成「三块」，是因为这样在 SAS / Stata 里也能一次跑完。 在 R 里两种写法都可以，但三块写法有一个实际好处： bootstrap 时整个流程是一个函数，不必在重抽样循环里同步维护两份数据。

Technical Point 13.1：bootstrap 的做法，书到这里才给

第 10 章讲了随机变异的概念，第 12 章用了稳健方差， 而「怎么算这个区间」的具体做法，书直到这里才写出来：

从 1629 人的研究人群中有放回地抽取 1629 人， 于是有些人可能出现多次、有些人可能一次都不出现。 这个规模为 1629 的新样本称为一个「bootstrap 样本」。 在它上面用同样的方法计算感兴趣的效应……重复大量次（比如 1000 次）。 结果是：这 1000 个效应估计的标准差，一致地估计了研究人群中效应估计的标准误。 95% 置信区间再用通常的正态近似算：\(\pm 1.96\) 倍标准误估计。

— What If, Technical Point 13.1, p.174（复述）

这一条顺手回答了上一章留下的问题：稳健方差到底保守多少

bootstrap 是一个适用于大样本的通用方法：一般地，当估计量的极限分布是正态时， 以 bootstrap 估计的标准误为中心构造的 95% Wald 区间在大样本下是校准的。 因此，边际结构模型的 IP 加权估计的 95% Wald 区间， 若标准误由 bootstrap 估计则是校准的； 若由（稳健方差估计量的平方根）估计，则常常是保守且更宽的。

— What If, Technical Point 13.1, p.174（复述）

上一章说稳健方差「保守」，但没有给出参照物。这里给了： bootstrap 是那个校准的基准，稳健方差是它的保守替代。 所以第 12 章那个 \((2.4, 4.5)\) 与本章这个 \((2.6, 4.5)\) 的宽度差别里， 有一部分根本不是方法之差，而是方差估计法之差。

书还给了两条实操：

  • 200–500 次很常见（bootstrap 对很大的数据集计算量太重）。 在本例中减到这个次数「会给出几乎相同的区间，但并不总是如此」。
  • 更好的出路是 “bag of little bootstraps”（Kleiner et al. 2014）。

落到 R 上：boot::boot() 最直接，但整个四步法必须整体进入重抽样循环—— 包括拟合模型这一步。只对预测值重抽样是错的，那样算出来的区间会太窄。

13.4 IP 加权还是标准化？：这个选择题的答案是「都做」

在我们的戒烟例子里，两者给出了几乎完全相同的效应估计。 事实上 Technical Point 2.3 证明了标准化均值等于 IP 加权均值。

那我们为什么还要在本章估这个标准化均值？ 原来，IP 加权均值与标准化均值只有在不使用模型估计它们时才恰好相等。 否则两者预期会有差别。

— What If, §13.4, p.173（复述）

差别的来源是被建模的量不同：

建的是什么模型 上一章 / 本章怎么建的
IP 加权 \(\Pr[A=a,\ C=0\mid L]\) 两个 logistic 回归：\(\Pr[A=a\mid L]\) 与 \(\Pr[C=0\mid A=a, L]\)
标准化 \(E[Y\mid A=a,\ C=0,\ L=l]\) 一个线性回归
两者都没建的 \(L\) 的分布 IP 加权不需要；标准化用经验分布（非参数）

实践中，所有模型都不可避免地有某种程度的设定错误，而模型设定错误会引入偏倚。 但处理模型的设定错误（IP 加权）与结局模型的设定错误（标准化）， 一般不会导致相同大小与相同方向的偏倚。

因此——IP 加权估计与标准化估计之间的巨大差别，会提醒我们至少其中一个估计存在严重的模型设定错误。 小的差别不能保证不存在严重的设定错误，但是令人安心的—— 虽然逻辑上可能，但两个都严重设错、却产生大小与方向都相近的偏倚，是不太可能的。

— What If, §13.4, p.174（复述）

这是全章唯一一条「免费」的模型诊断

它的成本只是把两条流水线都跑一遍，而它检出的是其它诊断查不到的东西： 平衡诊断只看处理模型，残差图只看结局模型， 而「两个数差多少」同时约束了两者。

但要注意它的不对称性： 「差得远」是有信息的（至少一个错了）； 「差得近」是弱信息的（书用的词是 reassuring，不是 guarantee）。 不要把两条估计吻合写成「模型设定正确」。

在本例中：IP 加权 3.5、标准化 3.5，四舍五入到一位小数完全一致。 书的原话是「无论我们拟合的是处理 \(A\) 的模型（IP 加权） 还是结局 \(Y\) 的模型（标准化），估计出的戒烟导致的体重增加都是 3.5 公斤」。

g-公式这个名字的来历

边注：为什么这本书只说 g-formula，不说 g-computation

Robins (1986) 描述了标准化向时变处理与时变混杂因子的推广， 并把它命名为 g-computation algorithm formula。 因为这个名字太长，有些作者缩写成 g-formula，另一些缩写成 g-computation。 尽管两者是同义词，本书只使用前一个术语，因为后者经常与 g-estimation 混淆——那是第 14 章描述的另一种方法。

— What If, §13.4 边注, p.175

这条边注值得记牢：中文文献里「g-computation」「g-公式」「g-估计」三个词经常混用， 而 g-estimation 是完全不同的东西（下一章），不是 g-computation 的别名。 本仓库笔记从此统一沿用原书的用法：标准化 = g-公式的插入式估计量； g-估计 = 第 14 章结构嵌套模型那一套。

于是有了本章标题里的两个词：

我们说标准化是一个插入式 g-公式估计量（plug-in g-formula estimator）， 因为它只是把 g-公式中的条件均值结局换成了它的估计值。 当这些估计值像本章这样来自参数模型时，我们把这个方法称为参数化 g-公式。

— What If, §13.4, p.175（复述）

更一般地，（针对概率密度函数的）参数化 g-公式需要估计 \(A\) 与 \(L\) 各水平下结局的条件分布， 才能计算其标准化值。在没有时变混杂因子时（见第三部分）， 参数化 g-公式不需要对混杂因子的分布做参数建模。

— What If, §13.4, p.175（复述）

本章只要平均因果效应，所以只参数化地估了条件均值； 如果要的是整个反事实分布（比如分位数、风险比的非崩溃版本），就得估条件分布。 这个区别在第 17 章（生存分析）会变得重要。

答案：不必选

常常没有必要在 IP 加权与参数化 g-公式之间做选择。当两种方法都能用来估计某个因果效应时，就两种都用。 另外，只要可能，就使用把处理模型与结局模型结合进同一个估计量的双稳健方法。 在给定 \(L\) 的可交换性与正性之下，双稳健估计量在处理模型与结局模型中 只要有一个是正确的（而且不需要知道是哪一个），就能一致地估计平均因果效应。

— What If, §13.4, p.175（复述）

最后一句顺带回答了「效应修饰怎么办」：

注意我们用参数化 g-公式估计的是整个目标人群中的平均因果效应。 如果我们感兴趣的是某个子集中的平均因果效应，可以把计算限制在那个子集上。 例如，若关心按性别的效应修饰，就分别在男性和女性中估计标准化均值。

— What If, §13.4, p.175（复述）

Fine Point 13.2：双稳健插入式估计量

有没有一种方法，只要求处理 \(A\) 的模型或结局 \(Y\) 的模型之一是正确的？ 这正是双稳健估计所做的事。……双稳健估计量给了我们两次做对的机会。

— What If, Fine Point 13.2, p.176（复述）

Bang & Robins (2005) 的那一个（无删失场景）只有三步：

  1. 按上一章的做法估出 IP 权重 \(W^A = 1/f(A\mid L)\)；
  2. 拟合一个带典则连接的广义线性模型 \(E[Y\mid A, L, R]\)， 其中多加一个协变量 \(R\)：\(A=1\) 时 \(R = W^A\)，\(A=0\) 时 \(R = -W^A\)；
  3. 用这个结局模型，把所有人的 \(A\) 分别设成 1 和 0 去预测，取两个标准化均值，相减。

就是在本章的结局模型里塞进一个由上一章的权重构造出来的协变量。 两条流水线的接口只有 \(R\) 这一列——这是我见过的对「双稳健」最短的操作性解释。

Technical Point 13.2–13.3：AIPW、二阶偏倚，以及 TMLE 的来历

记 \(b(L) = E[Y\mid A=1, L]\)、\(\pi(L) = \Pr[A=1\mid L]\)，则 \(E[Y^{a=1}]\) 有两种写法： \(E[b(L)]\)（插入式）与 \(E\!\left[\frac{AY}{\pi(L)}\right]\)（Horvitz-Thompson）。 两者各自的失效条件是对称的：

估计量 形式 偏倚大，当……
插入式 g-公式 \(\frac{1}{n}\sum_i \hat b(L_i)\) \(\hat b(L)\) 离 \(b(L)\) 远
Horvitz-Thompson IP 加权 \(\frac{1}{n}\sum_i \frac{A_i Y_i}{\hat\pi(L_i)}\) \(\hat\pi(L)\) 离 \(\pi(L)\) 远
增广 IP 加权（AIPW） \(\frac{1}{n}\sum_i\left[\hat b(L_i) + \frac{A_i}{\hat\pi(L_i)}\big(Y_i - \hat b(L_i)\big)\right]\) 两个都远

AIPW 那个式子可以整理成 \(\frac{1}{n}\sum_i\left[\frac{A_iY_i}{\hat\pi(L_i)} - \left(\frac{A_i}{\hat\pi(L_i)} - 1\right)\hat b(L_i)\right]\)—— 「用结局模型去校正 Horvitz-Thompson 估计量」， 这也是 augmented（增广）这个名字的来历。

而真正指向第 18 章的是下面这条性质：

所有双稳健估计量都有这样一条性质：偏倚取决于 \(\frac{1}{\pi(l)} - \frac{1}{\hat\pi(l)}\) 这个误差与 \(b(l) - \hat b(l)\) 那个误差的乘积。 正如我们将在第 18 章讨论的，这条被称为二阶偏倚（second-order bias）的性质， 使我们可以用机器学习估计量（而不是标准参数模型）来估 \(\pi(l)\) 与 \(b(l)\)， 从而构造出偏倚可能很小的双稳健估计量。

— What If, Technical Point 13.2, p.178（复述）

这是一条乘积而不是求和：两个误差各自都不必很小，只要乘起来小就够。 机器学习估计量通常收敛得比 \(\sqrt{n}\) 慢，单独用任何一个都不行； 但两个 \(n^{-1/4}\) 量级的误差相乘就是 \(n^{-1/2}\)—— 这正是第 18 章 §18.4 「双稳健机器学习估计量」的全部立足点。

Technical Point 13.3 再把 AIPW 与 Fine Point 13.2 的插入式版本对上： 要让插入式估计量同时是双稳健的，需要结局模型里那个多出来的项恰好使某个得分方程在每个样本中为零； 用 IRLS 拟合带「\(\frac{I(A=1) - I(A=0)}{f(A\mid L)}\)」这一项的模型即可做到。

由此得到的插入式估计量正是 Fine Point 13.2 里的那个估计量。 这个估计量是一个靶向最小损失估计量（TMLE），也称靶向最大似然估计量， 而 \(\frac{I(A=1)-I(A=0)}{f(A\mid L)} = \frac{A}{\pi(L)} - \frac{1-A}{1-\pi(L)}\) 就是 van der Laan & Rubin (2006) 后来引入的术语里的「聪明协变量」（clever covariate）。

— What If, Technical Point 13.3, p.179（复述）

书还提了两个聪明协变量的版本（把那一项拆成 \(\frac{A}{\pi(L)}\) 与 \(\frac{1-A}{1-\pi(L)}\) 两项、各估一个系数）： 它的好处是两个标准化均值各自也是双稳健的，而不只是它们的差。

于是本章末尾这三条边栏其实是一条完整的线： Fine Point 13.2 给操作，Technical Point 13.2 给形式与二阶偏倚， Technical Point 13.3 说明它就是 TMLE。 路线图 W5「双稳健估计入门」的全部理论前提，书在第 13 章就已经交完了。

唯一真正新的东西是「双稳健」这个提法——两个模型放进同一个估计量， 只要有一个对就行，而且不需要知道是哪一个。 它的三条边栏（Fine Point 13.2、Technical Point 13.2–13.3） 把 AIPW、二阶偏倚与 TMLE 一次交完，直接指向第 18 章与路线图 W5。

自检① 四步法里，第二、三块数据为什么不会影响模型拟合？

因为它们的结局 \(Y\) 被设成了缺失，而回归拟合只用完整观测的行。 把它们放进同一个数据框，纯粹是为了让「拟合」和「预测」共享同一套 因子水平、多项式基与缺失处理，并且让整个流程成为一个函数，方便 bootstrap。

验证方法：只用第一块拟合、再对复制块 predict()， 系数与两个标准化均值应当一模一样。对不上就说明缺失值没有被正确丢弃 （例如结局列被填补成了 0）。

常见错误还有一个：把 interv 这类块标记变量放进了模型公式。 一旦放进去，第二、三块就不再只是「新数据」了。

自检② IP 加权与标准化什么时候相等，什么时候不等？

  • 不用模型时恒等：Technical Point 2.3 证明了标准化均值 \(=\) IP 加权均值。 第 2 章那 20 个人的例子里两者都给 0.5，这不是巧合。
  • 一旦任何一侧用了参数模型就不再恒等： 两者建的是不同的量（\(\Pr[A,C\mid L]\) vs \(E[Y\mid A,C,L]\)）， 设定错误的大小与方向一般不同。
  • 本例中两者都是 3.5（四舍五入到一位小数），令人安心； 但书明确说这不是「模型设定正确」的证明。

怎么用这条差别：把它当成一个免费但不对称的诊断—— 差得远是硬信息，差得近是软信息。

再补一句上一章埋下的伏笔：IP 加权把赌注押在处理模型上， 标准化押在结局模型上，双稳健是唯一一个「押两次」的玩法。

自检③ 正性被结构性违反时，标准化能算出一个数——这是好事吗？

不是。 这正是 Fine Point 13.1 那条警告：

  1. IP 加权在这里算不出来（或者给出极端权重、极宽区间），它在报警；
  2. 标准化会照常给你一个漂亮的点估计与一条更窄的区间， 因为参数模型平滑地铺过了那些结构零的层；
  3. 那个数依赖于纯粹的外推，名义 95% 区间的实际覆盖率会低于 95%。

书的判断是：这时「标准误更小」不等于「方法更好」， 因为偏倚的差别可能远远盖过标准误的差别。

实操：先按几个关键混杂因子交叉制表找零格（上一章自检①第 3 条）， 分清结构零与随机零；结构零存在时， 要么把推断限制在正性成立的子人群上，要么明确声明结果依赖外推。

而 §13.5 的答案更一般：我们对估计的认真程度， 只能等同于我们对那五个条件的认真程度。

下一章讲同一个问题的第三条路线：第 14 章「结构嵌套模型的 g-估计」。 它既不是给处理建模、也不是给结局建模，而是给效应本身建模， 并且——按 §13.5 那张敏感性分析表里的那一行—— 它还是本书用来做未测量混杂敏感性分析的工具（Fine Point 14.2）。

代码那一侧，本章对应原书 Program 13.1–13.4。整条流水线用 R 写出来是这样的：

# 1. 扩展：三块数据。第一块原样，第二块全设 A=0，第三块全设 A=1
nhefs$interv <- -1                                  # 第一块：真实数据
b2 <- transform(nhefs, interv = 0, qsmk = 0, wt82_71 = NA)
b3 <- transform(nhefs, interv = 1, qsmk = 1, wt82_71 = NA)
onesample <- rbind(nhefs, b2, b3)                   # 后两块的结局是缺失的

# 2. 建模：只有第一块参与拟合（后两块 wt82_71 = NA 会被丢弃）
#    注意 interv 不进公式；唯一的乘积项是 A × 吸烟强度
fit <- glm(wt82_71 ~ qsmk + sex + race + age + I(age^2) +
             as.factor(education) + smokeintensity + I(smokeintensity^2) +
             smokeyrs + I(smokeyrs^2) + as.factor(exercise) +
             as.factor(active) + wt71 + I(wt71^2) +
             qsmk:smokeintensity,
           data = onesample)
mean(fitted(fit))                    # ← 自检：应等于观测结局的均值，本例 2.6

# 3. 预测 + 4. 各块取平均 = 两个标准化均值
onesample$pred <- predict(fit, onesample)
mean(onesample$pred[onesample$interv == 0])   # 全不戒烟：1.66
mean(onesample$pred[onesample$interv == 1])   # 全戒烟：  5.18

# 区间只能 bootstrap，而且「拟合」这一步必须在重抽样循环内
library(boot)
gcomp <- function(data, idx) {
  d  <- data[idx, ]
  d$interv <- -1
  s  <- rbind(d, transform(d, interv = 0, qsmk = 0, wt82_71 = NA),
                 transform(d, interv = 1, qsmk = 1, wt82_71 = NA))
  f  <- glm(formula(fit), data = s)
  p  <- predict(f, s)
  mean(p[s$interv == 1]) - mean(p[s$interv == 0])
}
boot(nhefs, gcomp, R = 1000)         # 本例 3.5 kg (95% CI 2.6, 4.5)
