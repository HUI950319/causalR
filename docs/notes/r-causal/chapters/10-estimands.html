估计目标、估计量与估计值

在进行因果分析、做出因果推断时，我们需要始终牢记自己感兴趣的因果问题。 因果问题不仅有助于指导我们需要作出的假设，也有助于决定如何回答这个问题。 本章讨论与回答因果问题密切相关的三个概念：估计目标、估计量和估计值。 估计目标是我们感兴趣的目标，估计量是利用数据近似这一估计目标的方法，而估计值是将数据代入估计量后得到的数值。 可以把估计目标想象成我们试图烘焙的一块漂亮蛋糕的精美照片，把估计量想象成食谱，把估计值想象成从烤箱里取出的蛋糕。

到目前为止，我们主要关注平均处理效应，即在整个总体中取平均的感兴趣暴露的效应。 这里的估计目标是所有个体潜在结局之差的期望值：

\[ E[Y(1) - Y(0)] \]

我们使用的估计量取决于所选择的方法。 例如，在 A/B 测试或随机对照试验中，我们的估计量可以是接受暴露 A 者的平均结局减去接受暴露 B 者的平均结局。

\[ \sum_{i=1}^{N}\frac{Y_i\times X_i}{N_{\textrm{A}}} - \frac{Y_i\times (1-X_i)}{N_{\textrm{B}}} \]

其中，\(X\) 是暴露 A 的指示变量（暴露 A 时 \(X = 1\)，暴露 B 时 \(X = 0\)），\(N_A\) 是 A 组总人数，\(N_B\) 是 B 组总人数，且 \(N_A + N_B = N\)。 让我们进一步说明这个例子。 假设我们有两种不同的行动号召设计（通常简称 CTA，即营销活动中的书面指令），想评估它们是否会导致用户购买商品的平均数量不同。 我们可以进行 A/B 测试，随机分配一部分用户查看设计 A 或设计 B。 假设我们有一个名为 ab、包含 100 名参与者的 A/B 测试数据集。 下面是模拟这类数据集的代码。

set.seed(928)
ab <- tibble(
  # generate the exposure, x, from a binomial distribution
  # with the probability exposure A of 0.5
  x = rbinom(100, 1, 0.5),
  # generate the "true" average treatment effect of 1
  # we use rnorm(100) to add the random error term that is normally
  # distributed with a mean of 0 and a standard deviation of 1
  y = x + rnorm(100)
)

这里，暴露是 x，结局是 y。 真正的平均处理效应是 1，这意味着平均而言，看到行动号召 A 会使购买商品的数量增加 1。

ab |>
  summarize(
    n_a = sum(x),
    n_b = sum(1 - x),
    estimate = sum(
      (y * x) / n_a - y * (1 - x) / n_b
    )
  )

ab |>
  group_by(x) |>
  summarize(avg_y = mean(y)) |>
  pivot_wider(
    names_from = x,
    values_from = avg_y,
    names_prefix = "x_"
  ) |>
  summarize(estimate = x_1 - x_0)

因为 \(X\)（即暴露）是随机分配的，所以该估计量会为我们感兴趣的估计目标给出无偏估计值。

不过，无偏是什么意思？ 请注意，虽然“真正的”因果效应是 1，但这个估计值并不精确等于 1；它是 1.149。 为什么会有差异？ 这项 A/B 测试包含的是 100 名参与者的样本，而不是整个总体。 随着样本量增加，估计值会越来越接近真实值。 让我们试试看。 我们再次模拟数据，但把样本量从 100 增加到 100,000：

set.seed(928)
ab <- tibble(
  x = rbinom(100000, 1, 0.5),
  y = x + rnorm(100000)
)

ab |>
  summarize(
    n_a = sum(x),
    n_b = sum(1 - x),
    estimate = sum(
      (y * x) / n_a - y * (1 - x) / n_b
    )
  )
# A tibble: 1 x 3
    n_a   n_b estimate
  <int> <dbl>    <dbl>
1 49918 50082     1.01

请注意，估计值是 1.01，比实际平均处理效应 1 接近得多。

假设 \(X\) 并不是随机分配的。 在这种情况下，我们可以利用暴露前协变量来估计 \(X\) 的条件概率（倾向评分），并将该概率纳入一个权重 \((w_i)\) 中，以估计这一因果效应。 我们可以将无权估计量扩展为使用加权均值，从而估计平均处理效应这一估计目标。 这种逆概率加权有时称为 Hajek 估计量。 虽然本书将重点放在使用回归建立结局模型上，但这个无权估计量的简单扩展说明了如何修改估计量，使其适应不同的估计目标。

\[ \frac{\sum_{i=1}^NY_i\times X_i\times w_i}{\sum_{i=1}^NX_i\times w_i}-\frac{\sum_{i=1}^NY_i\times(1-X_i)\times w_i}{\sum_{i=1}^N(1-X_i)\times w_i} \]

针对特定目标估计处理效应

根据研究目标或因果问题，我们可能希望估计不同的估计目标。 这里我们将概述最常见的因果估计目标、它们的目标人群、可帮助回答的因果问题，以及用于估计它们的方法 (Greifer 和 Stuart 2021)。

平均处理效应

一种常见的估计目标是平均处理效应（ATE）。 目标人群是整个样本或所关注的总体。 这里的估计目标是所有个体潜在结局之差的期望值：

\[ E[Y(1) - Y(0)] \]

一个研究问题示例是“是否应将某项政策应用于所有符合条件的患者？” (Greifer 和 Stuart 2021)

大多数随机对照试验都以 ATE 作为目标估计目标。 我们之前应用于 ab 的估计量在这里也适用。 我们还见过另外两类可使用的估计量：匹配和加权。 在非随机设置中，可以使用完全匹配来估计 ATE。 暴露组中的每个观测值至少与对照组中的一个观测值匹配（反之亦然），且不放回。 我们将在 理解匹配中的估计目标) 中进一步讨论使用匹配的估计目标。 或者，下面的逆概率权重可以让你使用倾向评分加权来估计 ATE。

\[ w_{ATE} = \frac{X}{p} + \frac{(1 - X)}{1 - p} \]

换句话说，对于暴露组，权重是倾向评分的倒数；对于对照组，权重是 1 减去倾向评分的倒数。 直观地说，该权重相当于对个体实际所属暴露组的逆概率进行加权。 注意，无论是匹配还是加权，估计量还包括拟合结局模型，正如我们将在 ?sec-outcome-model 中所做的那样。 也就是说，基于倾向评分进行匹配或加权只是这些 ATE 估计量的第一步。 最终生成 ATE 估计值的是将匹配后或加权后的数据放入结局模型中。

让我们使用 Touring Plans 数据深入研究这个因果估计目标。 回顾一下，在 使用倾向评分 中，我们考察了早晨是否有“Extra Magic Hours”与当天上午 9 点至 10 点之间七个小矮人矿车的平均等待时间之间的关系。 现在重新构建数据集 seven_dwarfs，并拟合此前指定的同一个倾向评分模型。

library(broom)
library(touringplans)

seven_dwarfs <- seven_dwarfs_train_2018 |>
  filter(wait_hour == 9) |>
  mutate(
    park_extra_magic_morning = factor(
      park_extra_magic_morning,

seven_dwarfs_with_ps <- glm(

    park_close +
    park_temperature_high,

  augment(type.predict = "response", data = seven_dwarfs)

图 64.2 中的许多权重接近 1（ATE 权重的最小可能值），并有一条长尾延伸至最大的权重（约为 24）。 这种分布凸显了 ATE 权重的一个潜在问题。 它们的取值范围是从 1 到无穷大；如果小样本中的权重过大，可能会导致估计值产生偏倚（称为有限样本偏倚）。 我们在 倾向评分 中看到，这些权重会使估计值的方差不稳定，而稳定化可以改善这一点。 然而，ATE 权重还会受到有限样本偏倚影响，而稳定化无法解决这个问题。

警告有限样本偏倚

我们知道，不考虑混杂因子会使因果估计值产生偏倚，但即使考虑了所有混杂因子，在有限样本中仍可能得到有偏的估计值。 统计学中许多我们常说的性质都依赖于大样本，但“多大”往往并不明确。 让我们看一个简单的模拟。 这里有一个暴露 \(X\)、一个结局 \(Y\) 和一个混杂因子 \(Z\)。 我们将模拟 \(Y\)（它仅依赖于 \(Z\)，因此实际处理效应为 0）以及 \(X\)（它同样依赖于 \(Z\)）。

set.seed(928)
n <- 100

    0.5 + z + rnorm(n) > 0 ~ 1,

利用无界权重（即理论上可以大到无穷）的估计目标更容易受到有限样本偏倚影响。 陷入有限样本偏倚的可能性取决于：
(1) 你选择的估计目标（即权重是否有界？）
(2) 暴露组和未暴露组中协变量的分布（即重叠是否良好？ 潜在的正值性违反发生在重叠较差的区域，此时权重可能变得过大）
(3) 样本量。

逆概率加权创建了一个伪总体，其中观测值（希望）在混杂因子上达到平衡。 这个伪总体不同于原始样本总体，因此尝试理解它是有帮助的（既有助于诊断，也有助于交流）。 {gtsummary} 包允许创建加权表格，这可以帮助我们建立对权重所创建伪总体的直觉。 首先，我们必须加载 {survey} 包并创建一个调查设计对象。 {survey} 包支持使用权重计算统计量和拟合模型。 从历史上看，许多研究者已经应用了将权重纳入调查分析的技术。 尽管我们并不是在做调查分析，但同样的技术对倾向评分权重很有帮助。

回顾一下，我们的估计目标是：

\[ E[Y(1) - Y(0)] \]

要使用数据估计潜在结局的平均值，我们需要满足 因果假设 中讨论的三个因果假设：可交换性、正值性和一致性。 这个估计目标还告诉我们，需要对数据的哪一部分作出这些假设。 ATE 是一个针对整个总体的估计目标。 因此，我们需要在处理取值的整个范围内满足这些假设；我们需要使用处理组来估计未处理组的反事实，并使用未处理组来估计处理组的反事实。 因为需要从两组相互借用信息，正值性假设的一个方面是：接受暴露的概率应大于 0 且小于 1：\(0<p<1\)。

处理组平均处理效应

另一个我们见过的估计目标——MatchIt 中的默认估计目标——是处理组平均处理效应（ATT）。 ATT 的目标人群是暴露（处理）组。 这一因果估计目标以暴露组中的个体为条件：

\[ E[Y(1) - Y(0) | X = 1] \]

ATT 受到关注时，示例研究问题可以是“是否应停止针对当前正在接受营销活动的人群开展该活动？” 或者：“医疗服务提供者是否应停止向当前正在接受治疗的人推荐该治疗？” (Greifer 和 Stuart 2021)

ATT 是匹配时常见的目标估计目标；这里，所有暴露观测值都会被纳入，并与对照观测值匹配，其中一部分对照观测值可能会被丢弃。 或者，我们可以通过加权估计 ATT。 ATT 权重估计为：

\[ w_{ATT} = X + \frac{(1 - X)p}{1 - p} \]

换句话说，处理组的权重为 1，而未处理组的权重等于其接受处理的优势比。 为什么这些权重能够将目标对准这一人群？ 另一种写法是将这些权重表示为 ATE 权重的一种变换。 ATE 与 ATT 权重的差异仅在于分子。 权重的分子有时称为倾斜函数。 ATE 权重的倾斜函数是 1，而 ATT 的倾斜函数是接受处理的概率。 如果我们将 ATE 权重乘以 1，什么都没有改变；我们仍然处理的是整个总体。 如果将 ATE 权重乘以处理概率，就会对权重进行缩放，使其现在针对处理组。

\[ \begin{aligned} w_i^{\mathrm{ATE}} &= \begin{cases} \dfrac{1}{p}, & X_i = 1,\\[8pt] \dfrac{1}{1 - p}, & X_i = 0, \end{cases} \quad \Bigl(tilt_{\rm ATE}(p)=1\Bigr) \\[1em] w_i^{\mathrm{ATT}} &= \begin{cases} \dfrac{p}{p} = 1, & X_i = 1,\\[6pt] \dfrac{p}{1 - p}, & X_i = 0, \end{cases} \quad \Bigl(tilt_{\rm ATT}(p)=p\Bigr) \end{aligned} \]

倾斜函数有助于我们理解如何修改权重以针对给定人群，以及权重如何变化。 例如，对于 ATE，倾斜函数使目标人群保持原样（整个总体），而权重可以趋于无穷大（处理组向左、未处理组向右），如 图 64.5 所示。

ATT 和其他估计目标相较于 ATE 具有一个优势：因为我们只针对总体中的一个子集进行推断，需要作出的因果假设只需在该子集内满足。 由于 ATT 的估计目标是：

\[ E[Y(1) - Y(0) | X = 1] \]

我们的假设更弱，因为它只适用于处理组，而不是整个总体。 对于可交换性，我们不再试图为未处理组估计潜在结局 y(1)；我们只对处理组进行推断，并且已经观察到该组的 y(1)。 我们只需要估计 y(0)，并借用未处理组的信息来完成这一点。 这会对我们的假设产生两个后果：1）可交换性假设被弱化为只针对潜在结局 y(0)；2）正值性假设被弱化为只要求 \(p<1\)；现在我们只要求存在某种不接受暴露的概率。

未暴露人群中的平均处理效应

用于估计未暴露（对照）人群中的平均处理效应（ATU / ATC）的目标人群，是未暴露（对照）人群。 我们将使用 ATU 和 ATC 来指代这一估计目标。 该因果估计目标以未暴露组中的个体为条件。

\[ E[Y(1) - Y(0) | X = 0] \]

ATU 所关注的研究问题示例包括：“是否应当向目前尚未接受营销活动的人群发送我们的营销活动？” 或者：“医疗服务提供者是否应当开始向目前尚未接受治疗的人推荐该治疗？” (Greifer 和 Stuart 2021)

ATU 也可以通过匹配进行估计；在这种情况下，所有未暴露观测值都会被纳入，并与暴露观测值进行匹配，其中一部分暴露观测值可能会被丢弃。 或者，也可以通过加权估计 ATU。 ATU 权重估计为：

\[ w_{ATU} = \frac{X(1-p)}{p}+ (1-X) \]

这与 ATT 正好相反：未暴露组的权重为 1，而暴露组的权重等于其未接受处理的优势比。 我们使用未接受处理的概率作为倾斜函数，将目标对准未处理组。

\[ \begin{aligned} w_i^{\mathrm{ATC}} &= \begin{cases} \dfrac{1 - p}{p}, & X_i = 1,\\[6pt] \dfrac{1 - p}{1 - p} = 1, & X_i = 0, \end{cases} \quad \Bigl(tilt_{\rm ATC}(p)=1 - p\Bigr) \end{aligned} \]

ATC 的倾斜函数会使总体更接近未处理组。 因此，未处理组的权重为 1，处理组的权重根据未接受处理的优势比确定，其范围从 0 到无穷大。

可均匀匹配人群中的平均处理效应

用于估计可均匀匹配人群中的平均处理效应（ATM）的目标人群，是可均匀匹配人群。 该因果估计目标以根据某种距离度量被认定为“可均匀匹配”的个体为条件。

\[ E[Y(1) - Y(0) | M_d = 1] \]

这里，\(d\) 表示距离度量，\(M_d=1\) 表示某个单位根据该距离度量可以均匀匹配 (Samuels 2017; D’Agostino McGowan 2018)。 关于 ATM 的研究问题示例包括：“处于临床均势的人是否应接受该暴露？” (Greifer 和 Stuart 2021) 在医学中，处于临床均势是指我们确实不确定应当如何为其选择治疗方案的人。 这往往正是我们希望作出推断的人群，因为我们希望在这种不确定性面前作出最佳决策。

ATM 是匹配时常用的目标估计目标。 在这里，一些暴露观测值会与对照观测值匹配。 不过，两组中都可能有一些观测值被丢弃。 这种匹配通常通过卡钳完成：只有当观测值之间的距离落在预先规定的卡钳范围内时，才进行匹配，正如我们在 匹配 中所展示的。 或者，也可以通过加权估计 ATM。 ATM 权重估计为：

\[ w_{ATM} = \frac{\min \{p, 1-p\}}{Xp + (1-X)(1-p)} \]

ATM 的倾斜函数为 \(min\{p, 1-p\}\)。

\[ \begin{aligned} w_i^{\mathrm{ATM}} &= \begin{cases} \dfrac{min \{p, 1-p\}}{p}, & X_i = 1,\\[6pt] \dfrac{min \{p, 1-p\}}{1 - p}, & X_i = 0, \end{cases} \quad \Bigl(tilt_{\rm ATM}(p)=min \{p, 1-p\}\Bigr) \end{aligned} \]

这会对权重产生有趣的影响。 倾斜函数以三角函数的形式缩放权重：在 0.5 处取最大值，此时处理组之间的不确定性（均势）最大。 当概率高于 0.5 时，未处理组的权重为 1；但随着其概率趋近于 0，权重会降低。 接受处理概率较低的个体不会贡献太多信息。 对于处理组，情况正好相反。 当概率低于 0.5 时，处理组的权重为 1；随着概率趋近于 1，权重会降低。

重叠人群中的平均处理效应

ATM 估计的是一个处于均势的特定人群（可均匀匹配人群），但我们可以用多种方式理解均势。 一个相关的目标人群是重叠人群中的平均处理效应（ATO）。 ATO 所关注的研究问题与 ATM 相同，例如：“处于临床均势的人是否应接受该暴露？” (Greifer 和 Stuart 2021)

同样，这些权重与 ATM 权重相似，但经过了轻微衰减，因此具有更好的方差性质。

ATO 权重估计为：

\[ w_{ATO} = X(1-p) + (1-X)p \]

ATO 的倾斜函数为 \(p(1-p)\)1。

\[ \begin{aligned} w_i^{\mathrm{ATO}} &= \begin{cases} \dfrac{p(1-p)}{p} = 1-p, & X_i = 1,\\[6pt] \dfrac{p(1-p)}{1 - p} = p, & X_i = 0, \end{cases} \quad \Bigl(tilt_{\rm ATO}(p)=p(1-p)\Bigr) \end{aligned} \]

与 ATM 一样，ATO 的倾斜函数最重视倾向评分为 0.5 的个体，并降低倾向评分接近 0 或 1 的个体的权重。 不过，ATO 的倾斜函数比 ATM 更平滑，因此具有更好的方差性质。 对权重的影响是：权重在整个倾向评分范围内呈线性变化；随着倾向评分趋近于 1，未处理组的权重趋近于 1；相反，随着倾向评分趋近于 0，处理组的权重趋近于 1。 我们为每个组赋予等于其属于另一组概率的权重！

sim <- function(n) {
  ## create a simulated dataset
  finite_sample <- tibble(
    z = rnorm(n),
    x = case_when(
      0.5 + z + rnorm(n) > 0 ~ 1,
      TRUE ~ 0
    ),
    y = z + rnorm(n)
  )
  finite_sample_wts <- glm(
    x ~ z,
    data = finite_sample,
    family = binomial("probit")
  ) |>
    augment(data = finite_sample, type.predict = "response") |>
    mutate(
      wts_ate = wt_ate(.fitted, x),
      wts_ato = wt_ato(.fitted, x)
    )
  bias <- finite_sample_wts |>
    summarize(
      effect_ate = sum(y * x * wts_ate) /
        sum(x * wts_ate) -
        sum(y * (1 - x) * wts_ate) / sum((1 - x) * wts_ate),
      effect_ato = sum(y * x * wts_ato) /
        sum(x * wts_ato) -
        sum(y * (1 - x) * wts_ato) / sum((1 - x) * wts_ato)
    )
  tibble(
    n = n,
    bias = c(bias$effect_ate, bias$effect_ato),
    weight = c("ATE", "ATO")
  )
}

注记再论截尾与截断

正如我们在 加权 中所见，截尾或截断是处理正值性和重叠问题的常用技术。 你可以把由此得到的估计目标看作另一类重叠人群。 例如，对于被截尾的观测值，倾斜函数为 0；对于保留下来的观测值，倾斜函数为 1。 许多分析者希望这样做仍然是在近似 ATE——即这个目标人群与总体足够接近，能够给出大致相同的答案，同时具有更好的方差。 不过，我们也知道，重叠人群本身就是一个有价值的目标人群。 考察截尾或截断时各人群之间的变化，可能有助于了解你的目标人群在多大程度上近似整个总体，或者它是否更适合被视为重叠人群。

理解匹配中的估计目标

MatchIt 可以通过 estimand 参数轻松针对不同的估计目标。 请注意，ATE 需要使用完全匹配，而 ATM 需要使用卡钳。

ATT matchit(…, estimand = "ATT")

权重如何针对不同人群的直觉，归根结底在于倾斜函数：我们缩放权重，使其代表感兴趣的人群。 匹配的直觉更直接：关键在于哪些观测值会被丢弃，哪些不会。 从数学上说，两者是相同的：在匹配中，每个人的权重都是 0 或 1，而这些权重的确定方式与一种算法倾斜函数有关。 不过，对于匹配而言，思考谁被丢弃以及为什么被丢弃更容易。

请考虑 图 64.20，其中展示了一个以 ATE、ATT、ATC 和 ATM 为目标的模拟示例。 对于 ATE，我们在整个总体中寻找匹配对象。 对于 ATT，我们为处理组寻找匹配对象；因此，如果某个未处理（对照）观测值落在处理组的范围之外，它可能会被丢弃。 ATC 则相反：我们为对照组寻找匹配对象，因此，与未处理组没有重叠的处理观测值可能会被丢弃。 对于 ATM，我们关注的是两组之间存在重叠的人群；因此，如果某个组中的观测值找不到良好匹配，它就可能被丢弃。 在匹配中，我们通过卡钳控制认为可接受的重叠程度。

注记使用匹配的加权表格

进行匹配时，我们会把总体限制在存在匹配的区域。 这意味着不需要使用加权表格来描述我们将据此作出推断的人群。 不过，假设你正在探索多种匹配方案。 在这种情况下，使用 bind_matches() 在原始数据集中记录每种匹配方案的（0 或 1）权重会很有帮助，这样就不必复制多份数据。 随后，你可以使用相应的二元权重创建加权表格。

有效样本量

正如 评估你的倾向评分模型 所述，有效样本量（ESS）是理解各种估计值效率的一种方式。它衡量需要多少个相互独立的观测，才能达到与你的加权样本相同的方差。ESS既可作为检查所选方法和估计过程效率的一般工具，也可在有多种方法都能回答研究问题时，帮助选择方法。

在考察平衡性与精确度时，根本的矛盾在于偏差—方差权衡。观测样本量最高，但平衡性也最差，而且可能无法回答我们的研究问题。ATO具有最好的平衡性和最高的ESS，但它所对应的是一类特定的研究问题，未必适合我们的需求。假如我们对暴露进行了随机化，至少在平均意义上、并且实际样本量足够大时，我们会得到最好的平衡性和最高的ESS。然而，在观察性数据中，我们往往必须在偏差和方差之间作出权衡。加权会降低有效样本量，但这通常是必要的权衡：否则，我们得到的可能只是一个估计得很精确的错误答案！

多变量线性回归的估计目标是什么？

在 从问题到答案：分层与结局模型 中，我们讨论了多变量线性回归等标准方法何时有效、何时失效。但是，像 lm(outcome ~ exposure + confounder) 这样的回归估计量估计的是什么估计目标？

在探索简单问题时，你会注意到，多变量回归得到的答案通常接近使用ATE权重得到的答案。如果暴露组之间的分布表现为处理组或未处理组所占比例明显偏高，那么这个答案可能更接近ATT或ATU。

现实是，我们并不总能明确知道自己处理的是哪一种估计目标。一种探究方法是使用一种技术，从线性回归中推导出隐含权重 (Chattopadhyay 和 Zubizarreta 2022; Aronow 和 Samii 2015)。{lmw} 包可以帮助我们计算这些权重。默认目标是ATE，但我们也可以针对其他估计目标。

library(lmw)
implied_weights <- lmw(
  ~ park_extra_magic_morning +
    park_ticket_season +
    park_close +
    park_temperature_high,
  data = seven_dwarfs_with_ps,
  treat = "park_extra_magic_morning"
)
seven_dwarfs_with_ps$iw <- implied_weights$weights

这些隐含权重具有一些不错的性质。它们在均值上实现了完美平衡，并且在这类权重中方差最低。

seven_dwarfs_with_ps |>
  mutate(park_close = as.numeric(park_close)) |>
  tidy_smd(
    .vars = c(park_ticket_season, park_close, park_temperature_high),
    .group = park_extra_magic_morning,
    .wts = iw
  ) |>
  ggplot(aes(abs(smd), variable, color = method, group = method)) +
  geom_love()

它们的均值也为1，这意味着它们的总和等于原始数据集的大小。相对于观测样本量，有效样本量也很高。

seven_dwarfs_with_ps |>
  summarize(mean = mean(iw), sum = sum(iw), n = n(), ess = ess(iw))

问题在于，它们也具有一些不协调的性质。尽管它们在均值上实现平衡，却未必能为目标人群创造平衡。与此相关的是，它们有时还会产生负权重。例如，如果我们在这个模型中加入交互项，有些权重会小于0。负权重意味着超出了数据中协变量联合分布范围的外推。虽然这里的负权重接近0，但它们可能会更加极端。因此，尽管我们针对的是ATE，却未必能非常精确地实现这一目标；目标人群究竟是谁也不再清楚。

implied_weights_int <- lmw(
  ~ park_extra_magic_morning *
    (park_ticket_season + park_close + park_temperature_high),
  data = seven_dwarfs_with_ps,
  treat = "park_extra_magic_morning"
)

min(implied_weights_int$weights)
[1] -0.1113

假设你认为这些性质在你的问题中表现得还可以。在这种情况下，这种方法还提供了一个额外好处：现在，你可以使用 倾向评分 和 评估你的倾向评分模型 中的技术，在不查看结局与暴露之间关系的情况下，诊断多变量线性模型的平衡性和函数形式。由于它们只是权重，你仍然可以使用 halfmoon、gtsummary 以及任何其他适合处理权重的方法所提供的全部工具。lmw 甚至自带一个方便的估计函数 lmw_est()，可以用稳健标准误计算结局上的效应。因此，如果你的合作者希望使用OLS，而你又想批判性地考虑平衡性和外推问题，就可以兼得两方面的好处。不过，如果最终得到负权重和其他奇怪的性质，根据你的估计目标，采用另一种方法可能更好。
