记号与约定

记号定义散落在正文、边注与 Technical Point 里

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）。 本页是查阅卡，不是原书译文；每条都标了原书页码， 分组与归纳方式为笔记作者所加，原书没有这样一页。

原书没有记号表。定义散在三个地方：正文里随讲随定义、左侧边注里给一行速记、 Technical Point 里给形式化版本。第一次读时没人会停下来背，回查时又想不起来在哪一页。

本页覆盖到第 10 章（原书第一部分 ＋ 随机变异）。 第 11 章起的建模与时变记号，以及全书的公式，在公式卡。

建议的读法：§一 的三条底层约定必须先看，后面所有记号都是它们的实例； 查某个字母跳 §二 §三；开始怀疑自己记混了跳 §六。

一、三条底层约定：后面所有记号都是它们的实例

1. 大写是随机变量，小写是取值

Capital letters represent random variables. Lower case letters denote particular values of a random variable.

— What If, 书页 3 边注

这条不只是排版习惯，它有一个直接后果：\(\Pr[A = A \mid L = L]\) 不是合法记号—— 它恒等于 1，是句废话。所以 IP 权重不能写成概率，只能写成在随机变量处取值的 条件密度 \(f[A \mid L]\)（TP 2.2，书页 23）。\(W^A = 1/f[A \mid L]\) 这个看着别扭的 写法，就是被这条约定逼出来的。

2. 上标是干预，竖线是观测

同一个字母放在两个位置，意思完全不同：

写法 位置 指的人群 概率类型
\(\Pr[Y^{a=1} = 1]\) \(a\) 在上标 全人群，假想所有人都被指派 \(a=1\) 边际（无条件）
\(\Pr[Y = 1 \mid A = 1]\) \(A\) 在竖线右边 实际碰巧接受了 \(A=1\) 的那部分人 条件

因果与关联的全部差别就是这一个位置差（§1.5，书页 11–12）：因果是「同一人群在两种 处理值下」的对比，关联是「由实际处理值切开的两个不相交子集」的对比。

同一个字母 \(A\) 同时担了两份活

Confusion often arises from the common practice of using the same letter to refer to the hypothetical intervention \(a\) and to the observed value \(A\) before enough information exists to match \(a\) and \(A\).

— What If, 书页 38 边注

假想干预 \(a\) 与观测值 \(A\) 本是两件事，书却用同一个字母。第 3.4–3.5 节 （良定义的干预 ＋ 把反事实接回观测数据）整整两节就是在补这个缺口。

3. 括号：\(\Pr\)、\(E\) 一律方括号，\(f\) 两种都用

  • \(\Pr[\cdot]\)、\(E[\cdot]\) —— 方括号，全书稳定。
  • \(f\) —— 第 2–3 章写方括号 \(f[a \mid l]\)（TP 2.2 / 2.3，书页 23、25）， 第 4 章起写圆括号 \(f(e_A \mid Y)\)（TP 9.1，书页 120）。 两者是同一个东西，不是两种记号。

本笔记统一写圆括号 \(f(\cdot)\)，只有直接引用 TP 2.2 / 2.3 的式子时照抄方括号。

二、变量字母：哪些是全书约定，哪些只是例子里的名字

符号 指什么 出处
\(A\) 处理 / 暴露 / 干预 §1.1，书页 3
\(Y\) 结局 §1.1，书页 3
\(L\) 为了可交换性需要调整的变量。书里 \(L\) 常是一个变量集，不是单个变量 §2.3 起；书页 41
\(V\) 效应修饰因子。选 \(V\) 这个字母的含义是「不打算为它做识别假设」 §4.2；书页 60
\(E\) 第二个处理（交互）。与期望 \(E[\cdot]\) 同字母 §5.1，书页 57
\(C\) 删失，\(C = 0\) 表示未被删失 §8.5，书页 103
\(S\) 选择节点，图上通常带方框 书页 79
\(U\) 未测量变量 书页 31 起
\(U_A\)、\(U_Y\) 除 \(A\)（\(Y\)）本身以外、决定 \(A^*\)（\(Y^*\)）的全部因素，即测量误差的来源 §9.1，书页 119
\(A^*\)、\(Y^*\)、\(L^*\) 实际测到的值；不带星号的才是真值 §9.1，书页 119
\(e_A\)、\(e_Y\) 测量误差，\(e_A = A^* - A\) TP 9.1，书页 120
\(W^A\) IP 权重，\(W^A = 1/f[A \mid L]\) TP 2.2，书页 23
\(I(A = a)\) 示性函数：\(A = a\) 时取 1，否则取 0 TP 2.3，书页 25

其余单字母（\(B\)、\(M\)、\(Z\)、\(H\) …）都是某个例子里的名字，不是全书约定， 换一张图就换意思——查它们要回到具体那一节，不能照搬。

\(V\) 和 \(E\) 的分工是「要不要为它做识别假设」

we used the notation \(V\) (rather than \(E\)) for variables for which we are not willing to make assumptions about exchangeability, positivity, and consistency

— What If, 书页 60

所以「\(V\) 修饰了 \(A\) 的效应」是能说的，而「\(V\) 对 \(Y\) 的效应」不能说—— 我们从没为 \(V\) 要过识别条件。想把第二个变量也当处理看（谈交互），它才改叫 \(E\)。

三、反事实上标：上标里放的是干预

写法 含义 出处
\(Y^a\) 读作「Y under treatment \(a\)」：若被指派 \(a\)，本人会有的结局 §1.1，书页 3
\(Y^{a=1}\)、\(Y^{a=0}\) \(a\) 取定具体值的写法，二分处理下最常见 §1.1，书页 3
\(Y^A\) 把 \(a\) 在本人实际接受的 \(A\) 处取值 §1.1，书页 4
\(Y_i^a\) 个体 \(i\) 的反事实。带下标时它不再是随机变量（个体反事实被设为确定值，见 TP 1.2） 书页 4 边注
\(Y^{a,e}\) 对 \(A\)、\(E\) 的联合干预 §5.1，书页 57
\(Y^{c=0}\)、\(Y^{a,c=0}\) 把删失也当成一次干预：若未被删失 §8.5
\(Y^l\) 对 \(L\) 做干预下的结局。同一个 \(Y^l\) 在不同图里可以指不同的量 第 9 章
\(\widehat{\Pr}[\cdot]\) 戴帽子 ＝ 样本比例，是超总体概率的估计量 §1.4，书页 9；正名见 §10.1

一致性其实是「递归替换」的特例

The counterfactual \(Y^a\) corresponding to an intervention on \(A\) alone is the joint counterfactual \(Y^{a,e}\) if the observed \(E\) takes the value \(e\), i.e., \(Y^a = Y^{a,E}\).

— What If, 书页 57 边注

于是观测结局 \(Y = Y^A = Y^{A,E}\)。第 1 章那个孤零零的 \(Y = Y^A\)， 到第 5 章才显出它是一族替换规则里的一条。

第 1–10 章不会出现的上标：时变处理的历史记号（\(\bar{A}_k\) 之类）要到 Part III 才登场， 本页读到哪儿写到哪儿，不预告。

四、要能默写的等式：全书就这十来条

个体与人群（第 1 章）

\[Y_i^{a=1} \neq Y_i^{a=0} \qquad \text{(个体因果效应，书页 4 边注)}\]

\[\text{若 } A_i = a,\ \text{则 } Y_i^a = Y_i^A = Y_i \qquad \text{(一致性，书页 4 边注)}\]

\[E[Y^{a=1}] \neq E[Y^{a=0}] \qquad \text{(平均因果效应，书页 6 边注)}\]

二分结局下 \(\Pr[Y^a = 1] = E[Y^a]\)（TP 1.1，书页 7），所以「风险」和「均值」是同一个数； 写成 \(E[\cdot]\) 只是为了让定义对连续结局也成立。

两个零假设不是一回事（书页 6）：

  • 尖锐零假设（sharp causal null）：对每一个人都有 \(Y^{a=1} = Y^{a=0}\)；
  • 因果零假设（平均无效应）：\(\Pr[Y^{a=1} = 1] = \Pr[Y^{a=0} = 1]\)。

尖锐零蕴含平均零，反之不成立——原书 Table 1.1 就是反例：6 人被治死、6 人被治活， 平均效应却是零。

三种度量：因果版与关联版长得一模一样，差别只在 \(Y^a\) 还是 \(Y \mid A\)：

尺度 因果（§1.3，书页 7） 关联（§1.5，书页 11）
风险差 \(\Pr[Y^{a=1}{=}1] - \Pr[Y^{a=0}{=}1]\) \(\Pr[Y{=}1 \mid A{=}1] - \Pr[Y{=}1 \mid A{=}0]\)
风险比 \(\dfrac{\Pr[Y^{a=1}{=}1]}{\Pr[Y^{a=0}{=}1]}\) \(\dfrac{\Pr[Y{=}1 \mid A{=}1]}{\Pr[Y{=}1 \mid A{=}0]}\)
比值比 \(\dfrac{\Pr[Y^{a=1}{=}1] / \Pr[Y^{a=1}{=}0]}{\Pr[Y^{a=0}{=}1] / \Pr[Y^{a=0}{=}0]}\) \(\dfrac{\Pr[Y{=}1 \mid A{=}1] / \Pr[Y{=}0 \mid A{=}1]}{\Pr[Y{=}1 \mid A{=}0] / \Pr[Y{=}0 \mid A{=}0]}\)

三者的零值分别是 0、1、1。NNT 是风险差的倒数（FP 1.3，书页 8）：

\[\text{NNT} = \frac{-1}{\Pr[Y^{a=1} = 1] - \Pr[Y^{a=0} = 1]}\]

三个识别条件（第 2–3 章）

\[Y^a \perp\!\!\!\perp A \qquad \text{(可交换性，书页 14 边注)}\]

\[Y^a \perp\!\!\!\perp A \mid L \qquad \text{(条件可交换性，第 3 章)}\]

\[\Pr[A = a \mid L = l] > 0 \ \text{ 对所有 } \Pr[L = l] \neq 0 \text{ 的 } l \qquad \text{(正性，书页 32 边注)}\]

可交换性还有两个变体（TP 2.1，书页 15）：完全可交换性 \(Y^{a=1}, Y^{a=0} \perp\!\!\!\perp A\) （联合独立，比可交换性强）、均值可交换性 \(E[Y^a \mid A = a'] = E[Y^a]\) （比可交换性弱，但已足以证明 \(E[Y^a] = E[Y \mid A = a]\)）。

两种调整方式（TP 2.3，书页 25）

\[\sum_l E[Y \mid A = a,\, L = l] \Pr[L = l] \qquad \text{(标准化)}\]

\[E\!\left[\frac{I(A = a)\, Y}{f[A \mid L]}\right] \qquad \text{(IP 加权)}\]

正性成立时两者相等，且都等于 \(E[Y^a]\)。

五、统计层的记号：第 10 章才补上的那一层

第 1–9 章一律假装「数据就是整个超总体」，所以那些式子里没有一个帽子。 第 10 章把这层假装撤掉，才正式给出三个词（§10.1，书页 132）：

词 指什么 例子
估计元（estimand） 超总体里我们想知道的那个参数 \(\Pr[Y{=}1 \mid A{=}a]\)
估计量（estimator） 一条规则：把样本数据变成一个数 \(\widehat{\Pr}[Y{=}1 \mid A{=}a]\)
估计值（estimate） 这条规则在手上这个样本上算出的数 \(7/13\)

帽子就是「估计量」这一层的标记——第 1 章（书页 9）已经用过 \(\widehat{\Pr}\)， 只是没给名字。95% Wald 置信区间的通用写法是（书页 132）：

\[\widehat{\theta} \pm 1.96 \times \widehat{se}\big(\widehat{\theta}\big)\]

覆盖性质有四个档（书页 133），不是同义词：

词 覆盖率
校准（calibrated） 恰好 95% 的随机样本盖住估计元
保守（conservative） 超过 95%
反保守（anticonservative） 低于 95%
有效（valid） 对参数的任何取值，要么校准要么保守，即至少 95%

第 10 章一口气定了三条全书默认

这三条是约定，不是结论——后面每一章的「95% CI」「无偏」都按它们读：

  • 「95% 置信区间」默认指大样本有效区间（如 Wald 区间），除非另有说明（书页 133 边注）。
  • 「有效置信区间」默认指大样本 honest 区间（Fine Point，书页 134）。
  • 「无偏」默认指 UANU（uniformly asymptotically normal and unbiased； Technical Point，书页 135），不是初等统计里那个「期望等于真值」的无偏。 这里的 uniform 是「一致收敛」的一致，与 §六·二 的两个「一致性」无关。

置信区间只有频率论解释（书页 133）：估计元是固定的，它要么在区间里要么不在， 「有 95% 的概率落在这个区间里」是错的说法。

六、最容易记混的六处：每一处书都专门提醒过

一 · \(Y^a \perp\!\!\!\perp A\) 不是 \(Y \perp\!\!\!\perp A\)

\(Y^a \perp\!\!\!\perp A\) is different from \(Y \perp\!\!\!\perp A\).

— What If, 书页 15 边注

前者是反事实与处理独立（可交换性，成立时说明分组可比）； 后者是观测结局与处理独立（无关联）。在一个有效的随机试验里，若处理真有效应， 前者成立而后者恰恰不成立。

二 · 两个「一致性」

Caution: the term ‘consistency’ when applied to estimators has a different meaning from that which it has when applied to counterfactual outcomes.

— What If, 书页 9 边注

\(Y = Y^A\) 是反事实的一致性（识别层面的假设）；\(\widehat{\theta} \to \theta\) 是估计量的 consistency（统计层面的大样本性质，正式定义在 §10.1，书页 132）。 中文更容易混——统计学里后者通常译作相合，本笔记照此区分： 反事实叫「一致性」，估计量叫「相合」。

三 · \(V\) 与 \(E\)：不是变量重要性的差别，是假设的差别

见 §二 的引文（书页 60）。一句话：能谈其效应的叫 \(E\)，只拿来分层的叫 \(V\)。

四 · 因果风险差是个体效应的平均，因果风险比不是

书页 7 边注专门说了这件事：\(E[Y^{a=1}] - E[Y^{a=0}] = E[Y^{a=1} - Y^{a=0}]\)， 因为「均值之差 ＝ 差之均值」；但 \(\dfrac{E[Y^{a=1}]}{E[Y^{a=0}]}\) 不等于个体比值 \(Y^{a=1}/Y^{a=0}\) 的平均。风险比是人群层面的效应度量，不是任何个体效应的平均。

五 · \(E\) 既是期望又是第二个处理

第 5 章起 \(E\) 兼职：\(E[\cdot]\)（带方括号）是期望，\(E = 1\) 是维生素这个处理的取值。 靠括号区分，书里没有改名。

六 · 下标 \(i\) 一出现，那个量就不再是随机变量

书页 4 边注：\(Y_i^a\) 是「个体 \(i\) 有结局 \(Y^a\)」的简写，但当 \(i\) 指某个具体的人时， \(Y_i^a\) 不是随机变量——因为个体反事实被假设为确定的（TP 1.2，书页 10）。 正文默认不写 \(i\)，写了就是在谈个体那一层。

七、因果图的画法约定：第 6 章起

  • 时间从左往右流（书页 71）。所以 \(L \to A \to Y\) 的排布同时也在声明时序。
  • 箭头的两个方向不对称：画一条 \(V \to W\) 只断言「至少对一个人有直接效应」， 是很弱的话；不画这条箭头断言「对每一个人都没有直接效应」，等于第 1 章那个 尖锐零假设，是很强的话。真正承载假设的是没画的那些箭头。
  • 方框 ＝ 已经条件化（书页 78）：分析被限制在该变量的某一层内。两个常见特例—— \(C\) 上的方框表示限制在未删失者（书页 103），\(S\) 上的方框表示限制在被选入分析的人 （书页 79）。
  • 星号 ＝ 测量值（书页 119）：\(A^*\) 是测到的，\(A\) 是真值，两者之间挂着误差来源 \(U_A\)。 \(U_A\) 严格说可以不画（它既不是共同原因，也不在因果通路上），书画出来只是为了看清 误差结构。

八、本笔记与原书记号的差异：只有四处

  1. 密度统一写圆括号 \(f(\cdot)\)；只有照抄 TP 2.2 / 2.3 的式子时保留原书的方括号。
  2. \(\Pr\)、\(E\) 保留方括号，与原书一致，不改写成 \(P(\cdot)\)。
  3. 独立符号一律写 \(\perp\!\!\!\perp\)。原书排版也是这个符号，但 PDF 文本层会把它吐成 空白，回查时搜不到——记住它长什么样比搜索有用。
  4. 「一致性 / 相合」按 §六·二 的规则分译，这是笔记作者的取舍，原书只有一个英文词。
