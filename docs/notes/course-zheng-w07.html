W07 · 缺失数据与因果推断

郑老师训练营第七周 · 讲义 55 页 + 3 段视频约 1 小时 24 分

本页两部分：讲义原件内嵌展示，版权归课程作者所有；内容整理是笔记作者 根据讲义与视频语音转写写的，不是课程原话。出处、压缩处理与已知限制见 课程讲义总览。

前六周默认数据是完整的，这一周补上现实：收集数据的过程中总会有缺失。 讲义按四段走——缺失数据对因果推断的影响、缺失的分析与 R 操作、 插补与 R 操作、插补之后怎么接着做因果推断。

最后那一段才是这周真正的新东西：多重插补产生 \(m\) 个数据集之后， 倾向得分匹配 / 加权 / TMLE 各自要怎么在这 \(m\) 份数据上跑、结果又怎么合并。

原书把缺失与删失归到选择偏倚处理，见第 8 章； 用 IP 加权校正删失的做法见第 12 章。

一、什么时候该填补，什么时候不该：三条可操作的界限

讲义 p3–9。先说影响：缺失会带来因果效应估计偏倚、数据不具代表性、 样本量减少导致置信区间变宽（p4）。但讲义提醒了一个容易忽略的点（p3）——

少量比例缺失数据对结果影响不大，但当多数变量都少量缺失时，对回归分析影响较大。 影响多因素回归效能的是存在着缺失个案的数量。

也就是说，看单个变量的缺失率会低估问题：三个患者各缺一个不同的变量， 单变量缺失率都很低，但完整个案一个都不剩。

缺失机制（Little 和 Rubin，p6）：

机制 含义 对应可用的方法
MCAR 完全随机缺失 数据的缺失与任何其它变量无关 单一填补也勉强可用
MAR 随机缺失 数据的缺失仅仅依赖于已测变量 多重插补的前提
MNAR 非随机缺失 不完全变量中数据的缺失还与未测变量或缺失值本身有关 上述方法都不足

讲义给的三条数字界限

p7 把「要不要处理」讲成可以照着执行的规则：

  • 若缺失个案总数不超过 5%，不处理缺失现象
  • 若一个变量缺失比较高，达 20–30% 以上，则该变量后续不考虑纳入分析
  • 若缺失个案总数超过 5%，或某变量缺失比例低于 20%，则建议填补

p8 还有一条同样实用的分工：观察性研究的差异性分析不进行数据填补， 回归分析之前才需要填补。 视频里讲师专门纠正了这个误区—— 「大家可能平时有个误区，就说我拿到数据我就要用完整的一个数据，它其实并不是的」； 做单因素的 \(t\) 检验、卡方检验一般不插补，只有要做回归分析时才插补。

单一填补（平均值、中位数、末次随访转结、最差值法、基线转结法、随机森林等） 的缺点写在 p9：没有考虑缺失值的不确定性与关联性，低估或高估数据的变异， 且只在 MCAR 下勉强成立。

多重插补（p10–11）为每个缺失值提供 \(m\) 个填补值，产生 \(m\) 个完整数据集， 分别分析后再合并效应——它考虑了缺失值的不确定性，已成为处理缺失值的标准。

二、R 操作：看清缺失、然后插补：mice 三件套

讲义 p12–19。案例是运动与肺病之间的因果关系：数据集含 18 个特征， 暴露是运动（PA，身体活动指数 1–9 分），结局是肺病（lungfun）， 协变量包括抑郁（CESD）、性别、身高、体重、高血压、糖尿病、心脏病、 居住地、吸烟、年龄、教育程度、心血管代谢共病、饮酒等。

填补方法四选一（p18）：删除法、单一数值插补、基于机器学习填补（随机森林、KNN）、 多重插补（讲义标红）。

多重插补的两个注意事项

讲义 p19 两条都是实操踩过的坑：

  • 插补之前必须在变量视图里定义数据类型。不然分类变量会被插补成连续型数据—— 多重插补对不同类型的数据用不同模型：连续用线性回归（含 PMM 法）、 二分类用 logistic、多分类用多分类 logistic
  • 线性回归插补时可能会出现错误数据，建议用 PMM 插补法 （预测均值匹配，取真实观测值作为填补值，不会插出负身高这种不可能的数）

视频里这段正好演示了一个连锁问题：忘了 install.packages() 直接 library()， 函数报「没有这个函数」，排查半天才发现包根本没装上。

三、插补之后怎么做因果推断：MatchThem 是关键

讲义 p25–51。这是本周的核心：\(m\) 个插补数据集，倾向得分该怎么算？

讲义在 p26 给了一个明确的红叉与对勾：

MatchIt 包 ✗     MatchThem 包 ✓

MatchThem 联合 MICE，把三件事串起来——缺失数据填补、匹配/加权、汇总分析（p27）。 它的两大核心函数（p28、p43）：

函数 做什么
matchthem() 缺失数据填补 + 倾向得分匹配
weightthem() 缺失数据填补 + 倾向得分加权

六步流程

讲义 p32 的流程，配合 p33–51 的代码：

  1. 数据导入整理：library(MatchThem)；read.csv("data_missing.csv")；summary()、str() 看类型

  2. 填补缺失数据：multi_imputed <- mice(datana, m = 5, seed = 123)，生成 5 个填补数据集

  3. 倾向得分匹配：

    matched.datasets <- matchthem(
  lungfun ~ CESD_CAT + sex + age + hypertension + diabetes + heart_disease + smoking,
  datasets = multi_imputed,
  approach = 'within',   # 内部匹配
  method   = 'nearest',  # 邻近匹配
  caliper  = 0.2,        # 倾向得分标准差 0.2
  ratio    = 2)          # 2:1 的匹配比

  4. 匹配后的数据分析：svyglm() 配 with()，再 pool() 合并

  5. 倾向得分加权：weightthem(...)，method = 'ps'，estimand = 'ATE'

  6. 加权后的数据分析：同样 svyglm() + pool()

within 还是 across：讲义给了明确建议

approach 参数只有两个取值，但差别不小（p37、p46）：

  • within 法：使用观察到的和插补的协变量值在每个插补数据集中分别匹配或加权， 再把 \(m\) 个数据集中各自估计的暴露效应合并起来
  • across 法：对插补数据集的倾向评分取平均值，用这个平均测量值在插补数据集中 匹配或加权，最后把估计的暴露效应汇总

讲义的结论写在同一页：在许多常见场景中，与 within 法相比，across 法的统计性能较差。

另一个易错参数是 caliper：R 语言卡钳值一般设为 0.2 个标准差， SPSS 卡钳值一般设为 0.02（p38）——两个软件的量纲不一样，照抄会错一个数量级。

平衡性怎么看

匹配/加权之后用 cobalt 包检查（p39–40、p48–49）：

bal.tab(matched.datasets, stats = c("m", "ks"), imp.fun = "max")
love.plot(bal.tab(matched.datasets, m.threshold = 0.1),
          stat = "mean.diffs", grid = TRUE, stars = "raw", abs = FALSE)

imp.fun = "max" 的含义讲义解释得很清楚：在匹配的所有插补数据集中， 每个协变量后生成最大的绝对标准化均值差（ASMD）和 KS 统计量，表明数据集中的最差平衡—— 看最差的那一个，而不是平均。

视频里还提到一个实际现象：设了 2:1 的匹配比，但实际匹配上的样本量 （57064 对 34620）达不到整二倍，「主要是它匹配的，就是有一些匹配不上」。

合并效应值

matched.models  <- with(matched.datasets,
                        svyglm(lungfun ~ PA, family = quasibinomial()), cluster = TRUE)
match.results   <- pool(matched.models)
summary(match.results, conf.int = TRUE)

pool() 走的是 Rubin 法则——把 \(m\) 次分析的点估计与方差按规则合并， 方差里同时包含插补内变异与插补间变异。

四、缺失数据下的 TMLE：没有现成包，要手写循环

讲义 p52–55。tmle 包是单时间点（point treatment）因果推断中最经典的 TMLE 实现， 它提供双重稳健估计，同时输出 IPTW 和 G-computation 作为对比（p54）。 适用数据类型：观测数据（非随机化）、二元治疗 \(A\in\{0,1\}\)、 基线协变量 \(W\)（无时间依赖）、结局 \(Y\) 二元或连续。

流程三段（p55）：多重插补 → 各插补数据集的 TMLE 分析 → TMLE 效应值 ATE 的 Rubin 合并。

这一步只能手动做

视频里讲得比讲义直白：前面的回归分析可以用 MICE 的 pool() 合并回归系数， 倾向性匹配后的数据也能直接接回归；但 TMLE「其实没有一个特定的包可以去完成多重插补的」， 这时候就需要手动去进行一个合并。

做法是写一个循环：对 \(i=1,\dots,m\)，用 complete(imputed, i) 取出第 \(i\) 份数据， 提取 \(Y\)、\(A\) 与 \(W\)（注意 \(W\) 必须是数据框形式），跑 tmle()， 只取出 psi（平均处理效应）与方差存起来；\(m\) 份跑完后再按 Rubin 法则合并。 改数据集份数只要改循环次数，但暴露 A、结局 Y、协变量 W 要逐个对准。

结局是二分类时 family 用 "binomial"，连续时用 "gaussian"。

#rubin合并
rubin_pool_scalar <- function(df, est_col = "psi", var_col = "var.psi",
                              conf_level = 0.95, tiny_B = 1e-12) {
  stopifnot(is.data.frame(df), est_col %in% names(df), var_col %in% names(df))
  
  Q <- as.numeric(df[[est_col]])      # Q_i
  U <- as.numeric(df[[var_col]])      # U_i
  ok <- is.finite(Q) & is.finite(U)
  Q <- Q[ok]; U <- U[ok]
  m <- length(Q)
  if (m < 2) stop("至少需要 2 个插补数据集的结果才能做 Rubin 合并。")
  
  Qbar <- mean(Q)          # 合并点估计
  Ubar <- mean(U)          # 插补内方差均值
  B    <- stats::var(Q)    # 插补间方差（样本方差，分母 m-1）
  
  # 总方差
  if (is.na(B) || B < tiny_B) {
    Tvar <- Ubar
    df_br <- Inf
  } else {
    Tvar <- Ubar + (1 + 1/m) * B
    df_br <- (m - 1) * (1 + Ubar / ((1 + 1/m) * B))^2   # Barnard–Rubin df
  }
  
  se <- sqrt(Tvar)
  alpha <- 1 - conf_level
  crit <- if (is.finite(df_br)) stats::qt(1 - alpha/2, df = df_br) else stats::qnorm(1 - alpha/2)
  
  ci_low  <- Qbar - crit * se
  ci_high <- Qbar + crit * se
  
  t_stat <- Qbar / se
  p_val <- if (is.finite(df_br)) {
    2 * stats::pt(abs(t_stat), df = df_br, lower.tail = FALSE)
  } else {
    2 * stats::pnorm(abs(t_stat), lower.tail = FALSE)
  }
  
  # 评价插补效果：RIV / FMI
  RIV <- if (Tvar > 0) ((1 + 1/m) * B) / Ubar else NA_real_
  FMI <- if (Tvar > 0) ((1 + 1/m) * B) / Tvar else NA_real_
  
  out <- data.frame(
    m = m,
    est = Qbar,
    se = se,
    df = df_br,
    lcl = ci_low,
    ucl = ci_high,
    t = t_stat,
    p_value = p_val,
    Ubar = Ubar,
    B = B,
    Tvar = Tvar,
    RIV = RIV,
    FMI = FMI
  )
  return(out)
}

对着上表的「取值」和「含义」两列看会发现，课程发的赋值表与数据本身并不一致：

变量 赋值表写的 数据里实际是
sex、hypertension、heart_disease、residence、marital、smoking、alcohol、cardio_metabolic 0 / 1 1 / 2
education_level 1 / 2 / 3 1 / 2 / 3 / 4（多一档）
diabetes、PA_CAT、CESD_CAT、lungfun 0 / 1 0 / 1 ✓

也就是说分析变量（暴露、中介、结局）是 0/1，多数协变量却是 1/2。 课程脚本没有重新编码这些列。
