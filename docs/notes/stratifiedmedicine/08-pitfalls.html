过滤反而制造假亚组

这是本手册最重要的一条方法学结论，也是默认 PRISM() 与手工拼流水线 结果不同的唯一来源。

s_full <- submod_train(Y, A, X, submod = "lmtree")          # 全部 50 个
fv     <- filter_train(Y, A, X, filter = "glmnet")$filter.vars
s_filt <- submod_train(Y, A, X[, fv], submod = "lmtree")    # 过滤后 16 个

s_full$Rules
#>   Subgrps                      Rules
#> 1       3 X1 <= 0.016 & X2 <= -0.565
#> 2       4  X1 <= 0.016 & X2 > -0.565
#> 3       6   X1 > 0.016 & X2 <= 0.693
#> 4       7    X1 > 0.016 & X2 > 0.693
s_filt$Rules
#>   Subgrps                                     Rules
#> 1       3                X1 <= 0.016 & X2 <= -0.565
#> 2       5 X1 <= 0.016 & X2 > -0.565 & X50 <= -0.401
#> 3       6  X1 <= 0.016 & X2 > -0.565 & X50 > -0.401
#> 4       9  X1 > 0.016 & X2 <= 0.693 & X26 <= -0.383
#> 5      10   X1 > 0.016 & X2 <= 0.693 & X26 > -0.383
#> 6      11                   X1 > 0.016 & X2 > 0.693

真值只有 X1、X2 两个效应修饰变量。 用全部 50 个变量时树只切 X1、X2；过滤到 16 个之后反而多切出 X50 和 X26。

把每一刀的分裂 p 值挖出来，原因一目了然：

library(partykit)
split_p <- function(tr) {
  m <- tr$fit$mod
  inner <- setdiff(nodeids(m), nodeids(m, terminal = TRUE))
  do.call(rbind, lapply(inner, function(i) {
    info <- nodeapply(m, i, function(n) n$info)[[1]]
    data.frame(node = i,
               var  = names(info$test[1, ])[which.min(info$test["p.value", ])],
               p    = signif(min(info$test["p.value", ], na.rm = TRUE), 2))
  }))
}
split_p(s_full)
#>   node var       p
#> 1    1  X1 1.8e-12
#> 2    2  X2 2.5e-02
#> 3    5  X2 1.8e-05
split_p(s_filt)
#>   node var       p
#> 1    1  X1 5.6e-13
#> 2    2  X2 8.0e-03
#> 3    4 X50 6.2e-02
#> 4    7  X2 5.8e-06
#> 5    8 X26 3.4e-02
重要为什么少给变量反而切得更碎

MOB 的分裂检验对候选变量个数做 Bonferroni 校正。 候选从 50 个降到 16 个，等于把校正放松了 3 倍多， 原本过不了阈值的边缘变量就挤了进来。

再加上本包 lmtree 的默认 alpha 是 0.1（不是帮助页写的 0.05）， X50 那一刀的 p 值是 0.062——在 0.05 下会被拒绝，在 0.1 下被接受。

判别办法：真分裂的 p 值通常小几个数量级（这里是 \(10^{-13}\)、\(10^{-6}\)）， 挤进来的在 0.03–0.06 之间。用上面的 split_p() 把 p 值打出来， 比看树图可靠得多。

推荐做法：想找效应修饰变量时不要过滤（filter = "None"）， 把全部候选变量交给 MOB，让它自己的多重性校正发挥作用。 过滤留给 \(p \gg n\) 的场景，或者只用来做”看一眼有哪些变量相关”的探索。

默认配置在零假设下的表现

generate_subgrp_data(null = TRUE) 生成的数据里， 治疗效应恒为 0，不存在任何亚组。跑 20 次看默认 PRISM() 报什么：

set.seed(99)
sim <- t(sapply(1:20, function(i) {
  d <- generate_subgrp_data(n = 800, seed = 1000 + i, family = "gaussian", null = TRUE)
  r <- PRISM(Y = d$Y, A = d$A, X = d$X, verbose = FALSE)
  pd <- r$param.dat[r$param.dat$Subgrps != "ovrl", ]
  c(亚组数 = nrow(pd), 显著亚组数 = sum(pd$pval < 0.05, na.rm = TRUE))
}))
table(sim[, "亚组数"])
#> 
#> 3 4 5 6 
#> 5 8 5 2
colMeans(sim)
#>     亚组数 显著亚组数 
#>       4.20       0.75
mean(sim[, "显著亚组数"] > 0)
#> [1] 0.45
警告三个必须记住的数字
  • 20 次里没有一次报告”没有亚组”——树总是切得出东西来；
  • 平均每份数据报出 4.2 个亚组；
  • 45% 的数据里至少有一个亚组 \(p < 0.05\)。

param.dat$pval 是在同一份数据上找完亚组之后算的，没有任何多重性校正， 也没有对”亚组是选出来的”这件事做修正。它不能按名义水平解读。

而 1.0.7 里唯一的内建修正手段 calibrate = TRUE 是空操作。 所以实践中只有三条路： ① 用外部验证集；② 用 resample = "CV"； ③ 像上面这样自己做阴性对照，把经验阈值标定出来。

推荐工作流：在生存数据上找效应修饰变量

下面这套在 GBSG2 上跑一遍。这份数据里 progrec（孕激素受体）是文献公认的 效应修饰变量，pnodes（阳性淋巴结数）是强预后但非修饰因子—— 正好用来检验流程是否分得清两者。

data("GBSG2", package = "TH.data")
Ys   <- with(GBSG2, Surv(time, cens))
Xs   <- GBSG2[, !(colnames(GBSG2) %in% c("time", "cens", "horTh"))]
Anum <- as.numeric(GBSG2$horTh == "yes")   # 数值 0/1，rmst 需要

第 1 步：用交互项筛一遍，看排序

f  <- filter_train(Ys, Anum, Xs, family = "survival", filter = "glmnet",
                   hyper = list(interaction = TRUE))
cf <- coef(f$mod, s = f$mod$sel.lambda)[, 1]
cf <- cf[cf != 0]

round(cf[!grepl("_trtA$", names(cf))], 4)     # 主效应 = 预后
#>               age menostat_lvl_Post             tsize     tgrade_lvl_.L 
#>           -0.0019            0.0381            0.0918            0.1746 
#>     tgrade_lvl_.Q            pnodes           progrec                 A 
#>           -0.0798            0.2361           -0.2645           -0.1248
round(cf[ grepl("_trtA$", names(cf))], 4)     # 交互 = 效应修饰候选
#> tgrade_lvl_.L_trtA tgrade_lvl_.Q_trtA        pnodes_trtA       progrec_trtA

主效应里 pnodes 最大（0.247），交互项里 progrec_trtA 绝对值最大（0.162）。 两列的排序不同——这正是”预后”和”效应修饰”是两回事的直接证据。

区间仍然把 progrec > 21 那一组的获益排除在 0 之外，这是支持性证据。 但 numb_subs 的分布说明树的大小在重抽样之间波动很大： 观测数据上只切 1 刀，重抽样里常常切出 4–5 个亚组。

注记resamp_dist 的行标签是观测亚组

每次重抽样对每一个观测亚组各给一行估计（\(R \times\) 亚组数 + \(R\) 行 ovrl）， 而 numb_subs 记录的是那一次重抽样自己的树切出了几个亚组。 两者不相等说明：重抽样区间回答的是 “在重抽样数据上重新估计这批人的效应”有多不确定， 不是”重抽样能不能找到同样的亚组”。

后一个问题要看 numb_subs（树的大小是否稳定） 与 resamp_subgrps（每个人是否稳定落在同一组）。 包里有内部函数 subgrp_stability() 处理后者，但没有导出。

data("GBSG2", package = "TH.data")

## 1. 交互筛选：看候选排序，不用它做过滤

cf <- coef(f$mod, s = f$mod$sel.lambda)[, 1]; cf <- cf[cf != 0]

## 5. 置换对照：跑几十次，统计"切出东西"的频率
##    注意必须 tryCatch——一刀未切时本包报错而不是返回空结果
set.seed(11)
perm <- replicate(50, {
  r <- tryCatch(PRISM(Ys, sample(Anum), Xs, filter = "None",
                      submod.hyper = list(parm = 2), verbose = FALSE),
                error = function(e) NULL)
  if (is.null(r)) 0L else nrow(r$Rules)
})
mean(perm > 0)          # 置换零假设下"找到亚组"的经验频率

第 5 步：置换对照

把治疗标签随机打乱，真实的效应修饰信号应当消失。本包没有提供这一步， 但它是这套流程里最便宜也最有说服力的一环：

set.seed(11)
perm <- sapply(1:10, function(i) {
  ap <- sample(Anum)
  r <- tryCatch(PRISM(Y = Ys, A = ap, X = Xs, filter = "None",
                      submod.hyper = list(parm = 2), verbose = FALSE),
                error = function(e) NULL)
  if (is.null(r)) "一刀未切" else paste(nrow(r$Rules), "个亚组:", r$Rules$Rules[1])
})
table(perm)
#> perm
#> 一刀未切 
#>       10

10 次置换里 10 次都一刀未切——这正是正确答案： 治疗被打乱之后确实不存在效应修饰。

重要“没有亚组”这个正确答案，在本包里是一个报错

上面那 10 次全都走了 tryCatch 的错误分支。裸跑是这样：

set.seed(11); A_p <- sample(Anum)
PRISM(Y = Ys, A = A_p, X = Xs, filter = "None",
      submod.hyper = list(parm = 2), verbose = FALSE)
#> Error in rep(1, dim(Xtest)[1]): invalid 'times' argument

树没有分裂时 extract_rules() 拿到零行规则， PRISM() 随后走进一条需要 Xtest 的分支（补上 Xtest 也救不了）。 和 maxdepth = 1 是同一个根因，但这一次 它触发在最正常的使用场景里：数据中本来就没有效应修饰。

所以任何批量运行（模拟、置换、交叉验证）都必须用 tryCatch() 包住 PRISM()， 并把错误当成”未发现亚组”来统计，否则整个循环会在第一次遇到阴性结果时中断。

并不是每次置换都这么干净。换一个种子：

set.seed(1)
r_fp <- PRISM(Y = Ys, A = sample(Anum), X = Xs, filter = "None",
              submod.hyper = list(parm = 2), verbose = FALSE)
r_fp$Rules
#>   Subgrps       Rules
#> 1       2 estrec <= 8
#> 2       3  estrec > 8
r_fp$param.dat[, c("Subgrps", "N", "est", "SE", "pval")]
#>   Subgrps   N         est        SE        pval
#> 1       2 179  0.56557928 0.2012576 0.004950674
#> 2       3 507 -0.08911965 0.1501065 0.552706379
#> 3    ovrl 686  0.08171287 0.1227404 0.505803047

这一次它切在 estrec 上，而且其中一个”亚组”的 \(p = 0.005\)—— 比真实数据上那棵树的分裂 p 值（0.010）还小。 11 次置换里出现 1 次，与 lmtree 默认的 \(\alpha = 0.1\) 大致相符。

这就是为什么置换对照要跑几十次而不是一次： 单次阴性说明不了什么，单次阳性更说明不了什么，要看频率。
