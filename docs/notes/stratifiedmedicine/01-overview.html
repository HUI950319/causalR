1. 总览、对象结构与数据生成

StratifiedMedicine 包函数手册

本页先把包的边界说清楚：它依赖什么、导出了什么、四个步骤各自返回什么形状的对象； 再逐项说明 generate_subgrp_data()——后面七页的所有例子都建在它生成的数据上， 而它的真值在源码里是写死的，因此可以用来判断某个方法是找对了还是找错了。

包的边界

packageVersion("StratifiedMedicine")
#> [1] '1.0.7'
sort(getNamespaceExports("StratifiedMedicine"))
#>  [1] "filter_train"         "generate_subgrp_data" "param_combine"       
#>  [4] "param_est"            "ple_train"            "plot_dependence"     
#>  [7] "plot_importance"      "plot_ple"             "plot_tree"           
#> [10] "PRISM"                "submod_train"

11 个导出函数，加上 6 个 S3 方法（predict/summary/plot 各自的 PRISM、ple_train、submod_train 方法），正好是 CRAN 参考手册里的 17 个帮助主题。

依赖关系值得单独看一眼，因为它决定了哪些选项”装了包才有”：

类别 包 影响哪个选项
Imports（必装） glmnet filter = "glmnet"、ple = "glmnet"
ranger filter = "ranger"、ple = "ranger"（默认）
partykit submod = "lmtree"/"glmtree"/"ctree"/"ctree_cate"/"mob_weib"/"otr"
coin 生存结局下 lmtree 用的 log-rank 变换
survival family = "survival"、param = "cox"
ggplot2、ggparty 全部绘图函数
mvtnorm generate_subgrp_data()
Suggests（可选） rpart submod = "rpart"、"rpart_cate"
survRM2 param = "rmst"
BART ple = "bart"
sandwich 部分方差估计

也就是说，submod = "rpart_cate" 和 param = "rmst" 在只装了主包的机器上会缺依赖， 而它们分别是”两阶段 CATE 建树”和”生存结局的相加尺度”这两条重要路线的入口。

四步流水线的对象结构

四个步骤可以单独调用，也可以由 PRISM() 串起来。各自返回的对象如下：

函数 返回类 关键字段
filter_train() filter_train mod（模型）、filter.vars（留下的变量名）、filter
ple_train() ple_train fit（拟合对象）、mu_train、mu_test、ple、meta、family
submod_train() submod_train fit、Subgrps.train、Subgrps.test、Rules、trt_eff、out.train
param_est() data.frame Subgrps、N、estimand、est、SE、LCL、UCL、pval、alpha
PRISM() PRISM 上面全部，外加 param.dat、resamp_dist、trt_assign
注记帮助页的 Value 段落与实际字段名对不上

三个 *_train 函数的帮助页都把拟合对象写作 mod，实际字段是 fit：

dat <- generate_subgrp_data(family = "gaussian")
p <- ple_train(dat$Y, dat$A, dat$X, ple = "ranger", meta = "X-learner")
names(p)                 # 帮助页写的是 mod / mu_train / mu_test
#> [1] "fit"      "mu_train" "mu_test"  "ple"      "meta"     "family"

submod_train() 的帮助页还写了 pred.train / pred.test 两个字段，实际不存在； 真正能用的是 Subgrps.train / Subgrps.test 与 trt_eff。 只有 filter_train() 的 mod 名副其实。写代码时以 names() 为准。

generate_subgrp_data()

generate_subgrp_data(n = 800, seed = 513413, family, null = FALSE, ...)
参数 默认值 说明
n 800 样本量
seed 513413 随机种子。函数内部直接 set.seed(seed)，因此默认调用永远给出同一份数据
family 无默认，必填 "gaussian"、"binomial"；"survival" 见下文
null FALSE TRUE 时治疗效应恒为 0，且不存在任何亚组
... — 不传递任何东西

返回一个五元素列表：

dat <- generate_subgrp_data(family = "gaussian")
str(dat, max.level = 1)
#> List of 5
#>  $ Y      : num [1:800] 1.11 2.31 2.66 1.04 1.94 ...
#>  $ A      : int [1:800] 1 0 1 0 0 0 1 1 1 1 ...
#>  $ X      :'data.frame': 800 obs. of  50 variables:
#>  $ subgrps: chr [1:800] "[X1+ X2+]" "[X1+ X2+]" "[X1+ X2-]" "[X1- X2-]" ...
#>  $ PLE    : num [1:800] 0.65 0.65 0.45 0 0.45 0.25 0.45 0.65 0.65 0.25 ...

subgrps 与 PLE 是真值，正式分析里当然没有，但用来判断方法对错非常方便。

真值是什么

源码（StratifiedMedicine:::generate_subgrp_data）把结构写死了，这里摘出来：

  • \(X\) 是 50 维多元正态，\(\Sigma = 0.9 I + 0.1 J\)，即任意两个协变量相关系数 0.1；
  • \(A \sim \text{Bernoulli}(0.5)\)，与 \(X\) 独立——这是一份 RCT 数据，没有混杂；
  • 按 \(X_1, X_2\) 的中位数（\(\Phi^{-1}(0.5) = 0\)）切成四个亚组。

连续结局：

\[ \mu = 1.5 + \tau(X_1, X_2)\cdot A + 0.15\tilde X_1 + 0.20\tilde X_2 + 0.10\tilde X_3 + 0.10\tilde X_5 + 0.10\tilde X_7, \qquad Y \sim N(\mu, 1) \]

其中 \(\tilde X\) 是标准化后的协变量，\(\tau\) 就是真 CATE：

table(dat$subgrps)
#> 
#> [X1- X2-] [X1- X2+] [X1+ X2-] [X1+ X2+] 
#>       219       201       178       202
tapply(dat$PLE, dat$subgrps, unique)
#> [X1- X2-] [X1- X2+] [X1+ X2-] [X1+ X2+] 
#>      0.00      0.25      0.45      0.65

于是真值可以列成一张表——这张表是后面所有”找对了没有”判断的依据：

变量 预后作用（影响基线 \(\mu\)） 效应修饰作用（影响 \(\tau\)）
X1 ✅ 0.15 ✅
X2 ✅ 0.20 ✅
X3、X5、X7 ✅ 0.10 ❌
其余 45 个 ❌ ❌

注意 X3、X5、X7 是纯预后变量：它们跟结局有关，但跟治疗效应无关。 一个工具如果把它们报成”重要”，说明它测的是预后而不是效应修饰。

二值结局用同一套亚组结构，但效应定义在 logit 尺度上 （\(b_0 = \text{logit}(0.3)\)，三个亚组的 log-OR 分别是 1.3 / 0.9 / 0.5）， PLE 字段给的是换算到风险差尺度之后的值：

datb <- generate_subgrp_data(family = "binomial")
tapply(datb$PLE, datb$subgrps, unique)
#> [X1- X2-] [X1- X2+] [X1+ X2-] [X1+ X2+] 
#> 0.0000000 0.1140378 0.2131725 0.3112815
mean(datb$Y)
#> [1] 0.39875

预后系数也更大（0.5 / 0.5 / 0.3 / 0.3 / 0.3），因为二值结局信息量更低。

family = "survival" 会报错

帮助页写 family 的取值是 "gaussian"、"binomial"、"survival"。 但源码里生存那一支是空的：

if (family == "survival") {
}
return(list(Y = Y, A = A, X = X, subgrps = subgrps, PLE = PLE))

于是 Y、PLE 从未被赋值，函数在 return() 处失败：

generate_subgrp_data(family = "survival")
#> Error in generate_subgrp_data(family = "survival"): object 'Y' not found

要做生存结局的例子，只能自己找数据。 官方帮助页的生存示例用的是 TH.data::GBSG2（德国乳腺癌研究组第 2 号试验，n = 686，299 个事件）， 本手册后面也沿用它：

library(survival)
data("GBSG2", package = "TH.data")
Y_surv <- with(GBSG2, Surv(time, cens))
X_surv <- GBSG2[, !(colnames(GBSG2) %in% c("time", "cens", "horTh"))]
A_surv <- GBSG2$horTh          # 真实的内分泌治疗分配
str(X_surv)
#> 'data.frame':    686 obs. of  7 variables:
#>  $ age     : int  70 56 58 59 73 32 59 65 80 66 ...
#>  $ menostat: Factor w/ 2 levels "Pre","Post": 2 2 2 2 2 1 2 2 2 2 ...
#>  $ tsize   : int  21 12 35 17 35 57 8 16 39 18 ...
#>  $ tgrade  : Ord.factor w/ 3 levels "I"<"II"<"III": 2 2 2 2 2 3 2 2 2 2 ...
#>  $ pnodes  : int  3 7 9 4 1 24 2 1 30 7 ...
#>  $ progrec : int  48 61 52 60 26 0 181 192 0 0 ...
#>  $ estrec  : int  66 77 271 29 65 13 0 25 59 3 ...
警告官方生存示例里的治疗是随机生成的

PRISM 帮助页的生存示例是这么写的：

X = surv.dat[, !(colnames(surv.dat) %in% c("time", "cens"))]
set.seed(513)
A = rbinom(n = dim(X)[1], size = 1, prob = 0.5)

也就是说，它把 horTh 留在了 X 里，然后另外掷硬币造了一个治疗变量。 这个 A 与结局完全独立，任何”亚组治疗效应”都只可能是噪声。 本手册在需要展示真实信号时改用 A = GBSG2$horTh，并把它从 X 中移除； 只有在复现帮助页输出时才沿用随机 A，并会明确标注。

null = TRUE：一份没有任何信号的数据

dnull <- generate_subgrp_data(family = "gaussian", null = TRUE)
unique(dnull$PLE)
#> [1] 0

这份数据的用途是做阴性对照。任何在它上面”找到”的亚组都是假阳性。 第 8 页会用它来量化默认配置的假阳性率—— 剧透一下：默认 PRISM() 在完全没有信号的数据上照样报出 5 个亚组， 其中两个在 \(\alpha = 0.05\) 下”显著”。

一次完整的流水线

把四步拆开写一遍，能看清 PRISM() 内部到底发生了什么：

Y <- dat$Y; A <- dat$A; X <- dat$X

## ① filter：50 → 16
f <- filter_train(Y, A, X, filter = "glmnet")
f$filter.vars
#>  [1] "X1"  "X2"  "X3"  "X5"  "X7"  "X8"  "X10" "X12" "X16" "X18" "X24" "X26"
#> [13] "X31" "X40" "X46" "X50"

## ② ple：每人一行反事实量
set.seed(1)
p <- ple_train(Y, A, X, ple = "ranger", meta = "X-learner")
head(round(p$mu_train, 3), 3)
