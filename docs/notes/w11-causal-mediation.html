第 23 章 · 把中介问题改写成能做的试验

Causal mediation · 因果中介

原书：Hernán & Robins, Causal Inference: What If（2025-01-02 版）， 第 23 章，书页 317–325。本章是原书最后一章。本页是读书笔记，非原书译文。

第三部分前四章问的都是「不同策略下结局会怎样」，不问「处理是怎么起作用的」。 最后一章转向后者：

因果中介的研究可以看成时变处理因果推断的一个特例。 不同之处在于：这里不是一个处理在不同时间取不同的值， 而是两个不同的变量——所关心的处理与中介——分处不同的时间。

— What If, §23 章首, p.317

而这一章要主张的东西，书在开头就亮了出来：

与其它基于纯直接效应与总间接效应的中介方法不同， 一个干预主义的中介框架为因果估计打开了经验验证的大门—— 而这对任何科学事业来说都是一个值得追求的条件。

— What If, §23 章首, p.317

全章地图（笔记作者绘制，原书无此图）。 本章的论证形状与前几章都不同：它不是「给出一个新估计量」， 而是「换一个问题，使得同一个公式变得可以被反驳」。 地图中段那一格——「同一个数，换了一个解释」——是全章的枢纽。

23.1 中介分析遭到的质疑：一个任何试验都验不了的量

设想一项随机试验：吸烟者被随机分配到戒烟（\(A = 0\)）或继续吸烟（\(A = 1\)）， 依从完美。研究者发现戒烟降低了 1 年心梗风险 \(Y\)，即 \(E[Y\mid A=1] > E[Y\mid A=0]\)。

接着他们想问：这个获益是不是因为 \(A\) 降低了高血压 \(M\)？ （\(M\) 在 6 个月时测量；为简单起见，假设前 6 个月无人发生结局。） 图 23.1 就是这三个变量的因果图—— 前提是「对 \(M\) 的干预是足够良好定义的」。

Figure 23.1 与 23.2（照原图重绘，粗箭头照原图表示确定性关系）。 图 23.2 里缺席的两条箭头就是两条实质假设： 缺 \(N \to Y\) = 尼古丁对结局没有直接效应；缺 \(O \to M\) = 非尼古丁成分对中介没有效应。

纯直接效应与总间接效应

名称 定义 Pearl (2001) 的叫法
纯直接效应 \(E\left[Y^{a=1,M^{a=0}}\right] - E\left[Y^{a=0,M^{a=0}}\right]\) 自然直接效应
总间接效应 \(E\left[Y^{a=1,M^{a=1}}\right] - E\left[Y^{a=1,M^{a=0}}\right]\) 自然间接效应

两者之和 \(E\left[Y^{a=1,M^{a=1}}\right] - E\left[Y^{a=0,M^{a=0}}\right]\) 由一致性等于总效应 \(E[Y^{a=1}] - E[Y^{a=0}]\)。 （这两个概念由 Robins & Greenland (1992) 引入。）

翻成人话：

在我们的例子里，纯直接效应是「如果我们能给每个人指派『她戒烟时本会有的那个高血压状态 \(M\)』， 戒烟 \(A\) 还剩下多少效应」。这个 \(M\) 值对实际戒了烟的人是已知的， 对继续吸烟的人则始终未知。

— What If, §23.1, p.318（复述）

「跨世界量」到底跨在哪里

因此我们说 \(E\left[Y^{a=1,M^{a=0}}\right]\)、以及纯直接效应，是一个跨世界量， 因为它涉及一个同时被两个处理值 \(a=1\) 与 \(a=0\) 索引的反事实结局， 而这两个值不可能在同一个世界里对同一个人同时发生。

— What If, §23.1, p.318

而识别它所需的那条假设，正好也是跨世界的：

中介公式的证明需要一条不可验证的假设： 某些定义在不同世界里的反事实变量是相互独立的。 具体地说，证明要求「在一个把处理设为 1、把中介设为 \(m\) 的世界里的结局 \(Y^{a=1,m}\)」 独立于「在一个把处理设为 0 的世界里的中介 \(M^{a=0}\)」。 因此，\(Y^{a=1,m}\) 与 \(M^{a=0}\) 不可能在单一世界里对同一个人被同时观察到， 它们的独立性在任何对 \(A\) 与 \(M\) 单独或联合随机化的试验中都无法被经验验证。

— What If, §23.1, p.318–319

中介公式

在图 23.1（\(M\) 与 \(Y\) 无未测共同原因）之下，那个跨世界量由中介公式识别：

\[E\left[Y^{a=1,M^{a=0}}\right] = \sum_m E[Y\mid A=1, M=m]\ \Pr[M=m\mid A=0]\]

Technical Point 23.1：三行证明，关键在中间那一行

\[\begin{aligned} E\left[Y^{a=1,M^{a=0}}\right] &= \sum_m E\left[Y^{a=1,m}\mid M^{a=0}=m\right]\Pr\left[M^{a=0}=m\right] && \text{概率的运算法则} \\ &= \sum_m E\left[Y^{a=1,m}\right]\Pr\left[M^{a=0}=m\right] && \textbf{跨世界条件独立 } Y^{a=1,m}\perp\!\!\!\perp M^{a=0} \\ &= \sum_m E[Y\mid A=1,M=m]\Pr[M=m\mid A=0] && \text{可交换性与一致性} \end{aligned}\]

上面用到的这条跨世界条件独立，在因果图代表一个 NPSEM-IE 时被假设成立， 在它代表一个 FFRCISTG 模型时则不成立。

— What If, Technical Point 23.1, p.318

第一行与第三行都是常规操作，全部重量压在第二行上。

这就是本书偏好 FFRCISTG 的理由

这些跨世界独立性在 NPSEM-IE 下被假设成立，在 FFRCISTG 模型下则不然。 这正是我们偏好 FFRCISTG 而非 NPSEM-IE 的一个理由： 因为跨世界独立性无法被任何随机试验验证， 我们希望使用那些结果在原则上可被验证的因果推断方法。

— What If, §23.1, p.319

边注补了 FFRCISTG 下的处境：纯直接效应与总间接效应不是点识别的， 但可以得到尖锐的界（Robins & Richardson 2010）。 另有一条边注提到：在某些非常不寻常的情形下，交叉设计试验可以识别这个跨世界量 （见 Fine Points 2.1 与 3.2）。

于是质疑就来了：

基于以上讨论，一些政策制定者对「研究者能识别纯直接效应」这件事无动于衷。 作为一个跨世界参数，他们觉得纯直接效应没有政策或公共卫生意义， 因为它不对应任何干预。要说服这些怀疑者，NPSEM-IE 的拥护者还得更努力些。

— What If, §23.1, p.319

注意书在这里的姿态：它没有说中介分析是错的， 它说的是「这个量不对应任何你能做的事」——这是全书一以贯之的标准。

23.2 为中介分析辩护：把处理拆成两个可以分别干预的成分

书让 NPSEM-IE 的拥护者讲了一个故事——而这个故事最后救的不是 NPSEM-IE，是中介公式本身：

「假设从一年后开始，无尼古丁香烟将上市，而你的政策目标是尽快了解无尼古丁香烟的获益。 为此，我们用上面那项戒烟试验已经收集好的数据，来估计 『要求所有吸烟者改抽无尼古丁香烟』这一干预之下的两年心脏病风险 \(Y\)。 假设有强有力的试验证据表明： (i) 尼古丁对结局 \(Y\) 的全部因果效应都通过它对中介 \(M\)（高血压）的效应； (ii) 香烟中的非尼古丁成分对中介 \(M\) 没有直接因果效应。 在 (i) 与 (ii) 之下，一个抽无尼古丁香烟者的高血压状态 \(M\)， 将等于她在完全不暴露于香烟时的高血压状态， 于是 \(E\left[Y^{a=1,M^{a=0}}\right]\) 就是 『若所有吸烟者一年后都改抽无尼古丁香烟』时吸烟者的心脏病风险。 那正是你关心的公共卫生效应，而这正是中介公式应用到我们的数据上会算出来的东西。」

— What If, §23.2, p.319（原书以引号整段呈现）

书对这个故事的第一反应，值得逐字记下

这很有意思。 为了论证参数 \(E\left[Y^{a=1,M^{a=0}}\right]\) 的实质重要性， NPSEM-IE 的拥护者讲了一个关于「干预香烟尼古丁含量」的故事—— 而这个干预根本没有提到中介 \(M\)。 另外，他们还对根本没被画进图 23.1 的那些变量做了「无直接效应」的假设 (i) 与 (ii)。

— What If, §23.2, p.319

这两句是全章最精彩的转折：辩护词本身已经不是中介分析了，它是一个关于可分成分的干预问题。

于是书把这个故事正面接受下来，并给它配了一张图：处理 \(A\) 可以分解成两个可分成分

  • \(N\)：尼古丁暴露，直接影响 \(M\) 但不影响 \(Y\)；
  • \(O\)：香烟中其它非尼古丁成分的暴露，直接影响 \(Y\) 但不影响 \(M\)；
  • 两者在原则上可以被分别干预：\(Y^{n=0,o=1}\) 就是「只去掉尼古丁成分」那个干预下的反事实结局。

图 23.2 里 \(A \to N\)、\(A \to O\) 是粗箭头，表示确定性关系： 在实际试验数据里，要么继续抽普通烟（\(A = N = O = 1\)），要么戒烟（\(A = N = O = 0\)）。 缺 \(N \to Y\) 编码假设 (i)，缺 \(O \to M\) 编码假设 (ii)—— 边注说明这两条都是「无受控直接效应」假设。 图 23.3 是对应的 SWIG（\(A \to N\mid n \to M^{n,o}\)、\(A \to O\mid o\)、\(M^{n,o} \to Y^{n,o}\)、\(O\mid o \to Y^{n,o}\)）。

Technical Point 23.2：正性不成立，但仍然可识别

这一条是本章技术上最漂亮的地方。按图 23.3，\(N\) 与 \(O\) 的可交换性成立， 所以 \(E\left[Y^{n=0,o=1}\right]\) 可由 g-公式识别。但是：

然而，在正文描述的那项戒烟试验里，没有任何个体有 \((N=0, O=1)\) 的数据。 因此正性不成立，看起来 g-公式无法识别 \(E[Y^{n=0,o=1}]\)。 但是，给定可交换性与一致性，正性只是 g-公式可识别的充分条件、而非必要条件； 识别只要求 g-公式是观测数据分布的一个函数。

— What If, Technical Point 23.2, p.320

而确定性关系正好提供了这一点：\(E[Y^{n=0,o=1}]\) 的 g-公式是

\[\sum_m E[Y\mid O=1, M=m]\ \Pr[M=m\mid N=0]\]

（\(N\) 不是 \(Y\) 的父节点、\(O\) 不是 \(M\) 的父节点，所以各自可以从对应的条件事件里去掉）， 而在数据里 \(O=1\) 当且仅当 \(A=1\)、\(N=0\) 当且仅当 \(A=0\)，于是它可以改写成

\[\sum_m E[Y\mid A=1, M=m]\ \Pr[M=m\mid A=0] \qquad =\ \textbf{中介公式}\]

书自己承认这个推导因确定性带来的零测集而略显启发式， 严格证明见 Robins et al. (2022)（用 Technical Point 21.12 的 SWIG 马尔可夫性质）。

这条 Technical Point 值得单独记住一句：「正性不成立」不等于「不可识别」—— 当模型里有确定性关系时，g-公式仍可能落在观测数据分布的像里。

这个故事到底贡献了什么：两种人，两种收获

原本就接受 NPSEM-IE 的人

\(E\left[Y^{a=1,M^{a=0}}\right]\) 本来就已被中介公式识别， 所以可分成分的故事对识别没有任何贡献。

它只起到一个作用：表明参数 \(E\left[Y^{a=1,M^{a=0}}\right]\)—— 因而纯直接效应与总间接效应——编码了一个具有公共卫生意义的参数 \(E\left[Y^{n=0,o=1}\right]\)。

— What If, §23.2, p.321

持 FFRCISTG 立场的人

这个故事既给了 \(E\left[Y^{a=1,M^{a=0}}\right]\) 一个干预解释 （它就是 \(E\left[Y^{n=0,o=1}\right]\)）， 又让这两个均值都通过 g-公式（等价地，中介公式）变得可识别。

而且：当我们把「缺一条箭头」解释成「对所有个体都无直接因果效应」时， \(Y^{a=1,M^{a=0}}\) 与 \(Y^{n=0,o=1}\) 对每个个体都相等。

这套刻画还顺手定义了两个新效应：

名称 定义 等于
成分 \(N\) 的可分直接效应 \(E[Y^{n=1,o=1}] - E[Y^{n=0,o=1}]\) 对成分 \(N\) 而言是一个受控直接效应；也等于总间接效应 \(E[Y^{a=1}] - E\left[Y^{a=1,M^{a=0}}\right]\)
（另一侧） \(E[Y^{n=1,o=1}] - E[Y^{n=1,o=0}]\) 等于纯直接效应 \(E\left[Y^{a=1,M^{a=0}}\right] - E[Y^{a=0}]\)

注意这张表的方向：跨世界的那两个效应被翻译成了两个「单世界」的干预对比。 这就是「干预主义」这个词的全部含义。

23.3 可以被经验反驳的中介：做一个三臂试验

\(E\left[Y^{a=1,M^{a=0}}\right]\) 的干预解释只在「\(N\) 与 \(O\) 可分效应的故事是对的」 且图 23.3 表示一个 FFRCISTG 时才成立。 干预解释的一个优势在于：这个故事的有效性在原则上可以被一项随机试验经验地反驳。

— What If, §23.3, p.321

做法很具体：一年后无尼古丁香烟上市，做一项三臂随机试验——

臂 干预 与原试验的关系
1 戒烟 \(A = N = O = 0\) 与原试验同一臂
2 继续抽普通烟 \(A = N = O = 1\) 与原试验同一臂
3 抽无尼古丁香烟 \(N = 0,\ O = 1\) 新增的那一臂

（无时间趋势时，前两臂的均值在两项试验里应当相同；假设两项试验的样本量都大到可以忽略抽样变异。）

由随机化，新试验里的 \(E[Y\mid N=0, O=1]\) 应当等于 \(E[Y^{n=0,o=1}]\)。于是：

因此，如果我们的故事是对的，我们预期 \(E[Y\mid N=0,O=1]\) 会等于由前一项试验算出的中介公式。 否则，\(N\) 与 \(O\) 的故事就被经验地反驳了，这意味着下列假设中至少有一条不成立： (i) 尼古丁对结局无直接效应；(ii) 其它非尼古丁成分对中介无直接效应； (iii) 图 23.2 上 \(M\) 与 \(Y\) 之间无未测共同原因 \(U\)。

— What If, §23.3, p.321

而且还能进一步查出是哪一条错了：

检验 若成立，则
\(E[M\mid N=0,O=1] - E[M\mid N=0,O=0] \ne 0\) 假设 (ii) 被反驳，应当把 \(O \to M\) 加进图 23.2（以及对应 SWIG）
\(E[Y\mid N=1,O=1,M=m] - E[Y\mid N=0,O=1,M=m] \ne 0\)（对某些 \(m\)） 假设 (i) 被反驳（应加 \(N \to Y\)），或者存在 \(M\) 与 \(Y\) 的未测共同原因 \(U\)

Fine Point 23.1：要分清 (i) 与 (iii)，得再做一个八臂试验

要判定这两条假设中哪一条为假，我们需要另一项随机试验，比如说八个臂， 其中我们对 \(M\) 也进行干预，同时干预 \(N\) 与 \(O\)。 如果 \(N\) 除了通过 \(M\) 之外对 \(Y\) 没有直接效应，那么在八臂试验里 给定 \(M\) 与 \(O\) 时 \(N\) 将与 \(Y\) 独立。 如果 \(M\) 与 \(Y\) 不共享未测共同原因，那么给定 \(N\) 与 \(O\) 时 \(Y\) 关于 \(M\) 的条件分布， 在三臂试验与八臂试验里应当相同。

— What If, Fine Point 23.1, p.322

还有一个看起来自相矛盾的地方，书专门解释了： 既然我们假设图 23.1 是一个「\(M\) 与 \(Y\) 无共同原因」的 FFRCISTG， 图 23.2 怎么还可能漏掉一个 \(M\) 与 \(Y\) 的未测共同原因？

解释是：共同原因可能只在「给不同人指派不同 \(N\) 与 \(O\) 值」的干预之下才出现（即活跃）。 与图 23.2 所关联的 FFRCISTG 不同，图 23.1 所关联的 FFRCISTG 只考虑 \(A=N=O=1\) 与 \(A=N=O=0\) 这两种「给每个人指派相同值」的干预。

— What If, Fine Point 23.1, p.322

而且这时还有一个很细的结论：若 \(U\) 是新试验结果与中介公式不一致的唯一原因， 则对每个个体仍有 \(Y^{n=0,o=1} = Y^{a=1,M^{a=0}}\)， 但 \(E[Y^{n=0,o=1}] = E\left[Y^{a=1,M^{a=0}}\right]\) 不再由中介公式识别。 （Robins et al. (2022) 给了一个关于河盲症治疗的、假想但现实的研究， 在那里图 23.1 是 FFRCISTG 而图 23.2 不是。）

如果对不上，不同立场的人会怎么反应

两种人都会同意的

\(N\) 与 \(O\) 可分效应的故事是错的， 且 \(E[Y^{n=0,o=1}]\) 应当由新试验第三臂的均值估计， 而不是由早先那项试验的中介公式估计。

两种人的分歧

NPSEM-IE 阵营：可以继续相信 \(E\left[Y^{a=1,M^{a=0}}\right]\) 仍等于中介公式， 但他们无法再用「无尼古丁香烟的效应」来正当化纯直接效应的政策意义。

FFRCISTG 阵营：可能对原来那个中介公式兴趣不大， 他们感兴趣的是从三臂试验里学到的无尼古丁香烟的效应， 以及「(i)(ii)(iii) 中至少有一条为假」这个发现本身。

一个否定的回答，而且它的论证方式很值得学

书最后问：既然这次故事错了，那么处理 \(A\) 是不是总能被分解成另外某对 （可能未知的）可干预成分 \(N'\)、\(O'\)，使得图 23.2 是 FFRCISTG、 且两条无直接效应假设成立，从而 \(E[Y^{n'=0,o'=1}]\) 等于 \(E\left[Y^{a=1,M^{a=0}}\right]\)、两者都等于中介公式？

答案是否定的，因为若总能如此， \(E\left[Y^{a=1,M^{a=0}}\right]\) 就总是被中介公式点识别了，而事实并非如此。

— What If, §23.3, p.323

边注把这个反证补完：若 \(E\left[Y^{a=1,M^{a=0}}\right]\) 总是被中介公式点识别， 那么 Robins & Richardson (2010) 给出的尖锐界就会被违反。

这是一个纯粹的「不可能性」论证：用一个已知的界，反推「万能分解」不存在。 它也顺带说明了为什么可分成分的故事必须是实质性的（substantive）—— 它不是一个可以随手编出来的数学技巧。

23.4 干预主义的中介理论：五条要点，与一句坦白

本章引入了一种干预主义的因果中介理论，它不同于基于纯直接效应与总间接效应的标准做法。 由于干预主义理论是针对标准理论被认为存在的缺陷而发展起来的， 我们先描述了标准理论及其依赖跨世界（嵌套）反事实的问题所在。 然而，干预主义理论可以被视为自主的： 它提供了一个不需要引用跨世界嵌套反事实就能讨论中介的自足框架。

— What If, §23.4, p.323

关键想法只有一句：把中介问题重新表述成「对处理 \(A\) 的、实质上有意义的可分成分 \(N\) 与 \(O\) 做干预，对 \(Y\) 有什么效应」的问题。

若 \(N\) 与 \(O\) 确实是 \(A\) 的可分效应，那么在一项未来的六臂试验里 （\(a=1\)；\(a=0\)；\(n=1,o=1\)；\(n=0,o=0\)；\(n=0,o=1\)；\(n=1,o=0\)），下面两句话为真：

  1. 第 1 臂的结局均值等于第 3 臂的，第 2 臂的等于第 4 臂的；
  2. \(E[Y^{n=0,o=1}]\) 由第 5 臂的均值识别，\(E[Y^{n=1,o=0}]\) 由第 6 臂的均值识别—— 无论 \(E[Y^{n=0,o=1}]\) 是否能从观测数据中识别。

（边注：Stensrud et al. (2021) 强调了第 1 句那些跨臂均值相等的必要性—— 它们正是这套理论可被反驳的地方。）

而用现有的 \(A\)、\(M\)、\(Y\) 数据去识别可分效应，需要的假设是： (i) \(M\) 与 \(Y\) 无未测共同原因；(ii) \(O\) 对 \(M\) 无直接效应、\(N\) 对 \(Y\) 无直接效应。 此时 \(E[Y^{n=0,o=1}]\) 就等于中介公式。

偏好干预主义的另一个理由：对 \(M\) 的干预常常根本不存在

我们现在讨论另一个偏好干预主义方法的理由。具体地说，常常出现的情况是： 对所谓中介 \(M\) 的干预并非良好定义，于是 \(Y^{a,m}\) 这样的反事实就没有意义。 那么基于 \(M\) 的纯直接效应与受控直接效应都不存在。 相比之下，干预主义理论关心的是那些确实存在的效应—— 只要实质上有意义的可分成分 \(N\) 与 \(O\) 存在并且能被干预。

— What If, §23.4, p.324

这一条把第 3 章「良好定义的干预」那条要求推到了终点： 「降低血压」听起来像一个干预，但「用哪种方式降」不同则效应不同； 而「去掉香烟里的尼古丁」是一个具体的、可制造的东西。

书把这套方法的要点列成了五条（逐条照录）：

干预主义中介方法的组成部分
① 假设处理 \(A\) 可以被分解成多个实质上有意义的可分成分，每个成分都对处理的总体效应有贡献，且原则上可以被独立干预
② 识别这些可分成分效应所需的假设，原则上可以在「真正对这些成分施加干预」的未来随机试验中被经验验证
③ 对所谓中介的良好定义干预不必存在
④ 由于可分成分具有实质上的具体性，与领域专家的沟通得到改善
⑤ 当识别假设成立时，用于识别的 g-公式与中介公式完全相同；但被识别的因果效应指的是对可分成分的干预

书补了一句：为简单起见这里只用了两个可分成分， 但干预主义框架可以容纳多个可分成分，包括随时间变化的那些。

Fine Point 23.2：如果 \(M\) 只是真中介的代理

\(M \to Y\) 这条箭头只在「对 \(M\) 的干预良好定义」时才有因果解释。 当这样的干预不存在时，图 23.1 就不是一张因果图—— \(M\) 不是中介，而是某个未知真中介 \(H\) 的代理（图 23.4：\(A \to H \to Y\)、\(H \to M\)、\(A \to Y\)）。

图 23.5 是图 23.4 加上可分成分 \(N\)、\(O\) 的版本。与图 23.2 不同， 在图 23.5 里给定 \(M\) 与 \(O\) 时 \(N\) 与 \(Y\) 并不 d-分离。 那么，如果三臂试验数据里居然观察到给定 \(M\) 与 \(O\) 时 \(N\) 与 \(Y\) 独立，该怎么解释？ 书给了四种可能：

a) 我们搞错了，真正的因果图是 23.1 而不是 23.4，\(M\) 就是真中介； b) \(M\) 是真中介 \(H\) 的一一确定性函数； c) 图 23.4 里存在一处非确定性的忠实性违反； d) \(N\) 与 \(O\) 并非条件独立，只是三臂试验样本量太小没检测出来。

因果发现的拥护者，在三臂试验样本量很大时会倾向于采纳解释 a)。

— What If, Fine Point 23.2, p.324

这条边栏把第 10 章 Technical Point 10.7（有限样本给因果发现判的刑） 与第 9 章 §9.5（非因果箭头）一起接了回来——全书在最后一章把伏笔收了。

Technical Point 23.3：同一套手法还能把前门公式再证一遍

本章的技术手法（引入一个与真实变量确定性相关的新干预变量）不止能用在中介上。

在图 23.6（图 9.14 加上 \(L \to Y\) 边）下，\(L\) 对 \(Y\) 的总效应不可识别—— \(L \to Y\) 这条通路的贡献无法与 \(H\) 的混杂效应分开。 但如果只问沿着 \(L \to A \to Y\) 这条通路的效应呢？

书把 Fine Point 9.5 里的实质故事扩展成图 23.7： \(N\) 记录「报告给开药医生的 BMI 值」，\(O\) 记录「用于决定转诊理疗与营养咨询的 BMI 值」， 粗箭头表示在观测数据里恒有 \(L = N = O\)。 图 23.8 是一个（不合伦理的）SWIG：向医生报告了一个与真实 \(L = N\) 不同的 \(n\)， 而转诊仍用真实值 \(L = O\)。 于是对 \(n\) 的干预对 \(Y\) 的效应被限制在经由 \(A\) 的那条通路上。

由 \(Y^n \perp\!\!\!\perp N \mid L\)，\(E[Y^n]\) 的 g-公式为

\[\sum_{l,a} E[Y\mid A=a, L=l]\Pr[L=l]\Pr[A=a\mid N=n] = \sum_a\left\{\sum_l E[Y\mid A=a,L=l]\Pr[L=l]\right\}\Pr[A=a\mid L=n]\]

（最后一步用了数据中 \(L \equiv N\) 的确定性）——右边正是前门公式。

书自己评论了一句很重要的话：

从实质上说，人们一般不会把 \(N\) 与 \(O\) 看成 \(L\) 的可分成分。但那无关紧要。 要紧的是：我们的实质因果故事蕴含了一张扩展图 23.7， 其中包含一个在真实世界里与 \(L\) 确定性相关的新干预变量 \(N\)。

— What If, Technical Point 23.3, p.325

（Stensrud et al. 2023；Wen et al. 2023 独立地同时得到了本质等价的结果； Fulcher et al. (2020) 更早证明了前门公式在图 23.6 关联的 NPSEM-IE 下识别跨世界量 \(E\left[Y^{L, A^{l=n}}\right]\)——本条与 Wen et al. 都可以看成对该结果的干预主义重述。）

全书的最后一段，是一句坦白

在没有「真正对中介（受控直接效应）或对处理成分（可分直接效应）施加干预」的随机试验时， 所有这些方法学都依赖观察数据，因而依赖本书通篇讨论的那些可交换性假设。 因此，有效的中介分析要求对「处理的效应」与「中介的效应」的混杂因子都做调整， 此外还要加上本章讨论的其它假设。 我们的图 23.1 是作为一个教学装置，用来在简化情境下探讨与中介有关的理论问题， 而不是对大多数因果中介研究的现实表示。 在实践中，因果中介分析是观察性分析，它依赖的假设比非中介分析更加英勇（heroic）。

— What If, §23.4, p.325（全书正文的最后一段）

这章停在哪里，以及全书停在哪里

第 23 章没有给出新的估计量——它给出的是一种把问题重写的办法：

标准中介分析 干预主义中介
估 \(E\left[Y^{a=1,M^{a=0}}\right]\)，一个跨世界量 估 \(E\left[Y^{n=0,o=1}\right]\)，一个单世界的干预
识别靠任何试验都验不了的跨世界独立性（NPSEM-IE） 识别靠两条无直接效应假设 + 无未测共同原因（FFRCISTG）
无法被经验反驳 可以被三臂试验反驳，还能进一步定位是哪条假设错
要求对 \(M\) 的干预良好定义 不要求；只要 \(N\)、\(O\) 实质上有意义且可干预
与领域专家难以沟通 可分成分是具体的东西（尼古丁 / 非尼古丁成分）
— 识别公式完全相同——都是中介公式

最后一行是全章的落点：两种立场算出来的是同一个数， 区别在于这个数代表什么、以及它能不能被将来的试验证伪。

自检① 「这个效应有多少是通过 X 中介的」——这句话哪里有问题？

按本章的标准，逐条检查：

  1. 对 \(M\) 的干预良好定义吗？ 「把血压设为 \(m\)」——用什么方式设？ 不同方式效应不同的话，\(Y^{a,m}\) 就没有唯一含义（Fine Point 23.2 的 \(H\) 与 \(M\)）。
  2. 你要的是跨世界量吗？ 纯直接效应 / 自然直接效应是跨世界的， 它不对应任何你能做的干预，其识别假设原则上不可被任何随机试验检验。
  3. \(M\) 与 \(Y\) 之间有没有未测共同原因？ 有的话，所有直接效应（含受控直接效应）都不可识别。
  4. 能不能把 \(A\) 拆成实质上有意义、原则上可分别干预的成分？ 能，就把问题改写成可分效应；不能，就承认这个中介问题目前没有可被反驳的表述。

第 4 问是本章真正的贡献：它把「我要不要做中介分析」 换成了「我能不能说出一个未来可以做的试验」。

自检② 为什么说「同一个公式，换了一个解释」是一件大事？

因为可反驳性。中介公式在两种立场下算出的数完全相同，但是：

  • 在 NPSEM-IE 下，它估的是 \(E\left[Y^{a=1,M^{a=0}}\right]\)—— 没有任何试验能检验它估得对不对；
  • 在可分效应的故事下，它估的是 \(E\left[Y^{n=0,o=1}\right]\)—— 一项三臂试验就能把它证伪（\(E[Y\mid N=0,O=1]\) 对不上就是对不上）。

而且反驳之后还有东西可学：两个具体检验能告诉你是假设 (i)、(ii) 还是 (iii) 出了问题 （要彻底分开 (i) 与 (iii) 还需要一个八臂试验，Fine Point 23.1）。

这正是全书从第 3 章「良好定义的干预」一路坚持的那条标准： 一个因果量的价值，取决于它能不能被某个可以想象的试验检验。

自检③ 读完这本书，我手里到底有什么？

按三部分归位：

  • 第一部分（1–10 章）：没有模型的因果推断。 三条识别条件（可交换性、正性、一致性）、DAG 与四类偏倚结构、随机变异。 这一部分决定了「你的问题能不能被回答」。
  • 第二部分（11–18 章）：有模型的因果推断。 IP 加权、标准化 / g-公式、g-估计、倾向评分、工具变量、生存分析、变量选择。 这一部分决定了「在高维数据里怎么把它算出来」。
  • 第三部分（19–23 章）：时变处理。 策略取代了「处理值」，序贯可交换性取代了可交换性， g-方法取代了分层与回归，目标试验协议取代了「分析计划」， 而中介问题被改写成了可分成分的干预问题。

而贯穿三部分的只有一句话： 先把你要比较的两个世界说清楚，再去想怎么算。 书自己在最后一段里把这条标准也用在了自己身上—— 它承认中介分析依赖的假设「比非中介分析更英勇」。

causalR 的路线图到这里正好走完原书： W1–W6 对应第一部分与第二部分的估计量全景，W7–W10 对应第 19–21 章， W11–W16 对应第 22 章，而第 23 章是 W17 之后做机制研究时的入口。

本章的计算极其简单——中介公式只是两列边际的加权和—— 难的是那些假设。下面这段把「算」与「验」都写出来：

## 原试验：A（1 = 继续吸烟，0 = 戒烟）, M（6 个月时高血压）, Y（1 年心梗）
## 中介公式：Σ_m E[Y | A = 1, M = m] · Pr[M = m | A = 0]
mediation_formula <- function(dat) {
  pm <- prop.table(table(dat$M[dat$A == 0]))                  # Pr[M = m | A = 0]
  ey <- tapply(dat$Y[dat$A == 1], dat$M[dat$A == 1], mean)    # E[Y | A = 1, M = m]
  sum(pm * ey[names(pm)])
}

## 纯直接效应 = 中介公式 − E[Y | A = 0]；总间接效应 = E[Y | A = 1] − 中介公式
pde <- mediation_formula(dat) - mean(dat$Y[dat$A == 0])
tie <- mean(dat$Y[dat$A == 1]) - mediation_formula(dat)
pde + tie == mean(dat$Y[dat$A == 1]) - mean(dat$Y[dat$A == 0])   # 一致性：两者之和 = 总效应

## 三臂试验（新数据 dat3：arm ∈ {"quit", "regular", "nicotine_free"}）
## ① 故事对不对：第三臂的均值 vs 原试验的中介公式
with(dat3, mean(Y[arm == "nicotine_free"])) - mediation_formula(dat)

## ② 若对不上，定位是哪条假设错了
##    (ii) O 对 M 无直接效应：在 N = 0 的人里比较 O = 1 与 O = 0
with(dat3, mean(M[arm == "nicotine_free"]) - mean(M[arm == "quit"]))
##    (i) N 对 Y 无直接效应（或存在 U）：在 O = 1 且 M = m 内比较 N = 1 与 N = 0
with(dat3, tapply(Y[arm == "regular"], M[arm == "regular"], mean) -
           tapply(Y[arm == "nicotine_free"], M[arm == "nicotine_free"], mean))
